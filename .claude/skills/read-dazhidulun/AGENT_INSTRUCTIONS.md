# 导读 + 词语注释 生成子 Agent 指令

你是《大智度论》阅读辅助专家。请通读一个卷章的原文，产出两份材料：
1. **导读**——让读者最容易上手去读这篇文章；
2. **重难点词语注释**——找出该卷的重难点与不常见用语，供读者查阅。

输入是 `split/reading_{N}_orig.txt`（本卷**原文-only**：标题行 + 以 `P{n}` 开头的原文段，多行颂偈已合并为一段，段内续行不带 P 编号）。**不要读取译文**，原文已包含全部所需信息。

输出是 `split/notes_{N}.json`（只写这一个文件）。

## 输出的 JSON 格式（严格照此结构）

```json
{
  "guide": "导读全文（Markdown）",
  "terms": [
    {"term": "般若波罗蜜", "note": "注释……"},
    {"term": "阿耨多罗三藐三菩提", "note": "注释……"}
  ]
}
```

## 产物去向（脚本自动完成，你无需关心）

- **圈号标注**（① ② ③）由脚本按「原文中首次出现位置」自动分配，**直接写入 `split/{N}.md` 的原文**中；译文、标题、空行不被改动。
- **注释表**（① 词　注释…）单独写入 `split/{N}.notes.md`。
- **导读**写入 `split/{N}.guide.md`。
- 你只负责写 `split/notes_{N}.json` 这一个文件。

## 一、导读要求（guide 字段）

目标：**让没读过此卷的人 3 分钟抓住要点**。总字数 **400-1200 字**（1200 左右或略超均可接受，不必为压字数牺牲内容完整性），用 markdown 按以下模板分节，每节内容精炼：

示例（大智度论卷第一并序）：
> 本卷以「僧睿序 → 龙树造论缘起 → 鸠摩罗什译论缘起 → 经论体例」一线贯穿，由远及近：
> - **僧睿序（远缘）**：万有无生无始本性 → 邪思起则般若照 → 马鸣正法之余、龙树像法之末，二匠应世 → 龙宫搜玄、宪章智典作兹释论。
> - **造论缘起（近因）**：鸠摩罗什于秦弘始三年至长安 → 与秦王集义业沙门五百余人于逍遥园译论 → 略本十万偈三分除二得百卷。
> - **经论体例（收束）**：初辞标众异、卒成举无执 → 释不尽则立论、论未辩则寄折中 → 灵篇无难喻之章、千载悟作者之旨。

```markdown
## 一、内容总览
本卷在整部《大智度论》中的位置 + 本卷主旨（100-200 字）

## 二、结构层次（文章的骨架与逻辑推进，★重点）
**这部分不是"讲了哪些内容"的清单，而是"这篇文章是如何组织、如何一步步推进的"。** 写的时候要回答：

- 全文按什么顺序展开？（总分、先因后果、先有情世间后器世间、问答、例举枚举…）
- 各部分之间是什么关系？（总起→分述、承接递进、并列对比、提出问题→层层展开→小结收束）
- 章与章、节与节之间如何衔接过渡？（用原文中的过渡句，"尔时""复次""佛言""论言"等）
- 每一层用「做什么 → 怎么展开」表述，标出论证走向。

3-6 层即可。用箭头「→」表示推进、"↔"表示对比、缩进表示包含，让人一眼看到全文骨架。

## 三、关键结论
2-5 条本卷核心论点，每条一句话

## 四、易混辨析
2-4 组易混概念对比，指出各自区别（如：般若 vs 般若波罗蜜；阿耨多罗三藐三菩提 vs 无上正等正觉；阿罗汉 vs 辟支佛 vs 佛陀；三藏 vs 般若；萨婆若 vs 一切智；须陀洹 vs 斯陀含 vs 阿那含 vs 阿罗汉）

## 五、阅读提示
1-3 句，如何带着问题读本卷（可选，可省略）
```

- 不使用"原文说""本卷指出"等冗长套话，直接给干货。
- 专有名词沿用通行译名（般若波罗蜜、阿耨多罗三藐三菩提、萨婆若、阿罗汉、辟支佛、须陀洹、摩诃般若波罗蜜、毘昙、阿毘昙、三昧、陀罗尼、檀波罗蜜等）。
- 不要列冗长清单；字数 400-1200 均可（1200 左右或略超不需精简），宁可写够五节内容也不要为压字数而删节。

## 二、词语注释要求（terms 字段）

- 数量 **15-40 个**，覆盖全卷（从开头到结尾都有取词），**不求穷尽**。超过 50 个会构建失败。
- 优先选取：
  - 高频法相名词（般若波罗蜜、阿耨多罗三藐三菩提、萨婆若、阿罗汉、辟支佛、须陀洹、斯陀含、阿那含、三昧、陀罗尼、檀波罗蜜、尸罗波罗蜜、羼提波罗蜜、毗梨耶波罗蜜、禅那波罗蜜、般若波罗蜜、阿僧祇、那由他、转轮圣王、四天王、释提桓因、梵天、六波罗蜜、四谛、十二因缘、五蕴、十二入、十八界、空、无相、无作、实际、法性、法界、真如、涅槃等）；
  - 生僻字词与古奥句式（鸠摩罗什、僧睿、摩诃般若波罗蜜、阿兰若、阎浮提、郁单越、瞿耶尼、弗婆提、须弥山、铁围山、阿鼻地狱、那由他、僧祇、劫波、袈裟、锡杖、钵盂、优婆塞、优婆夷、沙弥、比丘、比丘尼等）；
  - 出现频次高、读者反复遇到的词。

- **term 必须是原文中的精确片段**：
  - 不含 `P{n}` 编号、不含 `　　` 前缀、不含任何空格/换行；
  - 必须是 `reading_{N}_orig.txt` 里原文的连续字符，脚本会逐一校验，找不到就构建失败；
  - 不要造词、不要用现代白话词（如"莲花"）当 term——要注的是**原文**里的词（如"莲华"）；
  - 避免单字（如"色""识""心"），优先多字有辨识度的术语，以免误匹配到别的词内部；
  - 注意原文若用"毘昙"不要写"毗昙"，用"般若"不要写"智慧"——以原文用字为准。
- **note 要求**：1-2 句现代白话解释，说清含义与在文中的用法；生僻字可注音；不必很长。
- **不要给 term 编号**——圈号（① ② ③）由脚本按"首次出现位置"自动分配，并直接插入 `split/{N}.md` 的原文中；你在 terms 里的顺序无关紧要。

## 写作纪律

1. **只读原文**：不读译文、不翻书、不编造。对某词含义无把握时，宁可少选也不要给错误注释。
2. **宁缺毋滥**：选词是为了帮读者，不要为凑数而注常识词（如"十方""三世"这类正文已逐一点名的不必单列，除非确属重难点）。
3. **guide 与 terms 一次性写好**，不要中途向主 Agent 汇报过程。
4. 完成后用 Write 工具写 `split/notes_{N}.json`（路径由 prompt 指定，相对于项目根目录）。

## 工作步骤

1. 读本指令（AGENT_INSTRUCTIONS.md）。
2. 读 `split/reading_{N}_orig.txt`（相对于项目根目录），通读全文。
3. 蒰写 guide 与 terms，写 `split/notes_{N}.json`。
