# 大智度论卷第四十一(释第七品讫第八品) 导读

## 一、内容总览
本卷涵盖《大智度论》释第七品（三假品）后半至第八品（劝学品），由经文与龙树论释交替展开，核心议题是「般若波罗蜜的假名施设」与「菩萨应当学般若波罗蜜」。经文以佛命须菩提为诸菩萨说般若波罗蜜为发端，须菩提即就「菩萨字亦但有名字」展开三相假观（名假、受假、法假），论释则层层推演至诸法实相即名字空般若波罗蜜；第八品劝学品则从正反两面收束：广劝菩萨学般若以具足六度、三昧、善根，又特辨「堕顶」「法爱」「无生法忍」之微细差别，防止行者在空三昧中退堕声闻或起顺道法爱。

## 二、结构层次（★重点）
全文按「经→论」交替推进，三大段呈递进式收束：

- **第一段·三假施设（释三假品经文 P5-P24）**：佛命须菩提说般若 → 须菩提承佛力自谦「声闻无力为菩萨说」→ 反诘「何等法名菩萨」→ 佛以般若、菩萨、菩萨字三事皆为「和合故有、不生不灭、但以名字故说」作答 → 广举我名、五众、六根、内外身、草木、过去佛、梦幻等喻，层层比况 → 收束于「名假施设、受假施设、法假施设，如是应当学」。
- **第二段·论释三假与无著观（P26-P76）**：先释「佛何故命须菩提说」四因缘 → 次辨「着心说」与「不着心说」 → 以火喻明名、义二法和合假名 → 广说三种波罗聂提（法、受、名） → 推到「破名字→破受→破法→入诸法实相」，即名字空般若波罗蜜。
- **第三段·不见诸法章经文与论释（P77-P171）**：经文广说「不见色名字常无常乃至垢净」等，复以一系列反问勘验「色是菩萨不？离色是菩萨不？色如相是菩萨不？」 → 须菩提答「毕竟不可得」→ 佛述成「当作是学」 → 次辨法性与诸法「互相不见」，离有为不得说无为 → 收于「一切法不见故不惊不畏不怖不没不悔」；论释以「三种怖畏因缘」（心心数不可得、意及意界不可得）解释须菩提三度重问之故。
- **第四段·劝学品经文与论释（P173-P195）**：须菩提广劝菩萨「欲具足六波罗蜜、欲知五蕴六情、欲断三毒十结、欲得诸三昧陀罗尼，当学般若波罗蜜」 → 论释释重说因缘（断灭疑、深妙故重说）。
- **第五段·堕顶、法爱、无生法忍（P196-P235）**：经文言「不堕菩萨顶」→ 舍利弗问「云何堕顶」→ 须菩提释为「无方便行六波罗蜜入空无相无作三昧，不入菩萨位」与「顺道法爱生」（于色空受念着）→ 论释广辨「顶」「位」「无生」「生」「熟」诸名异义同：顶是柔顺忍与无生忍中间法，增长坚固名位，即无生法忍；法爱于人天为妙、于无生法忍为累，如必死之人药反成病。
- **第六段·十八空相入与心相常净（P236-P293）**：须菩提广说「内空中不见外空」至「无法有法空」十八空相入，收于「得入菩萨位」 → 次辨「不念色乃至十八不共法」「菩提心、无等等心、大心」三心差别与「心相常净如虚空」 → 舍利弗叹须菩提「从佛口生、取法分、得无诤三昧第一」→ 收于「三乘人皆应学般若，以般若中说诸法实相即无余涅槃」。

## 三、关键结论
1. 般若波罗蜜、菩萨、菩萨字三者，皆是因缘和合假名，不生不灭、不在内外中间，行者当学「名假、受假、法假」三种施设，破名字→破受→破法，入诸法实相即「名字空般若波罗蜜」。
2. 菩萨行般若时，于色等一切法「不见常无常、垢净、生灭、内外中间」，以般若、菩萨、菩萨字「有为性无为性中亦不见」故，能不著一切法，增益六度、入菩萨位、得阿鞞跋致。
3. 法性与诸法「互相不见」，离有为不得说无为、离无为不得说有为；以一切法不可得故，菩萨「不惊不畏不怖不没不悔」。
4. 顺道法爱（于空、无相、无作、寂灭等法受念着）名为「生」，于人天为妙、于无生法忍为累；顶法增长坚固名菩萨位即无生法忍，有实相智慧火名「熟」无则名「生」。
5. 菩萨初发心名菩提心，行六波罗蜜名无等等心，入方便心名大心；心相常净如虚空，客尘烦恼覆蔽故以为不净，不应取相自高。
6. 般若波罗蜜中说诸法实相即无余涅槃，故声闻、辟支佛、菩萨三乘皆应学般若，离空解脱门则无道无涅槃。

## 四、易混辨析
- **般若波罗蜜 vs 菩萨 vs 菩萨字**：三者皆假名施设、和合故有；般若是法，菩萨是假名人，菩萨字是再施设之名，论中以「火」喻（能照能烧为义、照烧二法和合假名为火）说明名、义关系。
- **三种波罗聂提（法假、受假、名假）**：法波罗聂提约粗法从微尘和合生；受波罗聂提约名色和合取假人（如树从根茎枝叶和合）；名字波罗聂提约多名字边更生名字（如梁椽瓦和合名屋）。修行次第为先坏名字、次破受、后破法，入诸法实相。
- **顶法 vs 菩萨位 vs 无生法忍 vs 生**：「顶」是柔顺忍与无生忍中间法，垂近应得而失名「堕顶」；顶增长坚固名「菩萨位」即无生法忍；有实相智慧火名「熟」、无则名「生」；顺道法爱（于空寂灭等受念着）即「生」，与「生」相违名「菩萨熟」。
- **菩提心 vs 无等等心 vs 大心**：初发心缘无上道「我当作佛」名菩提心；与佛相似（因似果）名无等等心；入方便心、与大悲合拔一切苦、诸法实相灭一切观而不堕断灭名大心。或约六度分：檀尸为菩提心，羼提毗梨耶为无等等心，禅无量心为大心。

## 五、阅读提示
读本卷宜先抓「三假施设」一线，再看论释如何以火喻、三种波罗聂提收束到「诸法实相即名字空般若」；次注意「不见诸法」章中法性与诸法「互相不见」之逻辑，与「不惊不怖」三度重问的递进；末段「堕顶」「法爱」「十八空相入」最易混，可对照「生/熟」「顶/位/无生」三组辨析同读。
