# 大智度论卷第八十一 导读

## 一、内容总览
本卷为《大智度论》卷八十一，续释《摩诃般若波罗蜜经·六度品》（“释六度品第六十八之余”）。主旨是“以一波罗蜜为主，取余波罗蜜”：经文依次说住忍辱（羼提）、精进（毗梨耶）、禅、般若为主时如何摄取布施（檀）、持戒（尸罗）等余度；论释则回答“何以但一波罗蜜为主”、诸度如何互相生起，卷末归结于“一心中一时能具足六波罗蜜”。

## 二、结构层次
- **【经】四组问答，每组五问五答**：须菩提问“住X波罗蜜取Y波罗蜜”，佛一一作答。
  - 住羼提取檀／尸罗／毗梨耶／禅／般若 → 住毗梨耶取五度 → 住禅取五度 → 住般若取五度。
  - 每答多收束于“持是功德与一切众生共之，回向阿耨多罗三藐三菩提，不向声闻、辟支佛地”，或以“三种心不生”（无人、无法、无回向处）的三轮清净作结。
  - 住般若取禅一节最详：入诸三昧 → 八背舍 → 九次第定 → 师子奋迅三昧 → 超越三昧，层层递进，是本卷禅法之纲。
- **【论】随经释疑**：
  - 总问“何以但一波罗蜜为主” → 答“行因缘次第应尔”，分在家／出家二种菩萨各有所宜。
  - 逐段释“取尸罗”“取毗梨耶”“取禅”“取般若”，穿插问答：忍与戒之别、禅定从精进而得之辨、十四空何以不说四空、无生忍与柔顺忍深浅、超越三昧“不得超二”乃小乘法。
  - 末后广说般若所生五度，兼以忍、禅、精进摄诸度，重重互摄，以“一心中一时能具足六波罗蜜”收束。

## 三、关键结论
- 一度为主非定法：随在家出家、行因缘次第，“次第所宜故名为主”。
- 戒与忍各有其相：戒名不夺他命（身口清净），忍名自摄其心（意清净），二法可互为因果。
- 精进更无异体，即于诸度中勤行不休，“一切处虽有精进，多处受名”。
- 菩萨依八背舍、九次第定入师子奋迅、超越三昧；“不得超二、不从散心入灭尽定”是小乘法，菩萨福德智慧深故能随意超越。
- 众生忍、法忍相成不相妨；得无生法忍即是般若波罗蜜，故不见忍法、忍者、忍处三事。

## 四、易混辨析
- **羼提（忍辱）vs 尸罗（持戒）**：忍是心数法、意清净；戒兼身口，心生口说而受持。畏罪而忍与深怜众生而忍，浅深亦异。
- **柔顺忍 vs 无生法忍**：柔顺忍破五众和合假名之我，未深破法执、犹有法爱；无生法忍深入法空，众生忍、法忍至此具足。
- **众生忍 vs 法忍**：一于众生不可得处忍，一于诸法不可得处忍，互不妨碍，但以深浅为别。
- **八背舍 vs 九次第定 vs 超越三昧**：背舍是八种舍离贪著之观门；次第定依四禅、四无色、灭尽定之序顺逆出入；师子奋迅即其次第逆顺都入；超越三昧则跳跃出入、乃至散心与灭尽定互入。

## 五、阅读提示
带着“一度何以能摄余五度”的问题读：先看经文每答“事行＋回向三轮不生”的双层格式，再看论释如何以“次第因缘”“二种菩萨”“多处受名”“大小乘法异”把表面重复的经文一一配平。
