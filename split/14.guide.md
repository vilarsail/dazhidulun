# 大智度论卷第十四 导读

## 一、内容总览
本卷为《大智度论》卷第十四，承接前卷续释「尸罗波罗蜜」之余义，并开启「羼提波罗蜜」（忍辱）一品。上半卷先以毒龙舍皮护戒的本生故事立定菩萨「不惜身命、决定不悔」的持戒精神，继而层层推演持戒如何次第生起檀、羼提、毗梨耶、禅那、般若五波罗蜜，复以「罪、不罪不可得」收束尸罗波罗蜜的般若义。下半卷释「羼提」，立「生忍、法忍」二门，广说菩萨于恭敬供养、女人欲染、瞋恼恼乱三类境界中修忍，以提婆达多堕地狱、羼提仙人血化为乳、拘睒弥比丘斗诤等事例，明忍辱为成佛根本。

## 二、结构层次（★骨架与逻辑推进）
全卷以「持戒功德 → 戒生六度 → 戒相本空 → 忍辱二门 → 忍境三类」一线贯穿，由事入理、由戒入忍：

- **本生立标（P8-P13）**：毒龙受一日戒、被剥皮不悔、舍身饲虫 → 以事证立「尸罗波罗蜜」不顾身命之相 → 追释本生人物对应（龙即释迦、猎者即提婆达等六师、虫即初转法轮诸天）。
- **戒之发心差别（P14-P18）**：四种「复次」递进——为度众生作大要誓 → 为生善处起六度 → 心乐善清净非为畏恶生天 → 大悲心持戒 → 能生六波罗蜜。从「事」升到「心」「悲」「能生」。
- **戒生六度展开（P19-P64）**：戒生戒（五戒→沙弥→律仪→禅定→无漏）→ 戒生檀（财施、法施、无畏施，引转轮圣王愿）→ 戒生羼提（忍为戒杖、刀车之喻）→ 戒生毗梨耶（野干截耳尾牙之喻、射箭之喻）→ 戒生禅（曲草麻中自直、戒摄粗禅摄细、戒摄身口禅止乱心）→ 戒生般若（莲华出污泥不净、破戒贵持戒贱即非般若、利刀割土成钝）。六度如轮，戒为毂轴。
- **罪不罪不可得（P66-P100）**：问难→答以慧眼观空 → 众生不可得故杀罪不可得故戒亦不可得 → 破「五众即众生」「离五众有众生」「五众因缘生众生」三执 → 长老被枕安设之喻（除六事更无我人）→ 五阴如梦如镜像，杀空相众生无杀罪 → 不乐罪贪无罪亦是起罪因缘 → 收束「于罪不罪不可得故具足尸罗波罗蜜」。由事戒入理戒，般若贯之。
- **羼提波罗蜜释（P101-P243）**：先释名「秦言忍辱」，分生忍、法忍二种 → 生忍福德、法忍智慧，如目与足 → 生忍境三类：①恭敬供养（利养疮深破皮至髓、提婆达多为供养造三逆罪、三供养辨、罽宾三藏借衣得食之喻）②女人欲染（魔王三玉女乱菩萨、菩萨说偈呵不净、拘牟头王女与渔师之子、王女逐旃陀罗等）③瞋恼恼乱（负债偿债之喻、羼提仙人截耳鼻血化为乳、迦利王被龙神毒害、瞋为三毒之最、释提婆那民问佛「杀瞋心安隐」之偈、拘睒弥比丘分二部佛凌虚而去、金师炼金垢随火去之喻、医师治鬼狂病之喻、慈父抚幼稚之喻、骨血皮肉如累墼木人之喻）→ 历举诸佛本行皆先修生忍 → 「是名生忍」收束。全卷由「戒」之相用，转入「忍」之心行，般若空慧一脉贯穿。

## 三、关键结论
1. 尸罗波罗蜜非畏恶道、非为生天、非自求涅槃，乃为大悲度众生、为得佛道故持戒；其极处即「罪、不罪不可得」——以慧眼观空，众生、杀罪、戒三相皆不可得，是名具足尸罗波罗蜜。
2. 持戒为六度之本：戒能生戒、生檀、生羼提、生毗梨耶、生禅、生般若，六度如枝叶，戒为根干；忍为戒杖、戒为平地，二者相须。
3. 羼提波罗蜜分生忍、法忍二门：生忍得无量福德（忍于恭敬供养、忍于瞋骂打害），法忍得无量智慧；福德智慧具足方得如所愿。
4. 利养疮深，破皮至肉、断肉至骨、破骨至髓——破持戒皮、断禅定肉、破智慧骨、失微妙善心髓；提婆达多身具三十相而以贪供养故造三逆罪生入地狱，为最切近之警示。
5. 瞋为三毒之最重、九十八使中最坚、心病中第一难治；杀瞋心安隐不悔、诸佛所赞，故菩萨于恼乱中当修忍辱，观众生如赤子、如师长，知因缘和合假名为人，无实可瞋。

## 四、易混辨析
- **尸罗 vs 尸罗波罗蜜**：尸罗泛指持戒、戒律；尸罗波罗蜜特指菩萨为度众生、为得佛道所持之戒，不以畏、不以愚痴、不以自求涅槃，极处即罪不罪不可得之般若戒。
- **生忍 vs 法忍**：生忍是于「众生」境界——恭敬供养不起爱着、瞋骂打害不起瞋心，得福德；法忍是于「诸法」——观罪福业因缘、内外毕竟空、无我无我所，得智慧。生忍就境对人，法忍就境对法。
- **恭敬供养之忍 vs 瞋恼之忍**：前者对软贼（利养、名闻），易生爱着贪高，须观无常、观三供养差别以伏心；后者对硬贼（骂詈刀杖），易生瞋恚，须观因缘偿债、众生本亲、瞋灭善根以伏心。一伏爱结，一伏恚结。
- **五神通 vs 漏尽通**：提婆达多入山不久得五神通（身能变现、天食天眼等），然未断烦恼、未得漏尽；五通是世间共外道法，漏尽通唯阿罗汉、佛方得，故提婆虽具通与三十相仍堕地狱。

## 五、阅读提示
读本卷可抓「戒—忍—般若」三者相即之线索：前半戒生六度、戒相本空，后半忍分二门、瞋为最毒；持戒而不忍则戒伤人（刀车之喻），修忍而不观空则忍不成（生忍之上须法忍）。又须注意提婆达多之事在卷中两度出现（毒龙本生中为猎者、此处为贪供养造逆罪），为贯通全卷之反面教证。
