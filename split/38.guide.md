# 大智度论释往生品第四之上(卷三十八) 导读

## 一、内容总览

本卷为《大智度论》卷三十八，释「往生品第四之上」，承接前品对般若波罗蜜修习的讨论，集中解答「修般若相应之菩萨从何来、生何去」这一核心问题。全卷以舍利弗之问为线索，佛以三处来生作答（他方佛国、兜率天、人道），论主龙树再层层设问、广为分别：从二谛开合到六道取舍、从死生有无之辩到三生菩萨之方便、从菩萨种类到初发心即成佛之利钝差别。主线是「般若相应 → 往生处所 → 菩萨阶位」，贯穿着「毕竟空不废生死因果」的中观立场。

## 二、结构层次

全文按「经—论」交替、问答递进展开：

- **第一番问答（来处）**：舍利弗问修般若相应菩萨从何终来生此间 → 佛以三处答（他方佛国来者利根疾相应、兜率天一生补处者不失六波罗蜜、人道中来者根钝）→ 论主设难「般若中众生毕竟不可得，何以问来去」 → 以二谛释（世谛故说有众生，第一义谛故说无）→ 释六道中唯取兜率天之故（三恶道心钝不任、色界着禅味、阿修罗同下二天）。
- **第二番问答（去处）**：舍利弗问此间终当生何处 → 佛答从一佛国至一佛国常值诸佛，复广说三类菩萨（入禅而不随禅生者、用方便力不随禅无量四无色生者、贤劫中成佛者）→ 论主设难「般若一相无相云何有往来」 → 以「大海摄一切法」、般若不违空义答 → 广辨死生因缘之实有（以先世习、六情所知、乳毒喻、冬木喻、圣言量等证成后世），归结「毕竟空不遮生死业因缘，是故说往生」。
- **第三番问答（菩萨生身种类）**：论禅定方便不随禅生 → 生欲界大家、欲界诸天、梵天作梵王请转法轮、三生补处菩萨修梵行生佛前 → 辨「生身菩萨」与「法身菩萨」之异 → 释三生菩萨何以但生兜率天（天人敬信、色无色界不堪、兜率结使薄心软利，喻如太子斋洁受位）。
- **第四番问答（释迦本生方便）**：难释迦于迦叶佛前恶口毁呰及六年苦行是实罪否 → 以「法身菩萨变化身度生、行人法现逆化」释为方便非实 → 引《阿毗昙鞞婆沙》九十一劫不堕恶道、薄拘卢一果施僧、菩萨初生七步能行后复不能等证成方便义。
- **第五番问答（三类发心菩萨）**：菩萨得六神通游诸世界、初发心即具诸禅乃至十八不共法生有益处、初发心即得阿耨多罗三藐三菩提或行六波罗蜜入菩萨位 → 以「乘羊、乘马、神通去」之喻总收利钝三等发心，指归「先集福德、利根心坚」为成佛疾迟之因 → 末以阿弥陀佛前身法藏比丘选择净国自庄严其国作结。

## 三、关键结论

1. **二谛不违**：世谛说有众生、有死生往来，第一义谛说众生无所有、诸法毕竟空；毕竟空为破爱着邪见，非为破后世因果，故空不堕断灭、有不着常见。
2. **往生三处差别在根利钝**：他方佛国来者诸根猛利疾与般若相应，兜率天来者是一生补处不失六波罗蜜，人道中来者肉身钝根不能疾相应——差别不在法、而在宿根。
3. **三生菩萨必生兜率天**：兜率天结使薄、心软利，常为菩萨住处，且天人下生为人则人敬信，如太子将受王位先于静室斋洁。
4. **菩萨方便非实罪**：释迦于迦叶佛前恶口、六年苦行、初生能行后复不能等，皆为度众生示现，非实受罪报；不受则一实一虚，受则方便皆通。
5. **发心疾迟三等**：罪多福少如乘羊久久乃到，福多罪少如乘马必有所到，但行清净福德者乘神通发意顷到——差别在先世集福与根利钝。

## 四、易混辨析

- **世谛 vs 第一义谛**：世谛随顺凡夫见，说有众生、有死生往来、有六道；第一义谛就诸法实相，说众生无所有、毕竟空。二者不矛盾，佛为不知名字相、初习行、着者说无，为久习行、不着者说有。
- **生身菩萨 vs 法身菩萨**：生身菩萨未断结使，或离欲得五神通，以肉身随业受生（如三生菩萨、人中命终还生人者）；法身菩萨断结使得六神通，变化自在游诸佛国，不随禅生、不须大方便。
- **阿毗跋致 vs 一生补处 vs 三生补处**：阿毗跋致（不退转地）是得不退位之总称，可仍未舍肉身；一生补处是次当补佛处之最后身菩萨（如弥勒），三生补处则尚须经三生方成佛。三生菩萨在十住地犹修四禅、三三昧，示行人法。
- **毕竟空 vs 断灭空**：毕竟空为除诸法中爱着邪见而说，不遮生死业因缘、不断灭因果，故「诸法毕竟空」与「说有往生」前后不相违；断灭空则拨无后世、坏善恶业报，是邪见。

## 五、阅读提示

读本卷可带着两个问题走：第一，龙树如何在「般若一相无相」的框架内安立「死生往来」？留意他反复回到二谛与「不遮业缘」的中道立场；第二，菩萨阶位（生身/法身、阿毗跋致/一生补处/三生补处、三等发心）的判摄依据是什么——是根利钝、是集福多少、还是方便示现？把这两条线看清，全卷自能贯通。
