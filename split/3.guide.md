# 大智度论卷第三 导读

## 一、内容总览

本卷为《大智度论》第三卷，释《初品》中「住王舍城」「耆阇崛山中」「共摩诃比丘僧」「大数五千」「皆是阿罗汉」等经文，属全论开篇的「序分」释义。全卷以「释住处 → 释山 → 释共比丘僧 → 释大数 → 释阿罗汉诸德相 → 释四众数」为一线，由所住之处渐次推进到所度之人，最后收束于「何以声闻众少」之答，为下文说般若波罗蜜张本。

## 二、结构层次（★重点）

全卷以经文为纲、论释为目，逐句申解，结构如下：

- **释「住王舍城」**（P5-P58）→ 先释「住」之名相（四种身仪 → 天住/梵住/圣住 → 加佛住成四种），再释「王舍城」本起，以三传说（摩伽陀王子裂身弃野、王城中失火七易其处、婆薮仙人妄语陷地与广车王见五山希有遂作舍）层层铺陈，由「何名王舍」收束于「略说王舍城本起竟」。
- **释「耆阇崛山中」**（P59-P160）→ 释山名（鹫头之形、尸陀林鹫集）→ 问佛何以住王舍城（诸大城皆不住，独住此二城）→ 答：边国弊恶人善根未熟、知恩报生身地法身地、精舍多闲静、外道毒草处近有良药、频婆娑罗王迎请、阎浮提四方摩伽陀最胜、乞食易得三因缘、迦叶结集 → 转入「何以住耆阇崛山而非竹园余四山」：山近城难上、摩诃迦叶于此入无余待弥勒出、三世诸佛住处、摩诃衍经多在此说，由「般若为最大，今欲说故」收束，为下卷说般若铺路。
- **释「共摩诃比丘僧」**（P161-P204）→ 释「共」（七一和合）→ 释「摩诃」（大、多、胜三义）→ 释「比丘」（乞士、破烦恼、怖魔三释，引舍利弗答净目四食之喻）→ 释「僧伽」（众义，如林；四种僧：有羞、无羞、哑羊、实僧）。
- **释「大数五千分」与「皆是阿罗汉」**（P205-P217）→ 释「大数」（少过少减）、「分」（多众取一分）→ 释「阿罗汉」（贼破、应供、不生三义）。
- **释阿罗汉诸德相**（P219-P346）→ 逐经句释义：「诸漏已尽」「无复烦恼」「心得好解脱慧得好解脱」（引须跋陀梵志经显八正道独得四果）→「心调柔软」「摩诃那伽」（龙象大力之喻）→「所作已办」（多组二法对辨）→「弃担能担」「逮得己利」「尽诸有结」（三种有、九结、果中说因之喻）→「正智已得解脱」（破摩犍提眼见求净之邪）→ 论阿罗汉所作已办何以常在佛边听法、共闻般若。
- **释「唯除阿难在学地」与四众义**（P348-P415）→ 阿难何以在学地（多闻故智慧多摄心少、本愿供给、处时人未合、厌世法少）→ 阿难立名三因缘（先世瓦师发愿、父母作字欢喜日、依因缘端正令人欢喜）→ 释四众数何以比丘五千余三众各五百，终答般若甚深故声闻众少、胜者难得。

## 三、关键结论

1. 佛住王舍城耆阇崛山，非偶然：知恩报法身地、精舍多闲静、乞食易得、外道毒草处必有良药、三世诸佛住处——诸因缘汇聚，尤为说摩诃衍般若之圣地。
2. 「住」有四种：天住（施戒善心）、梵住（慈悲喜舍）、圣住（空无相无作三三昧）、佛住（首楞严等三昧十力四无畏十八不共法），佛于圣住中住、复住佛住。
3. 「比丘」三释——乞士（清净活命）、破烦恼（「比」名破「丘」名烦恼）、怖魔（剃头染衣受戒即令魔怖），三义共显出家断结、入涅槃之实。
4. 「阿罗汉」三义——贼破（破烦恼贼）、应供（漏尽受人天供养）、不生（后世更不生）；其德相以「所作已办、弃担能担、逮得己利、尽诸有结、正智解脱」次第展开，皆归于漏尽、不退、心慧二解脱。
5. 般若波罗蜜经为诸经第一，故众亦应第一大会；然声闻众少者，以经甚深难解、胜者难得、皆已得道信解故——为下文正释般若波罗蜜预设缘起。

## 四、易混辨析

- **天住 / 梵住 / 圣住 / 佛住**：天住是六欲天法（或施戒善心），梵住是色无色界乃至非有想非无想天法（或慈悲喜舍四无量心），圣住是空无相无作三三昧（佛辟支罗汉所住），佛住是首楞严等无量三昧及十力四无畏十八不共法等诸佛功德——前三是共世间及三乘所共，佛住独佛所有。
- **心解脱 / 慧解脱**：外道一处一道心得解脱而非于一切障法得解脱，不名「好解脱」；阿罗汉以见谛道、思惟道二道心得解脱，复以无明离故属见结使离得慧解脱。爱能系心故说心解脱（属爱烦恼断），无明覆慧故说慧解脱（属见烦恼断）。
- **学人 / 数法人 / 阿罗汉**：学人是有为生法、欲灭有为，未离欲；数法人以智慧得无生法；阿罗汉所作已办、逮得己利、尽诸有结，更不求进。阿难虽多闻第一，以本愿供给佛、处时人未合，故在学地须陀洹，不入阿罗汉数。
- **九十六种外道 / 八正道**：外道法皆空，无道无果无沙门无婆罗门；唯佛八正道中具四沙门果。须跋陀百二十岁得五神通，闻佛说「我法中有八正道，是中有第一至第四道果」，方得阿罗汉道而先佛取灭度。
