# 大智度论卷第八 导读

## 一、内容总览
本卷接续初品「放光释论」第14之余，紧承上文身相放光，集中阐释佛在《大品般若》法会上所示现的四种神变——常光、广长舌相、师子游戏三昧动地、众生获益。前三卷已说身微笑与毛孔光，本卷由身光转入口业（舌相说法）与意业（三昧动地），层层递进，直至一切众生皆得等心、修十善、得好慧，归于涅槃之门。全卷以「经—论」交替的问答体展开，是理解般若法会为何必以神变庄严的关键文本。

## 二、结构层次（★重点）
全文依「四种神变」之次第展开，自外及内、自身及众：

- **常光遍照**（P5-P23）→ 释「常光」为何一丈 → 五浊众生钝根不堪多光 → 见常光欢喜即至阿耨多罗三藐三菩提。论式：问何以复放常光 → 答常光即三十二相之丈光相 → 喻如国王以常食之余赐群下。
- **广长舌相说法**（P25-P119）→ 出舌覆面为小信，覆三千界为般若大事 → 举老女人施食得辟支佛之本事为证 → 舌根放光化千叶宝华、华上化佛说六波罗蜜 → 释莲华坐之由来（劫初韦纽脐中莲华生梵王）→ 释般若与六波罗蜜一法无异、庄严与未庄严之别 → 三障（三恶道、人中老病、无色无想天）解释何未尽度。
- **师子游戏三昧动地**（P121-P165）→ 释三昧名义（师子搏鹿戏乐、佛人师子）→ 六种震动（东涌西没等三相六相）→ 动地因缘（八因八缘、火龙金翅鸟天王四种、小动大动）→ 般若授记故地神大喜。
- **地柔软与众获益**（P167-P360）→ 地柔软令心和悦（喻三十三天欢乐园与粗涩园）→ 三恶八难即得解脱生天 → 释五道四生（卵湿化胎）→ 生盲聋哑狂乱裸形饥渴病患形残各释先世今世业因 → 举祇洹奴犍抵节节解身蒙光平复本事。
- **等心十善归涅槃门**（P361-P444）→ 释等心非禅中等乃无怨无恚 → 十善业道（身三口四意三）→ 净修梵行断淫 → 惔然快乐譬如比丘入第三禅（释三禅乐最上、意识相应乐根满足）→ 好慧持戒自守不娆众生即戒身定身慧身所摄、向涅槃门。

## 三、关键结论
1. 般若波罗蜜与六波罗蜜一法无异：五波罗蜜不得般若则不名波罗蜜，与般若合方至佛道。
2. 佛神变非为炫异，皆为度生：常光为喜舌相为证、动地为柔软、获益为生信，一一对应众生根机。
3. 因果业报各各不同：值佛世犹饥渴者，以见佛因缘与饮食因缘各异，如持戒不布施之阿罗汉与布施不持戒之白象。
4. 三禅之乐为三界中最胜乐，故以「譬如比丘入第三禅」喻欲界众生等心修善之乐。
5. 好慧持戒自守不娆众生，摄戒、定、慧三身，是向涅槃门之正行。

## 四、易混辨析
- **常光 vs 神通光**：常光者佛身四边各一丈之光明，三十二相之一，菩萨生便有；神通身光则无量，可满三千大千世界。五浊众生钝根不堪多光，故释迦但受一丈。
- **覆面舌相 vs 覆三千界舌相**：前者为小信、为破婆罗门疑妄语而现；后者为般若大事兴故、为一切大会而现，须借佛神力方令皆见。
- **化佛 vs 化主**：外道声闻变化不能作化、灭后不能留化；佛以无量三昧力，化佛一时皆语、化复作化、灭后犹能留化如佛无异。
- **狂 vs 乱**：狂者失心，或先世破他坐禅、或风热病、或恶鬼所著；乱者不狂而心多散乱志如猕猴。裸形狂中别有恶邪自裸一种，外道灰涂裸形即属此类。

## 五、阅读提示
读本卷宜紧抓「佛为何以神变庄严般若法会」一线：每一种光、动、益皆是应机施设，层层由外境（光、舌、地）引入内心（柔软、等心、慧、戒），最终收束于「向涅槃门」。本事繁多，可随文标注每个喻事对应何种业因、何种根机，则全卷条理自明。
