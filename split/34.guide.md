# 大智度论卷第三十四 导读

## 一、内容总览

本卷为《大智度论》卷三十四，承接卷三十三「见一切佛世界义第五十一之余」，并开启「信持无三毒义第五十二」。主旨是：菩萨欲成就诸佛功德、满一切本愿，当学般若波罗蜜。全卷以一连串「菩萨愿」为骨架——愿见三世佛、愿放光照闇处、愿令三宝名遍闻、愿疗众生诸苦、愿度三恶道、愿得佛身光威仪、愿出家日即成道转法轮、愿法不灭、愿闻名者得道——逐条展开「为何发愿、何以能成、般若何故为母」三层论证，最后收束于「般若为诸佛母，余五波罗蜜离之不名波罗蜜」。

## 二、结构层次

全文按「经—论」逐段推进，可分四大板块：

- **信持三世佛法 → 见佛闻法**：先释「三世诸佛法皆可闻持」，因菩萨有「观三世诸佛三昧」与陀罗尼力故能见过去未来佛（P10-P24）。
- **光明普照 → 疗病济苦 → 度三恶道**：菩萨身光从兜率降神、初生、成道、转法轮、涅槃时皆照幽冥；身光由身业清净、慈心、念佛三昧、火一切入等业缘得（P28-P49）。进而愿令盲聋狂裸饥渴者皆如愿、三恶道众生皆得人身，释「菩萨恩力」（非菩萨业力令得，乃以神通变化说法力发起众生自修善业）及「但令得人身」之故——人中能修大功德、天上着乐不修道（P58-P86）。
- **佛身威仪 → 出家日成道 → 寿命光明无量**：详述佛四威仪（象王视、足离地四指、诸天侍送、天衣敷座、地变金刚），辨声闻经敷草与摩诃衍经天衣之异——生身佛把草、法性生身佛以天衣为座（P100-P167）。次明出家日即成道、转法轮，无量阿僧祇众生远尘离垢得法眼净、漏尽解脱、不退转；并以释迦苦行六年、然灯成佛不说法、大通十小劫成道等为对破，释菩萨「闻诸佛力等」而发愿之由（P171-P192）。寿光一段举过去七佛寿量对比，论「诸佛寿命实皆无量，为度人故现有长短」，以日出影水、火烧草木为喻（P207-P238）。
- **无三毒名 → 法不灭尽 → 闻名得道 → 般若为母收束**：愿国无三毒及三毒名，辨世间正见为无漏根本，三毒有邪正二种（P246-P268）；愿法无灭尽，论诸法实相不生不灭（P272-P284）；愿闻名者得道，举如意珠、喜见药、转轮王、释提桓因、梵天、观世音为况，以熟痈、熟果、新净白㲲喻福德淳熟者闻即得度（P288-P348）。末段总答「何以众行和合独赞般若」：般若为诸佛母，般舟三昧为父；五波罗蜜离般若则不名波罗蜜，如盲无眼、坏瓶盛水、鸟无两翼——胶合众彩乃成画，般若合五度乃成佛道（P350-P364）。

## 三、关键结论

1. 菩萨一切本愿——见佛、放光、济苦、度恶道、成道、转法轮、寿光无量、法不灭、闻名得度——皆由般若波罗蜜而成，般若为诸佛母，余五波罗蜜离之即失波罗蜜之名。
2. 诸佛寿命、光明实皆无量，现有长短者为度人故随众生福德优劣；释迦文佛生恶世故寿短，非佛功德有异。
3. 「闻名得道」非以名便得，乃闻名为得道因缘，福德淳熟、结使薄者闻即得度，如熟痈遇缘自溃。
4. 法性生身佛与随众生现身佛不同：前者无事不济、闻名即度；后者随业因缘有不尽度者，故有提婆达等堕地狱事。

## 四、易混辨析

- **生身佛 vs 法性生身佛**：生身佛（如释迦于树下敷草）为随众生所见之应化身；法性生身佛以天衣为座、身光常照，无事不济，闻名即得度。声闻经多说生身，摩诃衍经兼说法性生身。
- **诸佛力等 vs 诸佛发愿不同**：诸佛神力功德平等无异，菩萨未闻此理故作差别愿（苦行、即成道、不说法等皆佛本行不同），非佛功德有高下。
- **世间正见 vs 无漏智慧**：世间正见（信布施、罪福、今世后世、阿罗汉）是有漏法，但是无漏智慧根本；得此正见方能善施戒定梵行。不可混作无漏慧。
- **邪三毒 vs 正三毒**：贪瞋痴各有「邪」与「非邪」二种，邪三毒（邪贪、邪瞋、邪见愚痴）众生难度，余三易度；「国无三毒名」实指无邪三毒之名。

## 五、阅读提示

带着两个问题读：其一，菩萨既发愿度尽众生，何以众生实不尽度、法实有灭？——留意「愿事不必实」与「为众生故现」的反复出现。其二，全卷每段都结以「当学般若波罗蜜」，末段才总答其故——读时可将各愿累积，末段一并印证「般若为母」之喻。
