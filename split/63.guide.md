# 大智度论卷第六十三 导读

## 一、内容总览
本卷含两品：「信谤品第四十一之余」承接前卷，明毁谤深般若的重罪与破法四因缘，并借「不缚不解」「因净果净」显般若甚深；「叹净品第四十二」由舍利弗、须菩提与佛往复问答，以「毕竟净故」层层赞叹般若清净——诸法本自清净、空即清净、不二不别。全卷归于一句：般若毕竟净，谤者得无量罪，信解者得佛道。

## 二、结构层次
全文两品一贯，围绕「谤般若之罪 ↔ 净般若之深」正反两面推进：

1. **连锁破（经）**：毁呰般若 → 破十方诸佛一切智 → 破三宝 → 破世间正见 → 破四念处乃至一切种智 → 无量阿僧祇罪苦；随问随答，佛出破法四因缘：为魔所使 → 不信深法 → 随恶知识坚着五众 → 瞋恚自高。
2. **释因缘（论）**：意业为口业之本 → 声闻各执五部「决定相」，闻毕竟空「如刀伤心」 → 以四魔（五众、烦恼、死、自在天子魔）解「魔所使」，举阿难三不答佛为例。
3. **转深（经→论）**：问般若云何难信难解 → 佛答色乃至一切种智「不缚不解」（无所有性，本际、后际、现在皆然）→ 论明缚解俱空、三毒与三解脱门俱虚诳 → 「净故果净」珠串式展开：三毒净、无明净故十二因缘展转净，直至般若、诸度、一切种智净，「不二不别」→ 空即清净、有为净故无为净、三世皆空。
4. **判罪福（论）**：破般若二种——谤「非佛说」者堕大地狱 ↔ 着心论议者不名破 → 调达、祇域出佛身血与破像二喻，判罪福由心不由行 → 邪见如苦种，虽持戒精进皆成恶法 → 阿阇世王蒙佛与文殊师利除罪受记，明信解能转重罪。
5. **叹净（经）**：舍利弗九番设问——净甚深、净明、不相续、无垢、无得无著、无生、不生三界、无知、净净——佛皆答「毕竟净故」→ 再显般若于萨婆若无益无损、于诸法无所受。
6. **释净（论+须菩提问答）**：智净与缘净相待，实相本自清净，清净有无量名字（如、法性、实际……毕竟空）→ 净明、不相续、得着等逐问配释 → 「我净故色净」：有为说「无所有」、无为说「自相空」，不二清净方是真清净，毕竟空即毕竟净 → 般若无定相，以道种智分别说 → 方便力知「色不知色」，十三空故「无所碍」。

## 三、关键结论
1. 毁呰深般若即破十方诸佛一切智，连锁破三宝与正见，得无量无边阿僧祇罪。
2. 破法四因缘：为魔所使、不信深法、随恶知识坚着五众、瞋恚自高轻人。
3. 诸法不缚不解、因净果净、不二不别——「空」即是「毕竟清净」，有为净故无为净，三世皆空。
4. 罪福由心：谤经卷堕大地狱，着心论议不名破般若；邪见虽持戒精进亦成恶法，信解则重罪可除。
5. 般若毕竟净，故于萨婆若无益无损；毕竟空但为破着心，非是实空，菩萨以方便力故无所碍。

## 四、易混辨析
- **「无所有」vs「自相空」**：我与五众、六度等有为作法虚妄可破，说「无所有」；须陀洹果乃至佛道是无为法，无生灭邪行，只说「自相空」。
- **「得」vs「着」**：见道十五心（或生柔顺忍）名「得」，第十六心沙门果（或无生法忍入菩萨位）名「着」；「着」是「着不堕落」，仍是「得」之别名，真清净中俱不可得，故「无得无著」。
- **二法清净 vs 不二法清净**：前者于净中分别垢净，是「名字清净」；后者无垢无净，是「真清净」。
- **毕竟空 vs 毕竟净**：同实异名，「以人畏空，故言清净」。

## 五、阅读提示
抓住两条线索读：一是「心异则罪福异」（调达/祇域喻），判破般若之罪轻重；二是「空即毕竟清净」，会通全卷一切「X净故Y净」，最后落到毕竟空但为破着、菩萨方便力无所碍。
