# 大智度论卷第八十五 导读

## 一、内容总览

本卷为《大智度论》第八十五卷，含三品：〈道树品〉第七十一、〈菩萨行品〉第七十二、〈种善根品〉第七十三，逐品解释《摩诃般若波罗蜜经》对应经文。全卷主旨：菩萨不见众生可得，仍为众生求阿耨多罗三藐三菩提；此行以「如」与「无所有」（毕竟空）为体，以方便力为用，最后归于供养诸佛、种善根、亲近善知识三事。

## 二、结构层次

三品皆「经文立义 → 论释广解」，论中又以「问曰／答曰」层层推进。

**〈道树品〉：从「虚空种树」之叹到「无所有般若」**
- 须菩提叹甚难：不得众生而为众生求菩提，如于虚空种树 → 佛以种树为喻作答：叶益（离三恶道）、华益（生刹利大姓乃至非有想非无想天）、果益（三乘圣果、入无余涅槃）。
- 「菩萨如佛」之辨：以「如」故说如来、辟支佛乃至色与无为性，诸如无异 → 菩萨学是如，得一切种智，故说如佛 → 递进链：学一切法如 → 于如得自在 → 善知众生根与业因缘 → 愿智具足 → 净三世慧 → 饶益众生 → 净佛国土 → 一切种智 → 转法轮。
- 一切种智无法：无法缘，念为增上、寂灭为行、无相为相；诸法和合生故无自性，故一切法无性 → 问：既一切法无性，凭什么行六波罗蜜？→ 答：知诸法无性而能行、能度，正是方便力。
- 须菩提难「离法不能知离法」→ 佛答：以世谛说若有若无，非以第一义；世谛如即第一义谛如。

**〈菩萨行品〉：菩萨行与佛、菩提的名义**
- 何等是菩萨行：为阿耨多罗三藐三菩提行，于色乃至有为无为性行空而「不作二」。
- 何义名佛：知实义、得实相、通达实义、如实知一切法，四义递进 → 何义名菩提：空、如、法性、实际之义；论中广列诸师异说。
- 行般若于诸法无得无失、无增无减 → 不以二法行；行不二法故善根增益，凡夫依二法故不得。
- 不为善根故行般若 → 收束于三事：供养诸佛、种善根、得真知识，由闻持十二部经得陀罗尼。

**〈种善根品〉：三事何以难得**
- 不供养诸佛、不种善根、不得真知识，能否得萨婆若 → 佛答：三事具足尚难得，何况不具 → 何以难得？离方便力 → 依六度分述，皆「应萨婆若念」「观一切法自相空」「不受世间果报」→ 于羼提处点出「无生法忍」。

## 三、关键结论

- 菩萨与佛同以「如」为体，学如般若即学一切法如，故说菩萨「如佛」，非以我心贵之。
- 诸法和合生故无自性，即是无法、无所有；知无所有而能集功德、度众生，即是方便力。
- 世谛如即第一义谛如，二谛不异；故可借世谛为众生说若有若无。
- 凡夫依二法不得增益善根；菩萨行不二法，从初发意乃至后心善根增益，无有错谬。
- 供养诸佛、种善根、亲近善知识，加以般若方便，方得一切种智。

## 四、易混辨析

- **般若波罗蜜 vs 菩萨行**：般若偏指遍知诸法实相的智慧，菩萨行泛指一切菩萨道；论云二者共相摄无异，只是名字异。
- **一切种智 vs 萨婆若 vs 阿耨多罗三藐三菩提**：论明言三者（连同「佛法」「佛道」）皆是一切种智的异名。
- **佛 vs 阿罗汉、辟支佛、大菩萨**：同知诸法实义，但前三果烦恼未尽故不能通达；阿罗汉、辟支佛、大菩萨烦恼虽尽而未得一切种智，亦不能通达，故不名佛。
- **尽智 vs 无生智**：尽智知「生已永尽」，无生智更知「不复更生」；论中诸师或取一智、或合二智以释菩提。
- **世谛 vs 第一义谛**：体不异，异在众生知与不知；故无二谛相违之过。

## 五、阅读提示

带着一个张力读：既然一切法无所有，为何还要种善根、度众生？本卷的回答——正因无所有，才能不受果报、纯为众生而修；「观一切法自相空，无生，无定相，无所转」一句贯穿种善根品六度，可视为全卷眼目。
