# 大智度论卷第八十三 导读

## 一、内容总览
本卷含两品：前半〈释大方便品第六十九之余〉承接卷八十二末「如、法性、实际、不合不散」四门之问——须菩提以为此门甚深，唯利根菩萨能入；佛则明言钝根、中根、散心菩萨「一心学」皆得入，并广赞行般若之功德，收束前卷「善知」诸法之列。后半〈释三惠品第七十〉以「云何行、生、修般若」三问展开，层层逼向「不行是名行般若」「一切法不可说」「无所得平等」的甚深行相，是全论发挥般若无所得义的著名篇章。

## 二、结构层次
**前半（大方便品之余）**：
- 问答开合：须菩提谓利根乃入 → 佛答「钝根、中根、散心」一心学者皆入，唯懈怠乱心不能入 → 论以热时清凉池为喻，配八圣道（正精进、正念、正定，「如」等四门为正见）和合能入。
- 功德赞叹：行般若则魔事欲起即灭 → 十方诸佛忆念，三世诸佛皆从般若中生 → 故应常不离萨婆若念 → 乃至弹指顷、一劫百劫之福，胜教三千大千世界乃至恒河沙众生得四果辟支佛道。
- 「善知」长列收束（承前卷）：字门／非字门 → 世、涅槃二法 → 一语多语男女语 → 色识、四缘、四谛、五道、四果三乘 → 十种慧 → 三世、方便、待众生、深心、义语 → 论随难释（钝斧喻利慧、如意宝喻宝慧、鸯崛魔罗例深心、四无碍辩分别三乘）。

**后半（三惠品）**：
- 三问三答：观色寂灭、空、虚诳、不坚实故「行」；如虚空生故「生」；观诸法破坏故「修」 → 论释三义（干慧地行、无生忍生、禅定熏修），并明破五众通达令空即是涅槃寂灭相。
- 时限与用心：从初发意乃至坐道场常行 → 常念萨婆若、不令余念得入 → 「心、心数法不行」 → 论展开本卷核心论难：与无想定、灭尽定、无余涅槃的「心不行」何异？不可依《阿毗昙》小乘义难《摩诃衍》；涅槃无相无缘，故非「所缘」。
- 四句遮破：修／不修／修不修／非修非不修得萨婆若否？佛皆答「不」 → 得萨婆若「如如相」→ 如实际 → 如法性 → 如我、众生、寿命性，归到我不可得、一切法不可说但有假名。
- 无所得收束：学一切法不增不减 → 不生不灭 → 不起不作行业（无作、无相二解脱门）→ 观诸法自相空 → 「不行，是名行般若波罗蜜」 → 有所得（二、相待）与无所得平等 → 从一地至一地不住有所得 → 终以「无所为、无所作」结经。

## 三、关键结论
- 般若之门无碍：入不入不在利钝，而在精进摄心、一心求学。
- 三世诸佛皆从般若生，故行般若虽弹指顷，福已胜过教人布施持戒、得四果辟支佛道。
- 行般若的相貌是「心、心数法不行」——非灭心之定，而是离一切戏论、无相可取。
- 得萨婆若「如如相」：如、实际、法性一体异观，我、众生、寿命皆不可得，一切法不可说、但有假名。
- 二（相待）是有所得即世间；不二平等是无所得即毕竟空；因无所得破有所得，事办之后无所得亦舍。

## 四、易混辨析
- **行／生／修般若**：行＝观色等寂灭虚诳而趣入；生＝「如虚空生」，无自性可生；修＝观诸法破坏，以禅定熏习令熟。
- **般若「心不行」与无想定、灭尽定、无余涅槃**：前者慧离戏论而无相可取；后者是外道灭想、小乘取证灭心，属《阿毗昙》义，不可难大乘。
- **如、实际、法性**：一体异观——如是诸法体性（见谛、学道中观），实际是行者心取证，法性是诸法本生处（无学道定心作证而通达）。
- **有所得与无所得**：眼色相待为「二」是有所得；「不从有所得中无所得，不从无所得中无所得」，二俱平等观才是真无所得。

## 五、阅读提示
带着「什么才是真正的般若行」去读：留意「不行是名行」「无所为、无所作」等遮诠句式，并看龙树如何一次次挡住「取相」之问、如何以「不应以阿毗昙难摩诃衍」为大乘辩护。
