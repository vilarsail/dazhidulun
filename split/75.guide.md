# 大智度论卷第七十五 导读

## 一、内容总览

本卷为《大智度论》卷七十五，含三品：〈灯喻品〉之余（第五十七品后半）、〈梦中入三昧品〉第五十八、〈恒伽提婆品〉第五十九。前半以「燃灯燋炷」答须菩提「初心、后心得菩提」之问，并标出菩萨十地；中品辨梦中修行、梦业因缘与实相回向；后品借一女人受记作佛，示范「净佛世界、成就众生」的愿行。全卷一贯主旨：得道不离因缘而不可执取，般若行要在无所得而方便不坏。

## 二、结构层次

- **灯喻品之余**：须菩提发难（初心不至后心、后心不在初心，心心数法不俱，善根云何增益？）→ 佛以燃灯燋炷作譬（非初焰燋炷、非离初焰；非后焰燋炷、非离后焰）→ 法合：不用初心、不离初心，不用后心、不离后心而得菩提 → 佛点出「从初发意行般若，具足十地」→ 论释逐一解十地（干慧地至佛地，每地分声闻、菩萨两重名义）→ 佛反覆勘验心念（心灭更生不？生是灭相不？如如住当作实际不？）→ 须菩提以「无处所行」「第一义中行」应之 → 收于「不取相亦不坏相，住自相空，入三三昧成就众生」→ 论释空、无相、无作对治众生作愿、我相、诸相，兼明利钝根次第。
- **梦中入三昧品**：舍利弗问梦中入三三昧有益于般若否 → 须菩提以「昼、夜梦中等无异」双遣有益无益二边 → 追问梦中所作业有「集成」否 → 立义「有缘业思生，无缘不生」（缘即见、闻、觉、知）→ 再问梦中六度回向是实回向否 → 须菩提转推弥勒，弥勒以「不见能答者、不见授记处」之空作答，且「如我所说法，如是不证」→ 佛还问舍利弗「用是法得阿罗汉，见是法不」，类通菩萨得无生忍、受记而不作见、不生疑。
- **净佛世界之愿**（经文后半）：佛广说菩萨行六波罗蜜时，见众生饥寒、杀生、瞋害、懈怠、五盖、愚痴，及三聚、三恶道、国土粗恶、四姓、六道、四生等过患，一一发愿令未来佛土无如是事 → 末以「生死边如虚空，众生性边亦如虚空，是中实无生死往来、亦无解脱者」消解久劫度生的疲厌。
- **恒伽提婆品**：女人散华供养、回向无上道 → 佛微笑放光，授记其劫名星宿、佛号金花，当生阿閦佛国转女身 → 论释其发心因缘（然灯佛所种善根）及女人五碍、转女身诸难。

## 三、关键结论

1. 得无上道「非初心亦不离初心，非后心亦不离后心」——灯焰燋炷之喻显心念相续因缘，不堕断常二见。
2. 十地具足方成佛道；同一十地，声闻与菩萨名义各别（如见地在声闻是须陀洹果，在菩萨即阿鞞跋致）。
3. 菩萨以方便力不取有相、不取无相，行于中道；住自相空起三三昧教化众生，利根闻空兼得无相无作，钝根须次第开示。
4. 昼梦等无异：业从取相因缘生，无缘故业与思不生；弥勒知涅槃亦空、无所得故不证不答。
5. 受记之后菩萨唯余净佛世界、成就众生二事；生死与众生皆如虚空，实无往来者，故不应生疲厌。

## 四、易混辨析

- **初心 vs 后心**：初心是发心之始，后心是功成之念；孤取任何一端皆堕一边，二者以因缘相续而成果，如灯焰非初非后而炷燋。
- **如 vs 实际**：「如」是一切法实相，遍一切法而无分别；「实际即是涅槃」，是如之究竟边际。心可「如如住」而不即作实际，因实际无相、心是忆想分别之法。
- **空、无相、无作三三昧**：空破我我所，无相破一切取相，无作舍诸作愿；三者俱是度生方便，钝根人闻空易转取「空相」，故须次第补说无相、无作。
- **受记 vs 证**：受记是佛悬记当来成佛，证是自心实证涅槃；弥勒「如我所说法，如是不证」——知涅槃相而不取证，正显菩萨不住实际、不共二乘。

## 五、阅读提示

可带着三个问题读：灯喻如何同时遮破「初心得」与「离初心得」两边；梦中业与觉时业的分际何在；女人五碍与女人受记何以不相妨碍。
