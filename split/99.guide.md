# 大智度论卷第九十九 导读

## 一、内容总览

本卷为《大智度论》卷九十九，释经〈昙无竭品〉后半，属全书末尾“萨陀波仑（常啼菩萨）求般若”的叙事高潮。萨陀波仑历经卖身、割肉出血等考验，于众香城得见昙无竭菩萨；昙无竭为说“诸佛无所从来、去亦无所至”，以阳焰、幻事、梦、海中宝、箜篌声等譬喻破对佛来去相的执着；论主复以二谛与“五种求”抉择佛身义，并逐段解释七岁入定、立待不卧、刺血洒地、魔蔽水、帝释献花等情节。

## 二、结构层次

全文“经—论”双线推进，经立譬、论抉择：

- **经·说法（初段）**：先立宗“诸佛无所从来，去亦无所至” → 历数无生法、实际、空、寂灭、虚空性“即是佛”，如一无二无分别 → 继设阳焰、幻事、梦三问三答，斥分别佛有来去为愚夫 → 正说海宝、箜篌二喻：佛身从众缘和合而生，缘离则灭，来无所从、去无所至 → 收束：“应如是知诸佛来相去相”，知一切法无来去，必得菩提。
- **经·叙事（中段）**：帝释献花赞叹 → 萨陀波仑与长者女、五百侍女以身车供养，昙无竭受已还与 → 昙无竭七岁一心入定，萨陀波仑经行住立不坐卧 → 恶魔蔽水令洒地不得，菩萨自刺其身出血洒地 → 帝释复献三千石天华敷地 → 昙无竭出定说法，萨陀波仑欢喜“譬如比丘入第三禅”。
- **论·抉择佛身（后段之一）**：答“何等是诸法如”（实相、性空）→ 设难“若无佛岂非邪见，云何发心求佛” → 以二谛总答：世谛故说佛说般若，第一义故说佛空无来去 → 五种推求（五众即佛、离五众有佛、五众在佛中、佛在五众中、佛有五众）逐破，结归“离有无二边，处中道，诸法实相即是佛”。
- **论·释譬叙事（后段之二）**：释海宝喻（懈怠不得、大心乃得）与箜篌喻（佛身从六波罗蜜及方便力众缘生、不即不离）→ 依次答帝释与花、以身布施、受已还与、说法入宫、七岁立待诸疑 → 释魔蔽水与刺血洒地 → 释三昧自期出定（犍捶比丘之喻）→ 末以三禅乐释见师之喜，收束全卷。

## 三、关键结论

1. 诸佛不可以色身见；法身即诸法如，一如无分别，无来无去。
2. 佛身如箜篌声，从无量功德众缘和合而生，非一因一缘生，亦非无因缘有。
3. 言“无佛”为破着佛想，非取无佛见；离有无二边处中道，诸法实相即是佛，得实相名为得佛。
4. 供养贤圣乃至为法舍身，福果无尽，故真佛弟子“不虚妄食人信施”。
5. 爱法不惜身命、大欲大精进，是过去诸佛求般若的共同道路。

## 四、易混辨析

- **法身 vs 色身**：法身是真佛，即诸法实相，无来无去；色身为世谛故有，从本业因缘果报生，必归无常磨灭。
- **世谛 vs 第一义谛**：世谛故说有佛、有来去；第一义故说佛空、无来无去。执佛有来去是常见，闻无佛便取无是断灭，偏执任何一边皆堕邪见。
- **一切智 vs 一切种智**：论中“一切智”泛指佛菩提（未得一切智故名“近”）；“一切种智”唯佛独具，遍知诸法总相别相。
- **须陀洹、斯陀含、阿那含、阿罗汉、辟支佛**：声闻四果次第——预流、一往来、不还、无学；辟支佛出无佛世独自悟道。同“得诸法实相”而有浅深差别，皆名真佛弟子，所应受供养亦层层递升。

## 五、阅读提示

带着两个问题读：佛身既从众缘生，何以说“无来无去”？说“无佛”何以不是断灭见？先随经文譬喻走，再对照论主的二谛分析与五种求，可见“破来去执而不坏佛”的论法。
