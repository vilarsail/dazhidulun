# 大智度论卷第七十八 导读

## 一、内容总览
本卷收《大智度论》释经两段：释《愿乐品》第六十四与释《称扬品》第六十五，属《摩诃般若波罗蜜经》的般若深观段落。前半以帝释（释提桓因）赞叹发心菩萨、问随喜福德为线索，引出「随喜回向」与「毕竟离、无分别」的甚深义；后半称扬品借舍利弗与须菩提问答，显菩萨「知众生毕竟空而度众生」的大誓庄严，结以诸天作礼、十方佛念、魔不能留难，「当知是菩萨为如佛」。

## 二、结构层次
- **愿乐品·经**：帝释叹行六度菩萨出一切众生之上，胜过未发心者 → 散华发愿「自既自度，亦当度未度者」，终不令菩萨退堕二乘 → 问四阶菩萨（初发意／久发意／阿鞞跋致／一生补处）随喜福德几许 → 佛以四天下可称斤两、三千大千世界可称斤两、分发渧海可知滴数三重递进譬喻答「不可称量」 → 随喜已当回向菩提，以「不一不二相」故，福德「非心非离心」
- **须菩提设难**：「是心如幻，云何能得阿耨多罗三藐三菩提？」→ 佛反显：若般若非毕竟离则不名般若，正以毕竟离故能得菩提，「亦不以离得离」
- **舍利弗设难**：一切法无分别，云何有六道与须陀洹乃至佛道？→ 答：众生颠倒故造业受六道身，圣贤亦「无分别故有」→ 当行无分别般若
- **论释**：发心菩萨胜一切众生（转轮圣王太子在胎、歌罗频伽鸟在壳、沙弥三转衣钵三喻）→ 「小乘人言」与「摩诃衍论言」判为二边，离二边名中道 → 释「以离得离」（以指触虚空喻）→ 以世谛／第一义谛会通佛说「难」与须菩提说「不难」
- **称扬品·经**：问行般若为行真实法、无真实法？→ 答行「无真实法」，般若空无定相 → 菩萨大誓庄严：知众生毕竟不可得而度之，「如欲度虚空」「与虚空共斗」→ 闻一切法离相心不惊不没者，帝释至净居诸天作礼、十方诸佛所念、恒河沙魔不能留难，「当知是菩萨为如佛」

## 三、关键结论
1. 随喜回向福德不可称量，且所随喜的菩萨阶位愈近佛道，随喜福德转多；不随喜者从魔中来生。
2. 般若波罗蜜毕竟离，正因毕竟离才名般若、才由之得菩提；虽不离般若得菩提，亦不以离得离。
3. 一切法无分别：六道由众生颠倒作业而有，四果圣贤与佛道亦依毕竟空无分别而立。
4. 菩萨真难事不在空理难证，而在「知众生毕竟不可得而誓度之」——为无所有众生结誓，如欲与虚空共斗。
5. 能行深法而不证实际、心不惊不没不怖不畏者，诸天作礼、诸佛护念、众魔不坏，「当知是菩萨为如佛」。

## 四、易混辨析
- **随喜 vs 回向**：随喜是见他功德心生欢喜，回向是将其福德趣向菩提；一得一导相续而起，故说「不一不二」。
- **毕竟离 vs 断灭空**：毕竟离是离一切相、了不可得，非落入无；若非毕竟离反不名般若波罗蜜。
- **佛说「难」 vs 须菩提说「不难」**：佛依世谛说难以劝发怯者，须菩提依第一义谛说无难以止退废者，二说不相违。
- **小乘人言 vs 摩诃衍论言**：一执「得律仪小沙弥尚胜补处菩萨」，一执「发大乘心必胜二乘解脱」，论主判为二边，离二边名中道。

## 五、阅读提示
带着「一切法毕竟空，凭什么修行有成、度生有果」的问题去读：本卷的回答是——正因毕竟离故能得，正因无分别故行无分别般若、得无分别菩提；众生虽空，誓愿不废。
