# 大智度论卷第十六 导读

## 一、内容总览
本卷为《大智度论》卷第十六，释初品中「毗梨耶波罗蜜义第二十七」，专论「精进波罗蜜」。全卷以问答为骨、以本生故事与地狱苦相为肉、以实相观照为髓，层层推演菩萨精进之所以独名「波罗蜜」者。其要在二：一者界定「精进」与「精进波罗蜜」之别——世间、声闻、辟支佛之勤但名精进，唯菩萨为佛道、为众生、以实相为首而不休不息者方名波罗蜜；二者明「身精进」与「心精进」之分——从初发心至得无生忍名身精进，得法性身后乃至成佛名心精进，粗细、内外、福慧各有其相。

## 二、结构层次（文章的骨架与逻辑推进，★重点）
全卷按「释相→明义→举苦兴悲→本生示范→辨般若→归实相」六层推进，以问答相扣、因果相承：

- **释精进相** → 先以五事（于事必能、起发无难、志意坚强、心无疲惓、所作究竟）立相，复以释迦本生为贾客主五体着鬼而不息之心喻菩萨心不休息；再以阿毗昙心数法摄之，分判五根、五力、七觉、八正、四念处、四正勤、四如意足、六度中精进之异名。
- **明波罗蜜义** → 设三问三答：何精进？何独菩萨精进名波罗蜜？何云「满足」？——层层逼出「到彼岸」之所以然：无大慈大悲、不求十力四无畏十八不共法者，勤而不至彼岸；菩萨以大悲为首、实相智慧为首，不休不息，方名波罗蜜。
- **观苦兴悲** → 菩萨得天眼观众生轮转五道——天死人生、地狱饿鬼畜生互为出入，复历举八大地狱（活、黑绳、合会、叫唤、大叫唤、热、大热、阿鼻）及十六小地狱（八炎火、八寒冰）之苦毒宿业，以「见苦→生悲→发愿勤修六度」收束，引出「当以佛道涅槃常乐益于一切」。
- **本生示范身精进** → 举三喻：梵摩达王猎群鹿、鹿王代死而感王断肉（慈悲精进）；爱法梵志剥皮为纸、以血书偈（求法精进）；雉鸟渍羽灭火、以死为期（弘誓精进）。皆明「难为能为、不惜身命」之身精进相。
- **辨心精进无厌与世俗般若** → 答穿井之喻，明「至佛无厌、诲人不惓」；复举太子识破不食五谷梵志之伪，辨世俗般若（求满智、寝慈悲）与出世间般若（于施戒心不染着）之别，示菩萨行般若时不废精进。
- **归实相平等** → 菩萨观一切法不生不灭、非一非异，知有为虚诳、精进邪伪，以平等法中无所求索，而常成就不退——「虽知精进虚妄，而常成就不退，是名菩萨真实精进」；引然灯佛所授无生法忍为证，身平等故心平等，心平等故一切法平等，是为真实精进波罗蜜。

## 三、关键结论
1. 精进名波罗蜜，唯在菩萨为佛道利益众生、以大悲实相为首而不休不息；余人勤修但名精进，不名波罗蜜。
2. 身精进粗、为福德、从身力出；心精进细、为智慧、得无生忍后舍肉身得法性身方究竟；二者贯菩萨始至终。
3. 菩萨观众生五道轮转、地狱苦毒，以大悲兴精进——非自求涅槃，乃为度众生集诸功德。
4. 真实精进者，知一切作法虚妄、诸法平等，于平等中无所求而常不退；以无生法忍为极，身平等故心平等，心平等故一切法平等。

## 四、易混辨析
- **精进 vs 精进波罗蜜**：精进通世间、声闻、辟支佛，是心数法勤行不住；波罗蜜（此云到彼岸）唯菩萨具足——以大悲为首、为佛道、不求自利涅槃，方能到彼岸。
- **身精进 vs 心精进**：身精进从身力出，行布施持戒、受诸勤苦，粗、为福德、生身未舍时；心精进内自专精，修忍辱禅定智慧，细、为智慧、得法性身后方究竟。生身菩萨行六度为身，法性身菩萨行六度为心。
- **世俗般若 vs 出世间般若**：世俗般若求满智而寝慈悲，如太子破梵志之伪、不畏人瞋；出世间般若于施者受者财物、罪不罪、瞋不瞋皆不可得，心不染着。菩萨或时行此、或时行彼，皆不废精进。
- **八炎火地狱 vs 八寒冰地狱**：八炎火以炭坑、沸屎、烧林、剑林、刀道、铁刺林、咸河、铜橛为名，因烧炙苦；八寒冰以頞浮陀、尼罗浮陀、阿罗罗、阿婆婆、睺睺、沤波罗、波头摩、摩诃波头摩为名，前二约孔罅有无、中三约寒战呼声、后三约冰色似莲华，皆因冻裂苦。

## 五、阅读提示
读此卷可紧握「相—义—喻—实相」四阶：先以五事与阿毗昙心数法把握精进之相，再以三问三答锁定波罗蜜独属菩萨之因，继而于地狱苦与本生故事中体会菩萨大悲所起之勤，终归诸法平等、精进虚妄而常不退之真实精进。问答处多暂停自反，本生喻处宜对照前文「相」义，方见龙树以事明理之妙。
