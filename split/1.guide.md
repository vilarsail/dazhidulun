# 大智度论卷第一并序 导读

## 一、内容总览

本卷为《大智度论》开篇第一卷并序，含僧睿所撰《摩诃般若波罗蜜经释论序》与龙树造论本体的开首合订。三段式结构：僧睿序（远缘→译缘→体例）→ 释论正文「初序品中缘起义释论第一」（广答佛说般若经因缘）→ 经首「如是我闻一时」五字释。本卷主旨：阐明佛说《摩诃般若波罗蜜经》的种种因缘（发起众疑、对治邪见、显诸法实相），并解经首六字义，为后续百卷释论立根。

## 二、结构层次（文章的骨架与逻辑推进）

**僧睿序（远缘 → 译缘 → 体例）**
- 万有本于生生而性本无生 → 邪思起则般若照 → 二乘颠沛于三藏、杂学曝鳞于龙门
  → 马鸣起正法之余、龙树生像法之末 → 龙宫搜玄、宪章智典作兹释论 → 开夷路、辩实相
  → 鸠摩罗什弘始三年自姑臧至长安 → 秦王集义业沙门五百余人于逍遥园译论 → 十万偈三分除二得百卷
  → 经论体例：初辞标众异以尽美、卒成举无执以尽善；释不尽则立论、论未辩则寄折中

**释论正文：礼佛偈 → 问 → 广答因缘**
- 礼佛偈（稽首三宝 → 归敬舍利弗须菩提 → 愿说大智彼岸实相义）
- 问：佛以何因缘说《摩诃般若波罗蜜经》？（譬如须弥山王不以小因缘动）
- 答：广列十二种因缘，层层展开——
  - 为弥勒广说菩萨行 → 为念佛三昧人增益 → 菩萨降魔成道、梵天释提桓因请转法轮 → 断「佛不得一切智」之疑 → 破恶邪人谤「佛以幻术惑世」 → 令人信受法、令众生欢喜 → 大医王治结使病 → 示佛身不可思议 → 拔二边入中道 → 分别生身法身 → 说阿鞞跋致相 → 当来供养般若因缘 → **说第一义悉檀**（最系统，统摄四悉檀）→ 度长爪梵志等大论师 → 说诸法实相 → 明无诤处 → 异门说四念处五众等

**四悉檀一节（本卷义理高潮）**
- 世界悉檀（因缘和合假有，如车如人）↔ 第一义悉檀（离言绝虑，诸法实相）
- 各各为人悉檀（随人心行，于一事或听或不听）↔ 对治悉檀（对治烦恼病：不净治贪、慈心治瞋、因缘治痴）
- 四悉檀各各有实不相违；第一义悉檀通三悉檀所不通

**经首「如是我闻一时」释**
- 「如是」=信清净，能入佛法大海 → 「我」=随世俗说我，非第一义实我 → 「闻」=多因缘和合故闻，无一法能闻 → 「一」=破一异二门，随俗假名 → 「时」=破时实有，说三摩耶除邪见

## 三、关键结论

1. 佛说般若经因缘无量，略举若干：为弥勒说菩萨行、增益念佛三昧、降魔成道、断众生疑、破恶邪、示佛身无量、拔二边入中道、说第一义悉檀、度长爪梵志、说诸法实相、明无诤处、异门说三十七道品。
2. 四悉檀统摄十二部经八万四千法藏，各各有实而不相违；第一义悉檀为究竟——「过一切语言道，心行处灭，遍无所依，不示诸法」。
3. 佛法大海，信为能入，智为能度；经首「如是我闻一时」五字各随世俗假名，非第一义实有。
4. 「我」「一时」「三摩耶」等皆世界悉檀故有，第一义悉檀故无；破立双行，随俗无诤。

## 四、易混辨析

- **般若 vs 般若波罗蜜 vs 摩诃般若波罗蜜**：般若是智慧，般若波罗蜜是到彼岸之智，摩诃般若波罗蜜加「大」字——本论所释之经名，亦本论「大智度」之「大智」所指。
- **四悉檀**：世界悉檀（因缘和合假有，如车辕轴辐辋和合、人五众和合）；各各为人悉檀（随听者心行，于一事或听或不听，如为断见人说杂受、为我见人说无受者）；对治悉檀（对治烦恼病，如不净治贪、慈心治瞋、因缘治痴）；第一义悉檀（离言绝虑，诸法实相，过一切语言道）。
- **生身 vs 法身**：生身是佛随顺世间所示现的肉身（降生、出家、苦行、降魔、成道等示现）；法身是佛以功德智慧所成、过诸世间不可思议之身。
- **迦罗 vs 三摩耶**：皆天竺「时」之两名；佛避「以时为因」的邪见（如《时经》「时来众生熟」），于通经多说三摩耶（假名时），少说迦罗（实时）；唯毗尼中说「时食」「非时食」仍用迦罗，以白衣不闻、不生邪见。
- **犊子阿毗昙 vs 说一切有道人 vs 方广道人**：犊子执「五众不离人，人是第五不可说法藏所摄」（五众外别有人）；说一切有执「十八界十二入五众实有，而此中无人」（如兔角龟毛常无）；方广道人执「一切法不生不灭，空无所有」（拨无世俗有）。

## 五、阅读提示

本卷为全书纲领，建议先抓「僧睿序—造论因缘—经首六字」三段骨架，再细读「四悉檀」一节（P37-P100）与「长爪梵志」因缘（P101-P108）——前者是本卷义理高潮，后者是大论议师归佛的典范。
