# 大智度论卷第八十六 导读

## 一、内容总览

本卷为《大智度论》卷八十六，含〈释遍学品第七十四〉与〈释次第学品第七十五〉，对应《摩诃般若波罗蜜经》〈遍学品〉〈次第学品〉。两大议题贯穿全卷：其一，菩萨“行深般若而不受果报”，理由是菩萨安住诸法无所有性、离一切戏论；其二，菩萨遍学声闻、辟支佛诸道而不堕二乘，以道种智入菩萨位。前半以“无所有性、无戏论”破一切取相，后半以“有法是菩萨道，无法是菩萨果”立修道次第，是龙树般若学“空而不断、行而无著”的代表作。

## 二、结构层次

**【经】遍学品**按问答层层推进：
- 总起：须菩提叹菩萨行深法而“不受果报” → 佛印可：“于无所有性中不动” → 四句勘验（无所有得所有？所有得所有？所有得无所有？无所有得无所有？四句皆不）→ 佛示正答：“非所有、非无所有，无诸戏论，是名得道”。
- 遮戏论：由观色常无常、苦乐、我无我 → 四谛应见断证修 → 三十七品、三解脱门 → 四果 → 十地 → “我当净佛国土、成就众生、得一切种智”，凡取相计著皆判为戏论 → 收束：“法性无，即是不可戏论”，应行无戏论般若。
- 遍学问答：问以何道入菩萨位 → 答：不以三乘道，“遍学诸道”而入，举八人先遍学诸道后入正位为喻 → 须菩提难：诸道各异，遍学岂不成八人、辟支佛？→ 佛：从初发意以智观过干慧地至辟支佛八地，“直过”而不证果；二乘若智若断皆是菩萨无生法忍。
- 道种智与圣法：释道种净智——知诸法相貌、解一切音声如响、知六道因果、开善道遮恶道 → 须菩提难：助道法一相无相，云何能取菩提？→ 佛：诸法自相空无取无舍，“以世俗法故为众生说，非以第一义” → 释圣法义（一切法不合不散、一相无相）→ 修般若即“修诸法坏”“不念有法” → 结归“二者是有法，不二者是无法”，取相即二、适有便有生死。

**【论】释**随经逐段：释四句皆过、破常无常二边 → 八人喻（“如人亲亲系狱，入而看之，亦不与同着杻械”）→ 释智断（学人八智、上下分十结）→ 四谛一谛 → 无生忍三义与“真无生”（语言道断）→ 梵音说法、十善十恶上中下 → 知见四句 → 着法者无解脱无道无涅槃 → 顶堕与忍位。

**【经】次第学品**：无法相者当得顺忍否 → 佛：“无有法相、非法相，即是菩萨顺忍”，“有法是菩萨道，无法是菩萨果” → 佛自述本行：离五欲五盖入四禅、起五神通、不受禅味、一念相应慧成佛、分别三聚众生 → 论释重问缘由（般若无一定相故）、道果诸解、二禅“定生”喜乐、自性他性辨、四禅得解脱、六神通得自在。

## 三、关键结论

1. 得道不在“所有／无所有”四句中，离一切戏论，“非所有、非无所有”方是得道。
2. 一切法无所有性故不可戏论；“有佛无佛，诸法一相，性常住”，菩萨不学相、亦不学无相。
3. 菩萨不以声闻、辟支佛、佛道入菩萨位，而是遍学诸道、观过八地直过，以道种智入位。
4. 二乘若智若断皆是菩萨无生法忍；声闻以四谛得道，菩萨以一谛入道。
5. 有法念者即是着法，着法则无解脱、无道、无涅槃；“无有法相、非法相”即是顺忍，有法是道、无法是果。
6. 佛以四禅于诸烦恼得解脱，以六神通于诸法得自在度众生——正因诸法无所有性，才成得自在之因。

## 四、易混辨析

- **戏论 vs 正观**：戏论非指思辨本身，而是对诸法取相计著两端（常无常、我无我），乃至执“我当修某法、证某果”；取相即是二，不取相而行方为般若。
- **道种智 vs 一切种智**：道种智知一切道差别与众生根缘，是菩萨位之智；一切种智唯佛具足，入位之后断烦恼习而得。
- **柔顺忍 vs 顺忍 vs 无生法忍**：柔顺忍是得无生忍前随顺法性的阶段；顺忍是趣向见谛之忍（大小乘各有）；无生法忍入菩萨位——论举三义，“真无生”则谓“从本已来常自无生，非以智慧观故令无生”。
- **有法 vs 无法**：非存有与否之谓。一说有为八圣道为道、无为为果；一说五度是有法（道）、般若毕竟空是果；一说般若有为是道、如法性实际常是果——本卷归趣：“一切相皆是二”，取相为有法，不二为无法。

## 五、阅读提示

带着一问去读：若一切法无所有，修行为何不是断灭？本卷答——正因无所有，方有顺忍、道与果；著“有”反成不修。读“遍学”处留意“直过”与“不受果报”的呼应，读“修坏”处留意“不念有法”才是真修。
