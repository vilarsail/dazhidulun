# 大智度论卷第七十 导读

## 一、内容总览

本卷为《大智度论》卷第七十，论释《摩诃般若波罗蜜经》〈佛母品第四十八〉之余义与〈问相品第四十九〉。“佛母”点出主眼：般若波罗蜜能生诸佛、能示世间相。前半由“佛如实知众生心行出、没、屈、申”切入，历数外道依五蕴妄计的六十二邪见，归结于“诸法如皆是一如”；后半天子问“何等是深般若波罗蜜相”，佛答以空、无相、无作乃至虚空相，末以大事、不可思议、不可称、无量、无等等五事赞叹般若，法会大众闻法得道。

## 二、结构层次

全卷三段经文各配论释，经立其义、论广其破：

- **佛知出没屈申（经）** → 依色受想行识列四类邪见：神与世间常无常四句 ↔ 世间边无边四句 ↔ 身神一异 ↔ 死后如去四句 → 收于“佛知五众如”：六波罗蜜如 → 三十七品、十八空、九次第定…… → 一切种智如 → 四果、辟支佛、阿耨多罗三藐三菩提如即是诸佛如，“皆是一如相，不二不别” → 般若能生诸佛、佛名如来。
- **论释出没屈申** → 清池观鱼喻总观六道 → 逐门破外道：神常无常与“细神”调和说、世性（僧佉）、微尘、自然、天主等邪因、身神一异、如去四句 → 断语：外道种种分别“皆缘五众”，佛但知五众空、无相、无作 → 能信者三：阿鞞跋致菩萨、具足正见人（三果“三道人”）、漏尽阿罗汉。
- **问相品（经→论）** → 天子问深般若相 → 佛答空相、无相、无作乃至虚空相，并自明“以世谛故说，非第一义” → 论释“相不能破相、相不能知相”，能所俱空，天人阿修罗不能破坏 → “有佛、无佛，相性常住”，佛得如实相性故名如来 → 佛得一切法无相故成无碍智，反而善分别诸法各各别相（恼坏相是色相等）。
- **佛母再申（经→论）** → 般若是诸佛母，佛自供养恭敬 → 须菩提以“一切法无知者无见者，云何能生诸佛”诘难 → 佛答“不缘色生识”即“不见色”，不见色故示世间相 → 般若示世间空、离、寂灭、毕竟空乃至“独空” → 离断常二边：虽空而说罪福，虽说罪福不堕常见。
- **五事赞叹（经→论）** → 大事（救一切众生，不舍一切众生）→ 不可思议、不可称、无量、无等等（佛法、如来法、自然人法、一切智人法，如虚空不可思量）→ 比丘、比丘尼漏尽得果，优婆塞、优婆夷法眼生，二十菩萨得无生法忍、贤劫中受记。

## 三、关键结论

- 一切邪见皆缘五众而起；佛破“于世间起常颠倒”，不破世间——如教无目人识蛇非璎珞。
- 诸法如“不二不别”：从六波罗蜜到佛果、善法与不善法、有为与无为，如相一味平等；佛得此如，故名如来、一切智人。
- 深般若相即空、无相、无作乃至虚空相；佛为众生“用世间法故说”，是世谛非第一义。
- 相不能破相、相不能知相：能知所知俱毕竟空，故一切世间天、人、阿修罗不能破坏。
- 般若虽毕竟空而中道圆具：离断常二边、为众生说罪福；能生诸佛、救一切众生，故为大事乃至无等等事而起。

## 四、易混辨析

- **出、没、屈、申**：出＝离世间（出家求道），没＝为爱欲烦恼所没还堕世间，屈＝不离欲界，申＝离欲界上进。
- **空、无相、无作**：三解脱门，三乘共有。空＝无我我所（配“离”），无相＝离男女等外相乃至无一切法相（配“寂灭”），无作＝不复愿着后世身（配“苦”之无所愿求）。
- **独空 vs 十八空**：十八空皆因缘相待而立（如内空因内法得名）；独空无因无待，如虚空、如、法性、实际、涅槃。
- **佛法、如来法、自然人法、一切智人法**：觉（于无明睡眠中最初觉）、从如道来（如过去诸佛之道而来）、不从他闻（自觉自成）、遍知一切（辟支佛自然得而无一切智）——四名层层显佛德。

## 五、阅读提示

带着两个问题读：外道也讲常无常、有边无边，佛破的究竟是什么、不破的是什么？般若既“毕竟空、无知者无见者”，为何又说它能生诸佛、示世间相、教人罪福？本卷正是这一空有不二中道的示范。
