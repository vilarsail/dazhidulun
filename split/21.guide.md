# 大智度论卷第二十一 导读

## 一、内容总览

本卷处于《大智度论》释初品中段，承接前卷对禅定功德的讨论，依次释三组与禅观紧密相关的法门：八背舍（第三十四）、九相（第三十五）、八念（第三十六之一）。三者构成一条「由禅定枝末功德 → 不净对治 → 恐怖中对治」的修行辅线：先列出背舍色身的禅定阶次，再以九相作离欲利器，最后以八念对治行人于阿兰若处所起之恐怖。菩萨行此三法而以大悲心、一切法空观驾驭，故不堕二乘疾入涅槃。

## 二、结构层次

全文按「三义分段、问答应机」推进，三段之间以「次第相因」衔接：

- **八背舍义（P4-P115）**：先列八背舍名相 → 分释初二背舍（内有色外观色 / 内无色外观色）→ 净背舍身作证（不净中净观）→ 四无色定及灭受想定 → 引入八胜处（背舍的进阶）→ 十一切处（胜处的广大）→ 九次第定（心心相续）→ 末以「有漏无漏、禅地所摄」收束分类。
  - 关键过渡句：「是三事一义，转变有三名」（背舍→胜处→一切处，同一禅观的三阶名）、「八背舍、八胜处、十一切处、九次第定，声闻法中略说」。
- **九相义（P116-P194）**：【经】列九相名 → 【论】问答「先禅后九相」之次第 → 详述胀、坏、血涂、脓烂、青瘀、啖、散、骨、烧九相观想 → 对辨九相与十想之异（缚贼 vs 斩杀、初学 vs 成就、外门 vs 内门）→ 九相破七种染着 → 九相性、所缘、所摄 → 菩萨行九相不堕二乘证。
  - 关键过渡句：「九相为因，十想为果」「二为甘露门：一者不净门，二者安那般那门」。
- **八念义之一（P195-P293）**：【经】列八念 → 【论】释九相后次第说八念之由（阿兰若处恐怖）→ 详释初念「念佛」：先释如来十号（多陀阿伽度、阿罗呵、三藐三佛陀等）→ 次释佛身相好、戒定慧解脱解脱知见五众具足。
  - 关键过渡句：「佛弟子于阿兰若处……善修九相……自随懎然惊怖……以是故，佛次第为说八念」。

三层呈「枝末禅相 → 对治利器 → 障难防护」递进：背舍是禅定枝末功德，九相是离欲的入手利器，八念则是行人修不净观后遭遇恐怖时的对治依怙。

## 三、关键结论

1. 八背舍、八胜处、十一切处是同一禅观从浅至深的三阶名——背舍是初行、胜处是中行、一切处是久行；九次第定则统摄前八背舍等，心心相次，无余心间杂。
2. 九相（胀、坏、血涂、脓烂、青、啖、散、骨、烧）以不净观对治淫欲为最胜，破众生对色、形容、威仪、语言、细滑、人相之七种染着；与十想为因果——九相为因、十想为果，九相为外门、十想为内门，二门合称甘露门。
3. 八念（念佛、念法、念僧、念戒、念舍、念天、念入出息、念死）专为行人在阿兰若、冢间修九相而起恐怖者设，念佛居首以佛九种名号与五众功德为所缘。
4. 菩萨行九相、八念而以大悲心与一切法空观为度，不堕二乘疾取涅槃——以「因缘和合生无自性、皆归空相」故不于不净中没，以「未具足一切佛法」故不早入涅槃。

## 四、易混辨析

- **八背舍 vs 八胜处 vs 十一切处**：同一禅观三阶。背舍是「背弃净洁五欲、离着心」之初阶；胜处是「于净观中能胜烦恼贼、能少能多多能少」之中阶；一切处是「遍满十方虚空、普缘一切」之广阶。
- **九相 vs 十想**：九相是「缚贼」——遮伏未得禅定者之淫欲，为外门、为初学、为因；十想是「斩杀」——已能除灭淫欲等三毒，为内门、为成就、为果。十想中不净想摄九相。
- **不净观之净背舍 vs 颠倒净见**：净背舍是「于实青色广大净相」中调心、不取着，非颠倒；世俗以女色不净妄见为净，是颠倒。前者为久习不净心厌故习净观，后者为痴使所覆。
- **无色定 vs 无色背舍**：凡夫所得是无色定，圣人深心一向不回方名背舍。背舍重在不回、不著、能究竟背弃。

## 五、阅读提示

读本卷可带着两个问题：（1）从背舍到胜处到一切处，禅师心量如何由「少」到「多」到「遍满」一层层打开？（2）菩萨与声闻同修九相、八念，何以菩萨不堕二乘证——其差别究竟在「观」还是在「愿」？留意文中「以大慈悲心」「一切法相空」两处转折。
