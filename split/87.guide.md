# 大智度论卷第八十七 导读

## 一、内容总览
本卷为《大智度论》卷八十七，由〈释次第学品第七十五〉之余与〈释一心具万行品第七十六〉两品组成，各含经文与论释。全卷围绕一个总问题展开：既然「诸法无所有性」（一切法毕竟空、不可得），菩萨为什么还要发心、修行、度众生？前品给出下手处——新学菩萨须次第行、次第学、次第道，先修六波罗蜜与六念；后品给出究竟处——正以无所得故求菩提，无所得即是道、即是果、即是阿耨多罗三藐三菩提，一念中能具足万行。

## 二、结构层次
**〈次第学品〉之余**
- 须菩提问：新学菩萨于诸法无所有性中，云何次第行、次第学、次第道 → 佛先明「得无所有故是佛、乃至须陀洹」，一切贤圣皆以得无所有立名 → 由此激劝发心：「我何以不发心？得菩提已，令众生从有相住无所有中」
- → 新发意菩萨应学六波罗蜜：檀、尸罗、羼提、毗梨耶、禅、般若。每一度都以「自行、教人行、赞叹功德、欢喜赞叹」四法展开，递进为「过声闻辟支佛地 → 入菩萨位 → 净佛国土 → 成就众生 → 得一切种智 → 转法轮 → 三乘度生」，末了皆收归「是皆不可得，自性无所有」
- → 次修六念（念佛、法、僧、戒、舍、天），一一以「无所念是为念佛（法、僧、戒、舍、天）」的遮诠方式说
- → 须菩提设难「无所有则无道、无智、无果」 ↔ 佛反问「汝见色性实有不？」 → 须菩提自陈：为当来比丘闻空而取空相、破戒破净命堕三恶道故问
- →【论】层层解释：未得实相皆名新学；「小儿服药须蜜乃下」喻深空可与布施持戒和合；毕竟空「无所障碍，何妨发心」；次第行／学／道的多种判分；布施先施何人的两说；六念易行，如苦药以蜜下之

**〈一心具万行品〉**
- 须菩提问：诸法无所有，菩萨见何利益求菩提 → 佛答「正以无所有空故能发心」，有得有著者难可解脱 → 立「无所得即是道、即是果」 → 须菩提连环追问：云何有十地、无生忍、报得神通？云何一念中具足六波罗蜜乃至八十随形好？
- → 佛答：行般若波罗蜜不二相，以无漏心、无相心行布施乃至智慧，「不见谁施谁受、所施何物」；回向时亦观回向者、回向处不可得，是名正回向 → 于无相无得无作中次第具足尸罗（起四禅得五神通）、羼提（众生忍＋无生法忍）、毗梨耶（身精进＋心精进）、禅（八背舍、九次第定，过干慧地等入菩萨位）、般若（不见诸法定实相、一切法皆不受）
- →【论】释问者以着心问、答者以无著心答；法性不可坏、邪行假名坏（如虚空不能染污）；「一念」即得无生法忍、住无漏心；得无生忍菩萨舍寂灭乐入生死度生，比生身菩萨割身更难

## 三、关键结论
1. 一切有为作法无毫末实有，佛与四果贤圣皆以「得无所有」而有名。
2. 毕竟空无所有「无所障碍」，不碍发心修行；次第行如缘梯自初桄渐上，先易后难、先粗后细。
3. 无所得即是道、即是果、即是阿耨多罗三藐三菩提；有所得、有著者无道无果，难可解脱。
4. 与般若波罗蜜和合（不二相、无漏心），则一念中具足六波罗蜜乃至八十随形好；远离般若则须渐渐次第行。
5. 恶人闻空「取空相」而废戒破见，反堕三恶道——故空须次第学，六念等柔软易行之法正是初门。

## 四、易混辨析
- **次第行 vs 次第学 vs 次第道**：一说义一名异、无有差别；一说初中后为序；一说行＝檀与毗梨耶、学＝尸罗与禅、道＝羼提与般若；又一说八正道中正语业命为「行」、正精进念定为「学」、正见思惟为「道」。
- **五众 vs 五蕴**：本卷「五众」指戒、定、慧、解脱、解脱知见众（五分法身），论中一一配当六波罗蜜，不是色受想行识。
- **无所得 vs 断灭空**：无所得是「不得布施而行布施」的不取相行，非拨无因果；闻空便言「谁垢谁净」者正是着空的误解。
- **道种智 vs 一切种智**：道种智是菩萨知种种道法差别、应机教化的智；一切种智是佛圆知诸法总别相的究竟智。
- **生身菩萨 vs 得无生法忍菩萨**：前者贪惜未除、以身布施犹有所悕望；后者如化人行施无苦，但舍寂灭乐、入众生中受种种身，才是真正的难行。

## 五、阅读提示
带着一问读：既然无所有，凭什么修行？再看论主两面拆解——空不碍行（缘梯喻、蜜药喻），行不碍空（每段末「是皆不可得」）。两品问答体例相同，前品说「渐」，后品说「顿」（一念具万行），可对照读。
