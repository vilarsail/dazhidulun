# 大智度论卷第五十九 导读

## 一、内容总览
本卷为《大智度论》卷五十九，释「校量舍利品第三十七」。整卷以释提桓因（帝释）与佛、舍利弗、阿难之间的问答为线索，反复以「满阎浮提（乃至三千大千世界、恒河沙等世界）佛舍利」对「一卷般若波罗蜜经卷」校量功德，结论一致：般若波罗蜜胜。理由是舍利由般若熏修故得供养，般若为诸佛及一切功德根本。论文部分又以「无价摩尼宝珠」为喻，从总相、别相两层广明般若功德远胜宝珠；最后佛自说「我所得法即般若波罗蜜，自供养依止」，将般若推为三世诸佛与一切众生的大利益因缘。

## 二、结构层次
全卷以「经—论」交替、校量层层增广的方式推进：

- **舍利对经卷（初校）** → 佛问帝释：满阎浮提舍利与般若经卷二分取何 → 帝释取般若，自说因缘「舍利从般若生、般若熏修故得供养」。
- **般若无二相（深一层）** → 舍利弗难「般若无相不可取」 → 帝释顺答「般若不行二法，不与诸佛法不舍凡人法」 → 佛赞印「法性、实际、不可思议性与般若无二无别」。
- **帝释自喻与广益** → 帝释以己身喻佛、坐处喻般若经卷 → 受持般若者不堕三恶道、不堕二乘、世世见佛 → 校量境由阎浮提扩至三千大千世界，理由「见般若即见佛」。
- **三事示现与十二部经（第二段经）** → 佛住三事示现说十二部经，与受持般若等无异 → 供养十方恒河沙佛与供养般若经卷福等 → 以「负债人依王」喻舍利依般若得供养 → 复以「无价摩尼宝珠」喻般若，广列宝珠治热冷杂病、明闇、解毒、愈眼痛癞疮、令水随色、浊水令清等功德。
- **论释宝珠喻（别相差别）** → 论主先释宝珠由来（龙脑、帝释金刚、佛舍利、福德自然） → 次以总相、别相两层比较：宝珠但治身病、般若治身心病；宝珠但破一处热、般若一吹灭劫尽大火；宝珠治肉眼、般若治慧眼；宝珠不能转人心、般若能转一切众生所欲 → 收束「般若是如意宝珠，函箧是舍利」。
- **有为无为法相与般若为首（第三段经论）** → 佛说有为法相（十八空、三十七品、十八不共法等智慧）、无为法相（无生无灭诸法自性）皆般若所摄 → 三世诸佛及弟子皆因般若得三乘道 → 般若性无所有不可得 → 菩萨尽行六波罗蜜，般若为明导，如阎浮提诸树荫无差别 → 般若为大、一切、无量、无边、无等功德成就。
- **书写与他胜于自供养（收束）** → 帝释问自书供养与书与他人何福多 → 佛反问自供养舍利与分他令供养孰胜 → 帝释答分他福多，佛即印可「书般若与他令学福甚多，于众中广解其义者胜前，当视如佛、如次佛」 → 佛自说成道时思念「我所得法即般若波罗蜜，自供养依止」 → 劝一切求三乘者皆应供养般若。

## 三、关键结论
1. 般若波罗蜜是诸佛之母：诸佛、三十二相、十力四无所畏四无碍智十八不共法、大慈大悲、五波罗蜜、一切种智，皆从般若波罗蜜中生，故供养般若即等同供养三世诸佛与佛舍利。
2. 赜若波罗蜜无二无相：不为取不舍、不增不减、不与佛法不舍凡夫法，性无所有不可得；以世谛故说三乘，第一义中无所得。
3. 舍利得供养全由般若熏修：如负债人依王、如函箧因珠而有威德，舍利本身因般若熏修故得天人供养，故二分中取般若即兼得舍利之利。
4. 书写般若与他令学、广解其义，胜于自供养：以无吾我、大悲心、作佛道因缘故；佛自入金刚三昧碎身作舍利令人供养，亦为利生，何况以般若经卷化他。
5. 般若为六度明导，万行归一：如阿那婆达多池四河俱失本名入海一味，又如阎浮提诸树形色虽异荫无差别；般若和合五度则功德具足、义味调适，独行般若则如愚人纯食盐失味致患。

## 四、易混辨析
- **般若波罗蜜 vs 五波罗蜜（檀、尸罗、羼提、毗梨耶、禅）**：般若是前五度的明导，能令五度具足波罗蜜名字并到萨婆若；五度离般若则有种种差别，入般若中则一相无别。佛呵「但行般若不行五法」如纯食盐，须和合方功德具足。
- **有为法相 vs 无为法相**：有为相是十八空、三十七品、十八不共法等作相（先无今有、已有还无）；无为相是诸法自性无生无灭、无垢无净；二法皆般若所摄，有为是行处、无为是依止处。
- **阿鞞跋致 vs 阿罗汉/辟支佛**：阿鞞跋致是菩萨不退转位，受持般若者正住此地，不堕二乘地，终当得无上菩提；阿罗汉、辟支佛是声闻、缘觉极果，亦由般若中学得，但止于三乘之一，未穷般若究竟。
- **如意宝珠 vs 般若波罗蜜**：宝珠但能满在家人今世富乐、治身病、却外毒；般若能满出家求道人三乘解脱乐、治身心病、破魔天与无始来病，且能转一切众生心性所欲——宝珠有所不能，般若尽能。

## 五、阅读提示
读本卷可扣住一条主线「校量层层增广」与一个核心喻「摩尼宝珠」：注意校量境从阎浮提→三千大千世界→恒河沙等世界的递进，以及经文与论文之间「经立喻—论解喻」的对应；读宝珠别相一段时，可逐条对照「珠能…般若亦能…珠不能…般若能…」，体会般若功德如何在每一譬喻中被推至究竟。
