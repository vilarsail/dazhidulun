# 大智度论卷第四十九 导读

## 一、内容总览

本卷为《大智度论》卷四十九，释「发趣品第二十」之上半。承前卷须菩提问「摩诃衍」之后，更问「云何菩萨摩诃萨大乘发趣」——即菩萨如何从一地至一地、渐次升进。佛先以经文列十地「治地业」（初地十事、二地八法、三地五法、四地不舍十法、五地远离十二法、六地具足六法远离六法、七地二十不着二十具足、八地两番各五法、九地十二法、十地「当知如佛」），随即须菩提逐条请问，佛一一作答；论主龙树再逐条释义。全卷以「地」为骨，以「不取相而修治」为髓，阐明菩萨大乘发趣的阶次与心行。

## 二、结构层次

全卷由「经·列十地法相 → 经·一一请问作答 → 论·逐条释义」三段层层推进，总→分→释：

- **总列十地治地业（P5-P20）**：佛先答「从一地至一地」之总相——「知一切法无来去相」「不念不思惟而修治地业，亦不见地」，次第列初地至十地所修法数。
  - 初地十事 → 二地八法 → 三地五法 → 四地不舍十法 → 五地远离十二法
  - 六地具足六波罗蜜、远离六法 → 七地二十不着、二十具足 → 八地两番五法 → 九地十二法 → 十地「当知如佛」
- **经·逐条请问作答（P21-P211）**：须菩提就初地至六地各法相发起请问，佛以「应萨婆若心」「不可得」「不取相」等为枢纽作答；答中多以「不念声闻辟支佛心」「不取戒相」「不见法可作」等否定式收束，显般若空慧贯穿诸地。
  - 初地十问（深心、等心、布施、近善知识、求法、常出家、爱乐佛身、演法教、破憍慢、实语）→ 二地八问 → 三地五问 → 四地十问 → 五地十二问 → 六地六问
- **论·释义（P44-P281）**：论主释「发趣」即「大乘即是地」，地有「但菩萨地」与「共地」二种；复依次释深心（应萨婆若心、利根福德、般若气味、五根成就）、等心（四无量）、求法（皮骨血书偈、萨陀波仑、金坚王）、常出家、爱乐佛身、演出法教（初中后善、妙义好语、清净具足）、破憍慢、实语；再释二地至六地诸法，重点辨「知恩报恩」（伐木人卖熊本生）、「信师如佛」（弊囊盛宝、夜行执炬）、「不生二识处」等。

## 三、关键结论

1. **大乘发趣即「从一地至一地」**：十地有「但菩萨地」（欢喜地至法云地）与「共地」（干慧地至佛地）二种；菩萨知一切法无来去相、不念不思惟而修治地业，亦不见地——升进而不取地相。
2. **初地以「深心」为本**：深心即「应萨婆若心」——系心愿我当作佛，世世于世间心薄，集诸善根但向萨婆若；利根、福德厚、烦恼薄、般若气味初得者，发心即得深心。
3. **诸地修治皆以「不可得」「不取相」为枢**：布施无所分别、戒清净不取戒相、头陀以无生法忍为果、远离自大以不见内法、远离蔑人以不见外法——般若空慧贯十地。
4. **菩萨视师如佛、视众生如佛**：法师虽有过恶，如弊囊盛宝、夜行执炬，但取其益；观一切法毕竟空，视众生如佛，何况法师有智慧利益。
5. **六地具足六波罗蜜而畏堕二乘**：菩萨观一切诸法空，未得方便力则畏堕声闻辟支佛地，故佛将护说「不应生声闻辟支佛心」；以大悲深念故施无所惜，以信力大故不疑深法。

## 四、易混辨析

- **但菩萨地 vs 共地**：但菩萨地指欢喜地、离垢地乃至法云地，纯菩萨行位；共地指干慧地乃至佛地，三乘所共，声闻辟支佛亦历。本卷所说「十地」主要就菩萨地言。
- **深心 vs 等心**：深心是「应萨婆若心」、深乐佛道、一切法中爱无如爱萨婆若；等心是得深心已、怨亲平等、视之无二，以四无量心（慈悲喜舍）为相。深心为体、等心为用。
- **舍财之舍 vs 舍结之舍**：四无量中「舍心」，初地以除悭为舍（舍财行施），至七地乃能舍结（舍烦恼结使得道），前者为后者作因缘。
- **不取戒相 vs 戒清净**：不取戒相是「不舍戒」之实相义——知诸法实相故不见持戒破戒；戒清净是初地所立、离破戒垢乃至声闻辟支佛心皆是戒垢。前者约般若、后者约持犯。

## 五、阅读提示

读本卷宜带着两条线索：一是「阶次」——十地各有几法、所修何事，可作表对照；二是「空慧」——每答皆归「不可得」「不取相」「不见」，此即般若波罗蜜贯十地之明证。论中本生故事（伐木人卖熊、皮骨血书偈、金坚王燃灯）可细读，既显菩萨行苦，亦为教化方便。
