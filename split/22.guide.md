# 大智度论卷第二十二 导读

## 一、内容总览
本卷为《大智度论》卷第二十二，释「初品中八念义」第三十六之余，承上卷八念之余文。八念即念佛、念法、念僧、念戒、念舍、念天、念安那般那、念死。本卷先由「念法」后半展开，详述法之六义（巧出、得今世果、无热恼、不待时、能到善处、通达无碍）及三法印；继而念僧、念戒、念舍、念天、念安那般那、念死依次敷演，末以八念次第及菩萨八念与声闻八念之别收束。通篇以「为什么修此念、此念对治何病、此念之功德」为主线，层层推进。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

- **念法六义 → 三法印**：先以「巧出、得今世果、无热恼、不待时、能到善处、通达无碍」六义释法之功德，每一义皆设问答辨难；「通达无碍」引入三法印（一切有为法无常、一切法无我、寂灭涅槃），并会通摩诃衍「一相无相」与声闻三印之广略差异 →
- **念法二分**：法有二种——佛所演说三藏十二部（教法）、佛所说法义（戒定慧八圣道解脱果涅槃等，义法），行者先念教法之深妙普益，次念义法三印之不可坏 →
- **念僧**：僧为佛弟子众，五众（戒、定、慧、解脱、解脱知见）具足，四双八辈为世间无上福田。以沙弥应供、檀越悔悟、佛与僧福平等之长篇事缘，明圣众不可称量，不应以年岁威仪分别 →
- **念戒**：戒分有漏（律仪、定共）与无漏；详释清净戒之八相（不缺、不破、不穿、不杂、自在、不着、智所赞、无漏），并以八圣道次第会通「慧前戒中定后」之问 →
- **念舍**：舍分财施、法施、舍烦恼三种；财施法施对辨（量与无量、欲界与出三界、旧法与新法），并劝观财为恶心因缘而舍 →
- **念天 → 念安那般那 → 念死**：念欲界天五善法因缘，为着五欲者设方便；次念出入息灭恶觉，见身危脆；终念死相，以「出息不望入、入息不望出」为真修死相 →
- **八念次第 → 声闻菩萨之别**：总收八念何以佛在前、何以有次第；菩萨为一切众生、为具一切智，声闻但为自身脱老病死，此为根本差别，并以不住、不可得二印显菩萨异。

## 三、关键结论
1. 三法印（无常、无我、寂灭涅槃）是一切论议师所不能坏，诸法性不可坏如虚空不可伤；广说则四印，略说则一印（无相即寂灭涅槃）。
2. 佛宝与僧宝福无增减：为佛布施而僧能消受，正显僧力之大；以一指测海、以蚊嘴测海底皆为智者所笑，圣众不可称量。
3. 持戒清净能生长禅定实相智慧，为出家人初门、到涅槃初因缘；无漏戒（正语、正业、正命）在八圣道中为智者所赞。
4. 法施胜于财施：果报无量、出三界、能除九十八使烦恼病；财施唯救饥渴寒热。
5. 真修死相者，于出息不望入、于入息不望出；一切有为法念念生灭，住时甚少，犹如幻化。

## 四、易混辨析
- **有漏戒 vs 无漏戒**：有漏戒含律仪戒（防恶自在）、定共戒（依禅定生，遮烦恼不求世乐）；无漏戒即正语、正业、正命，能拔烦恼根本。有漏似无漏、随无漏同行因缘故亦为智者所赞，如贼中来归者可借以破贼。
- **四种天**：名天（国王称天子，世间假名）、生天（从四天王至非有想非无想，实生天者）、净天（人中圣人）、生净天（三界天中得道圣人，如五种阿那含）。本卷所念主要为生天与生净天二种。
- **声闻八念 vs 菩萨八念**：声闻为自身脱老病死、为自利；菩萨为一切众生、为遍具一切智功德。菩萨以不住法住般若波罗蜜中具足八念，「不住」于初、「不可得」于后，以此二印异于声闻。
- **三法印 vs 一实相印**：声闻广说三印（无常、无我、寂灭），略说即一；摩诃衍说诸法不生不灭一相无相。观无常即观空因缘，无色相即空，空即无生无灭，生灭与无生灭其实是一，但有广略之异。

## 五、阅读提示
读本卷宜抓住「八念次第」之逻辑主轴：每一念皆为对治一类烦恼病——念法对治疑、念僧对慢、念戒对破戒散乱、念舍对悭贪、念天对著五欲、念息对恶觉、念死对懈怠。再以声闻菩萨之别贯穿全局，可见龙树会通二乘归于大乘之巧思。
