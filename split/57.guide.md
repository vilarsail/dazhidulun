# 大智度论卷第五十七 导读

## 一、内容总览
本卷承前品般若功德之赞，由释提桓因两度发问、佛以校量与反问层层展开，收摄于「述诚品」论般若在世与三宝不灭之关系。全卷主线为：般若波罗蜜是一切善法、一切种智、三宝之所以住世之本，故书写、受持、供养般若经卷之福，远过起七宝塔供养舍利之福。般若既是诸佛之母，亦是声闻、辟支佛、菩萨共学之法印；离般若方便，发心者多堕二乘。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

- **般若护身功德（经 P5-P9）** → 佛告帝释：受持深般若者入军阵刀箭不伤、毒药火坑不能害 → 以「长夜修六波罗蜜、自除亦除他三毒刀箭」释其因缘 → 以「般若是大明咒、无上咒」明诸佛共学 → 复以菩提树喻明般若所止处诸天守护。
- **论释护身义（论 P11-P24）** → 问：业因缘无免，何以兵刃不伤？ → 答：业有必受报与不必受报二种，般若济不必受报者 → 复约福德(五波罗蜜)+智慧(般若)二事明不中失命 → 复以外道仙咒入水不溺况显般若为诸佛成就咒 → 次释「但书写供养亦得功德」及「诸天守护难信，故以菩提树为喻」。
- **舍利与般若校量（经 P26-P45）** → 帝释问：书经供养与涅槃后起塔供舍利，何福多？ → 佛反问：佛一切种智及相好身从何道学？ → 帝释答：从般若波罗蜜中学 → 佛印可：一切种智从般若生，故供般若即供一切种智 → 广明五波罗蜜、内空乃至无法有法空、三十七品、十八不共法、三乘果位皆从般若生 → 复以佛眼见十方发心者离般若方便多堕二乘，劝依止般若。
- **论释校量义（论 P47-P86）** → 问：佛已赞般若，帝释何以更校舍利？ → 答：信根多者喜供舍利、慧根多者好读经法，故有此问 → 释「反问答」、释「从般若生五波罗蜜」、释般若实相令布施持戒通达中道 → 释阎浮提人不供般若（智人少，如盲者不识金宝） → 分别不坏信、无疑、决了三事及果报 → 释「诸余善法入般若」即《法华》《密迹》等十二部经义同般若者 → 释三乘共学般若各随分到彼岸。
- **塔量递进校量（经 P87-P108）** → 佛自设譬：一七宝塔高一由旬 → 满阎浮提 → 满四天下 → 满小千 → 满二千中 → 满三千大千 → 三千大千众生各起塔 → 十方恒河沙世界众生各起塔若一劫减一劫供养，一一皆「不如书持般若其福甚多」 → 帝释自摄一切善法（十善道乃至一切种智）皆入般若，名诸佛法印，三乘学之度彼岸。
- **论释塔喻（论 P110-P122）** → 问：塔为实为假？ → 答：为分别福德多小作譬喻，不应问虚实 → 一说有实有假（吉梨姞王起塔五十里、德主转轮王一日起五百塔） → 一说皆实（梵天王、菩萨能起满三千大千世界塔） → 明「满」举其多、「一一众生」明施主多 → 舍利是无记法为善法依止处故后与果报，行般若即时得果后亦得报。
- **述诚品（经 P125-P127 + 论 P129-P143）** → 佛述诚印可：书持般若福德过出前供七宝塔，算数譬喻不能及 → 释般若在世则三宝不灭、十善乃至一切种智皆现于世 → 论释：般若体性有佛无佛常住，「在世」指经卷可修习，因中说果，如井深绠短言失井而井实不失 → 三宝名义广解（佛宝、法宝、僧宝各摄何法），余十善道等为道方便门故别说。

## 三、关键结论
1. 般若波罗蜜是一切善法、五波罗蜜、内空乃至无法有法空、三十七品、十八不共法、三乘圣果、一切种智之所从生，是诸佛之母。
2. 书写、受持、供养般若经卷之福德，校量恒河沙世界众生各起七宝塔尽劫供养，犹不能及，以供般若即供一切种智、即供三宝故。
3. 受持深般若者，以福德智慧二事具足故，入军阵兵刃不伤、毒药水火不能害——此就「不必受报」之业说，非谓般若无因果力势。
4. 发无上道心者离般若方便力，则多堕声闻、辟支佛地；般若是一切三乘共学之法印，各随分学皆得度彼岸。
5. 般若体性有佛无佛常住不灭，「在世」特指经卷可修习读诵；般若在世则三宝不灭、世间善法与圣果皆现。

## 四、易混辨析
- **般若波罗蜜 vs 一切种智**：般若波罗蜜是因行（菩萨所学、诸佛所由），一切种智是果德；般若为母、一切种智为子，佛从般若中学得一切种智，不以身为佛、以一切种智故名佛。
- **必受报业 vs 不必受报业**：前者如大逆重罪，强力财宝不可免，《法句》所说是；后者罪轻理在可救，藉般若力势得济度，本卷「兵刃不伤」所说是。
- **不坏信 vs 无疑 vs 决了**：于三宝得不坏信是信根成就，无疑以信根故不疑，决了以智慧究竟故彻了；或配见谛道、思惟道、无学道；或喻渡水初入为无疑、出彼岸为决了。
- **舍利供养 vs 般若经卷供养**：舍利是无记法，为善法依止处故后乃与果报；般若经卷是法门，行般若即时得果后亦得报，故福胜舍利塔。信根多者喜供舍利，慧根多者好读经法。

## 五、阅读提示
读本卷可带着两问推进：佛何以用递进校量（从一塔到恒河沙塔）反复申明供般若福多？「般若在世则三宝不灭」与「般若相一切观灭、语言道断」如何会通？前者指向般若为一切善法之源，后者指向体性常住与经卷在世的「因中说果」之辨。
