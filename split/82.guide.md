# 大智度论卷第八十二 导读

## 一、内容总览

本卷为《大智度论》卷八十二，释《摩诃般若波罗蜜经》第六十九〈大方便品〉。全卷一线贯穿的论题是般若波罗蜜与方便力如何统摄其余五波罗蜜：先以九喻明般若导五度，再辨「诸法自性空」与「行六度得佛果」如何相容，继而反复敲打「最上最妙」与「无差别」的表面矛盾，最后收束于「不取不舍、不念不住」的般若行相与「略、广相」四门。经文须菩提与佛往返问答，龙树释论逐段拆解。

## 二、结构层次

**【经】问答递进，一波三折：**
1. **三问定基**：成就方便力的菩萨发心几时（无量亿阿僧祇劫）→ 供养几佛（恒河沙诸佛）→ 种何善根（六波罗蜜无不具足）→ 佛以九喻层层显「般若导五度」——日月照四天下、轮宝成转轮圣王之名、无夫妇人易侵凌、军将铠仗难坏、小王朝侍、众川入海、右手便左手不便、众流入海一味、轮宝导四种兵 → 以「诸波罗蜜性无所能作，自性空」收束。
2. **空与行如何相容**：须菩提问「若一切法自性空，云何行六波罗蜜得菩提」→ 佛答：世间心皆颠倒，「我若不行方便力，不能度脱众生生死」，为众生故舍内外物、不破戒、不瞋、不懈怠、不散乱、不离智慧——为众生而行，正是〈大方便品〉正意。
3. **无差别与最上之辨**：实义中诸度无差别，「但以世俗法故」说有六度 → 般若「取一切善法到萨婆若中住，不住故」→ 转入「不取不舍」：不念色乃至不念菩提，善根反而增益（以念故着三界，不念故无所著）→ 不住 → 三种取相之失（着空、住般若生余度之念、演说「诸佛知诸法无受相」）→ 云何无失：于一切法不生，不观常无常、苦乐、我无我等。
4. **道与非道、起用与回向**：声闻、辟支佛道非菩萨道，一切种智道是菩萨道 → 般若为大事故起、为众生导 → 般若无所生灭不妨行六度：念萨婆若而行，「持是功德与众生共之，回向阿耨多罗三藐三菩提」→ 习行六度：观一切法不合不散、以无所住法习行 → 庵罗果种果喻 → 净佛国土、坐道场、转法轮当学般若 → 十方诸佛所念（以不得诸法故）→ 多有所学实无所学 → 知略广相四门：如相、实际、法性、不合不散 → 「是名略摄般若波罗蜜」，从初发意到十地皆应学。

**【论】逐段释经**：解三问 → 广明「方便」内涵（金色身、三十二相、十力、大慈大悲等佛功德具足方能化生）→ 释九喻、答「川流」之难（萨婆若即般若异名）→ 明三种失 → 说二乘非道之由（同行空、同求涅槃而唯求自了）→ 释习行与种果喻 → 破「二指合散」之难（入破一异门）→ 辨如、法性、实际与总相、别相。

## 三、关键结论

1. 离般若则五度但名善法，不得波罗蜜之名；为般若所护，随到萨婆若。
2. 诸波罗蜜实无差别，般若「最上最妙」是就世俗说，其实质是「取一切善法到萨婆若中住」。
3. 般若正行在无取无舍、无念无住：以念故着三界，不念故无所著；着空、着无性、着「能不着」，三者皆失般若。
4. 二乘同空同涅槃而非菩萨道，萨婆若（一切种智）才是菩萨道，因中说果。
5. 知如、法性、实际、不合不散四门，即知一切法略、广相，是名略摄般若。

## 四、易混辨析

- **般若波罗蜜 vs 方便力**：般若照实相，方便是化度善巧——论释「方便」为具足金色身、神通变化、大慈大悲等佛功德，众生必能信受；二者相资，正是本品名「大方便」之意。
- **萨婆若 vs 一切种智**：萨婆若意译一切智，论明言「即是般若异名」——五度福德入般若清净，得佛道变名萨婆若；一切种智则兼知总相别相，为佛智完整名目。
- **声闻、辟支佛 vs 菩萨道**：二乘同行空、同求涅槃，但唯求自了；菩萨以萨婆若为归，故判二乘道「非菩萨道」。
- **自性空 vs 着无所有**：诸法自性空是实相，但执「无所有」之见（着无所有法）反失般若——空亦不可执。

## 五、阅读提示

带着「既然一切法自性空，为何还要行六度」这一问读全卷，佛的答案是「为众生故行，行而不着」。卷中喻多而密，先抓两个总纲——「轮宝导四兵」（般若导五度）与「右手便左手不便」（有无般若之别），其余诸喻自然贯通。
