# 大智度论卷第十一 导读

## 一、内容总览

本卷承上启下，前接「初品」中关于般若波罗蜜「对机说法」的讨论，后启「檀波罗蜜」一系的详细展开。全卷由三段释论组成：第十六「舍利弗因缘」解释佛为何独告舍利弗说般若、兼述舍利弗与须菩提的本生因缘，并广辨「一切种」「一切法」之义；第十七、十八、十九「檀波罗蜜义/赞檀/檀相」转入布施主题，释布施之利益、体相、净不净差别；第二十「法施义」辨财施与法施胜劣。文脉以「人物因缘 → 法义广辨 → 事相因果 → 施相分类 → 法施校量」层层推进。

## 二、结构层次

- **舍利弗因缘（释初品中第十六）**：以「佛何以告舍利弗而不告菩萨」之问起 → 答舍利弗智慧第一，广叙八岁升论座、与目连同师删阇耶、逢阿说示闻因缘偈得初道、半月后于佛说长爪梵志时证阿罗汉 → 复以须菩提行空三昧、华色比丘尼化为转轮王礼佛之喻，说明须菩提亦堪受般若 → 再叙舍利弗得名本生（母名舍利、父名提舍、舅名拘郗罗即长爪梵志），归结「以般若甚深故为智慧第一者说」。
- **一切种知一切法（承上转入法义）**：经言「菩萨欲以一切种知一切法当习行般若波罗蜜」 → 论以「智慧门名种」「识所缘、智所缘法名一切法」展开，历举凡夫三观、八解脱观、十六行、出入息十六行、六念、二法三法四法五法六法摄一切法 → 以「量大地、数海水、称须弥、量虚空」设难，答以菩萨为度一切众生故须具知一切种药，如函大盖亦大。
- **舍利弗请问般若（鸽本生喻）**：释佛令舍利弗发问之由 → 广说《阿婆檀那经》鹰逐鸽、佛影覆鸽令安、舍利弗影覆鸽仍怖之事 → 舍利弗入宿命智三昧、愿智三昧各观八万大劫不能尽知鸽之本末 → 佛明示此鸽恒沙劫中常作鸽身、后得人身经五百世利根、三阿僧祇劫行六波罗蜜十地具足成佛 → 舍利弗忏悔，宁入阿鼻地狱为求佛智。
- **檀波罗蜜三品（义/赞/相，第十七至十九）**：先释「不住法住般若波罗蜜中具足檀波罗蜜」之理，广辨般若体相（无漏慧根、有漏慧、有漏无漏总、不可得相诸说，归宗末后不可破不可坏之真实般若） → 次赞檀之种种利益（宝藏、破苦、善御、安隐、慈相、集乐、伏悭敌、净道等）与失火家出物、勇士吞敌、树华大果诸喻 → 次释檀名与三种、净不净施差别、布施生相似八正道、三十二相因缘、得报增多诸缘 → 末以画师千那施僧、韦罗摩大布施、释迦文佛割肉燃灯、鸽投火施身等本生，明内布施与外布施之相。
- **法施义（第二十）**：问「云何名法布施」 → 历举好语利益、诸佛妙法演说、三藏（修妒路毗尼阿毗昙）、四藏（加杂藏）、声闻法摩诃衍法诸说 → 破提婆达、呵多以三藏教人却入地狱，明非以言说为法施，须以净心善思 → 次以阿输伽王宫中说法比丘口出妙香本生，明赞佛说法功德十果 → 末校量财施法施胜劣（法施为胜：果报出三界、无量无尽、净多垢少、不待众力、令无漏根力觉道具足、有佛世方有、能生财施及三乘圣人），归结二施和合名为檀行，愿求作佛能至佛道。

## 三、关键结论

1. 般若波罗蜜甚深微妙无相，佛特为智慧第一之舍利弗、无诤三昧第一之须菩提宣说，以声闻漏尽者易生众信，而菩萨漏未尽者未堪为证。
2. 「一切种」即一切智慧门，「一切法」即识所缘、智所缘法，可由二法、三法乃至无量法尽摄；菩萨为普度一切众生故发大心求一切种智，如医欲治一切病须备一切药。
3. 般若波罗蜜真实相不可破不可坏，超四句绝百非，寂灭无戏论；以不住法住般若波罗蜜中，于般若相亦不取，方能具足六波罗蜜。
4. 布施具破悭、嫉妒、谄曲、调、悔、不敬、无惭无愧、爱、瞋、憍慢、无明、邪见、疑等诸烦恼，生相似八正道乃至三十七品善法，是趣涅槃之初缘、三十二相之因缘。
5. 净施为出世间檀、圣人所称誉，杂结垢者不称誉；法施胜于财施，以法施果报出三界、无量无尽、净多垢少、能生财施及三乘圣故，二施和合愿求作佛即得佛道。

## 四、易混辨析

- **舍利弗 vs 须菩提**：舍利弗于佛弟子中智慧第一，佛以般若甚深法为说初分；须菩提得无诤三昧第一、好行空三昧，以与般若空相相应故佛命说后分。一主「智慧门」入，一主「空三昧」入，皆堪受般若而机不同。
- **世间檀 vs 出世间檀**：世间檀为凡夫或圣人有漏心施，杂属爱、属见二种结使，有三碍系心、颠倒计我；出世间檀为圣者得无作三昧、断结使清净施，实知法相、心不颠倒，为圣人所称誉。
- **声闻檀 vs 佛菩萨檀**：声闻檀但畏老病死、为脱自苦、欲得功德少分；佛菩萨檀为一切众生、为知诸法实相、为助佛道、欲具足一切功德，不畏老病死。
- **财施 vs 法施**：财施果在欲界、有量有尽、净少垢多、待众力、令四大诸根增长、有佛无佛世间常有；法施果或出三界、无量无尽、净多垢少、不待他、令无漏根力觉道具足、唯佛世有，且法施能出生财施及三乘圣人，故法施为胜。
- **相似无漏般若 vs 真实无漏般若**：声闻人于暖、顶、忍、世第一法先行相似无漏，后易生苦法智忍；菩萨未断结亦行相似无漏般若波罗蜜，断结清净者方行真实无漏般若。

## 五、阅读提示

读本卷可循「人缘 → 法义 → 事相 → 校量」四阶推进：先把握舍利弗、须菩提受般若之由，再随「一切种知一切法」广摄诸法之数，进而观鸽本生喻舍利弗与佛智之悬殊，末于檀波罗蜜诸品中辨净不净、财法二施胜劣，则全卷义脉自现。
