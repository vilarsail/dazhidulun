# 大智度论卷第一百 导读

## 一、内容总览
本卷是《大智度论》末卷（卷第一百），含〈释昙无竭品〉结尾与〈释嘱累品〉全篇，卷末附译场后记。前半收束萨陀波仑（常啼）菩萨求般若的长篇叙事：昙无竭以「诸法等故，般若波罗蜜等」式排比宣说般若之相，萨陀波仑即座得六百万三昧门，佛为须菩提开列其今世、后世果报。后半是全论的遗嘱：佛三度以般若嘱累阿难，层层问答辨明缘由，末答「大乘何以不入结集三藏」，并记鸠摩罗什译论始末。

## 二、结构层次
- **经·闻法得定**：散华礼座 → 昙无竭说「般若波罗蜜相」，由「诸法等→离→无念→无畏→一味→无边→无生灭」层层铺排 → 再以虚空、大海、须弥山三喻说无边、庄严、无分别 → 收于「性不可得、无所有、无作、不可思议」→ 萨陀波仑即座得六百万三昧门。
- **论·逐句释义**：先明说法时机（七岁渴仰、以血洒地，心不退方堪受教）→ 释「平等」：住众生等则怨亲平等、开福德门，住法等则分别皆灭、唯见空 → 释「离」：平等相亦不可着，安住空中则戏论、烦恼、无常皆不能动 → 释「一味、无边」：大海百川同归一味；大海喻禅智之翅能度，须弥喻般若为一切善法中第一坚实 → 释「如金钢、无分别、性不可得、无所有、无作、不可思议」→ 释得定之由：散心但有智慧，「一心思惟名为三昧」，如风中灯不及静室之灯 → 佛说今世果报（多闻如海、常不离佛）与后世果报（生有佛土、梦中见佛、诸难永断）→ 劝「坚正一心，不可倾动」。
- **经·嘱累**：佛问阿难师弟之分 → 「我灭度后，当爱敬供养般若波罗蜜」→ 三嘱、诫「莫作最后断种人」→ 书写受持供养者不离见佛闻法 → 弥勒等大众欢喜。
- **论·嘱累问答**（问曰→答曰层层推进）：佛既无着何以嘱累（大悲不舍＋金钢三昧碎身如麻米）→ 何以不嘱须菩提、弥勒等（须菩提得无诤三昧，弥勒还兜率天，文殊、维摩各赴所化；阿难闻持第一，是「随佛转法轮第三师」）→ 何以两处嘱累（先说般若体，今说方便用）→ 何以郑重（如估客主独嘱大价妙宝；遮有边、破无边以显中道）→ 何以问「汝是我弟子不」（拣别须那刹多罗等名字弟子）→ 何以三嘱（诸佛常法，语不过三）→ 既毕竟空何言「莫令断灭」（灭在取相斗诤者，「莫著文字语言」是名不灭）。
- **收束**：般若在世即为佛在（般若是诸佛母、佛以法为师）→ 释大阿罗汉断疑大欢喜 → 大乘不入三藏之辩（三藏仅三十万偈，「小物应在大中」；大小同是「苦尽解脱味」，只差自利利他）→ 修多罗、毗尼各分二分 → 译场后记：弘始三年入长安，逍遥园出论，七年乃讫。

## 三、关键结论
- 般若无别相：诸法等、离、无念、无边、无作、不可思议，即是般若波罗蜜相。
- 般若虽妙不可取着：不令因般若更生垢着，如热金虽好不可手捉——贵般若而贱余法恰违般若。
- 般若在世即为佛在：般若是诸佛母、佛以法为师，法宝不离佛宝，受持供养即不离见佛闻法。
- 受持功德由薄而厚：初始微薄，其心转厚、功德转多，渐渐见十方佛、具足六度、皆得作佛。

## 四、易混辨析
- **一切智 vs 一切种智**：一切智知诸法总相空理，声闻辟支佛亦得；一切种智遍知总别二相，唯佛独有，即阿耨多罗三藐三菩提。
- **般若波罗蜜道 vs 方便道（沤和拘舍罗）**：本体是一，随用受名；般若实证空，方便则不取涅槃证、还修六度引导众生。
- **名字弟子 vs 真弟子**：须那刹多罗欲取射法、须尸摩为盗法而作弟子，皆退失自绝；真弟子以善身口意业供养其师、不惜身命——阿难尽具足。
- **三藏 vs 摩诃衍**：同是一「苦尽解脱味」，只差自度与兼度众生；摩诃衍能兼小乘，故不入三藏并非阙失。

## 五、阅读提示
带着两个问题读：为何全论以「求法故事＋遗嘱」收尾——留意「不令因般若生着」如何贯穿全卷；为何嘱累的是声闻阿难——论主的层层辩答正是理解大小乘关系的一把钥匙。
