# 大智度论卷第二十七 导读

## 一、内容总览

本卷紧承「大慈大悲」义，以《释初品》中四段经文为骨架，依次阐释菩萨修学般若波罗蜜所成的四类智慧与阶位：先立「大慈大悲」为佛道根本，次明「道慧→道种慧→一切智→一切种智」的智慧次第，再论「断烦恼习」之差别，末以「菩萨位」与「阿鞞跋致地」收束。全卷主线是：慈悲为因 → 智慧差别为阶 → 断习尽净为果 → 不退位为归宿，层层递进地回答「菩萨为何学般若、学成何智、至何位」。

## 二、结构层次

- **慈悲根本（P7–P71）**：先释大慈大悲与小慈小悲之别（与乐事 vs 仅心念、能令脱苦 vs 仅怜愍）→ 次明佛慈悲之所以名大（从十力等大法出、遍满三世、不惜身命）→ 再破迦旃延「慈悲是有漏法」之执，引《无尽意经》三种慈悲（众生缘、法缘、无缘）证佛慈悲离众生相而无漏。
- **道慧与道种慧（P73–P139）**：先总标「道」义（一向趣涅槃）→ 次以二道、三道、四道乃至一百六十二道广列道门 → 收束于「如是诸道尽知遍知，是为道种慧」→ 再问答抉择：诸道虽别，皆入一相诸法实相；世间相即出世间相，不可得故。
- **一切智与一切种智（P141–P216）**：先辨二智差别（总相 vs 别相、略说 vs 广说、四谛 vs 八苦等）→ 次明声闻辟支佛但有一切智名而无实，佛具实一切智与一切种智 → 引「萨婆若多」梵名释义（一切+智+相），结归「以道种智具足一切智，习行般若」。
- **断烦恼习（P218–P300）**：先出疑难——一心顿得，何须次第说 → 答「实一时得，为令众生信故次第差品」→ 广辨「烦恼」与「烦恼习」之别（三毒九十八使 vs 残气），举难陀淫习、舍利弗瞋习、迦叶等诸圣习气未尽之例 → 论佛以一切智火尽断残习，胜劫尽火 → 收归三说皆是方便、实相在得无生法忍时断烦恼、得佛时断习。
- **菩萨位与阿鞞跋致（P302–P392）**：释菩萨位即无生法忍（观世间空、住实相）→ 明住顶不堕之相 → 辨声闻「正位」与菩萨「位」之异 → 释阿鞞跋致义（观不生不灭、世世得果报神通不失），以大龙喻「尾在海、头在空」明悲智双行；末辨二种阿鞞跋致（得无生忍 vs 佛授记肉身菩萨）。

## 三、关键结论

1. 大慈大悲是佛道根本：菩萨见众生苦而发心求菩提，以慈悲力故久不入涅槃。
2. 佛慈悲离众生相而生，非有漏法——此即无缘大慈，胜声闻辟支佛之众生缘慈悲。
3. 道慧、道种慧、一切智、一切种智是菩萨修学般若的智慧次第：诸道尽知为道种慧，总相遍知为一切智，别相尽知为一切种智。
4. 烦恼与烦恼习不同：声闻辟支佛断烦恼未尽习，唯佛以一切智火断烦恼及习都尽无余。
5. 菩萨位即无生法忍、即阿鞞跋致地：观诸法不生不灭、悲智等观、世世不失，是过声闻辟支佛地之真实不退位。

## 四、易混辨析

- **一切智 vs 一切种智**：一切智知诸法总相（无常苦空无我），如说四谛、苦谛；一切种智知别相尽相（种种因缘、名字、果报），如说四谛义、八苦相。声闻辟支佛但有总相一切智名而无实（如昼灯有名无用），佛具二智皆实。
- **道慧 vs 道种智**：道慧是知一道（一向趣涅槃）之慧；道种慧是尽知遍知无量道门（世间、出世间、三恶道、四圣谛道等）之慧。道智则是菩萨于道中分别思惟而行之智。
- **烦恼 vs 烦恼习**：烦恼略说即三毒、广说即三界九十八使；习是烦恼残气，如久锁脚人脱锁后犹有步态、如乳母衣浣净而垢气犹在。阿罗汉断烦恼未尽习，佛断二俱尽。
- **菩萨位 vs 声闻正位**：声闻入苦法忍名正位，菩萨入无生法忍名菩萨位；声闻无大慈悲、多求诸法生邪见疑悔，菩萨大悲愍众生、不分别戏论，故但名位。阿鞞跋致有二种：得无生忍者清净、肉身授记者结使未尽而佛记必得作佛。

## 五、阅读提示

读本卷可抓「四段经文」为纲：每段皆以「欲……当习行般若波罗蜜」起，论主随经文展开一重义。留意「实一时得，次第差品说」这一关键——智慧与断证本是顿得，而经论方便次第说，为令众生信入。读「道门」枚举段可略观其类，不必逐记，重点在收束「皆入一道诸法实相」。
