# 大智度论卷第六十四 导读

## 一、内容总览
本卷为《大智度论》卷六十四，释《摩诃般若波罗蜜经》〈叹净品〉之余与〈无作实相品〉。主线是「碍与无碍」：善法若取相回向，反成菩萨碍法；般若无相、无起无作、无所得，才是无碍之行。由此展开「度众生如度虚空、护般若如护虚空」等譬喻，末以十方千佛同说、弥勒当来续说，证此法三世诸佛共说。

## 二、结构层次
全卷经文与论释交替（【经】…【论】「释曰」…），循问答层层剥落取相：

1. **碍法（经）**：帝释问「云何是碍法」 → 须菩提答：于六度、诸空、道品、佛功德取相回向即碍，「所可有相，皆是碍相」 → 教他应「示、教、利、喜」实相，不分别「我施我戒」 → 佛自说「微细碍相」：取相念佛、忆念善根皆碍 → 须菩提叹甚深难解 → 佛结归「诸法一性，所谓无性，无起无作」，知此则碍相远离。
2. **论释**：辨粗碍（着我我所）与微细碍（念佛三昧中取相）；释般若非心生、非五众所生——五众可为因缘不能生般若，如猛风除云能现日月而不能作日月。
3. **云何行般若（经）**：问「般若无所作，应云何行」 → 佛答不行常无常、苦乐、我无我、净不净（一切法无所有性故） → 递进至「不行不具足」「不行不碍」 → 须菩提叹菩萨大庄严：欲度如虚空之众生，度无量众生而众生性不增不减 → 一比丘惊喜礼般若：无法生灭而有三宝、诸果、转法轮。
4. **论释**：般若不受常无常等观，恐生着心；「具足／不具足」两解而双遣；以虚空、幻人为喻，明实相说与不说皆不增不减。
5. **习空与守护（经）**：帝释问「习般若为习何法」 → 「为习空」 → 帝释愿守护，须菩提言如所说行即是守护，护行般若菩萨如护梦焰影响幻化、佛所化、法性实际 → 帝释问如何知见如梦等法，答以「不念色、不念是色、不念用色、不念我色」四句，于喻亦不生着。
6. **流通结净（经）**：佛神力现十方各千佛同说此品，说者皆字须菩提、问者皆字释提桓因 → 引弥勒将于耆阇崛山出迦叶骨身、续说般若 → 层层问答「般若清净」：色清净、虚空不生不灭、不可污、不可取、可说与不可说，收归「一切法毕竟清净」。

## 三、关键结论
- 「所可有相，皆是碍相」：取相福德如食中杂毒，不得无上道。
- 行般若是遮诠：不行二边分别、不行不具足、不行不碍，即是行般若。
- 众生毕竟空，佛度无量众生入涅槃而众生界不增不减，故「欲度众生，为欲度虚空」。
- 守护般若不在外护：如所说修行即是守护，人非人不得其便（舍利弗入灭尽定、夜叉拳击不觉为证）。
- 般若清净如虚空：不生不灭、不可取、不可污；为众生故可说，第一义中语言道断。

## 四、易混辨析
- **粗碍 vs 微细碍**：粗碍取「我是与者、彼是受者」的我我所相；微细碍是念佛三昧等微细心中取相——皆属取相，唯粗细之异。
- **具足 vs 不具足**：一解起常无常分别名具足、以观破之名不具足；一解唯补处菩萨如实观名具足。佛意双遣：「不行色不具足」即是行具足般若。
- **四句「不念」**：不念梦（不执定有梦法）、不念是梦（不分别好恶）、不念用梦（不执喻为得智之用）、不念我梦（不执「我因梦知诸法」）——能喻所喻俱不着。
- **可说 vs 不可说**：般若一事分别说为十二部经，如虚空因声出响；毕竟空中则语言道断——二说相成，非相违。

## 五、阅读提示
带着「善法何以反成障碍」一问去读：全卷诸喻（虚空、幻人、梦焰响化）都在对治对「修」与「度」的实有执，读时留意每番问答如何层层剥落取相。
