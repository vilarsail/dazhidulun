# 大智度论卷第五十四 导读

## 一、内容总览
本卷为《大智度论》卷五十四，释「天主品第二十七」，承接前品佛放光明、诸天云集的场景，由释提桓因启问、须菩提承佛神力代答般若波罗蜜义，继由舍利弗与诸天子层层递问，论主于经后逐段释义。全卷以「诸天集会 → 须菩提说般若体相 → 菩萨应住不应住 → 一切法如化如梦无说无听」为脉络，阐明般若波罗蜜以「无所得」为相、以「不住」为住、以「无言说」为究竟，终归毕竟空、不可思议。

## 二、结构层次（★重点）
全卷由三段【经】+【论】交替构成，呈「启问 → 作答 → 释难」的递进结构：

- **第一段（诸天集会，须菩提说般若体相）**：
  - 诸天光明为佛光所蔽 → 释提桓因代众请法，三问「云何住、何等是、云何行」 →
  - 须菩提劝发心、明声闻不堪发心之因 → 应萨婆若心观五蕴无常苦空无我、如病如痈乃至寂灭无所得 → 观十二因缘、四念处乃至十八不共法、六波罗蜜皆无所得 →
  - 回向心与菩提心「非心相、不可思议」 → 佛赞须菩提善说深般若 → 须菩提自述报恩义。
  - 论释：广解四天王至首陀婆诸天名义、业报光明与佛常光之别；辨般若相即五蕴实相即涅槃；释「诸法因缘和合而有、无作者」之幻化义；以「非心相常非心相」明回向与菩提皆空。

- **第二段（应住与不应住）**：
  - 须菩提对释提桓因说「应住」：色空菩萨空不二不别，乃至一切种智空、菩萨空不二不别 →
  - 说「不应住」：于五蕴、六根六尘、六波罗蜜、四念处乃至十八不共法、须陀洹至佛果、初地至十地、五神通、三十二相等一切法中「以有所得故不应住」 →
  - 舍利弗疑「都无所住当住何处」 → 须菩提以「诸佛无所住、菩萨应如是学不住法」答之。
  - 论释：明五众相空以十八空观；「不住即住」之义；须陀洹等无为相、福田不应住之次第；广解八人、家家、一间、斯陀含、阿那含、阿罗汉诸果差别；金刚世界、菩提树香等愿相亦不应取着。

- **第三段（无说无听无知）**：
  - 诸天子疑须菩提所说「了不可知」，以夜叉语况之 → 须菩提以四喻（化人说法、梦中说法、深涧赞佛、幻师化佛）明「一切法如化如梦，无说者无听者无知者」 →
  - 诸天子觉所说「转深转妙」 → 须菩提说色乃至一切种智「性非深非妙」、法中不说名字语言 → 诸天子悟「不离是忍」即得诸果佛道。
  - 论释：辨夜叉语与深般若所以相况之故；明毕竟空「言语道断、心行处灭」；以「五众实相即般若波罗蜜」收束，归于「无说无闻、无受无著则入涅槃」。

## 三、关键结论
1. 般若波罗蜜以「无所得」为相：观五蕴乃至十八不共法皆寂灭无所得，五蕴实相即涅槃，不离五蕴有涅槃。
2. 菩萨应住于「不住」：于色乃至一切种智、初地至十地、声闻至佛果一切法中以有所得故不应住；不住即住，如诸佛于一切法无所住。
3. 回向心与菩提心皆「非心相、不可思议」：毕竟空中无是心非心，无二法可得则无可回向，唯有因缘和合似有作用。
4. 一切法如化如梦、无说无听无知者：名字语言皆空虚诳，诸佛得菩提亦无说无听，三乘果位皆因无为法而有，离是忍则无所得。

## 四、易混辨析
- **应住 vs 不应住**：应住指「色空菩萨空不二不别」之实相住，即以无所得心住于诸法实相；不应住指「以有所得故」于色等诸法取相而住。不住即真住，非另有一不住处可着。
- **声闻正位 vs 发菩提心**：已入声闻正位者与生死作障隔（漏尽无后生），不堪发菩提心；然若发心，须菩提亦随喜，以「上人应更求上法」故。
- **四圣行（八事） vs 凡圣共行（七事）**：如病如痈疽如箭镝等八事名「圣行」，为利根说；痛恼衰坏忧畏不安等七事凡夫圣人共行，为钝根说；初四（无常苦空无我）入十六圣行，般若中常说。
- **世谛 vs 第一义谛**：世谛以如幻如梦说回向因缘，第一义谛说二心皆空、非心相；论主依第一义答释提桓因之难，故言「不可思议」。

## 五、阅读提示
读本卷宜扣「无所得」「不住」「无说无听」三关：先看须菩提如何以「应萨婆若心、无所得故」一语贯通五蕴至十八不共法；再看「应住—不应住」如何以「有所得」为取舍标准；末观四喻如何将「言语道断」之毕竟空以譬喻显发，体会「转深转妙」之机。
