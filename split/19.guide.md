# 大智度论卷第十九 导读

## 一、内容总览
本卷（《大智度论》卷第十九）为释「初品中三十七品义第三十一」，承接上卷菩萨摩诃萨以不住法住般若波罗蜜、不生故应具足三十七品之经文，广释三十七道品的菩萨义。全文先破「三十七品是小乘法」之疑，立「菩萨学一切道而不取证」之宗；次以三十七品逐项展开——四念处、四正勤、四如意足、五根、五力、七觉分、八圣道分，声闻义与摩诃衍义双线并陈，最终收束于「观三十七品得超二乘地、入菩萨位、成一切种智」。核心是：同一道品，二乘取证涅槃，菩萨以般若方便不取证而久住生死度生。

## 二、结构层次
全文以「总难→总答→分释→双释→收束」五段推进：

- **立宗破疑（P7-P26）**：先设难「三十七品是声闻辟支佛道，何以菩萨道中说」→ 答以菩萨应学一切善法一切道，九地学而不证，佛地亦学亦证 → 次设难「三十七品但说涅槃不说波罗蜜大悲」→ 答以菩萨虽学是法未具六波罗蜜故不取证，以般若箭射三解脱门、复以方便箭射般若箭令不堕涅槃 → 引《中论》「涅槃不异世间」结成「世间即是涅槃」之菩萨实相观。

- **总明三十七品结构与十根本（P27-P45）**：
  - 问答「四念处已足何以说三十七」→ 答以众生心种种、结使种种、所乐所解种种，佛以八万四千法聚作分别说，如药师以众药治众病 →
  - 立三十七品「十法为根本」（信戒思惟精进念定慧除喜舍），统摄念处、正勤、如意足、根、力、觉、道 →
  - 释道品生起次第：念处→正勤→如意足→五根→五力→七觉分→八正道，喻如到师所听法→求果精进→摄心调柔→生五根→增长为力→分别三分→入涅槃城。

- **分释四念处（声闻义，P46-P226）**：
  - 身念处：观身五种不净（生处、种子、自性、自相、究竟），破净颠倒；次观无常、苦、空、无我，破常乐我倒 →
  - 受念处：观乐受是苦（颠倒生、能生大苦、乐少故名苦，喻一斗蜜投大河），苦受如箭，不苦不乐受无常坏败，破乐颠倒 →
  - 心念处：观心一念不住、过去已灭未来未生现在疾灭故不受乐，破常颠倒；引凡夫以身为常犹差、以心为常是大惑 →
  - 法念处：破我执，设「心使身故应有我使心」之难，以无穷、两神、火自烧不假人等破之，引〈我闻品〉 →
  - 复以阿毗昙法门分别三种念处（性念处、共念处、缘念处）之色非色、有漏无漏、三世、内外入、相应因等，极尽法相分别之详。

- **分释余六品及内外观（P227-P330）**：
  - 内外身、内外受、内外心、内外法观之分别（自身他身、身受心受、意识五识、缘内缘外）→
  - 四正勤（性正勤、共正勤，遮二不善集二善）→ 四如意足（慧多定弱故须四种定摄心，喻美食得盐、人二足得好马）→ 五根五力（信为首，增长破烦恼）→ 七觉分（三分：起没心、摄散心、念集遮恶）→ 八正道（正见正思惟正方便正念正定正语正业正命，三分：戒、定、慧；五种邪命别释）→
  - 九地具足多少分别：初禅全具，未到地三十六（除喜觉），二禅三十六（除正行），中间及三四禅三十五，无色定三十二，有顶二十二，欲界亦二十二。

- **摩诃衍义双释及收束（P331-P448）**：
  - 菩萨观身：四大和合如水沫，八万户虫，身相空不可得，无生无相，入无作智门，不惜身命 →
  - 菩萨观受：诸受无所从来灭无所至，三世中不可得，空无相无作入解脱门 →
  - 菩萨观心：心无来去不在内外中间，生灭相续强名为心，客烦恼着故不净，心性本净 →
  - 菩萨观法：一切法因缘生无自性，实空无相无作，入无生法忍门 →
  - 菩萨五根：信根信一切法因缘生如旋火轮如梦幻；精进昼夜除五盖摄五根；念根一心念布施持戒乃至不生不灭；定根善取定相自在出入；慧根为尽苦观三界无常如救头然 →
  - 菩萨知众生根：染欲离欲、钝利、上下、正定邪定不定等无量根相 →
  - 七觉分空：念觉分不忆不念，择法求善不善无记不可得等 →
  - 八正道菩萨义：正思惟断一切思惟分别，正语知语中无语相，正业入一切诸业平等（以「去业」之难破去者去业实有），正命住不戏论智中不见命非命 →
  - 收束：「若菩萨能观是三十七品，得过声闻辟支佛地，入菩萨位中，渐渐得成一切种智。」

## 三、关键结论
1. 三十七品非独小乘法，三藏中不说独是声闻法；《般若波罗蜜摩诃衍品》中明说是摩诃衍；佛以大慈说涅槃道，随众生愿各得其道，如龙王降雨普雨天下，根大者多受根小者少受。
2. 菩萨学九地而不取证、佛地亦学亦证，以般若波罗蜜箭射三解脱门空中、复以方便箭射般若箭令不堕涅槃地——般若与方便双箭相柱是菩萨不取证的关键。
3. 菩萨法中说「世间即是涅槃」，智慧深入诸法故；声闻辟支佛法中不说，智慧不深入故；引《中论》「涅槃际世间际，一际无有异故」为证。
4. 四念处破凡夫四颠倒：观身不净破净倒、观受是苦破乐倒、观心无常破常倒、观法无我破我倒；以阿毗昙门分别性、共、缘三种念处之色非色有漏无漏等法相。
5. 菩萨观三十七品皆入实相空：观身无生无相入无作智门，观受空无相无作入解脱门，观心心性本净客烦恼着故名不净，观法因缘生无自性入无生法忍门；能如是观则超二乘地入菩萨位成一切种智。

## 四、易混辨析
- **声闻三十七品 vs 菩萨三十七品**：声闻以取证涅槃为终，智慧不深入诸法故说世间非涅槃；菩萨以般若方便不取证、久住生死度生，智慧深入故说世间即是涅槃。同一道品，发心与趣向异。
- **般若波罗蜜 vs 方便**：般若箭射三解脱门，是观空之智；方便箭射般若箭令不堕涅槃地，是起用之巧。般若证空，方便扶空入有，二者相柱不堕二边。
- **性念处 vs 共念处 vs 缘念处**：性念处唯取观身受心法之「智慧」自性，无色不可见无对；共念处以观身为首因缘生道（有漏无漏），兼通色（身口业）与名；缘念处以所缘境分别——十入及法入少分为身念处，六受为受念处，六识为心念处，想行众及三无为为法念处。
- **有漏乐 vs 无漏乐**：有漏乐从颠倒爱等结使生、能生大苦，下贱弊恶，乐少故名苦（喻一斗蜜投大河）；无漏乐从三三昧十六圣行生、常无众生相、智慧多故不生染着，上妙而不生着——喻羊近虎虽得美草不能肥。

## 五、阅读提示
带着两个问题读：一者，菩萨既学声闻法，云何不堕声闻地？二者，四念处观不净苦无常无我，与菩萨观身实相「无生无相」、观心「心性本净」如何衔接？前者看般若方便双箭，后者看性念处（智慧性）与缘念处（所缘境）之分、及卷末摩诃衍义之翻转——从破四倒转入实相观。
