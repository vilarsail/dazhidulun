# 大智度论卷第七十四 导读

## 一、内容总览

本卷为《大智度论》卷七十四，含〈释转不转品第五十六之余〉与〈释灯炷品第五十七〉两品，主题一贯——**阿鞞跋致（不退转）菩萨**。前品之余续辨不退菩萨的行、类、相貌：住诸法空中不说世间杂事、能识魔试、护法不惜身命；后品盛赞其功德：七番校量福德，一日如说修行般若，胜恒河沙劫离般若之施，终归于“诸法实相不可说、不可说义无增无减”的深奥处。

## 二、结构层次

**〈转不转品〉之余（先相后义）：**
1. 【经】反面立相：历数“不好说官事、贼事、军事、斗事、妇女事、聚落、城邑、国事、我事”，每条以“诸法（自相）空故”“住实际中”“法性中住”作释 → 正面立相：行六度不为六弊，“但好说般若波罗蜜”，常愿见佛，以方便力生欲界佛前。
2. 【经】明“不疑”：住诸空、四念处、三解脱门，于自地自证了了（须陀洹自了知喻、五逆罪心至死相随喻）→ 依次出三种魔事——魔作佛身劝取阿罗汉、与声闻记、谤“所学非佛说”——菩萨皆觉知不惊 → 护持三世诸佛法不惜身命 → 得陀罗尼故闻法不忘不疑。
3. 【论】逐段释经：“一切法毕竟空，即是如、法性、实际”故不喜世间说 → “生欲界”义在故“留爱、慢分”，不取禅定果报 → 疑由取相（夜见树杌喻）→ 魔试如试金钱“弹之声出”即知真伪 → 狂人谤毕竟空、菩萨没命佐助护法之例 → 闻持、断疑二陀罗尼分释“能受”“不疑”。
4. 【论】问答收束：引《阿毗昙毗婆沙》（过三阿僧祇劫种三十二相因缘）与《毗泥阿波陀那》（然灯佛授记）二旧说，归本经正义——具足六度、得无生法忍、入菩萨位方名不退 → 再分生死肉身/法性生身、佛前授记/不授记、未得者信疑多少二类（修柔顺忍、断法爱进至无生忍）。

**〈灯炷品〉（由相入功）：**
5. 【经】须菩提三叹功德 → 佛说因由：得不共二乘之智慧，生四无碍智 → 问答“深奥处”：空乃至涅槃是深奥，色等一切法亦深奥，以“如非是色、非离色”会通 → 应般若一念超无量劫（淫欲人忆女喻）。
6. 【经】七番校福：离般若而恒河沙劫布施三宝、供养四果、行六度、法施、修四念处乃至一切种智、财法施禅定回向、随喜回向，皆不如深般若中一日如说修行 → 般若是菩萨母、是“第一回向” → 须菩提难“因缘起法从妄想生非实，云何得福” → 佛答善学十八空、福德清净故胜 → 分释无数、无量、无边，归“一切法不可说……是空不可说”、不可说义无增无减 → 无增减云何成佛？佛答：方便力故不作“我增”之念，“但名字故名檀波罗蜜”，如阿耨多罗三藐三菩提相回向 → “一切法如相，是名阿耨多罗三藐三菩提”。
7. 【论】释校福：知福德虚诳而不着故胜（金刚虽小摧大山）、二乘证实际烧尽功德而菩萨不证故有福德；释“空亦复空”、离二边中道、诸法如寂灭相，收于“不增不减、不可得故，疾得无上道”。

## 三、关键结论

- 不退菩萨以“住诸法空相”为体，不好说世间事而唯好说般若；虽行空而乐法、爱法，不着空见。
- 勘破魔试的总诀：“若佛与菩萨受声闻记，终无是处”——凡教人舍菩提趋二乘、谤所学非佛说者，皆魔所为。
- 本经判“不退”以得无生法忍、入菩萨位为准，不同于毗昙（三阿僧祇劫）与毗尼譬喻（然灯授记）二说。
- 离般若之行虽久且多，不及一日如说修行：般若是菩萨母，回向以般若无杂毒为“第一回向”。
- 实相不可说而佛以方便力说；不可说义无增无减，菩萨不作“我增波罗蜜”之念，正因此疾得无上道。

## 四、易混辨析

- **阿鞞跋致 vs 授记**：不退是自证阶位，授记是佛预记作佛；相未具足者虽“从初发心以来名阿鞞跋致”而不与授记，具足则决定受记。
- **柔顺忍 vs 无生法忍**：柔顺忍在前，未断法爱、或生着心或还退没；增长断法爱方得无生忍、入菩萨位，才是真不退。
- **生死肉身 vs 法性生身**：肉身不退犹在生死，有佛前/非佛前授记二种；得无生忍断烦恼、舍身后得法性生身。
- **无数、无量、无边**：不堕有为无为数中名无数，三世量不可得名无量，十方边不可得故名无边；与“不可尽”名字虽异，义是一——毕竟空。

## 五、阅读提示

带着三个问题读：凭什么判定一个菩萨“不退”？（相貌、自证地、勘破魔事三重）为何“一日行般若”胜恒河沙劫布施？（母义、无杂毒、知空不着）无增无减何以还能成佛？（方便力与如相回向）。
