# 大智度论卷第六十二 导读

## 一、内容总览

本卷释《摩诃般若波罗蜜经》之**照明品第四十**与**信谤品第四十一**，含两品经文与论释。照明品承前随喜义：舍利弗赞叹般若诸德，帝释与舍利弗论难“般若将导五度”，佛开示“云何生般若”“般若与何法合”“信般若为信何法”，须菩提结赞般若为“摩诃（大）波罗蜜”；信谤品对比两极：信解深般若者何所从来，毁谤般若的“破法人”受何果报。般若能照一切法毕竟净，众生对之或信或谤，果报天渊。

## 二、结构层次

- **照明品·经（叹般若 → 供养 → 生 → 合 → 信）**
  - 舍利弗连叹般若十余德（照毕竟净、不着三界、除闇、助道法中最上、示导离二边、一切种智、诸菩萨母、不生不灭、转法轮、示诸法性）→ 问“云何供养” → 佛答“如供养世尊”：佛与般若不二，般若出生三乘圣众及十善道、三十七品、佛十力等一切法。
  - 帝释问缘由 → 舍利弗举“生盲无导”喻：五度离般若如盲无导，不得一切种智 → 帝释难“五度不具足亦不名波罗蜜，何独赞般若” → 舍利弗答“住般若中能具足五度”，故最上、第一、无与等。
  - 问“云何生般若” → 佛答“色不生故般若生”，不起、不生、不得、不失 → 问“与何法合” → 答“无所合”，不与善不善、世出世间、有漏无漏、有为无为合 → 帝释追问“亦不合萨婆若耶” → 佛答亦不合亦不得，“如不取、不受、不住、不着、不断，如是合”。
  - 须菩提警策：作念“合与不合”则舍般若，念“般若空无不坚固”亦舍 → 问“信般若为信何法” → 佛答：色乃至一切种智不可得故，信般若即于一切法无所信。
- **照明品·论**：逐句释诸叹（五种法藏、百八烦恼、六十二见、金刚三昧等）→ 释“如供佛”（人久着众生相、于贵法情薄）→ 释盲喻问答（“百千”但显力势；檀中智慧“客来非正体”，如四大不相离；石散、主将喻六度和合而般若力大）→ 释“如佛心合”（不取相、不受、不住、不着、不断）。
- **摩诃波罗蜜段**：须菩提历数般若于色乃至佛不作大小、合散、无量非无量、广狭、有力无力，故名大波罗蜜 → 新发意菩萨作大小等想即“不行般若”，用有所得故有大过失 → 论释凡夫随忆想于色作大小（八背舍随心变色、执微尘为实），般若随色性如实观。
- **信谤品·经（信解者所从来 vs 破法者所堕落）**：舍利弗问信解般若者何所从来 → 佛答从十方诸佛所来、久发心常行六度 → 须菩提问般若可闻可见耶 → 佛答“无闻无见，诸法钝故” → 佛分别二类菩萨：习行深般若者不离诸佛、成就众生净佛世界；用有所得者闻深般若舍去毁呰，堕大地狱展转十方、生盲贱之家 → 问五逆罪相似否 → 佛言不相似，谤般若者自饮毒亦饮他毒 → 问破法人受身大小，佛不为说，足为未来世作明诫。
- **信谤品·论**：释“从他方佛所来者贵” → 释“诸法钝”（诸法入般若如百川归海同一味）→ 释破法业果报次第与百亿阿鼻地狱 → 释五逆不得喻谤般若（出佛身血但坏肉身，毁般若罪无喻）→ 释“衰浊、黑性”与佛不说身大之二因缘。

## 三、关键结论

- 佛与般若不二：供养、礼敬般若即如供养、礼敬佛；般若是“诸菩萨母”，出生三乘圣众与一切世出世间善法。
- 五度如盲、般若如导：五度得般若将导方名“波罗蜜”；六度和合共行，般若力大故独得标名。
- 般若无生无所得：观色等不起不生、不得不失即是生般若；般若不与任何一法合，乃至不合萨婆若——“有所得相者，无阿耨多罗三藐三菩提”。
- 信般若即不信诸法：色乃至一切种智自性不可得，故信般若时于一切法无所信。
- 谤般若罪胜五逆：破法人自失亦令他失，堕阿鼻展转遍历十方；信解者见经卷如见佛。

## 四、易混辨析

- **萨婆若 vs 一切种智**：萨婆若译“一切智”，重知一切法总相；一切种智更能知种种别相、断尽烦恼习气，唯佛具足。
- **须陀洹→斯陀含→阿那含→阿罗汉**：声闻四果——预流、一往来、不还、无生（漏尽不受后有）；辟支佛则无佛之世自观因缘独悟，不假师教。
- **五逆罪 vs 破法（谤般若）罪**：五逆但坏肉身、堕阿鼻一劫；谤般若坏佛母、自他善根俱失，罪遍历十方地狱，故佛言“不应言相似”。
- **五度 vs 般若**：五度各有实事能办，般若无别相可取、唯以照导为功；离般若五度如盲，离五度般若亦心散乱不调顺——六度相须而般若为导。

## 五、阅读提示

带着两个疑问读：其一，“信般若则不信色乃至一切种智”，信与不信何以不矛盾？其二，佛既说“见经卷如见佛”，又说般若“无闻无见”，二者如何相成？论中连环譬喻（生盲无导、四大、石散、主将、百川归海）皆对应经文疑难，宜对照细读。
