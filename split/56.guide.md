# 大智度论卷第五十六 导读

## 一、内容总览

本卷属《大智度论》卷五十六，含三品：释顾视品第三十、释灭诤乱品第三十一及后续功德广说。全卷围绕「般若波罗蜜的功德力用」展开——先由诸天赞叹须菩提所说深般若，佛印证并自述然灯佛本事；次明受持般若者魔不能得便、人不横死；再广说菩萨因缘故世间有三善道、三乘及三宝；末以「世间波罗蜜生高心、出世间波罗蜜不生高心」收束，显般若波罗蜜统摄五度、灭诸诤乱、回向萨婆若而无所得的深义。

## 二、结构层次

全卷以「经→论」交替推进，论中再以问答层层开显，骨架如下：

- **诸天叹深般若 → 佛印证并引本事**：诸天三反称叹须菩提承佛神力说深般若，谓行般若者当视如佛 → 佛然其赞，广说六度乃至一切种智中佛不可得，复引然灯佛授记本事为证 → 诸天解心转深，重复赞叹「不取不舍」。
- **受持般若现世功德 → 内外二缘护持**：佛告释提桓因，听受般若者魔不能得便 → 论释何为魔、何为得便、何故不得便 → 内因缘（善修十八空、四无量心）+ 外因缘（诸天守护）+ 三处不怖（空舍、旷野、人间）。
- **菩萨因缘利益世间 → 供养菩萨即供佛**：诸天白佛，以菩萨因缘故断三恶道、有三乘三宝 → 佛可之，并说供养初发意菩萨胜于满中声闻辟支佛 → 论释三事不如之因。
- **灭诤乱品：般若灭诸法诤乱**：帝释重请今世后世功德 → 佛说外道魔民增上慢人欲坏般若即时灭去 → 摩祇药喻 → 广列淫怒痴、诸见、着五众乃至着涅槃等一切诤乱，般若悉能灭。
- **出世间波罗蜜不生高心**：佛广说菩萨自行教他十善、六度、三昧、陀罗尼、四念处乃至十八不共法 → 回向菩提无所得 → 帝释问何故不高心 → 世间波罗蜜着吾我生高心，出世间波罗蜜三轮体空不生高心 → 论释「初门相似法，后得真道」收束全卷。

## 三、关键结论

1. 般若波罗蜜虽毕竟空而不堕断灭，虽分别三乘而不生着心——般若摄五度乃至一切种智，是三世佛母，故行般若者当视如佛。
2. 受持般若者，内由善修十八空、外由诸天守护，魔若魔民、人非人皆不能得其便，于空舍旷野人间三处不怖不横死。
3. 菩萨虽结业生身未离欲，以方便力能断三恶道、开三善道、出三乘三宝，故供养初发意菩萨福德胜于满三千世界声闻辟支佛。
4. 肉身菩萨道力尚少而魔不得便，以善修诸法空亦不着空故——如无疮不受毒、如火不灭火，三解脱门虽与有相违而无自性故魔不得便。
5. 世间波罗蜜以无方便力着吾我而生高心，出世间波罗蜜不见施者受者施物、不见戒忍乃至一切种智，回向萨婆若故不生高心——是为般若波罗蜜正行。

## 四、易混辨析

- **世间波罗蜜 vs 出世间波罗蜜**：世间者着吾我、取法相（我是施者、彼是受者、是施物），生高心，不能到佛道；出世间者三轮体空，施者受者施物皆不可得，回向萨婆若，不生高心。前者是初门相似法，后者是真道。
- **魔四义**：经论明列四种魔——烦恼魔（贪瞋痴等）、五众魔（色受想行识之身）、死魔（命终）、自在天子魔（他化自在天主）。本卷所论「魔不得便」以般若力坏四魔：断烦恼坏烦恼魔，入无余涅槃坏五众魔及死魔，得实相故天魔不得便。
- **得便 vs 横死**：「得便」指魔随前人所趣向而坏之（现可畏形、现五欲、转人心令供养或令骂打），主由外力破坏；「横死」指无罪而死（错投药、不顺药法、无看病人、饥寒夭命等），主由自身业缘。前者以空观、四无量心破，后者以平等行檀波罗蜜破。
- **善男子善女人 vs 菩萨摩诃萨**：论实相智慧难受、能受者名菩萨摩诃萨；说供养受持读诵等杂事，则通称善男子善女人——特为女人开「五碍不障作佛」之门。

## 五、阅读提示

读此卷可带着两个问题：一、佛为何反复说「视行般若者如佛」「供养菩萨即供佛」？二、般若波罗蜜如何同时「毕竟空」又「有三乘之教」而不堕断灭、不生着心？抓住「无所得」一线，则全卷功德力用自可贯通。
