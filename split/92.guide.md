# 大智度论卷第九十二 导读

## 一、内容总览
本卷是《大智度论》对经文“净佛国土品”（第八十二品）上半的解释，承前品“大庄严”之问而来。须菩提问“何等是菩萨摩诃萨道”，佛答六波罗蜜乃至一切法皆是菩萨道、无有法菩萨所不应学；继而辨明学一切法而不住一切法、菩提与道不一不异，最后转入本品正题“云何菩萨摩诃萨净佛国土”，答以“从初发意来自净三业，亦教他人净”。全卷眼目：空而不废遍学，学而不肯暂住。

## 二、结构层次
- **问菩萨道 → 一切法皆是道**：须菩提心念发问 → 佛历数六波罗蜜、三十七助道法、十八空、八背舍九次第定、佛十力乃至十八不共法，收以“一切法亦是菩萨道”“不学一切法，不能得一切种智”。
- **疑难空与分别 → 实空故须分别**：须菩提难：分别此彼诸法，岂非无戏论中作戏论 → 佛印可诸法实空，正因众生不知空，菩萨得菩提后分别诸法为说 → 观众生所著皆虚诳（小儿聚土为谷喻），故“众生易度”，教行布施持戒而不令著（热金丸喻）。
- **行道而不住**：行六度乃至证四果、辟支佛道皆“不住是中” → 二因缘：道果性空无住处；不以少事为足 → 一心向阿耨多罗三藐三菩提，能生菩提道。
- **四句遣执 → 菩提即是道**：一切法无生，云何生菩提道？——有佛无佛，法相常住，为不知者故生道 → 用生道、不生道、非生非不生道得菩提，三问三“不也” → 佛言“菩提即是道，道即是菩提”，如众水入海同为一味。
- **菩萨应即是佛之难 → 三义分别**：佛反问“佛得菩提不”——佛即菩提，菩提即佛 → 然须具足功德、住金刚三昧、以一念相应慧成佛方名为佛 → 结以“得者是佛，法是菩提，求菩提者是菩萨”。
- **入净佛国土正题**：一佛土摄无量三千大千世界，佛昼三时夜三时以佛眼观谁可种善根、谁应得度 → 净土之本在净三业，内法净故外法净（恶口故地生荆棘、悭贪故水旱不调）→ 层层辨粗业：十不善道、悭贪等六心、戒不净、远离三十七品与三解脱门，乃至贪须陀洹果、辟支佛道（请客不与喻）皆名粗业。

## 三、关键结论
- 一切法实空；正因是空，菩萨能得菩提，也须为不知空的众生分别说法——分别非戏论。
- 菩萨遍学一切法而无所住：一因道果性空、无住处亦无住者，二因不以少事为足。
- 生、不生、非生非不生四句求菩提皆不可得；不取相、不生著即是菩提道。
- 于摩诃衍中取善法相乃至涅槃皆名为粗；贪二乘果证即是欺佛、负一切众生。
- 净佛国土从净三业起：内法净故外法亦净，如面净故镜中像净。

## 四、易混辨析
- **生身菩萨 vs 法性生身菩萨**：前者以父母所生肉身修道，须分别诸法、次第行道；后者得无生法忍、以法性为身，不见诸法好恶，故说“一切法皆是菩萨道”。
- **破戒 vs 戒不净**：破戒是杀生等恼害众生的粗罪；戒不净是不犯所受戒而三毒覆心、不忆念戒、回向天福、邪见持戒等微细垢。
- **阿罗汉 vs 辟支佛 vs 佛**：阿罗汉闻声证四果，辟支佛无师自悟缘起，佛得一切种智、具十力等不共功德；菩萨对前二果“应当得而不应住”。
- **十不善道 vs 悭贪等六心**：十恶皆是恼众生法；悭贪、懈怠、乱心等六法不必恼人而也是菩萨粗业，故须别说。

## 五、阅读提示
带着两问读：一切法空，为什么反而必须遍学一切法？连证圣果为何也算“粗业”？再留意小儿聚土、热金丸、蛇入竹筒、请客负众四个比喻，全卷义理皆从此流出。
