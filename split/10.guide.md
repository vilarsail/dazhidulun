# 大智度论卷第十 导读

## 一、内容总览
本卷为《大智度论》初品中「十方菩萨来释论第十五」之余，紧承前卷放光、诸方菩萨云集之文，正面展开「普明菩萨受宝积佛遣，持千叶金色莲华远来供养释迦牟尼佛」一段因缘。全卷以经论问答交织，先释佛答普明之「动相」与三密义，次释普明欲来之因、莲华供养之仪、一心敬慎之诫，次释四种力共来、中道供养诸佛、头面礼足与一面立、宝积佛问讯之辞、释迦牟尼佛受华转散东方诸佛，次释华满世界、一一华上有菩萨说六波罗蜜，末释十方菩萨云集之相、佛世界神力庄严、华积世界之喻、诸大菩萨住处、天魔梵沙门婆罗门揵闼婆阿修罗等一切皆集之因缘。一线贯穿：由佛不动而说法 → 普明受华远来 → 供养仪轨 → 散华倍福 → 众生云集，层层推出「诸佛等而不碍供养、世界远而法相不异、华少而神力满界、众生无尽而般若大集」之旨。

## 二、结构层次（★重点）
全文以经文段段分隔，论中问答层层推进，可分七层：

- **释佛答普明「动相」与三密（P5-P33）**：问佛如须弥不动何以答普明 → 答「大慈悲风来则大动散，散身无数入五道教化」→ 复次佛实不动身边出声如响、如摩尼珠随心说法、无忆想分别 → 引《密迹金刚经》三密（身密、语密、意密）→ 身密：或见黄金色、或见一丈六尺乃至无量 → 语密：或闻一里或闻十里乃至十二部经八万法聚各各所闻 → 目连寻佛声过无量亿佛世界而不得边际 → 复次佛出世为断疑说法，不应难 → 问诸佛等觉何以称「彼神力」→ 答「示无吾我、彼此灭嫉慢」，诸佛实语不破因缘法相。
- **释普明欲来见佛之因与三昧自在（P35-P61）**：问诸佛戒定慧度人皆等，普明何欲来见释迦 → 答「菩萨见佛、听法、见僧三事无厌」→ 引手居士从净居天来身微细没失如消苏之喻，手居士三事无厌生净居天 → 声闻尚听法无厌况法性身菩萨 → 问菩萨亦一切三昧中得自在？→ 答「二种三昧：佛三昧、菩萨三昧；菩萨于菩萨三昧中得自在，非佛三昧」→ 引《诸佛要集经》文殊尸利不能觉近佛坐入定之女人，弃诸盖菩萨一弹指即觉之 → 佛告文殊：汝因此女初发菩提意，女因弃诸盖菩萨初发意；汝于诸佛三昧中功德未满。
- **释莲华供养与一心敬慎（P63-P164）**：佛告普明「欲往随意，宜知是时」，宝积佛以千叶金色莲华付之，诫言「娑婆世界诸菩萨难胜难及，当一心游彼世界」→ 问佛何以言欲往随意 → 答「爱断不着、未得一切智心中有疑、遥见佛身小生慢、世界虽远法相不异增益大信、先世因缘如绳系雀脚、娑婆菩萨见普明远来必自愧」→ 问诸佛力等何以华 为信 → 答「随世间法如二王相赠遗、示善软心、诸佛以法为师三世诸佛皆以法实相为师」→ 问佛不求福德何以供养 → 答「敬功德故、教化弟子故」，引盲比丘纴针之喻、百岁老翁舞之喻 → 问佛何不自遥散而遣人 → 答「为此间菩萨信普明故、佛所遣使水火兵毒不能伤」→ 问何以莲华不以好宝深经 → 答「佛不须物、华香清妙、莲华三种类（人华十余叶、天华百叶、菩萨华千叶）、彼世界多有金色千叶莲华而娑婆唯有化华」→ 问何以散华不上 → 答「身业口业意业三业得功德牢固」→ 问何以言一心敬慎 → 答「佛辟支佛阿罗汉皆一心敬慎，魔若魔民内身结使先世罪报皆是贼」→ 引优波鞠与百二十岁比丘尼麻油试威仪之喻：六群比丘弊恶而威仪胜六通阿罗汉 → 复次娑婆菩萨苦处生故智慧利、多方便故难近，引佛自说一日施人千命之喻。
- **释四种力共来与七众俱来（P166-P196）**：问出家在家童男童女云何自致 → 答「尽是四种人力：自力、普明菩萨力、宝积佛力、释迦牟尼佛光明照之」，如转轮圣王飞上天四种兵宫观皆飞 → 问何不独来而多将众人 → 答「翼从所宜如国王出必有营从、有因缘者来无因缘者住」→ 问何以与七众俱 → 答「佛弟子七众：比丘比丘尼学戒尼沙弥沙弥尼优婆塞优婆夷；优婆塞优婆夷居家余五众出家，大小二种小者童男童女；在功德不在大小，外道法中婆罗门得行非婆罗门不得，佛法无大小无内外皆得修行，如服药以除病为主」。
- **释中道供养诸佛与药王以身供养（P198-P216）**：问皆供养东方诸佛何时得讫 → 答「菩萨供养法身入禅定从身边出无量身化作种种供养之物满诸佛世界如龙王行时普雨天下」→ 问中道何故供养 → 答「诸佛第一福田得大果报、菩萨敬佛如敬父母、蒙佛说法得三昧陀罗尼神力知恩故广供养」→ 引《法华经》药王菩萨得一切变现色身三昧飞上天雨七宝华香、千二百岁服香饮油以白叠缠身而烧、身然千二百岁不灭，诸佛赞言「以身供养第一胜国城妻子百千万倍」→ 复次供养佛得无量名闻福德灭不善增长善根、久后作佛。
- **释头面礼足一面立与宝积问讯（P218-P292）**：问何以名头面礼足 → 答「头第一贵足第一贱，以所贵礼所贱；复次下中上礼：揖、跪、稽首，头面礼足是上供养；毗尼中下坐比丘捉上坐足以头面礼」→ 问何故一面立 → 答「为来不应行、为恭敬不应卧、立者恭敬供养法；外道轻佛故坐、白衣如客故坐、五众身心属佛故立；得道阿罗汉所作已办听坐，余虽得三道结贼未破不听坐；菩萨虽白衣以远来供养故立」→ 问宝积佛一切智何以方问讯释迦少恼少患兴居轻利气力安乐 → 答「诸佛法尔知而故问如问达贰迦作瓦窟；随世界法世人问讯佛亦问讯；佛人中生受人法寒热生死与人等；欲示佛世界身色光明胜而智慧神力等无异」→ 复次二种病：外因缘（寒热饥渴兵刃坠落等）为恼、内因缘（饮食不节卧起无常四百四病）为内病 → 圣人实知身为苦本四大合而为身地水火风性不相宜各各相害如疽疮无不痛时常病常治 → 复次二种问讯：问讯身（少恼少病兴居气力）、问讯心（安乐不）；身病淫欲瞋恚嫉妒等九十八结五百缠为心病 → 佛身二种：神通变化身、父母生身；父母生身受人法不如天故应如人法问讯。
- **释释迦受华散东方诸佛及庄严世界（P294-P569）**：佛受莲华已散东方恒河沙等世界中佛 → 问佛无胜何以供养 → 答「供养有上中下：下于己、胜己为上、等己为中；诸佛供养是中供养」→ 引大爱道比丘尼与五百阿罗汉比丘尼入涅槃，佛自在前擎香炉烧香、诸阿罗汉取牛头栴檀助之、是为下供养之例 → 唯佛应供养佛、智人能敬智如蛇知蛇足 → 复次十方佛世世劝助释迦：引七住菩萨观诸法空欲放舍六波罗蜜入涅槃，十方诸佛放光摩头诫以本愿度众生、未得金色身三十二相八十种随形好 → 佛初得道念法甚深欲分一法作三乘，十方佛现光赞言「我等亦在五恶世分一法作三分」，佛闻即称南无佛 → 华为宝积功德力所生非水生，普明十住法身菩萨送来，释迦知十方佛第一福田故供养福倍多 → 佛法中四种布施，今施东方诸佛二俱清净福最大 → 问圣人不受报福何大 → 答「是福虽无人受其相自大；诸圣知有为法无常空故舍入涅槃，譬如烧金丸虽好不可以手触；诸佛以身为疮舍放身疮故亦不受报药」→ 华满东方世界：佛神通力八种自恣变化法大能令小等 → 一一华上皆有菩萨结加趺坐说六波罗蜜 → 上化华有坐佛今普明供养华有坐菩萨，众生应见何身得度故 → 南西北上下上十方皆如东方 → 问佛法中实无诸方名今何以说十方 → 答「随世俗法说方，求方实不可得」，破日出处为东方等执，须弥山在四域中日绕须弥照四天下，皆东方皆南方，方但有名无实 → 佛入四禅中十四变化心庄严三千大千世界皆悉为宝为说般若波罗蜜 → 宝有四种金银毗琉璃颇梨，七种加车磲马瑙赤真珠，更复有摩罗伽陀因陀尼罗等，三种有人宝天宝菩萨宝 → 华积世界普华世界妙德菩萨善住意菩萨及大威神菩萨在彼住 → 何以华积世界为喻：彼世界常有净华此世界变化一时、阿弥陀佛安乐世界不如华积世界（法积比丘功德薄不能见上妙世界）→ 遍吉菩萨一一毛孔出诸佛世界无适住处，文殊尸利分身入五道或作声闻缘觉佛身、过去作龙种尊佛七十二亿世作辟支迦佛 → 佛知一切世界天魔梵沙门婆罗门揵闼婆人阿修罗及菩萨绍尊位者皆集 → 问佛神力何不令尽来 → 答「诸佛世界无边无量若尽来则成有边，十方各各有佛亦说般若波罗蜜」→ 问既有十方佛十方菩萨何来 → 答「与释迦因缘故来、本愿听受供养般若故来、以身力积功德示众生故来」→ 问佛于法不着何故令大集 → 答「般若甚深难解不可思议广集大菩萨令新发意者信乐如小人语不信贵重人语必信」→ 何以言天魔梵等三主：释提婆那民依地住常来佛所、魔王常娆佛今来听般若余人增益信、梵世界近又四识易闻又梵名离欲清净总说色界 → 沙门婆罗门智慧人有二分、余人心存世乐故不说 → 何以独说揵闼婆：是天伎人随逐诸天心柔软福德小减诸天，鬼神道摄龙王畜生道摄，甄陀罗亦天伎属天，揵闼婆王名童笼磨，恒在十宝山间天上作乐常番上下 → 阿修罗恶心斗诤不破戒大修施福生大海边城郭宫殿，王名毗摩质多婆梨罗睺罗 → 引罗睺罗欲啖月月天子求佛、佛说偈敕罗睺罗放月、婆梨问、罗睺罗答、婆梨赞佛之偈 → 问何以不说地狱畜生饿鬼 → 答「地狱大苦心乱、畜生愚痴覆心、饿鬼饥渴烧身不得受法；少有来听法者生福德心而已」→ 问揵闼婆阿修罗亦应不说（鬼神道摄）→ 答「佛不说摄，是迦旃延子等说；阿修罗力与天等或时战斗胜天、揵闼婆天伎有智慧能别好丑，如《杂阿含》富那婆薮鬼神母闻法得道」→ 复次摩诃衍中密迹金刚力士于诸菩萨中胜，屯仑摩甄陀罗王揵闼婆王弹琴赞佛三千世界震动乃至摩诃迦叶不安其坐 → 问佛是天人师不说三恶道龙鬼皆堕恶道 → 答「佛亦不分明说五道，是一切有部所说；婆蹉弗妒路部说六道，应有六道：三恶道一向罪处，若福多罪少应别立阿修罗揵闼婆等生处」。

## 三、关键结论
1. 佛虽常入深禅定不为世事所动，然大慈悲风来则怜愍心动散身无数入五道教化；佛实不动而身边出声如响、如摩尼珠随心说法无忆想分别，依《密迹金刚经》佛有三密身语意密，一切诸天人不解不知；目连以神足过无量千万亿佛世界闻佛声如近，寻佛声过无量亿劫不得边际。
2. 菩萨见佛、听法、见僧三事无厌足，于世间法皆厌患，于上三事心无厌；三昧有二种——佛三昧与菩萨三昧，菩萨于菩萨三昧中得自在非佛三昧中，如文殊尸利不能觉《诸佛要集经》中近佛坐入定之女人，弃诸盖菩萨一弹指即觉之，以女因弃诸盖菩萨初发菩提意故。
3. 诸佛力等而以莲华为信，随世间法如二王相赠遗，示善软心；诸佛恭敬法以法为师，三世诸佛皆以诸法实相为师；佛虽功德已满而敬功德恩、为教化弟子故而作供养，如盲比丘纴针、百岁老翁舞之喻；莲华三种类人华十余叶天华百叶菩萨华千叶，彼世界有金色千叶莲华而娑婆唯有化华千叶，故遣。
4. 娑婆世界菩萨难胜难及难破难近：以苦处生故乐因缘少有三恶道老病死土地自活法难，易生厌心故智慧根利；譬如利刀着好饮食便生垢，以石磨之脂灰莹治垢除刀利；菩萨多方便故难近，佛自说一日施人千命、六波罗蜜一切佛事具足而不作佛恒以方便度脱众生。
5. 普明等七众俱来尽是四种人力——自力、普明菩萨力、宝积佛力、释迦牟尼佛光明照之；如转轮圣王飞上天时四种兵宫观畜兽一切皆飞从。佛弟子七众，优婆塞优婆夷居家余五众出家；在功德不在大小，佛法无大无小无内无外一切皆得修行，如服药以除病为主不择贵贱大小。
6. 佛虽无胜而行供养，供养有上中下：下于己、胜己为上、等己为中，诸佛供养是中供养；十方佛世世劝助释迦——七住菩萨观空欲入涅槃时十方佛放光摩头诫以本愿度众生、佛初得道欲分一法作三乘时十方佛现光赞言我等亦尔；佛法中四种布施今施东方诸佛二俱清净福最大；圣人不受报而福相自大，诸佛以身为疮舍放身疮故不受报药。
7. 佛入四禅中十四变化心能令三千大千世界华香树木一切土地皆悉庄严，为说般若波罗蜜故、为十方菩萨客来及诸天世人故庄严；宝有三种人宝天宝菩萨宝，菩萨宝胜能出种种法音、雨十方诸佛上供养之具、雨衣被卧具给施众生；华积世界常有净华故以为喻，阿弥陀佛安乐世界不如华积世界（法积比丘功德薄不能见上妙清净世界）。
8. 佛法中实无诸方名——五众十二入十八界所不摄四法藏中亦无，说方是实法因缘求不可得；须弥山在四域中日绕须弥照四天下，皆东方皆南方皆西方皆北方，方但有名而无实；一切有部说五道、婆蹉弗妒路部说六道，应有六道——三恶道一向罪处，福多罪少者应别立阿修罗揵闼婆等生处。

## 四、易混辨析
- **佛三昧 vs 菩萨三昧**：佛三昧是佛所证究竟之三昧，菩萨于菩萨三昧中得自在而于佛三昧中功德未满少多入而未得自在；如文殊尸利不能觉近佛坐入定之女人而弃诸盖菩萨一弹指即觉之，以女因弃诸盖初发菩提意而文殊因此女初发意，故知菩萨三昧中自在佛三昧中未满。
- **神通变化身 vs 父母生身**：佛身有二种——一者神通变化身，二者父母生身；父母生身受人法故不如天，故应如人法问讯少恼少患兴居轻利气力安乐；神通变化身则不须如是问讯。诸佛恭敬法故以法为师，三世诸佛皆以诸法实相为师，此依法不依人身之精神贯穿全卷供养义。
- **人华 vs 天华 vs 菩萨华**：莲华三种——人华大莲华十余叶、天华百叶、菩萨华千叶；彼多宝世界多有金色光明千叶莲华是菩萨华，娑婆世界唯有化华千叶无水生者故遣华为信；供养唯以华香幡盖，华有色有香故宜为供养。
- **人宝 vs 天宝 vs 菩萨宝**：人宝力小唯清净光色除毒鬼闇饥渴寒热；天宝大而胜常随逐天身可使令可共语轻而不重；菩萨宝胜于天宝兼人天宝事，复能令众生知死此生彼因缘本末如明镜见面像，能出种种法音雨十方诸佛上供养之具。
- **五道 vs 六道**：一切有部僧说五道，婆蹉弗妒路部僧说有六道；应有六道之理——三恶道一向是罪处，若福多罪少者应别立生处，是名阿修罗揵闼婆等生处应别；佛亦不分明说五道，是部派所说。

## 五、阅读提示
本卷问答极密而层次分明，可抓「普明受华远来 → 供养仪轨 → 散华倍福 → 十方云集」四段总骨架。前段留意「三密」「二种三昧」「三事无厌」三节点；中段留意「莲华三种类」「三业得功德牢固」「娑婆菩萨苦处生智慧利」诸义；后段留意「四种布施二俱清净福最大」「七住菩萨十方佛摩头诫」「八种自恣变化法」「方但有名无实」诸节点。末段宝之分类、十方菩萨来与不来之因缘、五道六道之诤，皆是法相度量与部派义门之关键，宜细读。
