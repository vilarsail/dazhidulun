# 大智度论卷第八十四 导读

## 一、内容总览

本卷是《大智度论》卷八十四，"释三慧品第七十之余"，续前卷解释《大品般若经》〈三慧品〉的后半。"三慧"即全卷反复辨析的三种智慧：一切智（萨婆若）、道种智、一切种智。全卷以须菩提与佛的问答贯串，紧扣一个总疑难：诸法无所为、无所作、如幻如化，为什么还有三乘、三聚、断惑高下、般若之名？论释随文作疏，多用"问曰／答曰"自设宾主，间列"有人言""复有人言"诸说，最后归结于"无所得即是得"。

## 二、结构层次

经文一波接一波推进，论释逐段随文疏解：

- **立疑总起 → 化人喻**：诸法无作无起，云何分别三乘、三聚？→ 佛答：皆世俗法故说，非第一义；我得菩提"无所住"，不住有为相、无为相 → 引出化人喻：化人行六度、得菩提、转法轮、度化众生，实无众生可度，佛亦如是。
- **真化无差 → 供养等福**：佛与化人有何差别？→ 无差别 → 供养化佛福德亦不尽 → 论中广辩：恶心出化佛身血亦得逆罪、毗尼结戒逐假名不论实相、"意业最大"，乃至一称"南无佛"福至毕苦不尽。
- **名相不坏实相**：佛既分别说色受想行识等，岂不坏诸法相？→ 但以名字相示法令众生解 → 一切法但有名相，名相亦空、不住名相中 → 菩萨知名相空，离有离无处中道，故能发心行道度生。
- **三智分齐 → 实际作证**：萨婆若＝二乘智；道种智＝菩萨智；一切种智＝佛智 → 四句征问"住何处实际作证" → 佛反问须菩提："汝住道中漏尽得解脱不？"→ 无所住、不受诸法而证实际。
- **断惑无异、断习有异**：三乘断烦恼无差别，断习有差别 → 蜜婆私诧猕猴跳树、毕陵伽婆蹉唤恒神"小婢"，明二乘习在；骂赞无异、食马麦、空钵而出，明佛习都尽 → 自相空中前际后际俱不可得。
- **般若释名义 → 无所得**：以"第一度""到彼岸""析法至微尘不得坚实""如、法性、实际摄入""一相无相""能生诸智乐说照明"释般若名义 → 行深般若义：无常苦空无我与十智，唯如实智如如意宝 → 义与非义皆不可得（贪欲非义、无记非义非非义、一如相）→ 不以二法、不以不二法——"无所得即是得"。

## 三、关键结论

- 三乘、三聚、前后际等一切分别都是随世俗言说，第一义中诸法无作、无起、无分别。
- 真佛与化佛无差别，同以诸法实相为福田；供养乃至一称南无佛，福德至毕苦不尽。
- 佛说法但以名字相引导众生，不坏法相；菩萨应知名相亦空，离有离无、处中道而行。
- 三智有高下：二乘总相知一切法，菩萨知一切道度生而不取证，佛寂灭遍知、习气都尽。
- 得一切种智不以二法、不以不二法："无所得即是得，以是得无所得。"

## 四、易混辨析

- **一切智（萨婆若）vs 道种智 vs 一切种智**：本卷判位——一切智是声闻、辟支佛智，总相知内外诸法皆无常苦空无我；道种智是菩萨智，遍知人天及三乘一切道，用以度生而暂不实际作证；一切种智是佛智，通达寂灭相又了了知一切法名相行类。别处常以"萨婆若"泛称佛智，本卷特判归二乘，是论家的判教分齐。
- **烦恼 vs 烦恼习**：烦恼是心垢，三乘同断无差别；习是断后残留的身口惯习（如猕猴跳树、唤"小婢"），似烦恼而非真烦恼，二乘未尽，佛都尽。
- **义 vs 非义 vs 非义非非义**：六度等善法名"义"，贪瞋痴等烦恼名"非义"，色等无记法两者皆非；实相一如相中无义与非义，菩萨应离义非义而行般若。
- **有为般若 vs 无为般若**：学有为般若，具足六波罗蜜、住十地；学无为般若，灭一切烦恼习、成佛道；得萨婆若皆"不以二法故"。

## 五、阅读提示

带着两问去读：诸法如化无实，菩萨为何还要发心度生？（名相空故能离二边、处中道）既无所得，佛与二乘的高下又在哪里？（习气断与不断、如实智具足与否）。
