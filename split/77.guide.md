# 大智度论卷第七十七 导读

## 一、内容总览

本卷为《大智度论》卷七十七，释《摩诃般若波罗蜜经》〈梦中不证品〉之余、〈同学品〉、〈等学品〉三品，主题一贯：一切法空，如何修行、如何同学。先总说般若相如虚空、无所有，诸法亦然；再说行深般若者如何自利利他、如何共住防魔；最后以诸空立「等法」，明所学之体与学之功德。

## 二、结构层次

全卷三品皆「【经】问答 → 【论】释疑」相间，骨架如下：

1. **梦中不证品之余**：须菩提问般若相 → 佛答「如虚空相、无所有相」，且「如般若相，诸法相亦如是」 → 须菩提难：「若一切法离相、空相，云何知众生若垢若净？」 → 佛以我、我所心之有无释垢净：执我则烦恼→业→往来生死，是垢；般若照破则烦恼、业灭，往来中断，是净 → 以「阎浮提众生尽得菩提而供养之，不如于大众中说般若」两番校量福德，明菩萨是最大福田，六波罗蜜是「大智光明」 → 一连串「是X行般若不？」的否定问答（空、离空、般若自体、五蕴、六度乃至如、实际，皆不「行」般若） → 佛以反问层层逼出「无生法忍」，进而辨受记：生、无生、非生非不生皆不得记，慧眼不见有法得记者。

2. **同学品**：帝释叹闻深般若、不杂余心心数法者「不从小功德来」 → 比丘当面言其福德胜于帝释，帝释自谦「一发心便胜我」，层层校量至「胜行般若无方便力者」 → 佛为阿难广说魔娆乱菩萨之相（六种「魔得其便」、菩萨斗诤结恨不悔则罪不可出、忏悔和解之法） → 归结于「菩萨共住，相视当如世尊」，共乘六度之船，同戒同见同道，是名「同学」。

3. **等学品**：须菩提问菩萨「等法」 → 佛答内空乃至自相空；为色尽、离、灭、不生故学是学萨婆若，复以「学如」（不证不断、不增不减）正之 → 广说学之功德（尽诸学边、不堕恶道边地、不生长寿天、总摄诸波罗蜜——如我见摄六十二见、命根灭余根随灭） → 末以三句递进辨正行般若：作念「我用般若得一切种智」是邪行，不作是念是遮邪，知一切法如、法性、实际常住而于中不诤方是正行。

## 三、关键结论

- 般若以虚空、无所有为相；「不见有行般若者」非废修行，恰是无生法忍、得受记处。
- 垢净不系于法之实有，而由我、我所心之有无而立。
- 以着心、得心问受记，佛皆答「不」；第一义中无得者、无得处，无诸忆想分别即是真受记。
- 菩萨共住应相视如佛；斗诤结恨不悔，须历尔所劫补大庄严，罪不可出。
- 深般若总摄诸波罗蜜、令诸度增长，学般若即「尽诸学边」。

## 四、易混辨析

- **萨婆若 vs 一切种智**：萨婆若（意译「一切智」）泛指佛智，「应萨婆若心」即念念趣向佛智之心；一切种智特指知一切法总相别相、究竟圆满之智。本卷二者常互换。
- **行五波罗蜜 vs 行般若波罗蜜**：离般若行五度，福德虽多而有尽，如草芥；般若不可尽，如金刚，导余度到彼岸、总摄诸度。
- **无生法忍 vs 受记**：世俗谛说「得无生忍故受记」；第一义中无生法不生不灭、无得相，实无受记者与受记处。
- **生死肉身 vs 法性生身**：得无生忍前以肉身往来生死；得忍后舍肉身得法性生身，住果报神通，一时化作无量身度众生。

## 五、阅读提示

抓住「空与行」这对张力：经中一路否定「谁在行般若」，是为剥尽取相、得相之心，而非取消修行；再带着「斗诤之罪何以重过寻常忏悔」去看同学品，即得本卷劝学、劝和之旨。
