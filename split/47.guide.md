# 大智度论卷第四十七 导读

## 一、内容总览

本卷属《大智度论》卷四十七，为「释摩诃衍品第十八之余」。承接上卷以十八空释般若波罗蜜，本卷转向以「百八三昧」释禅波罗蜜，是「摩诃衍」（大乘）体量的又一展开。全卷由【经】【论】两部分构成：【经】先总列一百零八个三昧名号，再以「云何名…」逐一举名释义，末了结归「是名菩萨摩诃萨摩诃衍」；【论】则由龙树逐条重释，因古时人利根可信受佛说，今人根钝，故论主广为因缘分别，使百八三昧义皆易解。

## 二、结构层次

全文按「总列名相 → 逐名释义 → 论主重释 → 归宗般若」一线展开：

- **经·总列（P5）**：以「首楞严三昧」起、以「离着虚空不染三昧」终，一口气罗列百八三昧之名，构成全卷的相谱 → 此为「标相」层。
- **经·释义（P6）**：对每一三昧作「云何名 X 三昧？住是三昧…，是名 X 三昧」的固定问答，皆以「住是三昧能…于诸三昧」句式展开，显示一三昧即统摄、印持、照明、破散一切三昧 → 此为「释相」层，以同一结构贯穿百八。
- **经·收束（P7）**：结云「须菩提！是名菩萨摩诃萨摩诃衍」，将百八三昧总归摩诃衍 → 此为「归宗」层。
- **论·重释（P9–P157）**：先明重释因缘（今昔根异，P10–P11），再逐条释义，每条多引喻、立法相、辨异义，如金刚之喻分三义（金刚、金刚轮、如金刚，P79–P82）、不动三昧立四解（四禅、四无色、灭尽定、实相相应，P60–P63）、散疑三昧立三解（见谛道、无生法忍、无碍解脱，P115–P118）→ 此为「广分别」层。
- **论·结归（P158–P165）**：以两段问答收束——一问「佛多说诸三昧，汝何以但说诸法」，答以因缘果报合说、佛应机但说一法而论者广分别（P159–P163）；一结云「是诸三昧末后皆应言用无所得，以同般若故」，终归百八三昧和合名为摩诃衍 → 此为「会归般若」层。

层与层之间以「复次」「有人言」「问曰/答曰」衔接，经论之间以「释曰」过渡，结构极整。

## 三、关键结论

1. **百八三昧即禅波罗蜜之相**：上以十八空释般若，今以百八三昧释禅，二波罗蜜在此合观，般若为体、禅为相。
2. **一三昧即摄一切三昧**：经中每一三昧释义皆以「于诸三昧」为宾语，显示一三昧中具足一切三昧，相相相入。
3. **金刚三义有别**：初「金刚」能破诸法入无余涅槃，次「金刚轮」破而无碍，后「如金刚」贯穿诸法而不见通达——名字虽同，义与因缘各异，不应一概难之。
4. **末后皆归无所得**：百八三昧末后皆应言「用无所得」，以同于般若故；着三昧相者（如着虚空）尚须离着，方名真三昧。
5. **佛说果报、论说因缘**：佛应机但说一法（如说爱为苦因），论者广分别诸事，故经但举三昧之名，论则一一明其行相、喻譬、所破、所成。

## 四、易混辨析

- **般若波罗蜜 vs 禅波罗蜜**：上卷以十八空释般若（慧度），本卷以百八三昧释禅（定度）；般若为能观之智，三昧为所住之定，二者末后会归「无所得」。
- **金刚三昧 vs 金刚轮三昧 vs 如金刚三昧**：金刚破诸法入无余涅槃（如释提桓因执金刚破修罗）；金刚轮破而无遮无碍（如轮转无所不破）；如金刚贯穿一切法而不见通达（学人末后心，从此出三菩提）。
- **不动三昧四种解**：第四禅（离出入息）、四无色定（离色）、灭尽定（离心心数）、实相毕竟空相应——前三是事相不动，第四是理相不动，得已于一切法不戏论。
- **一行三昧 vs 不一行三昧 vs 妙行三昧**：一行是毕竟空相应更无余行次第，不见此岸彼岸；不一行是与上一行相违之余观行；妙行是毕竟空相应乃至不见不二相、一切戏论不能破。

## 五、阅读提示

读此卷可带着两个问题：其一，百八三昧名号虽繁，结构为何如此整齐？答案在「住是三昧能…于诸三昧」的固定句式——一三昧即印持、照明、破散一切三昧，所谓百八只是观门之异名。其二，论主为何要重释佛已说之义？答案在 P11「今则不然」——根机异故，须以因缘、譬喻、辨异再开演。末后 P164「皆应言用无所得」一句是全卷眼目，不可略过。
