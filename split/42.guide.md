# 大智度论卷第四十二 导读

## 一、内容总览

本卷为《大智度论》卷四十二，释《集散品第九》之余并展转接入「不住门」「不受三昧门」与「先尼梵志得道」之因缘。全卷以须菩提与佛往复问答为经，以龙树菩萨层层释论为纬，核心是借「集、散不可得」破菩萨字与一切法名字，再由「色即是空、空即是色」收束于「不住」「不受」的般若正行，并以先尼梵志求道证成法空非大乘独擅——小乘中亦有法空。贯穿线索：集散不可得 → 名字无住 → 色空相即 → 不住诸法 → 不受三昧 → 先尼证信。

## 二、结构层次（文章的骨架与逻辑推进）

- **经·集散不可得（破菩萨字）**：须菩提自陈「不觉、不得是菩萨行般若波罗蜜」→ 历举色乃至识、眼乃至意、六波罗蜜乃至十八不共法、如梦五阴、如法性实际、善不善有为无为、十方诸佛——皆不得集散 → 结论「是字不住亦不不住，无所有故」。逻辑由总（一切诸法）到别（五蕴、十二入、十八界、谛缘度、佛果），层层铺开「不可得」。
- **论·释集散义（成立不可得）**：先答「重说」之问——四爱中法爱过患难见故重说 → 释「不觉不得」非智慧少，乃法本无故 → 以眼色因缘生识、三事和合生触受想思为「集」、念念灭因缘离为「散」，喻以田谷运聚散民 → 生无来处、散无去处，故集散皆不可得。
- **论·释名字无住（车喻众生喻）**：名字依法和合立，法空故名字无住处 → 车由轮辋辐毂和合得名、散则失名 → 五众和合有众生字、离散则名字无住 → 反证「若名字在法中，说火则烧口」之过，故「非住非不住」。
- **经·异门破（梦虚空喻）+ 不住门**：换门径重破菩萨字——菩萨非五众、五众非菩萨，离不离皆不可得 → 梦中虚妄、虚空无相、四大慧眼观之皆虚诳 → 戒定慧解脱知见乃至圣果皆空 → 结「闻是说不惊不畏，是菩萨必住阿鞞跋致性中」。
- **经·不住门（色即是空）**：于色受想行识乃至老死、四念处乃至十八不共法、六波罗蜜中不应住 → 因「色空不名为色，离空亦无色，色即是空空即是色」→ 诸法自相空故无所住。
- **经·文字神通门 + 无常苦空门 + 陀罗尼三昧门 + 不受三昧**：扩至字门、神通、无常苦无我寂灭离、如法性实际、陀罗尼三昧门皆不应住 → 「无方便以吾我心住色」则作色行、不具足般若、不得萨婆若 → 色不受则非色性空故 → 是名「不受三昧广大之用，不与声闻辟支佛共」→ 十八空故一切不受。
- **经·先尼梵志证信（收束）**：先尼梵志于一切智不生信，以性空智入诸法相，非内外非无智慧观得见 → 此岸彼岸不度、色乃至十八不共法不受、亦不取涅槃 → 论释其得道因缘：六师生处异同之问 → 佛破其「我」于一一色受想行识如去中皆不得 → 先尼闻之得道出家证罗汉 → 释「我即如去，诸法无所属」，结「非法亦非非法」。

## 三、关键结论

1. 集散不可得：生无来处、灭无去处，毕竟空故集不可得，业因缘不失故散不可得——是为「集散相」之略说，菩萨字于此中立，故「不住亦不不住」。
2. 名字无住：名字依因缘和合假立，法空故名字无住处；强为立名，其名亦无所有，非住非不住。
3. 色即是空空即是色：诸法自相空，离空无色、离色无空，菩萨于色乃至老死、六度、十八不共法中皆不应住。
4. 不受三昧广大之用不与二乘共：以十八空观一切法不受，萨婆若慧亦不受；二乘虽有不受理而不广大不坚固、有习气碍障，菩萨久来知一切法不受皆如无余涅槃毕竟空。
5. 法空非大乘独擅：先尼梵志以小乘因缘证无我，诸法无所属如幻如梦，引证小乘尚有法空，况大乘者而不信。

## 四、易混辨析

- **集 vs 散**：集是因缘和合相续生（如三事和合生触、展转种业受报无穷），散是念念灭因缘离散；非如田谷之运聚散民，生无来处、灭无去处，故二皆不可得。
- **不住 vs 不受**：不住侧重「行般若时于诸法中无所依止」（色空相即故），是般若行的能立；不受侧重「色不受则非色性空故」，是般若行的能破，由不住入不受，由不受显十八空之广大用。
- **阿鞞跋致性 vs 阿鞞跋致（无生法忍）**：本卷明言「是菩萨未得无生法忍、未从诸佛授记，但福德智慧力故能信乐诸法毕竟空」，是得阿鞞跋致气分，如小儿在贵性中生虽未成事以姓贵故便贵——是「性中住」而非已得忍已授记。
- **二乘不受三昧 vs 菩萨不受三昧**：二乘漏尽时得不受，但无广大用、不利不深、不坚固、有习气碍障（如摩诃迦叶闻菩萨伎乐不能自安）；菩萨久来知一切法不受皆如无余涅槃毕竟空，惟佛遍知。
- **欲着 vs 见着**：观无常苦等可破欲着得解脱，犹着法生见者，须分别色相空以离见着——故不仅破五众欲着，更破于善无记法中取相生罪之见着。

## 五、阅读提示

读此卷宜紧扣「集散」二字作主轴：每见须菩提举一类法（色、六度、诸佛、实相）皆说「不得集散」，即知其以「不可得」贯通境、行、果。再随龙树「车喻」「先尼问佛」两处叙事停驻，前者显名字无独立实体，后者显无我之理通大小乘。末段「不受三昧不与二乘共」与「十八空」是全卷着力处，可对照《大品》「实际品」「不退品」参看。
