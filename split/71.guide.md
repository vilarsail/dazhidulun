# 大智度论卷第七十一 导读

## 一、内容总览

本卷为《大智度论》第七十一卷，释《摩诃般若波罗蜜经》〈大事起品〉〈譬喻品〉〈善知识品〉〈趣一切智品〉四品。全卷围绕一个总问题：**菩萨凭什么不中途退堕二乘、直趣佛果？**答案凝成一句——有无般若波罗蜜与方便力的守护。般若含受五度与一切佛法，为大事故起；行六度时若以我我所心分别执著，便中道衰耗、堕声闻辟支佛地；无我我所、远离此彼岸，便得到萨婆若。

## 二、结构层次（文章骨架）

- **大事起品**：须菩提赞般若为大、不可思议、不可称、无有量、无等等事故起 → 佛印证：般若「含受」五波罗蜜、诸空、道品、佛十力乃至一切种智（灌顶王委政大臣喻） → 「含受」之由在「不取、不着」：「不见故不取，不取故不着」，色乃至一切种智皆然 → 诸天子赞：二乘「若智、若断」即菩萨无生法忍，然不及菩萨一日行深般若 → 佛答闻深般若即时信解者从何处来：人中、他方佛所、弥勒菩萨所；先世「不问中事」者今生疑悔难悟 → 判下、中、上三品行相。
- **论释一**：答「何以重说甚深」——大王积年求得嫡子，使者十反告喜，王乐闻不已，「一语十万两」；深浅无定，随解者无深 → 释二乘智断即菩萨无生忍：所缘同（如、法性、实际），但二乘无大悲方便、不能于涅槃自反（众水入海，惟大力者能自出）；大臣功业虽大，不及太子。
- **譬喻品**：佛连说五喻，每喻正反对举——破船取浮囊得渡／不取者没海死；坏瓶盛水还归于地／熟瓶安隐持水；未庄治之船中道坏没、估客亡宝／庄治大船安隐到岸；老病人不能远行／两健人各扶一腋则随意所至 → 归结：为般若、方便力所护者得到萨婆若，不护者中道衰耗堕二乘 → 佛更自问答有方便／无方便：以我我所心行六度、以功德自高则堕；无我我所心、知「远离此彼岸是波罗蜜相」则到。
- **论释二**：释信、忍、净心、深心、欲、解、舍、精进八法之义 → 配五喻：船是行者身，浮囊是般若方便，老病人喻不断六十二邪见、百八烦恼，两人即般若与方便 → 点睛之句：「般若能灭诸邪见、烦恼、戏论，将至毕竟空中；方便将出毕竟空。」
- **善知识品**：新学菩萨先亲近供养善知识，受教「一切回向菩提」「莫以诸法是菩提」（诸法性空故） → 论谓性空有二：大菩萨所得、小菩萨所学柔顺忍（金翅鸟子、小火能烧喻） → 菩萨于性空法中求菩提为难事，佛列发心九因缘（安隐、安乐、救、归、依处、究竟道、洲、将导、趣）逐一展开 → 「一切法趣空，是趣不过」重复广说 → 谁能信解？久行六度、供养诸佛、与善知识相随者，以欲、瞋、痴断离为性相貌。
- **趣一切智品**：解深般若者趣一切种智 → 修般若即修一切法：无所修是修、不受修、坏修 → 阿鞞跋致当验知：于深般若乃至一切种智中「不着」即其相 → 行般若即「随顺一切种智心」，以空、无相、无作乃至如梦幻炎化随顺 → 结归「色即是萨婆若……色如相乃至一切种智如相皆是一如，无二无别」。

## 三、关键结论

1. 般若波罗蜜含受五度及一切佛法，故为大事故乃至无等等事故起；含受之由在「不取、不着」——不见可取可着故。
2. 二乘智断即菩萨无生法忍：所缘之如、法性、实际无二，但二乘无大悲方便、不能自出涅槃流，菩萨初忍已胜之。
3. 堕与不堕的分水岭唯一：有般若方便守护则不中道衰耗；以我我所心分别行善法则堕声闻、辟支佛地。
4. 般若入毕竟空、方便出毕竟空——一破一立，如两健人扶老者远行。
5. 一切法趣空乃至趣一切法，「是趣不过」——归趣穷极处，趣与非趣俱不可得；色如与萨婆若如，一如无别。

## 四、易混辨析

- **般若波罗蜜 vs 方便力**：般若观空破执、「将至毕竟空」；方便不舍众生、「将出毕竟空」涉有度生。守护菩萨不堕二乘，二者如车两轮，缺一即堕。
- **萨婆若 vs 一切种智**：萨婆若意译「一切智」，佛果总智之名、菩萨所趣；一切种智遍知诸法总相别相。经中常连举互用，失般若者即失此「大珍宝」。
- **二乘智断 vs 菩萨无生法忍**：所缘境相同，差别在二乘无大悲、无方便；如众水入海无力自反，又如大臣功业虽大，不及太子。
- **信行 vs 法行**：随信行凭信他人教语入见道；随法行凭自力思维法义而入。
- **下、中、上三品**：闻般若直信听受不问中义为下；问义而不能行为中；闻、解、能行、常随法师为上。下中二品不进，当堕二乘。

## 五、阅读提示

带着一个问题读此卷最得力：**同样是布施持戒，为什么有人成佛、有人退成阿罗汉？**五个譬喻都在回答这一件事；读到卷末「色即是萨婆若」，再回头看「不取、不着」，全卷脉络即贯通。
