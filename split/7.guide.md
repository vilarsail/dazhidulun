# 大智度论卷第七 导读

## 一、内容总览
本卷为《大智度论》初品中「佛土愿释论第十三」与「放光释论第十四」两段，承前品菩萨众功德之后，正面展开菩萨愿行与佛现神力两大主题。前段释「愿受无量诸佛世界」「念无量佛土诸佛三昧常现在前」「能请无量诸佛」「能断种种见缠及诸烦恼」「游戏出生百千三昧」「无量功德成就」六句经文，以菩萨愿行、念佛三昧、劝请断惑、三昧游戏为纲；后段释佛自敷师子座、入三昧王三昧、举身微笑、足下身分放光、光明遍照十方、毛孔皆笑等经文，以佛现神力、放光因缘、三千大千世界量、恒河沙喻为纲。问答往复，由愿行而入神力，由菩萨因地而显佛果德。

## 二、结构层次（★重点）
全文以「菩萨愿行六义 → 佛现神力五相」二段总起，每段内问答层层推进：

- **释愿受无量诸佛世界（P7-P36）**：菩萨见诸佛世界种种严净 → 发愿皆得之 → 问「行业清净自得净报何须立愿」→ 答「作福无愿无所摽立，愿为导御能有所成」→ 引少施少戒闻天乐生天中之喻 → 庄严佛土事大须愿力如牛须御者 → 罪福定报而愿能助福增长 → 罪报有量福报无量、声闻道福八万劫菩萨道福无量阿僧祇劫 → 收归「福德要须愿」。
- **释念无量佛土诸佛三昧常现在前（P37-P54）**：无量佛土即十方诸佛土 → 念佛三昧即心眼见十方三世诸佛常现在前 → 有声闻菩萨二种念佛三昧 → 何独赞念佛三昧：能除种种烦恼及先世罪（余三昧各除一毒，念佛三昧总除）、有大福德能度众生、入佛道中故、佛为法王菩萨为法将故常念 → 昔五百估客入海遇摩伽罗鱼王开口称南无佛得脱之喻 → 念佛得除重罪济苦厄何况三昧 → 收归常念亦不行余三昧。
- **释能请无量诸佛（P55-P79）**：请有二种——佛初成道时请转法轮、佛欲舍寿入涅槃时请久住世 → 问「诸佛法应说法何须请、十方诸佛不自见云何可请」→ 答「请者亦应得福如请王膳、如慈念众生自得福」→ 引多宝世尊无人请便入涅槃、须扇多佛、释迦文尼佛五十七日寂不说法待梵天请之例 → 二事必请：若不请而说则外道讥佛着法爱寿 → 引偈「诸佛说何实…怜愍众生故方便转法轮」→ 不答十四难之故 → 梵天自请伏外道心 → 菩萨昼夜六时常行忏悔、随喜、劝请三事。
- **释能断种种见缠及诸烦恼（P80-P105）**：见有常断二种、有无二种、三忍、四句（世间常无常等、有边无边、死后如去不如去）、五种见（身边邪见取戒取）、乃至六十二见 → 缠有十缠（瞋覆睡眠戏掉无惭无愧悭嫉），亦泛指一切烦恼绕心 → 烦恼分内着（五见疑慢）外着（淫瞋），无明内外共 → 爱见二结、淫瞋痴三结 → 九结七使合九十八结、十缠九十八结为百八烦恼 → 迦旃延子阿毗昙立十缠、犊子儿阿毗昙立五百缠 → 引颰陀婆罗为三人说诸法皆从念生之喻 → 菩萨巧方便自断亦断他烦恼。
- **释游戏出生百千三昧（P106-P122）**：何为三昧——善心一处住不动 → 三种三昧（有觉有观、无觉有观、无觉无观）、四种三昧（欲界系、色界系、无色界系、不系）→ 何故出生百千三昧——众生无量心行利钝、结使厚薄不同，须备种种三昧如备财物济贫、备众药治病 → 何故复游戏其中——菩萨于诸三昧有自在力能出能入如师子在鹿中自在 → 五种人于三昧各有自在不自在 → 菩萨三种自在故名游戏出生。
- **释无量功德成就与菩萨名（P123-P148）**：菩萨共佛住功德无量亿劫说不尽 → 列二十二菩萨名（颰陀婆罗等十六居家菩萨、慈氏妙德等出家菩萨、观世音等他方菩萨）→ 何独说二十二名——摄居家出家他方三事 → 何善守最前——王舍城旧人白衣中最大、佛在王舍城欲说般若故 → 弥勒补处余菩萨何亦言绍尊位——十方佛土皆补佛处。
- **释佛自敷座入三昧王三昧（P149-P208）**：佛自敷师子座——佛心化作故阿难不能敷 → 师子座是号非实师子、佛为人中师子 → 何唯结加趺坐——最安隐不疲极、摄手足心不散、魔见忧怖、出家人法、外道翘足立荷足狂狷故佛直身端心坐 → 三昧王三昧于诸三昧最第一自在能缘无量诸法 → 何独称第一——虽佛神力诸三昧皆第一然诸法应有差降如转轮王宝自有差别 → 应在第四禅中：佛于第四禅行见谛道得阿那含十八心得佛道、于第四禅舍寿入无余涅槃、第四禅名不动无遮、无火水风三患、无出入息舍念清净 → 唯佛能知其相、一切三昧皆入其中如众川入海 → 佛入此三昧故知不入则不知（破六师常知之执）→ 非如声闻辟支佛小菩萨方便求入应念即得 → 令六神通通彻十方、现大神力断佛用幻力咒术龙神力之疑、诸天声闻辟支佛乃至十住菩萨不能测知 → 光明神力下中上三等（咒术幻术下、龙天报得中、三昧心力上）故佛入三昧王三昧。
- **释佛举身微笑放光（P209-P247）**：佛从定起观世界举身微笑——观佛法藏无量、知众生贫苦不求 → 何用天眼非余眼——肉眼不遍、慧眼知实相、法眼见何方便得道、佛眼了一切法，天眼缘世界众生无碍 → 天眼之名——多在天中、人精进持戒禅定力得、人贵天为主、净天中尊是佛故亦名天眼 → 众生常求乐反得苦、常畏苦反行苦如盲人求好道反堕深坑 → 举身微笑——佛得自在能令一切身如口如眼、一切毛孔皆开 → 何故笑——大因缘故：欲说摩诃般若波罗蜜、无央数众生当续佛种、佛世世曾作小虫恶人集善本得大智慧一切众生亦可得尔、小因大果（赞一偈一称南无佛烧一捻香必得作佛）、般若波罗蜜清净如虚空难与难取须先调柔众生心、第一希有难事——诸法不生不灭真空无字无名而欲作名立字为众生说，喻如负干草入百由旬大火不烧一叶之难。
- **释足下放光至毛孔皆笑（P248-P337）**：何先放身光——令众生知非常人、现智慧光明神相、众生着五欲色为首见妙光舍本乐 → 佛光异天人——天人光有限量唯令欢喜，佛光满三千大千能令闻法得度 → 何先从足下放——身得住处皆由足、不自贵光不为利养故贱处放光、龙蛇鬼神口出光有毒害故佛不从口 → 身光是诸光之本如迦罗求罗虫得风转大 → 身分各放六百万亿——足下照下方余方不满故更放身分、足为立处故最大初种安住相、一切身分皆有神力 → 依三昧王三昧、如意通、第四禅火胜处火一切入放光 → 从诸光出大光明遍照三千大千及十方如恒河沙等世界遇光必得阿耨多罗三藐三菩提 → 何火光不上而遍满——光明有火气水气二种、佛力故遍至如强弓遣箭 → 何先照东方——日出东方为上、俱有一难故 → 光明几时灭——佛神力欲住便住舍则灭如灯脂 → 何为三千大千世界——千日月等名小千周利、倍之千倍名中千、再倍名大千，百亿日月乃至大梵天一时生灭 → 三千大千劫坏有水火风三、小劫有刀病饥三 → 须弥山四天王三十三天、余夜摩等七宝地风举空中 → 光远照不灭——佛心力为本如龙泉龙力水不竭 → 何常言恒河沙——沙多余河不尔、佛生处游行处弟子眼见、四河最大四远共以福德吉河、世世不转 → 恒河沙数唯佛及法身菩萨能知——引祇桓林叶之喻 → 值光得度者众生因缘不同如城有多门、有触身得度有见光触身不得度 → 复举身毛孔皆笑——细分先所未度者今值毛孔光即度如摇树取果熟者前堕未熟后摇、如捕鱼前网不尽后网乃得。

## 三、关键结论
1. 菩萨虽行业清净自得净报，庄严佛土事大独行功德不成，必须愿力为导御——福德如牛愿如御者，故因愿受胜果；罪报有量而福报无量，声闻道最大福八万劫、菩萨道净世界愿无量阿僧祇劫入道得涅槃。
2. 念佛三昧于诸三昧中最胜：余三昧各除一毒或不能除先世罪，念佛三昧能除种种烦恼种种罪，复有大福德能速度众生；昔五百估客入海称南无佛即脱摩伽罗鱼王之厄，故常念佛三昧即入佛道。
3. 诸佛法应说法广度众生，不待人请；然请者亦得福，且若不请而说，外道讥佛着法爱寿、佛应答十四难；故初成道时、欲入涅槃时二事必请，多宝、须扇多、释迦文尼佛皆有待请方说法之因缘；菩萨昼夜六时常行忏悔、随喜、劝请三事，功德无量转近得佛。
4. 见有常断、有无、三忍、四句、五种乃至六十二见，缠有十缠，烦恼有九结七使合九十八结，十缠九十八结为百八烦恼；菩萨以种种方便自断亦断他烦恼，如颰陀婆罗为三人说诸法皆从念生即得阿鞞跋致之喻。
5. 三昧王三昧于诸三昧中最第一自在，一切三昧皆入其中如众川入海；佛于第四禅中行见谛道、得阿那含、十八心得佛道、舍寿入无余涅槃，第四禅名不动无火水风三患无出入息舍念清净，故此三昧应在第四禅中；佛入此三昧令六通彻十方、现大神力断疑、诸天声闻辟支佛乃至十住菩萨不能测知。
6. 佛举身微笑放光，以大因缘故：欲说摩诃般若波罗蜜、无央数众生当续佛种、小因大果、般若清净如虚空须先调柔众生心、第一希有难事即诸法不生不灭真空无字无名而欲作名立字为众生说；足下先放光以贱处不自贵、避龙蛇口光毒害之嫌，身光是诸光之本如迦罗求罗虫得风转大；遇佛光明者必得阿耨多罗三藐三菩提，然众生因缘不同有触身得度有不得度，如城有多门各各至处不异。

## 四、易混辨析
- **愿 vs 福**：作福无愿无所摽立，愿为导御能有所成；福德如牛愿如御者，牛力虽能挽车要须御者能至。福可无愿而得然不如有愿，愿能助福常念所行福德增长；罪福定报而愿能令少福得大果报，故福有无量报罪报有量。
- **声闻道 vs 菩萨道**：声闻道中作五逆罪受地狱一劫，最大福受八万劫；菩萨道中破法人此间劫尽复至他方受无量罪，大福受无量阿僧祇劫。声闻念佛三昧于一佛身心眼见满十方，菩萨念佛三昧于无量佛土念三世十方诸佛。
- **十缠 vs 五百缠**：迦旃延子阿毗昙立十缠（瞋覆睡眠戏掉无惭无愧悭嫉）合九十八结为百八烦恼；犊子儿阿毗昙结使亦同而缠有五百。一切烦恼结绕心故尽名为缠。
- **肉眼 vs 天眼 vs 慧眼 vs 法眼 vs 佛眼**：肉眼所见不遍有障；天眼缘世界众生无碍不碍山壁树木，多在天中、人精进持戒禅定力得非生分；慧眼知诸法实相；法眼见是人以何方便行何法得道；佛眼名一切法现前了了知。欲见众生唯以肉眼天眼，以肉眼不遍故用天眼观。
- **名天 vs 生天 vs 净天**：名天即天王天子；生天即释梵诸天；净天即佛、辟支佛、阿罗汉，净天中尊是佛，故佛眼亦得名天眼无咎。
- **小千世界 vs 中千世界 vs 大千世界**：千日月等名小千即周利；以周利千世界为一数至千名二千中世界；以二千中世界为一数至千名三千大千世界。百亿日月乃至百亿大梵天，一时生一时灭；千千重数故名大千，二过复千故言三千，是合集名。

## 五、阅读提示
本卷问答密集而层次分明，可抓「菩萨愿行六义 → 佛现神力五相」二段总骨架。前段留意「愿为导御」「念佛三昧总除烦恼」「二事必请」三节点；后段留意「三昧王三昧应在第四禅」「举身微笑五因缘」「足下先放光三由」「恒河沙四义」诸节点。千辐相轮、白毫相、肉髻等身分放光不必强记次序，重在「身光是诸光之本如迦罗求罗虫得风转大」与「遇光必得阿耨多罗三藐三菩提然因缘不同」二义。末段三千大千世界量与恒河沙喻是佛土度量之基础，宜细读。
