# 大智度论卷第二十三 导读

## 一、内容总览
本卷承接前卷身念处之义，进入「十想」「十一智」「三三昧」「三根」四大法相门。十想是声闻、菩萨共修的断烦恼法门，从粗至细；十一智统摄有漏无漏一切智体；三三昧以觉观之有无分判定地浅深；三根依见谛、思惟、无学三道立名，收归菩萨从初发心到成佛的根力次第。全卷以「想→智→定→根」四门递进，由对治散心通向诸法实相，最终归宗于菩萨信等五根与如实智。

## 二、结构层次（文章的骨架与逻辑推进，★重点）
全文依四品释论次第展开，由粗及细、由行及证：

- **十想释论（主体，P5-P166）**：先列十想名目（无常、苦、无我、食不净、一切世间不可乐、死、不净、断、离、尽）→ 逐一想设问作答：先释名义、次辨与「智」「念」之别、再明观行层次与有漏无漏分判 → 以「初三想（无常苦无我）属见谛道，中四想属学修道，后三想属无学道」总收十想结构。
  - 无常→苦→无我三想构成一组递进：无常生厌 → 苦生畏 → 无我出拔解脱；三相分别对应断爱、断慢、断邪见，遮常见、乐见、着我处。
  - 食厌想、一切世间不可乐想属思惟道，专破欲界贪；死想、不净想引前已说；断离尽三想缘涅槃相，配暖顶忍世第一与无漏道、入涅槃三阶。
- **十一智释论（P167-P257）**：先列名（法、比、他心、世、苦、集、灭、道、尽、无生、如实）→ 逐智释名、明所缘、判有漏无漏 → 以阿毗昙门广辨智与智相摄、根相应、三昧相应、心次第修智多少 → 末以「如实智」十智所不知、唯佛独有收束，喻十水入海舍本名。
- **三三昧释论（P258-P291）**：先立三摩提总名（正心行处，蛇入竹筒喻）→ 依觉观有无分三地（欲界至初禅、中间禅、二禅至有顶）→ 辨觉观差别（粗为觉、细为观）与三类觉善恶 → 摄尽诸定归三三昧。
- **三根释论（P292-P323）**：先列三根名（未知欲知、知、知已）→ 释三根即九根（信等五+喜乐舍+意）于三道中转名 → 辨二十二根中何以唯取此三 → 末归菩萨位：初发心得信等五根→未知欲知根，得无生法忍至十地→知根，成佛→知已根。

## 三、关键结论
1. 无常、苦、无我三相原是一事（有漏受），随观门分别成三想：无常遮常见、苦遮乐见、无我遮着我处；三想次第生厌、生畏、出拔解脱。
2. 十想分属三道：初三想属见谛道破邪见，中四想属学修道离欲，后三想属无学道缘涅槃；断离尽三想对应有余、无余、二涅槃方便。
3. 十一智中十智为阿罗汉、辟支佛、菩萨共有，如实智唯独佛有——以独佛有不诳法故；十智入如实智中失本名字，如十水入海但名大海。
4. 三三昧依觉观有无分三地：有觉有观（欲界至初禅）、无觉有观（中间禅）、无觉无观（二禅至有顶）；觉观虽善而是三昧贼，能生亦能坏。
5. 三根即信等五根加喜乐舍意九根，于见谛、思惟、无学三道中转名；菩萨从初发心未具五根时虽愿知实相不能知，得五根清净即能信受不生不灭诸法实相。

## 四、易混辨析
- **断想 vs 离想 vs 尽想**：断约断结使（得无漏道时）、离约远烦恼（暖顶忍世第一时）、尽约灭苦不生（入涅槃时）；配涅槃则断是有余、尽是无余、离是二涅槃方便门。
- **法智 vs 比智**：法智缘欲界系法（现前分），比智缘色无色界（上二界分）；法智先证后比知，如见现在火热推知过去未来火亦热。
- **尽智 vs 无生智**：尽智是「我见苦已、断集已、修道已」之知，无生智更进一层「不复更见、不复更断、不复更修」；尽智是阿罗汉初心，无生智是得不坏解脱之后。
- **有觉有观三昧 vs 无觉有观三昧 vs 无觉无观三昧**：依地分判而非依法体——欲界、未到地、初禅有觉观；中间禅但观无觉；二禅至有顶觉观俱无。
- **未知欲知根 vs 知根 vs 知已根**：同是九根，随地不同——见谛道中名未知欲知（未见欲见），思惟道中名知根（已见而修），无学道中名知已根（知已究竟）；配菩萨位则初发心至无生忍前是未知欲知，得忍至十地是知，成佛是知已。

## 五、阅读提示
读本卷可带着两个问题：(1) 十想、十一智、三三昧、三根看似名相罗列，其内在次第如何对应修行阶位？(2) 龙树以阿毗昙门广辨相摄、根相应、心次第，最后为何独推「如实智」唯佛所有——这与《般若经》般若波罗蜜即诸法实相的旨趣如何相通？
