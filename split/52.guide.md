# 大智度论卷第五十二 导读

## 一、内容总览

卷五十二含三品：会宗品第二十四、十无品第二十五，并衔接下一品（不生不灭、无二法数）的经论。主旨是「以般若波罗蜜统摄一切善法，推征菩萨不可得，毕竟空入不二」。富楼那起问须菩提为何舍般若说摩诃衍，佛答「摩诃衍随顺般若波罗蜜」；须菩提再以十种门广破菩萨相，舍利弗事事致问、须菩提层层作答；末后归结到「不受不视不住不着」「不生不灭」「入无二法数」。全卷是一段反复推进、由总到分、再由分到极微的空义演绎。

## 二、结构层次

- **会宗品（总立宗）**：富楼那问「说摩诃衍将无离般若」→ 佛答三乘一切善法皆摄入般若 → 列举六度、三十七品、三脱门、十力乃至十八不共法为所摄法 → 以「不合不散、无色无形无对、一相无相」收束，明摩诃衍与般若「无二无别」。
- **十无品（破菩萨三相）**：须菩提提出菩萨前际后际中际不可得、五蕴无边故菩萨无边、色是菩萨不可得、一切处求不可得、但有名字、我毕竟不生、离毕竟不生无菩萨行菩提、闻说不惊不怖等八问 → 舍利弗逐句反诘「何因缘故」 → 须菩提以「众生空、五蕴空、六度空、内空乃至无法有法空、三十七品空、三脱门空、法性实际不可思议性空、声闻辟支佛佛空、一切种智空」一一作答，归于「空、菩萨、前际无二无别」。
- **佛自说（重申色如虚空、自相空、互相不可得）**：佛承须菩提义，说色如虚空无边无中 → 列一切法「自相空」（色色相空乃至佛佛相空） → 以「色色中不可得、受色中不可得」推展到「菩萨菩萨中不可得、般若波罗蜜中教化不可得」，结成「菩萨但有假名」「我名字毕竟不生」。
- **不生不灭品（推到极微）**：舍利弗再问诸法无自性、无常不失、非常非灭、毕竟不生不名为色等 → 须菩提答「诸法和合生无自性」「无常即动相即空相」「色非作法，作者不可得」「色性空无生灭住异」→ 毕竟不生即是般若波罗蜜，离毕竟不生无菩萨行菩提，闻说不没不悔是行般若。
- **不受不视品（行相收束）**：须菩提白佛菩萨行般若时于五蕴乃至一切种智「不受不视不住不着不言是」→ 色不生是非色、不灭是非色，不二不别，不生法非一非二非三非异 → 色乃至一切种智入无二法数。

## 三、关键结论

1. 三乘一切善法皆摄入般若波罗蜜，摩诃衍与般若波罗蜜无二无别——这是「会宗」的宗义。
2. 菩萨于三世、五蕴、一切种一切处求不可得，但有假名；「我毕竟不生」，法亦毕竟不生。
3. 毕竟不生即是诸法实相，即是般若波罗蜜；离毕竟不生则无菩萨行阿耨多罗三藐三菩提。
4. 无常即动相即空相，非常非灭，性自尔；诸法和合生故无自性。
5. 菩萨行般若时于色乃至一切种智不受不视不住不着，观诸法不生不灭、非一非异，入无二法数。

## 四、易混辨析

- **般若波罗蜜 vs 摩诃衍**：前者是到彼岸的智慧，后者是「大乘」之总名。本卷立宗二者不一不异——摩诃衍随顺般若，所说即说般若，因为一切善法皆摄入般若故。
- **毕竟不生 vs 涅槃（无为法）**：毕竟不生是诸法实相的称谓，与般若波罗蜜无二无别；非指另有一「不生法」可执。论中云「不生相法即是无为，非有为相」，但不落「无为相」之实执。
- **无常亦不失 vs 常断二见**：无常破「常倒」，不失破「断灭倒」，合之即入实相门；非世间所言之「无常即断灭」。
- **声闻人/辟支佛人/菩萨人/佛**：论中明示「我、众生、人一事」因功德别异而名字异——初入道至阿罗汉名声闻人，观因缘悟小深空名辟支佛人，深入空行六度大慈大悲名菩萨人。

## 五、阅读提示

本卷须菩提与舍利弗往返问答，句式高度复沓（「空故、离故、性无故」反复出现），读时不必逐句纠缠，抓住「破菩萨相→归于毕竟空→入不二法数」一条主线即可。
