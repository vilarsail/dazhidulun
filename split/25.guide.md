# 大智度论卷第二十五 导读

## 一、内容总览

本卷在《大智度论》中属「初品中四无畏义第四十」，承接前十卷论佛十力之后，专论佛四无所畏，并由「无畏」一题层层推开至「众中师子吼」「转梵轮」「菩萨十力与四无畏」「四无碍智」诸义，是大乘论佛功德具足度生的关键一卷。主旨是：佛之所以能在八大众中作师子吼、转大梵轮，非因骄慢，而是由于自德具足、能利众生、断诸所畏——故立四无畏为度生之根本依据，并明声闻所说与摩诃衍所说之别，及菩萨亦分得此诸功德。

## 二、结构层次

全文以「四无畏体相 → 何故说无畏 → 力与无畏异 → 无畏之实证 → 阿梨沙住处 → 师子吼 → 转梵轮 → 菩萨分得 → 四无碍智」九层推进：

- **四无畏总标（P4-P32）**：佛作四诚言（一切正智人 / 漏尽 / 说障法 / 说尽苦道）→ 每条皆设难者「如实言不能」→ 佛答「不见微畏相 → 安立圣主处 → 如牛王师子吼 → 转梵轮」→ 略说四无畏体（正知一切法 / 尽漏及习 / 说障道 / 说尽苦道）。
- **何故说四无畏（P33-P60）**：先由自德、利生、智断三类解释 → 再由破外道诽谤、显佛实德之因缘 → 再以二十对力与无畏之异同，明其「内力外用、自利利他」之关系。
- **无畏之实证（P61-P90）**：先释「无所畏」之义（无疑难、衣毛不竖）→ 以佛降诸大论议师、度诸王婆罗门、伏诸鬼神龙王恶人、坐树下降魔、于大众说法五重事证 → 复以世间功德（种姓、生处、色身、威仪、语音）皆无怖畏，况出世法。
- **十力中含无畏（P91-P97）**：一智在十处名十力，四处出用即四无畏——是处非处力、漏尽力为初二无畏，余八力为第三、四无畏，故别说无失。
- **阿梨沙住处与师子吼（P98-P159）**：先释「正遍知」与「如实难者」→ 释「漏」「障道法」「道」诸义 → 释「阿梨沙住处」（圣主：自德具足 + 利益众生）→ 释「八众」与「众中师子吼」→ 以师子王喻佛师子，详列其身相功德，明佛师子吼之二十事别义。
- **转梵轮（P160-P200）**：释「梵」（清净 / 广 / 四梵行 / 梵天请 / 梵天闻 / 令贵梵者喜）→ 以轮喻法（四念处为毂、五根五力为辐等），明转法轮能坏生死烦恼业苦 → 以转轮圣王宝轮喻法轮，详列其相似与殊胜 → 辨法轮、梵轮之异。
- **无畏性与次第（P201-P210）**：释无畏性（得道时得相应法）→ 四无畏次第（知法→漏尽→知障→说道，如药师示药、示病灭、示禁忌、示所食）。
- **空义与摩诃衍别说（P211-P225）**：答般若中言诸法空何以分别说相 → 以「不可得空」说一切佛法，如虚空长成万物 → 明声闻合四谛十二缘说，摩诃衍合大悲、实相不生不灭说，佛自说尽知遍知。
- **菩萨十力、四无畏、四无碍智（P226-P277）**：菩萨亦具十力（坚深心、大慈、大悲等）与四无畏（闻持、随应说法、无难、答问）→ 释四无碍智（义、法、辞、乐说）通声闻与摩诃衍 → 菩萨得无碍智转身受生自然悉知一切世间经咒工巧 → 终归度众生、令住阿耨多罗三藐三菩提。

## 三、关键结论

1. 四无畏即佛四种诚言：一切正智、漏尽、说障道、说尽苦道——皆因「正遍知了了」而于难者无所畏。
2. 力与无畏体同名异：内蕴名力（自德、猛健、集善），外用名无畏（度生、堪难、散无明）——如转轮圣王得七宝为力，降伏四天下为无畏。
3. 师子吼之别：世师子吼令众生死怖，佛师子吼令闻者离死畏、得二种乐（生天乐、涅槃乐），善人闻之怖而后喜，恶人则不怖。
4. 转梵轮即转法轮：以三十七道品为轮之各分，能坏生死、烦恼、业、苦四轮；佛灭后法轮犹转，胜于宝轮之随王灭而止。
5. 菩萨亦分得十力、四无畏、四无碍智，且摩诃衍所说尽知遍知合大悲与实相，故菩萨以无碍智转身自然通达一切世间经咒工巧，皆为度生、非为涅槃。

## 四、易混辨析

- **十力 vs 四无畏**：十力是佛内蕴之智慧猛健（自利、集善、能有所作），四无畏是十力外用于大众中堪受问难（利他、散无明、无所疑难）——如一人知十事为力，四处出用为无畏。
- **法轮 vs 梵轮**：名义无异，皆指佛所说令人随法行；别释则梵轮偏示四无量心、四禅、禅定圣道，法轮偏示四谛、三十七品、智慧圣道。
- **世师子吼 vs 佛师子吼**：世者粗恶、令死怖、善不善人皆怖；佛者柔软、令免死畏、唯善人怖（着吾我渴爱者怖，求涅槃离欲者怖），终令众生厌离得涅槃。
- **声闻所说 vs 摩诃衍所说十力无畏**：声闻依法体说，合四谛十二缘皆为到涅槃；摩诃衍依尽知遍知说，合大悲、诸法实相不生不灭，佛自说我尽知遍知。

## 五、阅读提示

读本卷宜带着三个问题：(1) 佛既十力已足，何以更立四无畏？注意「内力外用」之分工。(2) 师子吼与转梵轮两喻如何收束「无畏」之义？看其从自德到度生的展开。(3) 菩萨分得此诸功德，与佛之差别在何处？留意摩诃衍合大悲、实相说这一层。
