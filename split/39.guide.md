# 大智度论卷第三十九 导读

## 一、内容总览

本卷为《大智度论》卷三十九，属〈释往生品第四之中〉，紧承上卷继续列释菩萨摩诃萨行般若波罗蜜时所成就的种种不思议境界。全卷以「经文—论释」交替的体例展开，先说菩萨以方便力入超越定、不取证而以八圣道度人，次第论及一生补处、阿鞞跋致、化身入地狱度生、净三业、除粗业、净五眼等。其主旨在于：菩萨于般若波罗蜜中，以法空、不可得空为根本，行一切善法而不取证，不断烦恼而超越二乘，终至五眼圆净、无法不见。

## 二、结构层次

本卷按「菩萨功德枚举 → 净业根本 → 五眼圆净」三大块递进，经论穿插，层层上升：

- **超越定与不取证（P5-P35）**：先出菩萨以方便力入超越定，从初禅直入灭尽定，逆顺皆尔 → 论辩「凡夫不能入灭尽定」之疑，答以菩萨福德智慧力大、心无所著 → 次说菩萨修三十七品而不证四果，以方便起八圣道度人，果智皆入无生法忍，住阿鞞跋致地。
- **往生与补处（P37-P54）**：贤劫菩萨生兜率天道 → 一生补处菩萨离欲得四禅而「未证四谛」（故意留惑不证，恐成辟支佛） → 钝根杂行者经无量阿僧祇劫乃得菩提，深种善根者必得。
- **化身度生与净三业（P56-P116）**：菩萨利益众生不说无益语、从一佛国至一佛国断三恶道 → 以檀为首与众生乐 → 变身如佛入地狱为三途说法（破镬灭火、禁制狱卒） → 遍至十方恒沙世界、取净妙国土相 → 成就三十二相、诸根净利 → 得净根而不自高不下他（轻余菩萨者一劫远于佛道）。
- **净身口意与除粗业（P118-P207）**：从初发心住檀、尸波罗蜜不堕恶道 → 常行十善 → 作转轮圣王安立众生 → 以法照明自他 → 舍利弗问「云何身口意不净」，佛答「取相作缘即是菩萨罪」→ 大乘以取相着心为罪，与小乘十不善业为罪异 → 「粗业」与「细业」之辨 → 净佛道即一切诸法不可得（法空、众生空）。
- **无能坏与五眼净（P217-P328）**：菩萨不念色乃至不念菩提，住法空、众生空、观空者亦空故无能坏 → 具足智慧不堕恶道 → 「智慧」即行六度而不得六度、见十方佛而不得一切法 → 最后广明五眼净：肉眼见百由旬至三千大千世界、天眼见诸天生死、慧眼于一切法不念有无而无法不见闻知识，成佛时四眼皆失本名但名佛眼（如阎浮提四河入海）。

## 三、关键结论

1. **超越定唯菩萨能**：余人定力少不能远超，菩萨福德智慧力大、心无所著，故能从初禅直入灭尽定、逆顺随意。
2. **大乘罪相异于小乘**：声闻以十不善业为罪，大乘以「取身口意相、着心取相」为罪；入法空不见三业方为无罪、牢固。
3. **一生补处故意留惑**：补处菩萨离欲具足佛法，却「未证四谛」，恐取证成辟支佛故留不证，以方便力随补处法生兜率天。
4. **五眼成佛时唯名佛眼**：肉眼、天眼、慧眼、法眼至成佛时皆失本名但名佛眼，以无明习气尽故、尽其边极故，如四大河入海失本名。
5. **智慧即「具足一切法而不得诸法」**：菩萨行檀而不得檀（若一若异、若实若空皆不可得），见十方佛而不作佛想，以不得故能具足。

## 四、易混辨析

- **超越定 vs 次第定**：次第定从初禅渐次至二禅、三禅乃至灭尽定；超越定从初禅起直入第三禅乃至灭尽定，逆顺皆尔，中间不起余心。论云「二俱为大」，超越者无余心杂而能超越故胜，如槃马回转随意。
- **粗业 vs 细业**：声闻以身口不善为粗、意不善为细；以瞋恚邪见为粗罪、爱慢为细罪。大乘则于摩诃衍中尽皆为粗，乃至见我、知者、见者皆为粗，唯入法空、不见三业方为细、为无罪。
- **声闻慧眼 vs 佛慧眼**：声闻辟支佛慧眼见诸法总相（无常苦空），有量有限，如小灯不能广照；佛慧眼总相别相皆见，照诸法实性尽其边底，故「无法不见闻知识」。
- **肉眼 vs 天眼**：肉眼业因缘生，虚诳不净、有障碍、不能远及；天眼禅定或果报得，能见诸天生死善恶无碍。然菩萨果报天眼常与肉眼合用，因天眼开障故肉眼得名果报生天眼。

## 五、阅读提示

读本卷宜抓住两条主线：一为「不取证」——菩萨处处留惑、不证四果，以方便力度生；二为「不可得空」——净业、净佛道、五眼净皆归结于「一切诸法不可得」。凡论辩处（问曰/答曰）多为辨析大小乘罪相、粗细、慧眼差别之关键，宜细看。
