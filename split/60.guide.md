# 大智度论卷第六十 导读

## 一、内容总览
本卷为《大智度论》释「挍量法施品第三十八」之卷六十，承接前卷对般若波罗蜜功德的赞叹，专以「挍量」一法显般若法施之福远胜世间善法与财施。全卷由经、论两部分组成：经文为佛告释提桓因，以「教一阎浮提人行十善」为基线，逐级挍量书持般若、为他说般若义之福德，并广辩「相似般若波罗蜜」与「真实般若波罗蜜」之别；论释则由「者言」逐段解经义，会归「无所得行六度」「般若出生诸贤圣」「福田深厚」三义。主旨可摄为一句：般若波罗蜜是诸法实相，三世诸佛皆从中出，故为他人演说其义，福胜一切世间有漏善法及二乘果报之教化。

## 二、结构层次（★重点）
全卷以「挍量递进 → 正义显发 → 相似破邪 → 福田收束」为骨，由浅入深：

- **第一层·挍量世间善法（经 P5-P27）**：佛以「教阎浮提人行十善」对「书般若经卷与人」起问 → 由一阎浮提递增至四天下、小千、二千中、三千大千、十方恒河沙等世界 → 每一层皆「得福多不？甚多！不如……般若得福多」三问三答，以「般若广说无漏法、成三乘道」为胜因。→ 经界越大，越显般若出世间法之胜。

- **第二层·挍量禅定神通与自行正忆念（经 P28-P35）**：由教人「行十善」升进到教人「立四禅、四无量心、四无色定、五神通」 → 仍不如「自受持般若、读诵说、正忆念」 → 更不如「为他人演说般若义、开示分别令易解」。→ 论释以「采药未服」喻正忆念如服药病愈，以「自行→为他」递进显法施最胜。

- **第三层·有所得与无所得六度（经 P39-P45）**：先出「云何名有所得」之问 → 举布施时作「我与彼受所施物」等六度各起「我心取相」为有所得，名得檀不得波罗蜜 → 反显「不得与者、不得受者、不得所施物」之无所得为具足波罗蜜。→ 论释点明「有所得者，以我心于诸法中取相故」。

- **第四层·相似般若与真实般若之辩（经 P46-P65，★全卷枢纽）**：先标「未来世当有人说相似般若波罗蜜」起警 → 释提桓因三问「何等是相似般若」 → 佛广举七类相似相（说色等无常而求无常、说当得初地十地、说过声闻辟支佛地、说得无生法忍神通、说得阿僧祇功德、回向诸佛善本） → 反显「不说相似」之正义：莫观色无常，以色性空、色尚不可得，般若中非常非无常、无有法可过可住可生可灭。→ 论释以「名字语言同心义异」「着心取相说五众无常为相似，不着心破常颠倒为真实」收束。

- **第五层·出生贤圣与福田收束（经 P97-P126，论 P128-P151）**：复以「教阎浮提乃至恒河沙世界众生令得须陀洹、斯陀含、阿那含、阿罗汉、辟支佛、发无上心、住阿鞞跋致」层层挍量，皆不如「为他人演说般若义」 → 乃至为「疾得阿耨多罗三藐三菩提菩萨」演说，福最多 → 帝释发心法施财施供养近佛菩萨 → 须菩提赞帝释为圣弟子、安慰劝进诸菩萨，并以「菩萨中生诸佛圣众」「若菩萨不行六度则无须陀洹乃至辟支佛」收束全卷。→ 论释以「般若波罗蜜是诸法实相，正遍知名为佛」「生死肉身菩萨/法性生身菩萨二种」「供养太子不如供养国王」之譬，明福田深厚故福德转大。

## 三、关键结论
1. 般若波罗蜜广说无漏法、出生三乘贤圣及诸佛，故书持、读诵、为他说般若义之福，胜过教十方恒河沙世界众生行十善、立四禅、得声闻辟支佛果。
2. 「正忆念」者，受持般若乃至一切种智，不以二法、不以不二法；正忆念能具福德与智慧二事，如服药病愈，胜于徒事受持读诵。
3. 以「我心取相」行六度名有所得，得檀不得波罗蜜；以「不得与者、受者、所施物」行六度名无所得，方为具足般若波罗蜜正义。
4. 「相似般若波罗蜜」名同义异：以着心取相说五蕴无常苦无我、说当得初地十地神通功德回向等，皆为相似；以不着心、不取相、为破常颠倒而说，色性空、色尚不可得、非常非无常，方为真实般若。
5. 三世诸佛皆学般若成无上道，菩萨为诸贤圣之本、福田深厚，故为近佛菩萨演说般若义，功德最胜。

## 四、易混辨析
- **十善道 vs 无漏法**：十善道是世间有漏善法，受世间无常福乐，还复堕苦、不离三恶道；无漏法（四念处乃至十八不共法）是出世间法，成三乘道、入涅槃不复还。故教人般若胜教人十善。
- **相似般若波罗蜜 vs 真实般若波罗蜜**：相似者名字语言同而心义异，以着心取相、有所得说五蕴无常苦无我乃至说当得十地功德，行者求色无常等即为行相似般若；真实者以不着心不取相说五蕴无常但为破常颠倒，色性空、色不可得、非常非无常、无有法可过可住，是般若正义。
- **有所得六度 vs 具足六度**：布施时作「我与、彼受、所施物」之念，是得檀不得波罗蜜，六度皆然；布施时不得与者、受者、所施物（乃至修般若时不得智、不得所修智），方名具足檀波罗蜜乃至般若波罗蜜。
- **生死肉身菩萨 vs 法性生身菩萨**：前者是流转生死之因地菩萨；后者是出三界、不生不死之法性身菩萨，即阿鞞跋致以上、近佛道者，所说但过阿鞞跋致菩萨事（教化众生、净佛世界、分别三世心行业、大慈大悲一切智等），福田深厚故为说法福最多。

## 五、阅读提示
读此卷宜抓住「挍量」与「相似/真实」两线：前者由小至大层层递进，看每一层「胜因缘」如何升格；后者是全卷枢纽，留意「名字语言同而心义异」一句为破邪显正之钥——同说无常，着心取相即相似，为破常颠倒而不着即真实。又须菩提赞叹帝释一段，点明「菩萨为诸佛圣众之本」，是全卷福胜之所以然的根本所依。
