# 大智度论卷第六十一 导读

## 一、内容总览
本卷释《摩诃般若波罗蜜经》「随喜回向品」（第三十九品）。全卷围绕两个修行动作展开：随喜（见他修福而生欢喜）与回向（将福德趣向无上菩提）。弥勒菩萨、须菩提、释提桓因与佛依次问答，层层辨析：怎样随喜回向才称得上「最上、第一、最妙、无上、无与等」？核心答案是——不取相、无所得，如诸佛所知而回向；取相回向则如杂毒之食，堕于四颠倒。

## 二、结构层次
全卷经、论交替，六轮推进：
1. **立宗**：经——弥勒说菩萨随喜福德胜二乘及众生（二乘为自调、自净、自度，菩萨为度一切众生）→ 须菩提难问：取相回向，「如所念可得不？」→ 论——释随喜义（不劳身口、以心随喜），释「果报可与、善法体不可与」，再判取相即堕四颠倒（生时想→心→见，断时先断见）。
2. **深辨**：经——久行六度者能无相回向；毕竟空义不应为新学菩萨说 → 论——铁入炉则柔、鸟翼成乃飞二喻：新发意先教取相随喜，渐得方便力乃入无相随喜。
3. **转问**：经——帝释代新发意菩萨问云何回向 → 须菩提答：无所得行六度、多信解内空乃至无法有法空、常随善知识、闻魔事不增不减 → 论——释「弃重担、灭聚落刺、断五分结」等赞叹语，明正回向。
4. **毒喻**：经——取相回向如杂毒食，是谤佛；「如诸佛所知」随喜回向，则无杂毒 → 论——释「不诳道」即是般若，如射地无不着。
5. **较量**：经——诸法不系三界、三世不摄，无生则无法，无法中不可回向；佛较量功德：心不着回向胜取相供养百千亿倍；四天王乃至阿迦尼吒诸天赞叹「不堕二法」；佛说「一切法与解脱等」之最上随喜。
6. **收束**：论——释无相三种（假名相、法相、无相相）、无得无出、无垢无净；点出菩萨礼佛三品：悔过、随喜回向、劝请。

## 三、关键结论
1. 随喜不劳身口，但以心随喜他善，福德胜自作——因念过去佛即念佛三昧、六念实法。
2. 善法体不可与人，果报可与，故言福德「与一切众生共」。
3. 取相有所得而回向，堕四颠倒，如杂毒食，诸佛不许，是名邪回向。
4. 正回向以般若方便力，知回向心、所回向处皆尽灭、自性空，「如诸佛所知」而回向，不堕有无二边。
5. 无所得心回向之福，胜取相修行供养百千万亿倍；一切法与解脱等（不生不灭故），是名最上随喜。

## 四、易混辨析
- **随喜 vs 回向**：随喜是见他福德而生欢喜心；回向是将福德转趣无上菩提。随喜在先，回向在后。
- **正回向 vs 邪回向**：不取相、无所得、如佛所知为正；取相、有所得、自忆想分别为邪。
- **凡夫三倒 vs 学人二倒**：四颠倒中凡夫想、心、见三种具足；得初道之学人见倒已断，唯余想、心二倒，如渧水堕热铁，即起即灭。
- **一切智 vs 一切种智**：前者总相知诸法空，声闻辟支佛亦有；后者遍知一切法总别相状，唯佛具足。

## 五、阅读提示
带着这个问题读：诸法毕竟空、回向心念念尽灭，还有何福德可回向、向何处回向？本卷的回答是——正因无所有，才须以无所得方便「如诸佛所知」而回向；不坏法相而不住相，正是弥勒所谓「是事甚难」处。
