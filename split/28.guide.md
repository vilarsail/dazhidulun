# 大智度论卷第二十八 导读

## 一、内容总览

本卷接续初品中六神通义之后，分三大段释经：一释「欲住六神通，当学般若波罗蜜」，辨菩萨五通与佛六通之别、神通次第及六通生起因缘；二释「欲知一切众生意所趣向」，重明他心通境界限量与佛无碍解脱知心差别，并申「众生无边、佛智亦无边」之义；三释「欲胜一切声闻、辟支佛智慧」，举声闻辟支佛智慧相状，又引《宝顶》《明网》《毗摩罗诘》诸经证菩萨胜；最后释「欲得诸陀罗尼门、诸三昧门」，广辨陀罗尼与三昧同异。卷末附「布施随喜心过上第四十四」，明菩萨以随喜心回向菩提，胜过二乘布施持戒等六事功德。全卷以「六通—他心—二乘智—陀罗尼三昧—随喜」五义贯穿，皆归宗般若波罗蜜。

## 二、结构层次

- **六通辨异（问答展开）**：先问「菩萨已得五通，何以言欲住六通」→ 答「五通菩萨所得，六通佛所得」→ 次问「漏尽已断爱，云何复生」→ 答「菩萨入法位得法性生身，非三界生；阿罗汉无大慈悲、实际作证故不生」→ 神通次第（如意→天耳→他心→宿命→漏尽），并以佛三夜所得配通与明。
- **神通变化与一切入辨异**：问「变化为实为虚」→ 答「皆实，三毒已拔、法无定相故可转」→ 举酥胶蜡地类得火为水、石汁作金喻，明善恶可转之理。
- **他心通境界限量（对比递进）**：凡夫知四天下心 → 声闻知千世界 → 辟支佛知百千世界 → 佛无碍解脱知一切；上地钝不知下地利，辟支佛不知佛心，故须般若波罗蜜。
- **心有来去诤论（以般若空义收束）**：问「心去不去」→ 答「心不去不住而能知，一切法无来去相」→ 引《般若》「生无所从来，灭无所去」→ 心如幻化、不取相则得实法。
- **众生有边无边难（十四难置答）**：问「悉知心则众生有边」→ 答「众生无边、智亦无边，如函大盖亦大」→ 十四难是邪见戏论，佛说无常为入真谛门，非实有无常；引波梨国四十比丘闻五河血喻得道。
- **胜二乘智慧（举经为证）**：先明声闻智慧（总相别相、四念处四谛等、苦法智忍乃至空空三昧）→ 辟支佛智慧同声闻但时节利根福德有别 → 菩萨于果圣佛子菩提中皆无名而胜者，以摩诃衍法说菩萨事、次佛应供，引《宝顶经》转轮王胎喻、《明网经》舍利弗与普华问答法性、《毗摩罗诘》不堪问疾。
- **陀罗尼与三昧门（辨异收束）**：闻持陀罗尼四方便 → 入音声陀罗尼（知音声如响）→ 四十二字门（阿字入一切法初不生）→ 五百陀罗尼为善法功德藏 → 三昧分声闻三三昧与摩诃衍首楞严等无量三昧 → 三昧是心相应，陀罗尼通心不相应（如影随形）→ 三昧久习成陀罗尼，如坏瓶火烧成熟能持水；声闻法无陀罗尼名，以小不求持诸功德故。
- **随喜过上（卷末附品）**：明随喜心义（傍人得香无损）→ 菩萨以随喜福德回向菩提、以实相智慧随喜、和合诸功德如少水置海 → 辨六事（施戒定慧解脱解脱知见）摄尽二乘法 → 胜非力势相夺，乃一事中智方便力得福多，如蜂取味成蜜。

## 三、关键结论

1. 菩萨五通与佛六通之别在「漏尽」：菩萨漏尽而习未尽，故言得五通；佛漏习俱尽，方名住六神通；菩萨得法性生身受生非三界爱生。
2. 神通变化皆实不虚，以「诸法无定相」为本——地可作水、石可作金，以无定相故可转；众生亦尔，恶可为善。
3. 他心通有量：凡夫、声闻、辟支佛各随根器所知有量，唯佛无碍解脱知一切众生心心数法，故须学般若波罗蜜。
4. 心不去不住而能知，以一切法无来去相、心如幻化故；众生无边与佛智无边俱无边，十四难是邪见戏论，佛说无常为入真谛之方便。
5. 菩萨智慧胜二乘，以无量阿僧祇劫集诸智、五波罗蜜庄严、有大慈悲方便、住十地故；虽在烦恼胎中初发道意已为诸佛所贵，如转轮王胎、迦罗频伽鸟在㲉。
6. 陀罗尼与三昧异：三昧但心相应、或易身则失；陀罗尼通心不相应、世世常随；声闻法中无陀罗尼名，以小不求持诸功德，唯大乘须之。

## 四、易混辨析

- **五通 vs 六通**：五通（天眼、天耳、他心、宿命、如意）菩萨所得，漏尽通中菩萨「漏尽而习不尽」故言五通；佛「漏习俱尽」方具六通。
- **一切入 vs 神通**：一切入（背舍、胜处）是神通初道，一身见地变水他人不见，但成水相不实是水；神通则自他皆见实水，二定力别。
- **通 vs 明**：通是作用自在，明是照了无疑；佛三夜所得，初夜如意通+宿命明，中夜天耳通+天眼明，后夜他心智通+漏尽明，求明用功重故在后。
- **声闻智慧 vs 辟支佛智慧 vs 佛智慧**：声闻以总相别相观诸法实相、厌世念涅槃；辟支佛智慧同声闻，但「时节、利根、福德」三别——无佛世自悟、根深、或有相好；佛以无碍解脱知一切、无量阿僧祇劫集智、五度庄严、住十地，故胜。
- **三昧 vs 陀罗尼**：三昧但心相应、或易身失；陀罗尼通心相应与不相应（如闻持陀罗尼瞋时不失、如影随形）、世世常随；三昧久习能生陀罗尼，如坏瓶火烧成熟能持水。

## 五、阅读提示

读本卷可带着三组问题：菩萨既断爱云何受生？佛既悉知众生心，众生有边无边？声闻辟支佛已证实际，菩萨何能胜之？——三问皆归般若波罗蜜为答。注意卷中大量经证（《宝顶》《明网》《毗摩罗诘》及波梨国比丘喻），是龙树立宗的依据所在。
