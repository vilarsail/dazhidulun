# 大智度论卷第九十一 导读

## 一、内容总览

本卷为《大智度论》卷第九十一，疏释《摩诃般若波罗蜜经》第八十一〈照明品〉。眼目在「照明」二字：菩萨虽修六波罗蜜乃至十八不共法，若不「具足菩萨道」便不得阿耨多罗三藐三菩提；而具足之道，即在以方便力行六度——不得施者、受者、施物，亦不远离此法——如是「照明菩萨道」。全卷经、论两层都在化解「诸法性空」与「成就众生、净佛国土」的表面矛盾，论释部分一段一问一答推进，是《大智度论》问答体的典型一卷。

## 二、结构层次

**经文**（佛答二大弟子，层层递进）：
- 须菩提问「云何具足菩萨道」 → 佛答：以方便力行檀波罗蜜，不得施者、受者、施物而亦不离，「照明菩萨道」；持戒乃至十八不共法亦如是。
- 舍利弗问「云何习般若波罗蜜」 → 佛答「不坏色、不随色」，色性无故 → 六度乃至十八不共法皆然；无所得、不可取，是菩萨所应学。
- 舍利弗难：诸法无性，云何有凡圣差别？ → 佛答：众生但颠倒故着阴、入、界；菩萨见诸法无根本而发心，「自立如幻师」，先教布施等六法，后说四谛圣法，令入三乘。
- 舍利弗叹「旷大心」：于无所有中发大誓庄严，不生三界而度三界众生，而众生不缚不解 → 佛印证：法相常住、众生先空，度生无过罪 → 以幻师喻收束：幻人食幻食，不得言实。
- 须菩提问「何等是菩萨道」 → 佛以檀波罗蜜为例详说：自施教施而「莫着布施」，以四事（布施、爱语、利行、同事）摄取，以施生戒，次第教忍、进、禅、般若，令住三十七助道法 → 成就众生、净佛国土。

**论释**（逐段「问曰／答曰」）：
- 释「方便力」与「照明＝具足」：决定得施等三事堕常颠倒，决定不得堕断灭边；离二边，因空舍假名、因实相离着空。
- 释「不坏、不随」：不许说色常无常，亦破世性、微尘、大自在天、时、自然等生因邪执。
- 释先六法后「胜法」：施戒等「善智慧」感人天福，四谛圣法名「出法」，方能出三界。
- 释二谛说法、无过罪义，并答「幻师实有而所幻者无」之难。
- 释成就众生之行：莫着布施防憍慢、四摄摄取、转轮圣王报、「因布施生戒」；中间插出禅房二僧夜半互疑为鬼、相斗达旦的故事，警策「人身难得、佛世难值、好时易过」。
- 末释何以重说六度，及供给禅具（禅鞠、禅镇、骨人等）为修三十七品之因缘。

## 三、关键结论

1. 照明即具足：无所得而行六度，不堕常断二边，便具足菩萨道。
2. 习般若即不坏不随：不说常无常、不取相、不觅邪因，以诸法性无故。
3. 有佛无佛，法相常住：众生与法「先来无」，故佛菩萨度生无「先有今无」之过。
4. 菩萨住二谛说法：为爱有着说空，为着空者说有，有无二处不染。
5. 成就众生以檀波罗蜜为首：先以财施给足、令心濡软，再以三乘圣法令出生死。

## 四、易混辨析

- **照明 vs 具足**：论明言「是一义」——无所得心而行，即是照明，即是具足。
- **不坏 vs 不随**：不坏是不说色无常、空无所有；不随是不如眼见取相生着、不说若常若乐等。
- **初六法 vs 胜法（圣法／出法）**：布施等六法是「善智慧」，感人天福报；四谛是圣法、出法，能出三界生死。
- **幻师 vs 所幻物**：论破「幻师实有、所幻者无」之难——圣人观能幻所幻不异，「众生」异名即是幻师。
- **五道 vs 六道**：经言「无分别五道」，论释言「无六道分别」，开合不同、并存互见。

## 五、阅读提示

带着「既然一切法空，为何还要辛勤布施教化」的问题读：全卷问答都在拆解这个矛盾，关键词是「方便力」——知空而不废行，行而无所着；读禅房夜斗故事时，可留意「空取相致斗诤」如何落到日常生活。
