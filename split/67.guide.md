# 大智度论卷第六十七 导读

## 一、内容总览

本卷为《大智度论》卷六十七，释《叹信行品》之余。经文续说须菩提与舍利弗两番问答，论主逐段以"释曰"随解。全卷有三条主线：一、菩萨以"不见增减、不分别一切法"为具足般若；二、深般若如大珍宝多有盗贼，书诵之际魔事留难蜂起，唯仗佛与十方诸佛护念方能成办；三、佛授记：佛灭度后般若次第流布南方、西方、北方，末法书持信受者，佛皆以佛眼见、知、念。

## 二、结构层次

经论夹释（先列【经】文，继以【论】解释），推进如下：

1. **具足般若之义（经问→论释）**：须菩提问"云何具足修行般若波罗蜜" → 佛答：不见色乃至一切种智的增减之相，不见法与非法、三世、三界、六度 → 论归宗于"诸法无相、空、虚诳、不坚固、无觉者无寿者" → 须菩提叹"不可思议" → 佛更进一层：知法不可思议而住其中，反不具足——不可思议相亦不可取。
2. **谁能信解（追问答）**：问谁当信此深法 → 答"久行六度、种善根、亲近诸佛、随善知识"者 → 论释其行相为"不分别色、色相、色性"，借见烟知火、瞋人成恶性等喻辨相与性之别 → 须菩提以"色甚深故般若甚深"领解，赞般若为"珍宝聚"、"清净聚"。
3. **留难与佛力（经→论）**：须菩提惊怪"说是般若时多有留难" → 佛教"应当疾书"，一月乃至一岁勤成 → 舍利弗问"谁力故魔不能留难" → 佛答佛力与十方诸佛力，诸佛皆以佛眼见 → 论中备列书、诵、说、忆念时的种种魔事，并设问答辨佛眼与天眼、法眼、慧眼之别，明佛眼所摄所见皆实。
4. **北方授记（经→论）**：佛灭后般若至南方→西方→北方，北方"当作佛事"；书持者渐以声闻、辟支佛、佛乘而得涅槃 → 论释佛出东方、于拘夷那竭双树下灭度，法如日月右绕须弥山次第而转；北方三毒不发、信等五根有势力，故深法广行。
5. **誓愿与得经（收束）**：末世菩萨于佛前立誓度生、示教利喜，佛与过去佛知其"心大"而随喜 → 一心勤求者"当得应六波罗蜜深经"，得已精勤修行乃至净佛世界成就众生 → 卷末警策："若吝惜法，则常生边地无佛法处。"

## 三、关键结论

- 不见增减、不分别是法非法、连"不可思议"之相也不住著，才是具足般若；一有取著即失。
- 大珍宝所在多有盗贼，深般若多有留难；然般若真慧力大、魔事虚诳，菩萨得其"气分"魔即不能坏。
- 书持读诵深般若"皆是佛力"——释迦与十方诸佛以佛眼见之、念之、赞之，其人终不堕恶道、不离诸佛。
- 般若流布东→南→西→北，末法北方能信深法者是多世久种善根之人；佛"观是法末后炽盛"，故特加护念。
- 为他说法令住六度者，转身易得深经；吝惜法则生边地无佛法处。

## 四、易混辨析

- **一切智 / 道种智 / 一切种智 / 萨婆若**：一切智知诸法总相，声闻亦得；道种智知修道差别与众生根机，属菩萨；一切种智总别遍知，唯佛具足。萨婆若是"一切智"的音译，卷中多指佛智。
- **佛眼 / 天眼 / 法眼 / 慧眼**：天眼见现在众生而有限量；法眼但见诸法；慧眼但见毕竟空；佛眼统摄三眼，见三世众生无限无量、所见皆实——众生"虚妄"是就涅槃而言，非谓世谛中无所见。
- **留难 / 魔事**：疾病饥饿等皆可称留难，但以魔事为大，故专标魔事——魔民恶鬼入人身心、令人疲厌、遣人谤法。
- **相 / 性**：相是显现可见（地坚、见烟知火），性可由积习而成（热是火相亦是火性），亦有相性不异者；菩萨于此皆不分别。

## 五、阅读提示

带着一问读：末法恶世，凭什么信受深般若？全卷的答案——久种善根、佛眼见念、佛力护持——正是"叹信行"的落点；并留意"应当疾书"背后"人身无常、有为法不可信"的紧迫感。
