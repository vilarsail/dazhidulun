# 大智度论卷第六十六 导读

## 一、内容总览

本卷为《大智度论》卷六十六，释《摩诃般若波罗蜜经》〈叹信行品〉第四十五，以“信受深般若”为全卷主线：什么人能信、云何“住”而“习”般若、能信是何等受记先相，末后归于佛以慈悲善付菩萨事。经论三番相扣，由赞叹而入实修，由实修而证信相，由信相而结付嘱。

## 二、结构层次

- **第一番：叹信之难得。** 帝释先念：闻般若经耳者，前世必多供养诸佛、随善知识 → 舍利弗申明：能信深般若者“如阿鞞跋致”，毁呰者先世亦毁呰 → 帝释收束：不久行六度者不信“有何可怪”，随即顶礼——“礼般若波罗蜜，是礼一切智” → 佛印证，广列欲住一切智、生道种智、断诸结及习、得须陀洹等四果、辟支佛道乃至转法轮、总摄比丘僧，皆当习行般若。论中释帝释利根发问之由，设“新劈干毳随风东西”喻新发意随他语转，并答“先世毁呰何以复得闻”三解。
- **第二番：云何住、云何习。** 帝释问“云何名住般若乃至十八不共法” → 佛答：不住色中，为习行般若；不住般若中，为习般若——色三世不可得，故“不习色，是名习色” → 舍利弗三叹：甚深、难可测量、无量 → 佛遮其执：“不行色甚深，为行般若波罗蜜”，甚深相为非色 → 舍利弗诫“不应在新发意菩萨前说”。论中释佛赞“善哉”之由，明深浅无定（水于小儿则深、于罗睺阿修罗王则浅），及新学闻深法心没、毁呰之过。
- **第三番：信为受记先相。** 帝释问：颇有未受记菩萨闻深般若不惊怖否 → 舍利弗：有，“不过一佛、两佛”便得受记 → 连说五喻：梦中行般若、旷野见放牧疆界知近城邑、大海处平无山树、初春陈叶堕新叶华果将出、怀妊身重产生不久 → 须菩提叹佛“善付诸菩萨摩诃萨事” → 佛说菩萨以四摄法、十善道自行教他，自得般若、一切种智、转法轮亦教他得，教他证二乘果而“自于内不证”。论中逐喻配释：险道即三界，城即无上道，贼即六十二邪见，恶虫即爱恚烦恼；并广释四摄法与“空道、福德道”之付嘱。

## 三、关键结论

- 诸佛一切智皆从般若生；礼般若即礼一切智，即礼三世十方诸佛。
- 习般若的行相是“不住”：不得色可住可习处，三世求色不可得，不习而名习。
- 深浅无定：为凡夫新学则深，为久积德不退者则浅；佛得无碍解脱，于一切法无有深者。
- 能闻深般若不惊不怖，即近受记之先相，不久不过一佛两佛。
- 佛以慈悲心（非爱着）善付菩萨事——空道、福德道，嘱阿难、弥勒等好自奉行。

## 四、易混辨析

- **一切智 / 道种智 / 一切种智**：一切智知诸法总相（空、无我），声闻亦分得；道种智知济度众生种种道法，菩萨所修；一切种智总别圆知，唯佛具足。“欲住一切智当住般若、欲生道种智当习行般若”即据此而立。
- **阿鞞跋致 / 新发意菩萨**：一是不退位，一是初发心。深般若应在阿鞞跋致前说；新发意闻之或心没疑悔，毁呰反种三恶道业。
- **不住 / 不习 / 习**：论谓“习色”本是取色相（若常若无常）；今菩萨散坏诸相故“不习”，而常行正语正业、积习纯厚亦名“习”——不住不习，正是深层之“习般若”。
- **柔顺法忍 / 无生法忍**：论以聚落喻柔顺法忍（顺信而未证无生），以邑喻无生法忍（已证无生），城喻无上菩提——由近而远、由浅而深。

## 五、阅读提示

带着两个问题读：一、为何“礼般若”即“礼佛”？二、为何“不住”反是“习行”？论中于五喻一一配释，可经论对读，体会龙树“以粗喻细、以世间喻出世间”的释喻手法。
