# 大智度论卷第四十三 导读

## 一、内容总览
本卷含「释集散品第九下」「释行相品第十」及一段无品名的「学般若波罗蜜不可得」问答，位居《大智度论》释经文的中段，紧接前品以空门破诸法之后，进一步以无相门、无受门广破菩萨取相之行。主线是：先由须菩提为舍利弗决疑般若波罗蜜的体、名、所属；次明菩萨行般若时「有方便」与「无方便」的分野在于是否取相、是否有所受；最后广列百八三昧以示疾得佛道之广途，又归于「学般若波罗蜜即无所学、无所得」。全卷以「中道—无相—无受—不可得」四义层层递进，是理解《大品般若》「菩萨行」的关键一段。

## 二、结构层次（★）

- **释集散品第九下（体名义属）**：经文以须菩提三问「何者是般若波罗蜜？何以故名？是谁般若波罗蜜？」立纲 → 论释先以「诸法实相、常住法位」答体；次以「离二边行中道」广答何义；复以「十八空破诸法」明无所有不可得 → 三种智慧（世俗巧便、离生智慧、出世间智慧）较胜，般若为第一 → 世谛属菩萨、第一义无所属，成佛转名一切种智。

- **释行相品第十（行相与无相门）**：经文先列「无方便堕相」之相——于色等五蕴、四念处乃至十八不共法作常无常、苦乐、我无我、空、离、寂灭等行，皆名行相 → 次明「有方便」即不行色、不行色相，色即是空、空即是色，乃至诸法无所受三昧 → 论释点出前品用空门、此品用无相门；取相为初学者说、无相为行道者说；以颇梨珠、不净身、水沫幻梦等喻显诸法无定相。

- **百八三昧（疾得佛道）**：舍利弗问但一三昧疾得佛否 → 须菩提广举首楞严三昧乃至坏身衰、离着如虚空不染等无量三昧 → 三事不异：般若不异三昧、三昧不异菩萨 → 菩萨于诸三昧不知不念，过去现在诸佛授记。

- **学般若波罗蜜不可得（收束）**：舍利弗问如是学为学般若否 → 佛答「不可得故」：我乃至知者见者、五阴十二入十八界、四谛十二因缘、三界、六波罗蜜、四向四果乃至佛皆不可得、毕竟净 → 毕竟净即不出不生、不得不作 → 凡夫以无明渴爱妄见分别，如以指示月而愚者看指 → 菩萨无方便着般若则不得萨婆若，有方便不见般若、不见行者、不见缘法、不见亦不见，入十八空故不见。

## 三、关键结论

1. 般若波罗蜜即诸法实相，常住法位，有佛无佛不异；其相即「离二边行中道」——常无常、苦乐、色无色、有漏无漏、无明无明尽乃至菩萨与六波罗蜜、佛与菩提，一切二法皆离是二边行中道。
2. 般若波罗蜜为一切智慧中第一，超世俗巧便、离欲智慧、声闻辟支佛出世间智慧，以毕竟清净、无所著、为饶益一切众生故；成佛时转名「一切种智」。
3. 贑萨行般若「无方便」即于五蕴等作常、无常、苦、乐、我、无我、空、离、寂灭等行相——虽观空而取空相，亦堕相中；「有方便」即不行色、不行色相，色即是空、空即是色，乃至诸法无所受三昧，与声闻辟支佛不共。
4. 贑萨于百八三昧乃至无量陀罗尼门，不作「我入、我住、我已入」等忆想分别，以心清净不着故，十方诸佛授记；般若、三昧、菩萨三事不异。
5. 学般若波罗蜜毕竟无所学、无所得——诸法内空乃至无法有法空故，我乃至佛不可得；毕竟净即不出不生、不得不作。无方便着般若则两失，有方便「不见般若、不见行者、不见缘法、不见亦不见」乃得萨婆若。

## 四、易混辨析

- **般若波罗蜜 vs 一切种智**：菩萨位中名为般若波罗蜜，成佛时转名一切种智；体一而位异，非二物。论中以「因中说果」「果中说因」明世间法立名之通则。

- **空门 vs 无相门 vs 无作门**：前品（集散品上）以空门破诸法，此卷行相品以无相门破诸法，后段无受三昧以无作（无作无起）收束；三解脱门名异实同，皆归毕竟净。

- **无方便 vs 有方便**：无方便非谓全不行般若，而是于色等作常无常等行相、取般若相以为有所得；有方便即不行色、不行色相，色即是空、空即是色，行亦不受乃至不受亦不受。分野在「取相」与「无所受」。

- **世俗巧便智慧 vs 离生智慧 vs 出世间智慧**：世俗巧便即博识文艺仁智礼敬；离生智慧即离欲界乃至无所有处之世间定慧；出世间智慧即声闻辟支佛漏尽之慧。三者皆不及般若波罗蜜，以前二不净欺诳、第三无大慈悲不能饶益一切故。

## 五、阅读提示

读本卷可带着「般若波罗蜜到底是谁的、到底是什么」这一问入文：先看须菩提如何以「无所有不可得」一义贯通六波罗蜜、五蕴、四念处乃至一切种智；再看行相品如何分辨「观空」与「取空相」之差——同说空、无相、无作，有方便则疾得佛道，无方便则尚不得小乘；末后一段「以指示月」之喻最堪玩味，凡夫着语言音声而失圣人意，菩萨入十八空故不见，非以无智故不见。
