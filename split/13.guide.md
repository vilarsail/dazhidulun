# 大智度论卷第十三 导读

## 一、内容总览
本卷是《大智度论》释《大品般若经》初品中戒学部分的展开，承接上文檀波罗蜜之后，正式进入「尸罗波罗蜜」（戒度）的讨论。卷中先立戒体——释尸罗名义与八种身口律仪，再广赞持戒功德、痛陈破戒之过；继而以「戒相义」逐条剖析不杀、不盗、不邪淫、不妄语、不饮酒五戒的成立条件、罪相轻重与果报，并讨论优婆塞五戒的五种受法、一日戒（八关斋）、六斋日持戒、四种持戒人（下中上上上）、出家五众戒（沙弥、沙弥尼、式叉摩那、比丘尼、比丘）。全卷以「戒为一切善法根本」为骨，由在家戒推至出家戒，由事相持戒推至求实相、趣佛道。

## 二、结构层次（★重点）
全文按「戒体 → 戒相 → 戒用 → 戒机 → 出家戒」层层推进：

- **释尸罗波罗蜜（戒体）** P1–P80：尸罗秦言性善 → 八种身口律仪 + 净命为戒相 → 下中上三品持戒得人天、四禅天、三乘果 → 上清净持戒得不著不猗、趣佛道 → 广赞持戒如大地、如护身命、香遍十方 → 德瓶喻（持戒者如得德瓶，破戒则瓶破物失）→ 破戒人二十余譬（毒蛇、枯树、霜莲、罗刹、吐食、热铜铁鍱缠身等）。
- **戒相义第二十二之一** P81–P159：恶止不更作即戒相 → 以不杀生戒为例详析：何为杀罪（实是众生、知、发心、命根断、身业、故作、快心）→ 不杀戒三性（善或无记）与三界系（欲界、色界、无漏）→ 引《迦栴延子阿毗昙》与余《阿毗昙》异说辨析 → 杀罪重辨：命为第一、贾客失宝唯庆全命 → 佛说五大施、慈三昧 → 难提迦优婆塞说杀生十罪 → 护戒舍身：须陀洹人屠杀家自杀不杀羊即生天上。
- **不与取（盗）戒** P160–P194：盗相（知他物、盗心、离本处、物属我）→ 属他物二种（聚落、空地）→ 夺财即夺外命 → 偷盗十罪（含「五家所共」：王贼火水不爱子）→ 劫盗之中盗为最重，喻美食杂毒。
- **邪淫戒** P196–P217：人守、法守二种守护 → 受一日戒、有娠、乳儿、非道皆邪淫 → 夫妻异身同体、夺他所爱名为贼 → 淫罪为「罪中之罪」→ 邪淫十罪（剑树地狱、家道不穆等）。
- **妄语戒** P218–P263：覆隐实、出异语为妄语 → 罪从「言声相解」生 → 覆瓶喻（道法不入）→ 俱伽离谤舍利弗、目揵连，梵天王劝诫不听，举身生疮死堕大莲华地狱 → 地狱寿量次第（阿浮陀→尼罗浮陀→阿罗逻→阿婆婆→休休→沤波罗→分陀梨迦→摩呵波头摩）→ 罗睺罗妄语喻（澡槃覆水不入）→ 妄语十罪。
- **不饮酒戒** P274–P285：谷酒、果酒、药草酒三种 → 难提迦优婆塞说酒三十五失 → 「实为饮死毒」偈。
- **优婆塞五戒与一日戒** P286–P368：四身罪+妄语口罪为优婆塞五戒律仪 → 五种优婆塞（一分、少分、多分、满行、断淫）→ 赞天福偈（蜜涂苦药喻：先赞戒福令能持戒，再趣佛道，是为尸罗生尸罗波罗蜜）→ 一日戒（八关斋）受法 → 六斋日持戒因缘（四天王视察、恶鬼恼乱、摩醯首罗日分）→ 五戒与一日戒比较：有大心一日持戒胜终身无大心持戒（软夫为将 vs 英雄一日）。
- **四种持戒人 + 出家戒** P369–P432：居家持戒四品（下为今世乐、中为后世福、上为涅槃、上上为佛道怜愍众生）→ 持戒→不悔→喜乐→一心→实智→厌→离欲→解脱→涅槃，戒为诸善法根本、八正道初门 → 出家戒四众（沙弥沙弥尼、式叉摩那、比丘尼、比丘）→ 出家易修难缘 → 优钵罗华比丘尼本生（破戒堕狱竟，值佛出家得阿罗汉）→ 醉婆罗门暂发出家心 → 受戒法（和上、阿阇梨、二部僧、三师十僧、第三羯磨得无量律仪）。

## 三、关键结论

- 戒为一切善法住处，如大地载万物；无戒而求好果，如无足欲行、无翅欲飞，必不可得。
- 上清净持戒者不著不猗、知戒实相、为度众生，将来令人至佛道——此即尸罗波罗蜜，超越人天与三乘戒。
- 五戒中杀罪最重（命为第一）、盗为一切有物人中贼、淫为罪中之罪、妄语闭塞天道涅槃门、酒覆没智慧；故十不善、五戒皆以杀居初。
- 戒相核心在「恶止不更作」——心生口言或从他受，息身口恶；杀罪须具足「实是众生、知、故、命根断」等条件，否则不成立。
- 五戒终身持与一日戒（八关斋）俱等，但有大心一日持戒胜于无大心终身持戒；出家虽破戒，以戒因缘故终得道果。

## 四、易混辨析

- **尸罗 vs 尸罗波罗蜜**：尸罗是「性善、好行善道、不自放逸」，通受戒、不受戒，通人天、三乘；尸罗波罗蜜特指上清净持戒——不著不猗、知戒实相、为度众生、趣佛道，是六度之一。
- **五戒 vs 一日戒（八关斋）**：五戒为优婆塞尽寿持，戒少时长；一日戒为一日一夜持八戒（加不坐高床、不香涂身、不歌舞观听、不过中食），戒多时短。居家二种俱名优婆塞法。
- **下中上上上四种持戒**：下为今世乐怖畏名闻、中为后世富贵福乐、上为涅槃厌无常、上上为佛道怜愍众生求实相——动机高低判戒品高下。
- **沙弥戒 vs 式叉摩那 vs 比丘尼戒**：沙弥沙弥尼十戒；式叉摩那受六法二岁，为避出家后有娠之讥嫌而设，未受具足故如小儿给使不致讥；比丘尼略说五百戒、比丘略说二百五十戒，第三羯磨讫皆得无量律仪。

## 五、阅读提示
读本卷可带着两条线索：一是「戒如何从防恶止作（事相）升进到知实相、趣佛道（理体）」，二是「在家五戒、一日戒与出家众戒之间的同异与难易」。留意德瓶喻、覆瓶喻、澡槃覆水喻三组譬喻，分别点破持戒失戒、妄语障道、妄语覆心三义。
