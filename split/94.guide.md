# 大智度论卷第九十四 导读

## 一、内容总览

本卷为《大智度论》卷九十四，含两段：前半续释「毕定品」（第八十三之余），后半为「四谛品」（第八十四）。主线一以贯之：菩萨既住一切法空的般若中，如何还能起神通、受身、说法、成佛？——关键在「无所得」：以空不着空，故能游戏神通而不染；众生不知自性空，故须佛说四谛拔济。

## 二、结构层次

**上半·毕定品之余（经→论）**

- 须菩提问：菩萨住何等白净法，能起方便力而不受染污 → 佛答：住般若波罗蜜——着者、着法、着处三法不可得，空不着空，名「不可得空」 → 追问「一切法皆入般若？」→ 空中无入无不入，一切法、一切法相空。
- 转问：住空云何起神通波罗蜜 → 佛答：观国土与佛皆性空、但假名字，以方便力生六种神通（天眼、天耳、如意足、他心智、宿命智、漏尽智）→ 鸟无翅喻：离神通不能饶益众生 → 随类说法：悭者教施、破戒教戒、瞋者教慈、散乱者教定、愚痴者教观十二因缘，令入三乘正道。
- 【论】层层推进：肉眼有碍，故以方便力（令他界四大来在身中）更求天眼 → 蝇唯不着火焰喻：众生于诸法皆着，唯般若性空火不可着 → 释「游戏神通」之名 → 立因缘：净佛国土、成就众生，缺一不得菩提 → 论过：着心布施如美食杂毒，取相故果报不净；着空取相亦堕邪见 → 收束：以如、法性、实际回向菩提，「无所分别心，能行布施等，是名真菩萨道」。

**下半·四谛品（经→论）**

- 问：菩萨法与佛法何别 → 佛答：菩萨法亦是佛法，差别在佛以一念相应慧知一切法、断一切烦恼习（向道、得果之异；十四日、十五日月喻）。
- 复问：自相空中云何有凡圣差别 → 佛答：法体虽空，众生不知自性空故作善、恶、无动三业，往来五道；佛实不得五道、不得黑、白等四业，生死如幻如梦 → 菩萨为拔济故发心成佛，说四圣谛，助道善法摄在四谛，由是立三宝。
- 再问：用谛得度？用智得度？→ 佛答：非谛非智，「四圣谛平等故，我说即是涅槃」——无四谛亦无四谛智，如、法性、法住、实际，有佛无佛常住。
- 收束：菩萨如实见一切法空（谛所摄、所不摄法皆空）→ 入菩萨位、住性地、不堕顶 → 观如实相即是观自性空 → 末以方便力作结：得无生忍、大悲深念，庄严三十二相引导众生。

## 三、关键结论

- 神通是般若空慧所起的度生工具，不是境界炫耀：离神通不能随众生意说法，如鸟无翅。
- 菩萨六道受身而苦乐不染，枢纽在无所得空——空不着空。
- 净佛国土、成就众生是成佛必具的因缘，缺一则「因缘不具足」。
- 着心行布施如美食杂毒；执空取相亦堕邪见——菩萨双遣两边。
- 四谛与四谛智皆从缘生、虚妄不实，非以谛得度、亦非以智得度；四谛平等处即是涅槃，道谛到岸亦须舍（筏喻）。
- 若众生自知诸法性空，则菩萨「无所度」；度生正建立在众生不知空、取相起业之上。

## 四、易混辨析

- **菩萨法 vs 佛法**：所行同是六波罗蜜乃至十八不共法；菩萨在无碍道中行，佛于解脱道无一切闇蔽——如十四日与十五日月，同为月而力用异。
- **四圣谛 vs 四谛智**：谛是所观之理，智是能观之心；二者和合俱起，佛言非谛得度、非智得度。
- **有余涅槃 vs 无余涅槃**：爱等烦恼灭名有余；趣无余时连道谛亦以空空三昧舍离。
- **黑业、白业、黑白业、不黑不白业**：分别感地狱苦报、诸天乐报、人阿修罗苦乐杂报与无漏解脱；无漏业非黑非白，以空无相无作、无相待故。
- **五道 vs 六道**：本卷两词互见，六道多算阿修罗，所指实同。
- **性地 vs 顶堕**：性地（燸、顶、忍、世第一法）住之必望得道；若从顶位退堕，则落声闻、辟支佛地。

## 五、阅读提示

带着两个问题读：一是「住空者如何动作」——前半全在回答空与神通、空与度生的关系；二是「既一切法空，何须说四谛」——后半说明四谛是应众生不知空而立的方便，谛智俱泯处即是实相。
