# 大智度论卷第四十八(释第十九品) 导读

## 一、内容总览
本卷为《大智度论》释第十九品，紧承前卷阐释「菩萨摩诃萨摩诃衍」（菩萨大乘法相）。全卷可分两大段：前半先详释四念处——身、受、心、法，循观不净、苦、空、无我，以「不可得故」收束；后半以经文枚举大乘所摄一切法数：四正勤、四如意足、五根、五力、七觉分、八圣道分、三三昧、十一智、三根、十念、四禅、四无量心、四无色定、八背舍、九次第定、佛十力、四无所畏、四无碍智、十八不共法，终以「字等、语等诸字入门」即四十二字门陀罗尼作收。论主在经文夹缝中插入释义，由浅入深，由声闻暖顶忍第一法，导至菩萨无生法忍与文字陀罗尼，处处以般若波罗蜜毕竟空和合，明菩萨不取涅槃之本愿。

## 二、结构层次
全卷依「经—论—经—论」四重交错展开：

- **经·四念处广说（P5-P32）** → 佛告须菩提，先标四念处总相，再就身念处层层细分：行住坐卧四威仪 → 入息出息长短知 → 四大观 → 三十六不净 → 九想观（膀胀青瘀、禽兽食、骨锁、骨散、色白如贝）。「循身观」「不生身觉」「勤精进一心」「除世间贪忧」四个语汇反复出现，构成身念处的修法骨架。受、心、法三念处则略举同名循观。
- **论·释四念处疑（P34-P109）** → 设六重问（十二种观、内外、循身观、不生身觉、勤精进一心、除贪忧、不净观）逐一作答：
  - 内外三种邪行 ↔ 三种正行；自身他身、九受入、五情五尘诸分别内、外。
  - 循身观 = 寻随观察，知不净衰老病死；不生身觉 = 不取一异相起戏论。
  - 勤精进一心 = 攒燧求火之喻；除贪忧 = 破竹初节之喻，贪破则五盖尽去。
  - 不净观先、安那般那次，二法名「甘露初门」。
  - 屠牛、田夫仓、死尸九想三喻贯穿，明不净、无常、苦、无我四观。
  - 收束于四谛 → 暖顶忍第一法 → 须陀洹至阿罗汉辟支佛 → 菩萨无生法忍；三十七品总归「慧多故名念处、精进多故名正勤、定多故名如意足」。
- **经·三十七品至十八不共法（P110-P189）** → 复次广列：四正勤（未生恶不生、已生恶断、未生善生、已生善增广）→ 四如意分（欲定、心定、精进定、思惟定）→ 五根五力 → 七觉分（依离依无染向涅槃）→ 八圣道分 → 三三昧（空无相无作）→ 十一智（苦集灭道尽无生法比世他心如实）→ 三根（未知欲知、知、知者）→ 三三昧（有觉有观、无觉有观、无觉无观）→ 十念 → 四禅四无量四无色八背舍九次第定 → 佛十力 → 四无所畏 → 四无碍智 → 十八不共法。每段皆以「以不可得故」作结。
- **经·四十二字门陀罗尼（P190-P237）** → 标「字等、语等诸字入门」，列阿、罗、波、遮、那……乃至荼字共四十二门，每字配一法义（阿=初不生，罗=离垢，波=第一义……荼=边竟处不可得）；「过荼无字可得」收束，明诸法如虚空；次明修此陀罗尼得二十功德。
- **论·释字门（P239-P314）** → 释「字等语等」即陀罗尼，与毕竟空涅槃同等；四十二字是一切字根本，因字有语，因语有名，因名有义；逐字重释其梵音秦译（阿提=初、阿耨波陀=不生……），终以日月岁节四种月之巧分别收结，明世间法如幻如梦。

## 三、关键结论
1. 菩萨修四念处及三十七道品，与声闻同法而异心——以「不可得空」调伏心地，本愿牢故、大悲深故，不取涅槃。
2. 「循身观」非泛观身，乃寻随本末观察不净腐败归土；「不生身觉」则不取一异相起戏论，是为菩萨观身之要。
3. 不净观与安那般那二法为「甘露初门」；先治贪欲以破竹初节之喻，一节破则五盖尽去。
4. 三十七品之名义差别但由根性与用功偏重而立：慧多念处、精进多正勤、定多如意足，钝根名根、利根名力，未办名道、已办名觉。
5. 四十二字门为一切陀罗尼根本，诸字因缘未会时亦无、终归亦无，与毕竟空涅槃同等；得此陀罗尼即得般若波罗蜜毕竟空，自然具足无量功德。

## 四、易混辨析
- **四念处 vs 四谛**：四念处是所观行法（身受心法，观不净苦空无我），四谛是所证理（苦集灭道）；论中以四念处四观配四谛——不净无常等即苦谛，爱等烦恼即集谛，断即灭谛，方便即道谛。
- **暖法 vs 顶法 vs 忍法 vs 世间第一法**：暖如攒火得暖气必望得火，是信涅槃道似如无漏；顶如上山至顶两边道里俱等，罪福停等；忍至阿罗汉辟支佛是一边道，暖至顶是一边道；世间第一法在菩萨即柔顺法忍。
- **四念处 vs 四正勤 vs 四如意足**：同是三十七品之初三科，其体皆是智慧定精进，但用功偏重不同——慧多故念处、精进多故正勤、定多故如意足；如意足之「足」名如意因缘亦名「分」。
- **字等语等 vs 陀罗尼**：字等语等是陀罗尼之一种，特就「四十二字门」而言，诸字于诸字平等无爱憎，与毕竟空同等；五百陀罗尼略、无量广，此是诸陀罗尼初门，说初则余亦说。

## 五、阅读提示
读本卷宜抓住两条暗线：一是「以不可得故」六字在各段反复出现，是菩萨行异于声闻的根本标帜；二是论中屡以「破竹初节」「攒燧求火」「屠牛分四分」「田夫开仓」「人夜食不净」等譬喻串联，喻即法相，不可作闲文看过。
