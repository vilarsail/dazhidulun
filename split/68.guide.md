# 大智度论卷第六十八 导读

## 一、内容总览

本卷论释《摩诃般若波罗蜜经·魔事品第四十六》与《两不和合品第四十七》，是全经专讲"魔事"的一卷。前品应须菩提之问——行六波罗蜜、成就众生、净佛世界的菩萨，云何求佛道时生诸留难——佛广说种种魔事，论主随文解释魔的体性与每一魔事的成因；后品专讲"两不和合"：说法人与听法人两心不相应，般若便不能书写、受持。全卷宗旨是教菩萨觉知魔事、不随其事，而非教人惧魔。

## 二、结构层次

三段经文、三段论释，经立魔事之相，论究魔事之理：

- **经一·列举魔事**：以两类场景逐一列数——说法时（乐说辩不即生、乐说辩卒起）；书写、受持、读诵、正忆念时（偃蹇傲慢、戏笑乱心、轻笑不敬、心乱不定、各各不和合、不得经中滋味便弃舍、转相形笑、共相轻蔑）→ 须菩提追问"不得滋味"与"何以不与受记" → 佛答：前世不久行六波罗蜜、未入法位者不与受记、不说名字生处；起念弃舍者"念念却一劫"。
- **论一·释魔体性**：总原理（一切有为法各有增上，增上相违即是怨贼）→ 分列众生法、非众生法二种怨贼 → 总名"魔"，别为四魔（烦恼魔、五众魔、死魔、天子魔）→ 释名义："魔，秦言能夺命者"，亦夺慧命 → 问答辨难：四魔实是一魔、三魔不相远离 → 逐条回注经文（听者心坏、爱法求名如逸马、般若为破憍慢故出、信等五根薄故不得滋味）。
- **经二·学余经之魔事**："学余经、弃舍般若，终不能至萨婆若" → 七重譬喻（狗从作务者索食、见象反观其迹、欲见大海反求牛迹水、造帝释殿反揆日月宫殿、见轮王反取小王相貌、得百味食反食谷饭、得摩尼珠反比水精珠）→ 书经时乐说不如法事 → 般若无相、自性无故不可书 → 书时异念纷起、爱着利养、恶魔持余深经来乱。
- **论二·般若为根本**：声闻人以六足阿毗昙、八十部律、本生劝人舍般若 → 论判：般若是三藏根本，余经是枝叶；摩诃衍虽亦说三十七品、三解脱门，然与毕竟空合、不舍萨婆若与大悲 → "不如法"者不如般若实相，着心乐说即魔事 → 酥和毒喻：有方便者观声闻道而不证。
- **经三＋论三·两不和合**：六对师徒不相应（欲书对懈堕、欲说对不受、各欲他方、贵重利养对少欲知足、受头陀对不受头陀）→ 论释：如攒燧求火，师徒内外因缘和合方成 → 逐条解释十二头陀每支的立意 → 收束：头陀不名为戒，佛法唯以智慧为本、不以苦为先。

## 三、关键结论

- 凡能沮坏无上道心的众生法与非众生法，佛总名为魔；四魔实是一魔，分别其义。
- 未入法位者，诸佛不与受记、不说名字生处；于深般若起一念弃舍，念念却一劫。
- 般若是三藏根本、如树根茎，声闻经是枝叶；舍根取枝，终不能至萨婆若。
- 般若自性无故不可书、无文字；执"我书般若"与执"无法是般若"同为魔事——魔事关键在着心，不在事相。
- 书写受持般若须师徒同心，两不和合即魔事；十二头陀是助道庄严而非戒，佛法以智慧为本、不以苦行为先。

## 四、易混辨析

- **乐说辩不即生 vs 乐说辩卒起**：同判魔事而病因相反——前者钝根懈怠，魔令辩才不生；后者爱法着法、求名声而自恣乐说，如逸马难制。
- **摩诃衍说三十七品 vs 声闻经说三十七品**：法同而心异。大乘与毕竟空合、心无所著、不舍萨婆若与大悲；声闻经为小乘取证故说。
- **萨婆若 vs 一切种智**：萨婆若意译"一切智"，泛指佛果遍知；一切种智特指遍知一切法总相别相的佛智。本卷连言六度乃至一切种智皆自性无，故般若不可书。
- **"无记"（未受记）vs 无记性**："我于般若波罗蜜中无记"是说佛未与我受记，非阿毗昙"非善非恶"之无记法。
- **十二头陀 vs 戒**：头陀不名为戒，能行则戒庄严，不能行不犯戒——如布施能行得福、不行无罪。

## 五、阅读提示

带着一问去读："为何连'不得经中滋味'、'乐说辩才涌出'也判为魔事？"答案在一个"着"字——魔不在事相而在着心。再留意"有方便／无方便"一对：观声闻道而不证、以大悲心行三解脱门，即是魔不能转的分水岭。
