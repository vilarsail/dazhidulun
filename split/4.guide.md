# 大智度论卷第四 导读

## 一、内容总览
本卷是《大智度论》初品中「菩萨释论」第八，承接前卷对般若会上大众的说明，专释「菩萨」一名。以问答往复展开两大主线：先辨「何为菩萨」「何名菩提萨埵」，建立菩萨的得名、退与不退、三大阿僧祇劫修行位次；次广说三十二大人相的因缘、种业、福量，以及六波罗蜜满的本生事迹。最后摩诃衍人对声闻论师（迦旃延尼子弟子辈）所立菩萨义层层批驳，归宗于大乘般若波罗蜜广大无边、三世十方佛皆出世度生之旨。

## 二、结构层次（★重点）
全文以「释名 → 立位 → 明相 → 明行满 → 明佛果 → 破异执」六段递进，问答为骨，层层推进：

- **释菩萨次第之所以（P7-P33）**：问「何先比丘后菩萨」→ 答「现示法中阿罗汉烦恼尽故先，秘密法中菩萨已断无生法忍」→ 复问「何在优婆塞后」→ 答「四众通名声闻众，仪法不便故在后」→ 复以「二种道」（声闻道与菩提萨埵道）收束，显大乘经两众并说之所以。
- **释「菩提萨埵」名义（P52-P67）**：菩提名诸佛道，萨埵名众生或大心 → 复以「称赞好法为萨，好法体相为埵」重释 → 引三种道、大誓愿、不可动精进三事立名 → 退（鞞跋致）与不退（阿鞞跋致）二种菩萨分判。
- **明阿鞞跋致相（P68-P84）**：般若波罗蜜阿鞞跋致品佛自说相 → 一法（常一心集善法）、二法（知空不舍众生）、三法（金刚愿、彻骨悲、般舟三昧）递进 → 转入阿毗昙所立菩萨义（自觉觉他、离五法得五法、种三十二相业已来名菩萨）。
- **明三大阿僧祇劫与三十二相业（P85-P135）**：过三阿僧祇劫然后种相业 → 释阿僧祇数法（二二名四…过迦他名阿僧祇）→ 三劫中自知作佛之渐（初不自知、二知不称、三了了自称）→ 释迦文佛三劫所值佛（释迦文→剌那尸弃→燃灯→毗婆尸）→ 三十二相种处（欲界人道阎浮提男子身佛出世时）、种业（意业意识）、种相先后、一思一相百福庄严、福量种种譬喻、极迟百劫极疾九十一劫、弗沙佛前一偈赞超九劫。
- **六波罗蜜满与本生事迹（P147-P234）**：六波罗蜜名相列 → 檀满（尸毗王割肉饲鹰）、尸罗满（须陀须摩王宁死不妄语）、羼提满（羼提比丘为迦梨王截支体）、毗梨耶满（大施菩萨抒海、赞弗沙佛七日不眴）、禅满（尚阇梨仙人鸟生髻中）、般若满（劬嫔陀分阎浮提为七分）→ 菩萨生兜率天之所以（结使不厚不利、与佛出时会、中道）→ 四种观人间（时、土地、种姓、生处）→ 正慧入胎（歌罗罗、頞浮陀、伽那、五疱忆念不失）→ 出胎七步自称末后身。
- **三十二相逐一列举（P266-P316）**：从足安平立、足下二轮，至顶髻、白毛，共三十二大人相，每相附问答辨相之所以。→ 相师占相「在家为转轮王、出家当成佛」→ 菩萨相七事胜转轮圣王（净好、分明、不失处、具足、深入、随智慧行、随远离）。
- **成佛与破异执（P335-P417）**：见老病死出家、六年苦行、食乳糜、降魔成道 → 得尽智无生智名为佛，具十力四无所畏十八不共法 → 譬王子未作王名王子，已作王不名王子，明菩萨与佛得名之异 → 摩诃衍人破迦旃延尼子弟子辈所立菩萨义：三阿僧祇劫中非无相业（燃灯佛所已受记上升虚空见十方佛）、难陀等亦有相故相非九十一劫方种、初发心即知作佛（阿遮罗菩萨于长手佛边发心）、无量阿僧祇劫作功德非仅三劫、色界及余道亦可有种相因缘（娑伽度龙王十住等）、一思不能种一相须多思和合、弥勒弟子非必未纯淑、分地为七分仅世俗般若少许分、般若波罗蜜为三世诸佛母如幻如响、佛不待时故过八万岁亦应出世、十方世界皆应有佛（一三千大千世界无二佛出非十方无佛）、一佛不能度一切众生故应有余佛、众生罪垢不见佛非佛不来 → 结归欲作般若波罗蜜论议，余不能广。

## 三、关键结论
1. 菩萨虽智慧多而烦恼未尽，故现示法中在阿罗汉后；然以秘密法论，得无生法忍、断烦恼、具六通，实则超胜阿罗汉、辟支佛。
2. 菩萨得名在于「大心」「大誓愿」「精进不退」三事；从初发心至金刚三昧皆名菩提萨埵，有退（鞞跋致）与不退（阿鞞跋致）二种。
3. 三十二大人相须过三阿僧祇劫后种业，一一相百福庄严，极迟百劫、极疾九十一劫办；然相非声闻论师所执「九十一劫方种」，大乘以初发心即知作佛、无量阿僧祇劫作功德为正。
4. 六波罗蜜满各有本生事迹，般若波罗蜜满非世俗算数分地之少分，实是无量无边、三世诸佛之母、一切法实相。
5. 一三千大千世界无一时二佛出，非谓十方无现在佛；众生不见佛由自罪垢，非佛不来度——佛出世待福德根利之时，亦不待时（过八万岁佛亦应出）。

## 四、易混辨析
- **菩萨 vs 阿罗汉**：菩萨智慧多而烦恼未尽（现示），阿罗汉智慧少而烦恼尽无余；秘密中菩萨得无生法忍、烦恼已断、具六通，则超胜阿罗汉。故大乘经列菩萨众别于声闻四众。
- **鞞跋致 vs 阿鞞跋致**：前者退转菩萨，后者不退转；阿鞞跋致以常一心集善法、正直精进、知空不舍众生、金刚愿彻骨悲般舟三昧等相验之，是名实菩萨。
- **声闻乘 vs 佛乘（大乘）**：声闻乘狭小、自利自为、多说众生空；佛乘广大、益一切、说众生空与法空；喻如驴马驼象之乘与摩诃衍人乘，不可相比。
- **三十二相：菩萨 vs 转轮圣王**：二者皆具三十二相，然菩萨相有七事胜——净好、分明、不失处、具足、深入、随智慧行不随世间、随远离；转轮圣王相不尔。
- **世俗般若波罗蜜 vs 实般若波罗蜜**：分大地城郭为七分仅世俗算数少许分，如大海一渧；实般若波罗蜜三世诸佛母、示一切法实相、无来去、如幻如响如水中月。

## 五、阅读提示
本卷问答密集、层层转进，可抓住「释名—立位—明相—明行—破执」五段骨架。读三十二相逐一列举处不必强记每相，重在「七事胜转轮王」与「百福庄严」之义。末段摩诃衍人对声闻论的批驳是全卷论辩高潮，留意「燃灯佛所受记」「初发心即知作佛」「十方佛」「佛不待时」诸节点，皆归宗于般若波罗蜜广大无边之旨。
