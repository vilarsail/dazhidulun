# 大智度论卷第十五 导读

## 一、内容总览
本卷含两品：初品中「羼提波罗蜜法忍义第二十五」与「毗梨耶波罗蜜义第二十六」，即六波罗蜜中的**忍辱波罗蜜**与**精进波罗蜜**。前者广辨「法忍」——菩萨于内外诸法、烦恼结使、十四难、有无论、实相观中，心信不转、不随不着的能耐；后者辨「精进」所以列第四——前三是福德门，禅定般若是智慧门，唯精进能生禅定、能发先世福、能动无上道。一线贯穿：「忍」是从伏惑到观空，「进」是从发心到成办。

## 二、结构层次（★重点）
全文按「法忍总相 → 法忍别相 → 实相观忍 → 精进缘起 → 精进利益」五大段推进：

- **法忍总相（P7-P12）**：定义法忍——内六情不着、外六尘不受、二相俱不可得 → 引《毗摩罗鞊经》不二入法门为证 → 分法为众生法与心法、非心法两类，菩萨于此二能忍不动。
- **法忍别相（P13-P51）**：以「问→答→复次」层层展开外忍与内忍。
  - 外忍（P14-P26）：寒热风雨非心法虽无增损而生恼乱 → 自知宿罪、净不净国、世间八法、人身无牢、四大五众之苦、阿鼻泥犁誓愿 → 譬喻肥羊、乌衔肉，明富贫愚智皆苦。
  - 内忍（P28-P51）：诸结未断而能不随 → 外魔军与内魔军十支（欲、忧愁、饥渴、渴爱、睡眠、怖畏、疑悔、瞋恚、利养虚称、自高蔑人）→ 着忍辱铠、捉智慧剑、执禅定楯 → 不应断结恐堕阿罗汉 → 无脂肥羊喻、师子王喻、闭贼修业喻 → 实知诸法相、于结不瞋、功德不爱。
- **实相观忍（P52-P146）**：从法相数门深入观——一相门（可识、可知、可缘、假名）、二相门（内外、有无、漏无漏、为无为等）、三相门（下中上、善不善无记、见谛断等）→ 三法印（无常、无我、涅槃）→ 十四难不答（毒箭喻）→ 有无边、常无常皆不实、非有非无是痴论 → 有无二边虚诳、名字和合故谓有 → 色法析至微尘、无色法刹那生灭入空智门 → 中道实相，恒河沙诸佛所知所说 → 禅定柔软心、智慧力观 → 凡夫转相、圣智破无明毒 → 毕竟空不取相则法忍，取相则恶邪 → 三种清净行：不见忍辱法、不见己身、不见骂辱人，结归「住般若波罗蜜中能具足羼提波罗蜜」。
- **精进缘起（P147-P172）**：经文标「身心精进不懈息」→ 释名毗梨耶秦言精进 → 问：精进为善法本应列初，何以第四？答：施戒忍世间常有、不须精进；今欲知实相行般若、修禅定，禅定是实智慧之门，须大精进力 → 福德门与智慧门二门 → 散乱心不见实相，风中灯不能照，密屋灯能照 → 须血肉脂髓竭尽、皮骨筋在不舍精进 → 破福德自然得道之执（顶生王、罗频珠比丘乞食不得）。
- **精进利益（P178-P216）**：问：菩萨观精进有何利益？→ 一切今世后世道德皆由精进 → 赞精进偈（农夫、远路、火宅）→ 精进为一切善法根本、能动先世福如雨润种 → 荷负众生乃至阿鼻泥犁心不懈 → 巴豆为下药主、精进遍在一切诸法如无明使 → 增益精进如小火增益能烧大林 → 呵懈怠偈（懈怠黑云、毒食、被贼、马井二比丘坠恶道）→ 菩萨知法空而不证涅槃、集善法是精进力 → 一人独无等侣破魔军 → 法身付弥勒迦叶阿难、入金刚三昧碎身如芥子 → 七觉意中精进觉意佛三问三答、从坐起告阿难 → 精进亦名欲、名不放逸（远行喻）→ 擎油钵行大众中、偏阁险道、水流决石 → 三种思惟：我不作不得、不自作不从他来、我作者终不失 → 阿兰若比丘林神入尸骨歌儛警发得阿罗汉 → 不自惜身而惜果报，失火投瓶唯存灭火。

## 三、关键结论
1. **法忍非强抑**，乃于内外六情六尘、心法非心法、烦恼结使中，以实相观故不随不着——内相如外、外相如内，二相俱不可得。
2. **不应断结**：菩萨于诸烦恼中修忍而不断结，若断结则堕阿罗汉道、与根败无异；故遮而不断，以正思惟、观空无常相故不随。
3. **十四难不答**：为老病死人说济度法，十四难是斗诤法、戏论无益；如人中毒箭应先出箭涂药，不应先问箭所从来。于十四难中不滞不碍、不失中道，是法忍。
4. **常无常皆不实**：若常则无罪福、亦无缚解、世间则涅槃；若无常则是断灭、因缘果报亦失。有见无见二边虚诳，名字和合故谓有，不堕有无见得中道实相。
5. **精进列第四**：前三是福德门，禅定般若是智慧门，散乱心不见实相，故须大精进力为禅定实智慧之根；精进为一切善法根本，能动先世福德如雨润种，遍在一切诸法如无明使。

## 四、易混辨析
- **生忍 vs 法忍**：生忍是忍恭敬供养及瞋恼淫欲之「人」，法忍是忍恭敬瞋恼淫欲之「法」及寒热风雨饥渴老病死等「非心法」；生忍对众生，法忍对诸法。
- **外忍 vs 内忍**：外忍对寒热风雨饥渴老病死等非心法（外魔军），内忍对瞋恚忧愁疑淫欲憍慢等心法（内魔军结使烦恼）；菩萨着忍辱铠捉智慧剑执禅定楯，遮内外两种烦恼箭。
- **遮而不断 vs 断结**：菩萨于结使遮而不随、不令纵逸，如贼以因缘故不杀、坚闭一处而自修事业；若断结则堕阿罗汉道，失菩萨利他大行。
- **福德门 vs 智慧门**：施戒忍是福德门，除罪所愿皆得；摩诃般若波罗蜜是智慧门，不厌生死不乐涅槃，二事一故；精进为禅定实智慧之根，总贯二门。
- **欲 vs 精进 vs 不放逸**：欲是初发心去行，精进是发行不住，不放逸是自劝励不令稽留；欲生精进，精进生故不放逸，不放逸故能生诸法乃至成佛。

## 五、阅读提示
本卷是六波罗蜜中两品的论议核心，可抓住两条线索：法忍的「遮而不断—观空不取相—中道实相」三阶，与精进的「福德智慧二门—精进为禅定之根—欲进不放逸三义」。遇到长串偈颂，先看偈前长行所立何义，再以偈为证。
