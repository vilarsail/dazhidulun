# 大智度论卷第九 导读

## 一、内容总览

本卷为《大智度论》卷第九，承初品放光释论之余，并续入「十方诸菩萨来释论第十五」。全卷以「佛德特尊→放光神力→十方有无之辩→多宝世界与普明菩萨」四段一线贯穿：先答佛何以独尊而复受九罪，明二身（法性身、父母生身）之别；次释佛说般若前所现六种神力与天人供养华台；再大段辩「十方实有诸佛」，破「唯释迦一佛」之执；末了引东方多宝世界、宝积佛、普明菩萨来问因缘作结。核心是：佛以二身、二力普度，十方佛实有，众生不见乃由罪垢，非佛不来。

## 二、结构层次

- **佛德独尊与九罪报之辩（问答展开）**：问佛何力特尊 → 答因缘大故果报大、世世修诸苦行 → 转问既神力无量何以受九罪 → 答有二种身（法性身满虚空常度、父母生身次第如人法）+ 方便示现非实受罪 → 引《毗摩罗诘经》阿难乞乳事证「方便非实病」→ 收束「其德特尊，威德巍巍」。
- **说般若前现六种神力（枚举递进）**：佛以常身示三千大千世界 → 诸天持华供养 → 论释欲说摩诃般若波罗蜜入三昧王三昧，光明从足至髻 → 第二毛孔微笑 → 第三放常光 → 第四舌相覆界 → 第五师子游戏三昧六反震动 → 第六现最胜身 → 疑者见常身得信解。
- **诸天与供养（释名穿插）**：释净居天、梵世天（初禅三品、第四禅八处、十住菩萨住处）→ 释他化自在、化自乐、兜率、夜摩、三十三天、四天王 → 须弥山与由揵陀罗山四城 → 天华香气逆风、四色无黄、宝莲华以琉璃金刚阎浮那陀金为茎台叶 → 华散佛身化大台、台住虚空示因少果多福田不失。
- **十方有无之大辩（本卷重心，层层破执）**：问东方过恒沙世界最在边岂堕有边 → 答方便说非实、十四难俱邪见、多宝乃释迦所度之边 → 释多宝、宝积之名 → 问何独释迦一佛 → 引日出三昧、脐出莲华化佛满中偈 → 破「世无二佛」乃一佛世界非十方 → 依法依义依智依了义四依释未了义 → 优昙波罗华喻、舍卫九亿三见三不见、贫老母四向背佛证无缘不见 → 《杂阿含》雨渧世界喻、《长阿含》鬼神王礼三世佛 → 过去未来无量故现在亦无量 → 声闻法中不说十方佛者令勤精进故 → 信有得福、言无得罪 → 弥勒近不来何怪远佛 → 遍吉、法华、《阿弥陀佛经》《般若》现事证来者甚多。
- **普明菩萨来问（收束）**：东方多宝世界有菩萨名普明 → 释其明常照一切 → 见光、地动、佛身而至宝积佛所问因缘 → 答菩萨虽大不知佛智如月光日灭、犊子随母、小王朝大王、大象劈树令小象食 → 为小菩萨故发问。

## 三、关键结论

1. 佛有二种身——法性身满虚空常度众生、父母生身次第说法如人法；九罪报乃生身佛方便示现，非实受罪，为怜愍未来众生令白衣供养比丘。
2. 佛说般若前现六种神力，皆在令众生信解而至阿耨多罗三藐三菩提；所散少华化虚空大台，示因少果多、福田得报不失。
3. 十方实有无量诸佛；「世无二佛」「余劫无佛」皆是声闻法中一佛世界之方便说，非十方无佛，令众生怖畏难遇而勤精进。
4. 众生不见十方佛，非佛不来，乃自心罪垢深重不见不闻；心净则见佛，如明镜净水照面则见。
5. 依法不依人、依义不依语、依智不依识、依了义经不依未了义——四依为判别经中方便说与实义之准绳。

## 四、易混辨析

- **法性身佛 vs 父母生身佛**：法性身满十方虚空、相好庄严、常度一切无须臾息，非凡夫所见；生身佛次第说法如人法，受寒热罪报。受罪者乃生身佛，非法性身。
- **一佛世界 vs 十方世界**：一佛世界者，百亿须弥日月之三千大千世界恒河沙数合为一佛所化之域，其中实唯释迦一佛化作诸身；十方世界则各有其佛，如东方多宝世界宝积佛。经言「世无二佛」指一佛世界，非谓十方无佛。
- **了义经 vs 未了义经**：了义者直说实义，如布施得大富、持戒生天；未了义者方便说，如说法无财施而言得富（实由赞施破悭而得富）。四依中应依了义不依未了义。
- **声闻法 vs 摩诃衍（大乘）**：声闻法中佛不别说十方佛，恐众生懈怠谓佛易遇，亦不言无；摩诃衍中则明说实有十方佛。同是佛说，依众生机有隐显。

## 五、阅读提示

带着两个问题读：一者佛既神力无量何以受九罪——见二身之义与方便示现；二者十方有无佛之大辩——见四依、方便说、罪垢不见三层论证如何层层递进。注意本卷大段偈颂（日出三昧脐出莲华化佛偈、诸佛先观知人难度偈）为论证插叙，勿作闲文略过。
