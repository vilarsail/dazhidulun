# 大智度论卷第八十九 导读

## 一、内容总览
本卷合〈四摄品〉后半（"释四摄品第七十八之余"）与〈善达品〉（第七十九）。前半承四摄：列佛八十随形好，明菩萨以财法二施、爱语、利行、同事摄取众生，并以四十二字门总持说法；须菩提两番发难——众生毕竟不可得，云何为众生说法？色既不异法性，云何有业报圣果？佛以十八空、"不失诸空相""世谛故分别"作答。后半以化人、幻师二喻显"一切法但有名相"，菩萨善达法性而不坏法性，虽知诸法如幻如化，仍于阿僧祇劫行六波罗蜜、成就众生、净佛国土。

## 二、结构层次
**四摄品之余（经 → 论）**
- 列八十随形好 → 二施摄取众生 → 爱语、利行、同事（五神通入五道）四事摄取。
- 教四十二字门：一切语言皆入诸字门，四十二字亦入一字 → "为无字法故说字法""过一切名字故，名为佛法"。
- 难"众生毕竟不可得，云何说法" → 佛印可：众生不可得故当知十八空乃至诸果皆空 → 菩萨"不失诸空相"、不二不分别而说法，如化人无心数法而能教化，以不住法住诸法相、不缚不脱。
- 再难"色不异法性，云何分别业报圣果" → "世谛故，分别说有果报，非第一义" → 凡夫不知二谛故无果 → "修道得果不？""不也"，着心求果如"麻中出油"。
- 【论】释"识满足"（菩萨处胎十月总得一岁）、四十二字义（"阿"字为本）、唯说二空之由（余空如火烧木犹有灰烬）、修与不修俱不得果。

**善达品（经 → 论）**
- 化人喻起：一切色受想行识如化，化人无垢无净、不在五道生死，菩萨何用？→ 众生自不知诸法如幻如化，故菩萨于阿僧祇劫行六波罗蜜。
- 众生但住"名相虚妄忆想分别"中 → 广说何等为名、何等为相 → 一切法但有名相 → 菩萨无相故具足诸波罗蜜，无相法即三乘圣法，"一切善法皆入三解脱门"。
- 依三解脱门遍学五受阴：色如水沫、受如水泡、想如焰、行如芭蕉、识如幻作四种兵 → 知诸入、界、四谛、十二因缘 → "学法性则学一切法"，色即是法性。
- 难：法性中无分别，菩萨分别行六度岂不堕非道？→ 幻师喻收束：幻作男女象马乃至须陀洹、辟支佛，无智叹未曾有、有智知无实事 → "以无名相之法，以名相说"，法性前、后、中无异。
- 【论】释重问之由（犊子恋美乳喻）、恶狗临井自吠其影等喻、名相之别（见烟知火，相为本名为末）、微尘但有虚名、"摩诃衍法与声闻法异"、法性"从本已来常空"。

## 三、关键结论
- 菩萨以不住法住诸法相中，为众生说法而不失空相；口说空而心著有、执所说不空，皆失空相。
- 业报与四沙门果皆世谛分别；第一义中不缚不脱、无相无言说。
- 修道不得果，不修道亦不得果；不着心修道则有道果，着心求果如"麻中出油"。
- 一切法无有根本实事、但有名相；无相、无忆念是无漏法体，三乘圣道即是无相法。
- 众生不知诸法如幻，菩萨故于长夜行菩萨道；学法性即遍学一切法。

## 四、易混辨析
- **毕竟空 vs 无始空**：毕竟空破诸法，无始空破众生；余空如火烧木犹有灰烬，毕竟空无灰无烬。
- **世谛 vs 第一义**：业报圣果在世谛中差别建立；第一义"实无有相，无有分别，亦无言说"。
- **名 vs 相**：名是众物之字（热物字为"火"），相是可见之征（见烟知是火）——相为本，名为末。
- **一切智 vs 一切种智**：一切智知诸法总相；唯佛一切种智究尽别相、通达实相。
- **化人喻 vs 幻师喻**：前者喻说法无分别、不受报；后者喻从初发意游戏神通，示种种法而中无实事。

## 五、阅读提示
众生与诸法毕竟不可得，说法与修道何以可能？——"以不住法故住诸法相""以名相说无名相之法"。凡遇"不可得""不二不分别"，勿作断灭会：诸法非入涅槃时乃空，从本已来常空。
