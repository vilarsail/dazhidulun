# 大智度论卷第五十(释第十九品讫第二十品) 导读

## 一、内容总览

本卷承接第十九品末尾，分两大段：前段为《发趣品第二十》之余，以「菩萨十地」为骨架，逐地列举七地、八地、九地、十地菩萨所应具足的法门；后段为《出到品第二十一》，由须菩提三问（是乘何处出、至何处住、谁当乘出）引出佛对「大乘即无相、无住、无出者」的层层申说。全卷以「地地递进」配「无所得毕竟净」为双线，把菩萨从七地到佛地的行相与般若空观贯穿一体。

## 二、结构层次

全卷按「经—论」交替、由下地升上地的顺序展开：

- **七地：不著与具足二十法（P5-P76）** → 先以二十问答明「二十法所不应着」（我、众生、断见、常见、名色、三界、三宝、戒等皆不可得故不着），再以二十问答明「具足二十法」（空、无相证、无生忍、无生智、破分别相、转烦恼、等定慧地、无碍智、不染爱等）。论释（P129-P171）逐一解「因见」「具足空」「三分清净」「无缘大悲」「转见转烦恼」等难点，收于「七地竟」。

- **八地：四法与五法（P77-P98）** → 顺入众生心、游戏神通、观佛国、自庄严、如实观佛身、知上下根、净佛世界、如幻三昧、常入三昧、随应受身。论释（P172-P181）以「良医诊病」「转轮王宝轮」「如幻人」喻解，收于「八地竟」。

- **九地：十二法（P99-P123）** → 受无边所度分、得如所愿、知天龙语、胎生、家、所生、性、眷属、出生、出家、庄严佛树、功德成满。论释（P182-P201）广述佛世界海之层级、菩萨降生右胁出、四姓中取刹利婆罗门、初二姓与释迦姓之对照，收于「九地竟」。

- **十地：当知如佛（P124-P206）** → 具六度四念处乃至十八不共法、断烦恼习；过干慧地等九地住佛地。论释（P202-P206）描绘法云地、降魔、诸佛眉间光从顶入、十地功德转为佛法。

- **《出到品》：三问三答（P207-P313）** → 佛更称须菩提旧问而答，以「不二法」「无相」「实际」三义申明大乘从三界出、至萨婆若住；次答「无住处」——法性非住非不住；末答「无出者」——乘、出者、所用法、出时皆毕竟净不可得，菩萨以不可得法乘是摩诃衍出萨婆若。

## 三、关键结论

1. 七地菩萨以「相空」为具足空，以「无缘大悲」为慈悲智具足，核心是破相离着而不舍众生。
2. 八地名转轮地，菩萨如转轮王无碍自在，能雨法宝满众生愿；以如幻三昧与报生三昧度生。
3. 十地即法云地，菩萨坐道场降魔，十方诸佛眉间光从顶入，十地功德转为佛法，断一切烦恼习。
4. 大乘、萨婆若「不一不合、不异不散」，皆无色无形无对一相无相；实际、法性、六度、十八不共法乃至佛性皆不出三界不住萨婆若，以自相空故。
5. 是乘无住处，以一切法无住相故；亦无出者，乘与出者及出时皆不可得毕竟净，菩萨以不可得法乘是摩诃衍出萨婆若。

## 四、易混辨析

- **无生忍 vs 无生智**：初名忍、后名智，粗者名忍、细者名智；忍是信受通达不退，智是已了知名色不生之相。
- **如幻三昧 vs 报生三昧**：如幻三昧须役心有所作，报生三昧自然成事无所役用，如人见色不用心力，胜于如幻。
- **众生空 vs 法空**：我见乃至知者见者、佛见僧见属众生空故不着；断常乃至戒见属法空故不着。
- **初地至十地 vs 干慧地至佛地**：前者是菩萨十地（发趣大乘之阶次），后者是通说九地加佛地（过是九地住于佛地），二者名同实异，佛自合说为「菩萨十地」。
