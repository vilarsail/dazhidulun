# 大智度论卷第五十八 导读

## 一、内容总览
卷五十八承上启下，紧接劝持品，以「诸天劝持 → 佛印可受持功德 → 外道魔来不能得便 → 阿难问何以独赞般若 → 受持现验」一线展开，涵盖「释劝受持品第三十四」「释梵志品第三十五」「释阿难称誉品第三十六」三品。核心主旨：般若波罗蜜为一切善法之尊导、诸佛之母，受持者得今世后世功德，诸天守护，外道魔怨不能得便；五波罗蜜及一切种智皆依般若而立，回向萨婆若方名波罗蜜。

## 二、结构层次
- **诸天劝持 → 佛印可**：四王天乃至阿迦尼吒天劝释提桓因受持般若，谓三宝不断、六波罗蜜皆现于世 → 佛可其说，告帝释当受持，并说阿修罗斗、天子五死相等因缘，明般若能灭恶心、令还本处。
- **明咒之喻 → 功德之源**：释提桓因叹般若为「大明咒、无上明咒、无等等咒」 → 佛印可，释以诸外道咒术（抑叉尼、揵陀梨）虽能知他心、飞行、住寿，般若过出无量；又以满月喻诸佛、星宿喻菩萨，世间善法皆从般若生。
- **今世后世功德**：今世不中毒死、兵刃水火不害、四百四病不中、官事不谴、王臣欢喜；后世不离十善四禅六波罗蜜、不堕恶道、得三十二相、化生佛界、不离神通 → 论释辨「必受业报佛不能救」「四大相害起四百四病」。
- **梵志恶魔现验 → 般若守护**：外道梵志来欲求佛短，帝释诵般若，外道遥绕复道还去 → 恶魔化作四种兵，帝释再诵般若，魔渐还去 → 诸天散华愿般若久住阎浮提，自誓守护行者，视之如佛、若次佛 → 论释「如佛」法性身住阿鞞跋致，「次佛」肉身菩萨能说般若。
- **阿难问独赞般若 → 尊导之喻**：阿难问何以不称余五波罗蜜 → 佛答般若于五波罗蜜乃至十八不共法为尊导，以无二法回向萨婆若方名波罗蜜 → 地喻：种子散地得因缘生，五波罗蜜依般若得生 → 帝释续问，佛说不离萨婆若心者得无量戒定慧解脱知见众，胜二乘算数所不能及。
- **说法现验与梦境 → 供养功德胜佛塔**：诸天来益胆力、说法无畏、不没不怖 → 三千大千及十方诸天来至般若所住处，见大光明、闻异妙香 → 梦见诸佛三十二相、菩提树、转法轮 → 书持供养般若胜于供养十方诸佛及起七宝塔，以不取人相法相故。

## 三、关键结论
1. 般若波罗蜜统摄一切善法：声闻、辟支佛、菩萨、佛法皆从般若生，是诸佛之母、诸佛之师。
2. 五波罗蜜回向萨婆若方名波罗蜜，以无二、不生不可得故；般若为尊导，如大地能生万物。
3. 受持般若得今世后世功德，诸天守护、外道魔怨不能得便，视行者如佛、若次佛。
4. 般若与一切种智不二不别：般若作生因，一切种智作说因，如乳变为酪，离乳无酪。
5. 供养般若胜供养十方诸佛及起七宝塔，以不取人相、法相，福田无尽故。

## 四、易混辨析
- **般若波罗蜜 vs 一切种智（一切智）**：般若是因位之行，到果位变为一切种智；般若为生因，一切种智为说因，不相离故言「不二不别」，但不得言般若即是一切种智，如乳非酪而离乳无酪。
- **如佛 vs 次佛**：「如佛」指法性身菩萨，住阿鞞跋致得无生法忍乃至十地；「次佛」指肉身菩萨，能为人说般若波罗蜜及其正义。
- **必受业报 vs 不必受业报**：般若能令不横死、四百四病不中，但「除其宿命业报」——必受业报佛所不能救，何况般若；般若之力在于遮伏他作横缘，不能转定业。
- **回向萨婆若 vs 不回向**：布施等五波罗蜜不回向萨婆若则不名波罗蜜，果报有尽；以无二、不生不可得回向萨婆若，福报世世受而不尽，终得一切种智。

## 五、阅读提示
读本卷宜抓住「般若为尊导」一主线，留意三处问答层次：阿难问独赞般若（明尊导之理）、帝释问今世后世功德（明受持现验）、外道魔来（明守护不碍）。满月与星宿、大地与种子、乳与酪三喻最是理解般若与诸善法关系的钥匙。
