# 大智度论卷第五十三 导读

## 一、内容总览
本卷为《大智度论》卷五十三，释「无生品第二十六」，承接前品对菩萨、般若、观诸义的讨论而更深入。全卷以舍利弗与须菩提的往复问答为经，以须菩提白佛重说、佛印证赞叹为纬，层层推演「诸法无生、毕竟清净」的般若深义。主旨在于揭示：一切法从色乃至一切种智，自相空故本自无生，无生故不二，不二故无所依、无所得；世俗谛中方便说有知有得、有六道有贤圣，第一义中则无业无报、无生无灭。菩萨以大悲心与毕竟空二因缘，能不舍众生、不惮难行，于无生法中开菩萨道、净菩萨道，终成阿耨多罗三藐三菩提。

## 二、结构层次
全卷依经、论交替推进，可分四大段落：

- **第一段（释菩萨·般若·观三义）**：经中舍利弗三问「何等是菩萨/般若波罗蜜/观」→ 须菩提以「为无上菩提发大心」释菩萨、以「远离」释般若、以「非常非无常」等中观释观 → 论补释「菩提萨埵」词源、「阿罗蜜」与「波罗蜜」音义相会、远离即自相空。→ 由名义入实义。

- **第二段（释无生·不二）**：经中舍利弗三问「色不生是非色」「色不二是非色」「色入无二法数」→ 须菩提以「色相空故无生」「不合不散一相无相」「色即无生」三层递答 → 论释「无生」破因中先有果等生相、「不二」破有无等二相，二者「义一而观门异」。→ 自相空→散空→无二法数，层层收束于一相无相。

- **第三段（无生毕竟净与五种菩提）**：须菩提白佛重说色乃至佛法无生毕竟净 → 舍利弗作难：若皆无生，则无四果、无辟支佛道、无菩萨一切种智、无六道别异 → 须菩提答「不欲令无生法有所得」，菩萨以无所得故生大悲心、不生难心苦心 → 论广释柔顺忍与无生忍之别、五种菩提（发心、伏心、明、出到、无上）之相。→ 由无生引发「大悲与毕竟空并修」之要义。

- **第四段（生法不生之诤与净菩萨道）**：舍利弗再问「生法得道？无生法得道？」→ 须菩提两皆不立，唯许世俗名字故有知有得，第一实义中无知无得 → 反复破「生生」「不生生」「半生半不生」 → 须菩提自陈乐说无生法及无生相，语言亦不生 → 释「诸法无所依，性常空故」，由此开出世间与出世间二种波罗蜜及菩萨道、菩提道之远近 → 最后般若波罗蜜能生能受一切善法、三世诸佛皆从中得菩提，说般若时地六振动、佛微笑印可、十方同说。→ 以般若为诸善法之根本收束全卷。

## 三、关键结论
1. 菩萨、般若、观三名虽同前品，此中重释以显其义无量：菩萨即「为无上菩提发大心」，般若即「远离」，观即「不堕常无常等八门」之中道正观。
2. 色乃至一切种智，自相空故本自无生，非智慧力使之无生；无生故不二，不合不散，一相无相；色即无生，无生即是色。
3. 无生法中无所得：世俗名字故有四果、六道、贤圣，第一实义中无业无报、无生无灭、无净无垢；菩萨以无所得故能起大悲、行难行而不以为苦。
4. 菩萨行六波罗蜜有世间、出世间之别：有所依取相为世间（不动不出），三分清净、无所依为出世间（能动能出）；六波罗蜜为菩萨远道，三十七品为菩提近道。
5. 般若波罗蜜为一切善法之母，能生能受声闻、辟支佛、菩萨、佛法，三世十方诸佛皆由行般若得阿耨多罗三藐三菩提；说般若时地六振动、十方同说，以法稀有难遇故。

## 四、易混辨析
- **柔顺忍 vs 无生忍**：柔顺忍是渐习顺于无生之观，未毕竟净，犹有烦恼气；无生忍则灭诸烦恼、得菩萨位、入法位，毕竟清净。论中以「前说无生是柔顺忍观，得无生忍则毕竟净」辨其次第。
- **无生 vs 不二**：破色「生相」（初生、后生、因中先有果等）名无生，破色「二相」（有无、眼色等对待）名不二。义同一空，而所入观门异、所破侧重点不同：自相空 vs 散空。
- **世间波罗蜜 vs 出世间波罗蜜**：施时取我相、他相、施相，于世间中不动不出，名世间；施时我不可得、不见受者、施物不可得、不望报，三分清净，于世间中能动能出，名出世间。
- **菩萨道 vs 菩提道**：六波罗蜜（布施、持戒等杂行，有世间出世间杂）为菩萨远道；三十七道品、三解脱门乃至大慈大悲，毕竟清净，为菩提近道。菩萨时有道，佛已到不须道。

## 五、阅读提示
读本卷可紧扣两条线索：一是须菩提与舍利弗的问答如何由「名义」层层逼入「实相无生」，二是论主如何以「柔顺忍—无生忍」「世间—出世间」「远道—近道」等双轨释经中难义。遇「不生是非色」「不二是非色」等句，宜对照论中「破生相」「破二相」两段参看，方能辨其义一而观门异。
