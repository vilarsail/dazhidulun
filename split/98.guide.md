# 大智度论卷第九十八 导读

## 一、内容总览
本卷为《大智度论》卷九十八，「释萨陀波仑品第八十八之余」，续释《摩诃般若波罗蜜经·萨陀波仑品》后半：萨陀波仑（意译常啼）菩萨求般若，十方诸佛现前慰谕，指明其世世善知识昙无竭；他为供养般若与法师而在市中卖身，长者女相助、释提桓因试心，同诣众香城，以二分供养《般若波罗蜜》经卷与昙无竭，末请问「诸佛从何所来、去至何所」。论主随文设问答，剖明卖身、魔扰、帝释试验、先供经卷、女人发心诸深意。

## 二、结构层次
- **十方佛慰谕（收束前文三昧）**：诸佛自陈本行菩萨道时亦如是求般若、得诸三昧 → 观三昧性不见出、入三昧者 →「般若波罗蜜，所谓不念有是诸法」，住无所念中佛果万德自具 → 嘱令于善知识生如佛想，指认昙无竭 → 忽然不现。
- **卖身缘起**：从三昧起不见佛，起疑「诸佛从何所来、去至何所」→ 决意问昙无竭 → 自鄙贫穷无华香供养具 → 入大城市肆高声卖身。
- **卖身三折（帝释试心）**：恶魔隐蔽众人令不闻，唯长者女得闻 → 卖身不售啼哭 → 帝释化作婆罗门，诡称祠天须人心、血、髓 → 萨陀波仑欢喜刺臂割髀 → 长者女下阁问讯，闻佛功德心惊毛竖，许以珍宝、愿同行 → 帝释复本身赞其心坚 → 求愿「与我阿耨多罗三藐三菩提」，帝释言此非我力所办 → 求身平复如故，疮瘢即愈 → 长者女辞父母、率五百侍女东行。
- **众香城供养（本卷高潮）**：入城见昙无竭坐高台法座说法 → 七宝台黄金牒书《般若波罗蜜》、七宝印印之 → 帝释与诸天雨华散台：「般若是诸菩萨母，能生诸佛、摄持菩萨」→ 分供养具为二分，先供经卷、后供法师 → 萨陀波仑头面礼足，具陈本求般若因缘，请问诸佛来去。
- **【论】逐段释疑（问曰／答曰层层剥笋）**：重问善知识之由 → 何以不还入三昧问佛 → 大菩萨何以贫穷（财贫／法贫）→ 卖身即内施为重 → 魔何以破、何以不杀（心定出魔境界，如负债人欲出他界）→ 帝释何以试、何以妄语 →「大利／第一利」六重配释 → 先供经卷之义（入法宝故、众生着人相故）→ 女人见神通发心（依爱断爱、依慢断慢，爱慢烦恼是佛道根本）→ 末答新发意菩萨「知空而不能与空合」，深着佛相而以解空不失。

## 三、关键结论
1. 般若之相是「不念有是诸法」——不见三昧出入者、不见行佛道者，住无所念而万德自具。
2. 善知识守护是菩萨疾得菩提的增上缘，于善知识应生如佛想，供养百千劫不能报须臾之恩。
3. 内施重于外施；为法丧身是检验心定、破惜身见的极致，得无生法忍则魔不能坏。
4. 般若是「诸菩萨母，能生诸佛、摄持菩萨」，故供养经卷（法宝）先于供养法师（人）；昙无竭示现白衣眷属，正为断钝根者之疑、增益信根。
5. 爱慢等烦恼可为佛道根本——依爱断爱、依慢断慢；新发意菩萨深爱佛相非过，但以解空故不至偏失。

## 四、易混辨析
- **大利 vs 第一利**：论中六重配对——阿鞞跋致地／佛道、五波罗蜜／般若波罗蜜、般若／般若方便力、菩萨初地／十地、从初地乃至十地／第十地、菩萨地／佛地。
- **财贫 vs 法贫（功德法贫）**：财贫好人亦有；法贫最大可耻，好人所无。
- **数缘尽 vs 非数缘尽**：数缘尽（择灭）即涅槃，是无上法；一切有为法、虚空及非数缘尽皆是有上法。
- **供养经卷 vs 供养法师**：所书般若入法宝中，应先供养；众生取人相多生着心，着余相之患轻于着人。

## 五、阅读提示
带着三个问题读：卖身供养何以是般若之行？魔为何偏在心定之际出现？供养经卷为何先于供养说法之人？论中「问曰／答曰」随经文逐段设问，宜先读经再对读论释。
