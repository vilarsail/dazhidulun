# 大智度论卷第三十六 导读

## 一、内容总览
本卷为《大智度论》卷第三十六，承接卷三十五「习相应品」之余，由龙树造、鸠摩罗什译。全卷围绕「菩萨摩诃萨如何与般若波罗蜜相应」一问展开：先以三解脱门明菩萨胜过二乘而住阿鞞跋致地、净佛道；次明菩萨为世间福田、为善法根本；再广释「习应色空乃至一切诸法空」即与般若相应，层层推演五众空、自相空、三世不合，最后收束于「不生不灭、不垢不净、不增不减」的诸法实相空义。

## 二、结构层次
全卷以舍利弗五问、佛五答为经，龙树释论为纬，一线贯穿「过二乘→作福田→习般若→见空相→不与际合」：

- **第一问（过二乘、净佛道）** → 舍利弗问云何菩萨过声闻辟支佛地、住阿鞞跋致地、净佛道 → 佛答从初发意行六波罗蜜、住空无相无作 → 论释「无方便力入三解脱门即取涅槃，有方便力见涅槃而不住、更期大事」，以「仰射虚空箭箭相拄」之喻明菩萨不堕二乘地 → 直过四谛、入一谛（不生不灭）即阿鞞跋致地。
- **第二问（作福田）** → 舍利弗问菩萨漏结未尽住何功德为二乘福田 → 佛答从初发意乃至坐道场常作福田 → 论释菩萨以大慈悲胜二乘，世间一切善法（十善、五戒、八斋、四禅八定、三十七品、六波罗蜜、十八不共法）皆因菩萨因缘现世 → 败坏菩萨行世法、立法度，亦皆由菩萨有。
- **第三问（净毕施福）** → 舍利弗问菩萨净毕施福否 → 佛答「不也，本以净毕故」 → 论释菩萨初发心即为众生供养上首、代受勤苦、令世间即涅槃，故本已净毕，复为大施主施诸善法。
- **第四问（习应般若）** → 舍利弗问云何习应般若波罗蜜 → 佛广说习应色空、受想行识空、六根六尘空、十八界空、四谛空、十二因缘空、有为无为空 → 论广释五众名义（色众分可见不可见有对无对、粗动影像诳色；受众三十六受、百八受；想众小大无量无所有；行众三行、心数法属见属爱；识众六觉依意生）→ 辨五众与十二入十八界开合之异、次第之由 → 以十八空、性空、微尘不可得破一切法实有，归于毕竟空 → 明「习」「相应」之义（随般若修习不息、如函盖相称、不堕二边）→ 释七空（性空、自相空、诸法空、不可得空、无法空、有法空、无法有法空）广略开合 → 不见色生灭垢净、不见色与受合、色空中无色、色即是空空即是色、空相不生不灭不垢不净不增不减、空中无五蕴乃至无智无得、无四果无佛道 → 广说不见般若乃至一切种智若相应若不相应，般若相毕竟清净故。
- **第五问（空不合）** → 佛自说空不与空合、无相不与无相合、无作不与无作合 → 论释空有二种（空三昧、法空），性自空不从因缘生 → 入自相空故五众不作合不作不合 → 三际不合（前际空无所有、后际未有未生、现在生灭不住不可取相）→ 论破三世实有之执（泥揣瓶土之喻），三世及名字空故云何言合。

## 三、关键结论
1. 菩萨以方便力住三解脱门见涅槃而不取证，「今是观时非是证时」，直过二乘期于阿耨多罗三藐三菩提——此即菩萨胜二乘之根本所在。
2. 世间一切善法（人天十善八斋、二乘三十七品、菩萨六度、佛果十力一切种智）皆以菩萨因缘现世；菩萨为世间福田、为大施主，本已净毕施福。
3. 习应般若波罗蜜即习应五蕴、十二入、十八界、四谛、十二因缘、有为无为一切诸法空；色即是空、空即是色，空相不生不灭不垢不净不增不减，是中无五蕴乃至无智无得、无四果无佛道。
4. 法性自空，非以空三昧令法空；十八空乃至七空皆为对治众生种种著有著无之执而说，毕竟空故不见般若乃至一切种智若相应若不相应。
5. 三世诸法皆空，前际后际现在不可得，三际名字空故不合；微尘至极微亦不可得实有，离因缘名字则无一法。

## 四、易混辨析
- **阿鞞跋致地 vs 阿耨多罗三藐三菩提**：阿鞞跋致（阿毗跋致）为菩萨「不退转地」，是修行阶位；阿耨多罗三藐三菩提为佛果「无上正等正觉」，是所期之极果。菩萨住不退转地而更期佛果。
- **空三昧 vs 法空**：空三昧是禅观工夫，入时见空、出时不见则虚妄；法空是诸法本性自空，不从因缘生。以空三昧力合法空者，非法自性空，故不与法空合。
- **败坏菩萨 vs 清净菩萨**：清净菩萨行慈悲直入菩萨道；败坏菩萨亦有悲心，以国法治世、治一恶人以成一家，虽有所恼所安者多，得名败坏菩萨——非究竟清净，然世间善法亦由之而有。
- **五众 vs 十二入 vs 十八界**：五众（色受想行识）为对治于心数法多邪惑者说；十二入为惑于色者说，色开十处、心心数总二处；十八界为不了色心者说，心数法一界、色心十七界——同是一法，开合随病不同。

## 五、阅读提示
读此卷可带着两问切入：其一，菩萨既入三解脱门、见涅槃，何以不取证而能「箭箭相拄」不堕二乘地？其二，既说「色即是空、空即是色」「空中无色」，空与色究竟是何关系？留意论中「性自空」「非以空三昧令法空」一句，与经文「不生不灭不垢不净不增不减」相参，即得般若相应之实义。
