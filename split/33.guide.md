# 大智度论卷第三十三 导读

## 一、内容总览
本卷承上启下，仍是《大智度论》对《般若经》初品中若干菩萨愿求的逐一释义，居于卷三十三。全卷以六组「经—论」问答为骨架，自「到彼岸义」起，依次释「三世如、法相、无生际」「在声闻辟支佛前、为佛眷属、净报大施」「不起六蔽心」「立于四种福处」「得五眼」「见十方佛、闻法不忘、见三世佛世界、尽诵十二部经」。贯串主线是：菩萨欲成就一切世间与出世殊胜功德，皆当学般若波罗蜜——般若为一切功德的根本依止与净除之因。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

- **到彼岸义（总起）** → 以「有为、无为法尽到其边」立义 → 慧知有为总别相、了知无为从须陀洹至佛 → 引出「彼岸」即般若所到之究竟边。
- **如、法相、无生际（展开一：法义层）** → 问「上已说如，今何更说」 → 答「上略此广、上一此三」 → 法相即法性、无生际即实际 → 三世相即、如相非一非异 → 世间如三世各别、出世间如三世为一 → 破生法皆无生 → 结归「一切法即涅槃」。
- **眷属与净施（展开二：行果层）** → 问「菩萨未漏尽何得在圣人前」 → 答「初发意已在前，功德智慧大故世世为大」 → 鹿王、转轮王、外道大师之化迹 → 罗汉辟支佛利益少、菩萨有漏而利益广 → 法性生身有无量补处菩萨侍从 → 眷属三品（声闻、杂、菩萨） → 净报大施以般若空慧不证真际故能净毕。
- **不起六蔽（展开三：对治层）** → 悭、破戒、瞋、怠、乱、痴六心障蔽六波罗蜜 → 各以般若观空、念众生苦、念大悲为本对治 → 钻火数息、风中然灯、无目坠坑等喻 → 结「行般若能障六蔽、净六度」。
- **四种福处（展开四：福田层）** → 问「何等福处」 → 布施、持戒、修定、劝导四福 → 详析布施净不净、舍心相应思即业、施福增长因缘 → 五戒相、慈心为修定福五利 → 劝导福、财福、法施差别。
- **五眼与见佛闻法（展开五：神通智慧层）** → 肉眼碍求天眼 → 天眼见假名不见实相求慧眼 → 慧眼无所分别不能度生求法眼 → 法眼不遍知求佛眼 → 佛眼无事不知不见不闻 → 般舟三昧与天眼异 → 以佛神力及一如无异故知诸佛心 → 闻持、坚忆念二陀罗尼受持不忘。
- **见三世佛世界与十二部经（收束）** → 见过去未来三昧、不灭际三昧，慧假名眼 → 十二部经逐名释义：修多罗、祇夜、受记、伽陀、优陀那、因缘、阿波陀那、如是语、本生、广经、未曾有、论议 → 受记时光从足入至顶入的等差 → 声闻不闻大乘法之因缘 → 结「尽欲受持者当学般若」。

## 三、关键结论
1. 般若波罗蜜是一切殊胜功德的能到、能净、能成之因——到彼岸、不起六蔽、净报大施、知诸佛心、受持十二部经，皆以学般若为门。
2. 「如、法相、无生际」三名异义一：法相即法性、无生际即实际；三世之如相非一非异，世间如三世别、出世间如三世一，究竟即涅槃，故一切法皆无生际。
3. 菩萨以有漏智慧而利益无量，胜于罗汉辟支佛无漏而利少；由大悲久住世间、入法性而不证真际，故能净毕施福。
4. 五眼层层递进：肉眼碍→天眼见假名→慧眼灭诸着而不能度生→法眼知方便而不遍→佛眼无事不知不闻不见；前四眼皆有限量，唯佛眼遍照。
5. 十二部经各有体相，受记先现微笑放光、光从足至顶按所记趣等差而入，论议经（优波提舍）则以问答广解为体。

## 四、易混辨析
- **如 vs 法相 vs 无生际**：如即诸法平等实相；法相即法性，亦即诸法业用因果差别；无生际即实际，推求诸法相入无生之究竟。三名偏重不同，其体一。
- **世间如 vs 出世间如**：世间如三世各各异（因果历然）；出世间如三世为一（平等无相）。
- **天眼 vs 慧眼 vs 法眼 vs 佛眼**：天眼见和合假名不见实相；慧眼灭一异着、不受一切法、无所分别故不能度生；法眼知众生各各方便门令得道而不遍；佛眼无事不知不见不闻，于余甚深于佛甚浅。
- **般舟三昧 vs 天眼**：般舟三昧忆想分别、未离欲人亦得；天眼修神通、唯离欲人得，得色界造色眼，见色不难。
- **布施福处 vs 财福**：布施福处总摄财、法、俗、道一切施；财福别指衣服饮食卧具医药金银田宅等财物。
- **净施 vs 不净施**：不净施为今世事、与悭相违故施；净施治心庄严意、为助涅槃、生清净心，如新花未萎色好且香。

## 五、阅读提示
读本卷可带着一条线索：每一组经文都是「欲得某功德→当学般若波罗蜜」，论中则解释为何必以般若为因——般若能空、能净、能到边、能不证、能遍知。注意十二部经一段篇幅最长，可先记十二名相再读各各释义，受记放光一段按所记趣从足至顶依次而入，是全卷仪式感最强处。
