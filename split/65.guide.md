# 大智度论卷第六十五 导读

## 一、内容总览
本卷是《大智度论》卷第六十五，前半续释〈无作实相品〉之余，后半释〈诸波罗蜜品〉第四十四。主旨：以“大珍宝”喻般若——拔三途之苦、与三乘之乐，而其体无所得、无染，法轮无转无还；再以九十番问答显明“一切法实相即是般若波罗蜜”。

## 二、结构层次
- **经（珍宝波罗蜜）**：须菩提说受持般若者不病、不横死，六斋日诸天来听 → 佛印可“般若是大珍宝”，广明拔苦与乐、出生世出世间善果 → 再翻进一层：珍宝波罗蜜“无有法可得”，不生不灭、于诸法不与不舍，名无所得、无染。
- **论（释疑难）**：答“受持犹有众患”——非必受报业，如良药须将顺、利器须善用，非般若之过 → 答诸天何以下听：天着欲乐定乐不能书持，阎浮提人以断淫、强识、精勤三事胜天，故能书持般若 → 以如意宝珠为喻，拣别世间般若（生高心开罪门）与出世间般若（不分别）→ 结归“有佛无佛，法性常住”，法性即实相，实相即般若。
- **经（第二法轮转）**：诸天散四色莲华，赞“阎浮提见第二法轮转”，无量天子得无生法忍 → 佛遮一二之执：般若“不为转故出、不为还故出”，无法有法空故，诸法相皆自空 → 须菩提赞摩诃波罗蜜：毕竟不生故无转无还 → 立清净说十种，进说无说、无受、无证、无毕定福田。
- **论（释转与说）**：释第二转有密、现二义——声闻见憍陈如一人得初道，菩萨见无量众生得忍登地，如大雨大树多受、小树少受 → 释无转无还：破有无四句，畏堕常、灭、有、无、世间、涅槃六边，入空、无相、无作三解脱门 → 广释说、教、照、开、示、分别等十种清净说义 → 结以第一义毕竟空故无说无受无证。
- **〈诸波罗蜜品〉经+论**：九十组连珠问答——须菩提立名（无边、梦、幻、寂灭……十力、自然、佛），佛皆答“××不可得故” → 论随文释义，归宗于“一切法实相即是般若”；佛“不以佛身故名为佛，但以一切种智故”。

## 三、关键结论
1. 般若是大珍宝：拔三途之苦，与三乘圣果乃至佛道之乐，而体无所得、无染污。
2. 真修般若要“不知、不分别、不得、不戏论”，以无所得方便力知诸法寂灭，而能起诸善法、净佛国土。
3. 法轮非一非二、无转无还：般若无起无作相，“有佛无佛，诸法性常住”。
4. 阎浮提人以断淫、强识、精勤三事胜诸天，故能书持般若，诸天反来下听。
5. 九十种波罗蜜名异义同，皆以“不可得”为义；佛以一切种智为体，不以色身。

## 四、易混辨析
- **世间般若 vs 出世间般若**：前者分别善恶、着善生高心轻蔑人，开诸罪门；后者不分别善不善，毕竟无忧。
- **密转 vs 现转法轮**：初转时声闻见八万诸天得忍、憍陈如一人得初道，菩萨则见无量众生得忍、登地乃至补处——如大雨，大树多受、小树少受。
- **常住般若 vs 有用般若**：与五波罗蜜共行、破无明与真智的是有用般若（有为、无常）；般若所缘的如、法性、实际则常住无为。
- **道种智 vs 一切种智**：道种智名法眼，知众生以何道得涅槃，是说法无畏之本；一切种智遍知一切法总别之相，是佛波罗蜜之体。

## 五、阅读提示
卷末九十番问答看似重复，实是借名显体：每番皆以一句“××不可得故”收摄，对照论释体会“名异义同”。
