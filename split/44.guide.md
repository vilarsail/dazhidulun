# 大智度论卷第四十四 导读

## 一、内容总览
本卷含三品：「幻人无作品第十一」「句义品第十二」及一切法分类的广说。承接上一品对「菩萨字毕竟空」的破斥，须菩提进一步追问：既一切法空，菩萨与幻人有何差别？佛以「不异」一字作答，并由此展开「新发意菩萨的方便与善知识」「菩萨句义毕竟无义」「一切法的善不善乃至有漏无漏分类」三大主题。全卷主线是——空义已立之后，菩萨如何在不惊不怖中行般若、如何辨别善知识与恶知识、如何在「无句义」中安立「菩萨」一名。

## 二、结构层次（★重点）
全卷以「经—论」交替的三品层层推进：

- **幻人无作品**：问「幻人学般若得萨婆若不？」 → 佛反诘「色与幻有异不？」 → 须菩提答「不异」（色即是幻，幻即是色，乃至阿耨菩提即是幻） → 推论「不生不灭法不能学般若得萨婆若，但以无所得故得」 → 论释补出须菩提之疑与佛以譬喻开示之所以然 → 收于「五众即是幻人，性无所有故」。
- **方便与善知识段（经论）**：由「新发意菩萨闻般若惊怖畏」之问发起 → 佛答内无方便、外无善知识则怖畏 → 正说方便（应萨婆若心观色无常乃至离相亦不可得，六波罗蜜各以「不向声闻辟支佛」为相） → 广说善知识相（说无常不可得、回向一切智） → 反说恶知识相（离六波罗蜜、作佛身等教离佛道） → 论释归纳「离一切种智相应心、取般若定相」即无方便，「不教觉知魔事」即恶知识，并以「软语贼」喻显急当远离。
- **句义品第十二**：须菩提问「云何为菩萨句义」 → 佛答「无句义即菩萨句义」 → 以鸟飞虚空、梦、幻、响、影、焰、化、如法性法相法位实际、佛五众无处所、日出无闇、劫烧无物、佛光中诸天光不现等一连串譬喻广说「无义」 → 收于「一切法不合不散，一相所谓无相」 → 论释释「句义」之天竺语法（众字成语、众语成句）、何以须广譬喻、何等为「净」。
- **一切法分类段（经论）**：承「一切法无碍相应学应知」 → 列十对法（善不善、记无记、世出世、漏无漏、为无为、共不共） → 逐一广解世间善法（孝顺、三福处、九相、四禅四无量四无色、十念）、出世间法（三十七品、三解脱门、三无漏根、三三昧、八背舍、九次第定、十八不共法） → 论释释各法相及「色如即无为」之疑。

推进脉络：「幻人不异实菩萨」之空义 → 空故菩萨行须方便与善知识护持 → 方便极处即「无句义」 → 句义无所有故一切法皆可分类而不二中道不动。

## 三、关键结论
1. 色乃至阿耨多罗三藐三菩提与幻不异——以「无所得」故菩萨能学般若得萨婆若，非以「有所得」故。
2. 新发意菩萨怖畏般若，过在内外因缘不具：内无正忆念大悲方便，外不得善知识断疑；反之，应萨婆若心观诸法相亦不可得即不怖。
3. 善知识之相在「说无常等亦不可得，回向一切智」；恶知识之相在「教离六波罗蜜、不令觉知魔事」，世世害人甚于软语贼。
4. 「无句义是菩萨句义」——菩萨名但假名和合，阿耨菩提中无义处、亦无我，一切法不合不散、一相无相。
5. 一切法虽分善不善乃至共不共十对，然皆因缘和合生故无性、自性空，菩萨于无碍相中不动而入一切法。

## 四、易混辨析
- **幻人 vs 实菩萨**：幻人以咒术物事为本现诸相，无业无业因缘；实菩萨以先世无明业因缘生五众。然于「一相无分别」处二者不异——皆性无所有，故皆不生不灭、不垢不净。差别只在「无所得」与「有所得」。
- **善知识 vs 恶知识**：非以形相判，以「所说法门」判。善知识必令回向阿耨菩提、说亦不可得；恶知识纵现佛身、辟支佛身、和尚阿阇梨身、父母身，但凡教离六波罗蜜、赞小乘、以有所得说诸法空，皆是魔事。
- **句义 vs 名字语**：天竺语法，众字和合为语（菩提），众语和合为句。菩萨「句义」并非有一实义可指，而是「菩提」「萨埵」二语和合之假名，于第一义中无处所、无我我所。
- **有为无为**：色本是有为，何以言「色如即无为」？盖色有凡夫忆想分别色与圣人所知实相如涅槃二种，前者入如中更不生灭即同无为。五众等因缘和合假名虽属有为，其「如」「法性」「实际」即无为。

## 五、阅读提示
读本卷可带着两个问题：其一，既说「色即是幻、幻即是色」，菩萨修行与幻人作佛究竟差别何在？其二，「无句义是菩萨句义」是否落入断灭？留意佛以「无所得」「不二相不动」「方便回向」三义收束，避免将空误解为断无。
