# 大智度论卷第十八 导读

## 一、内容总览

本卷在《大智度论》中属「释初品中般若波罗蜜第二十九」与「释般若相义第三十」二段，承上「不着故应具足般若波罗蜜」一经句而展开。全卷以般若波罗蜜之体相、名义、所摄智慧、与外道之辨、三门入法、一相与种种相、得般若之方便行等为主线，层层追问，最终归于「诸法实相是般若波罗蜜」「以无所得为得」之要旨，为菩萨行般若、度众生立定根本。

## 二、结构层次（★重点）

全卷以「问答递进」为骨架，由名义辨析 → 实相体性 → 智慧摄属 → 三门入法 → 一相种种相 → 得般若之方便，逐层收束：

- **般若波罗蜜名义（总起）** → 先释「般若」「波罗蜜」「摩诃」三义，明般若在佛心中名一切种智、在菩萨心中名般若波罗蜜，因中说果；以入海、然灯二喻会通「佛穷底、菩萨未穷底而俱名入」之疑。
- **诸法实相（体性）** → 举〈赞般若波罗蜜偈〉总明实相「不颠倒、灭言语、离心行、不生不灭如涅槃」，并显般若为诸佛之母、三乘解脱皆从般若得，般若「四边不可取」。
- **摩诃独称之所以（辨智慧摄属）** → 明般若摄声闻、辟支佛、佛三乘智慧，分学、无学、非学非无学三种智；辨独觉、因缘觉、大小辟支佛之异；复辨三乘实智与外道虚妄之别，斥外道戒福、禅定、观空之失。
- **三门入法（核心转折）** → 为解「佛语种种异说不相违」之疑，立蜫勒门、阿毗昙门、空门：蜫勒有随相、对治二门；阿毗昙广分别相义；空门明生空、法空，辨「观空」与「邪见空」之异（真空不破不坏、不取相不戏论、有空空三昧）。
- **一相与种种相（展开）** → 菩萨知一切法一相（有相、无相、一、有所因、无所因、有相、无相）复知种种相，广列二法、三法乃至十九法等无量法门，终归「一切法皆一相」；复明不可得空、菩萨入自性空而以方便分别名字度众生。
- **得般若之方便（收束）** → 明初发心菩萨闻毕竟空、行五波罗蜜以助成般若，禅为般若依止处；辨「一波罗蜜中具五波罗蜜」与「随时别行」二种得般若，终归于「行无行法、无所得为得」「诸佛随俗故说行，非第一义」。

## 三、关键结论

1. 般若波罗蜜即诸法实相之慧，佛心中名一切种智，菩萨心中名般若波罗蜜，因中说果同名波罗蜜。
2. 般若独称「摩诃」，以能生佛、菩萨、辟支佛、声闻四大人，能与涅槃大果报，余五波罗蜜不能尔。
3. 三乘智慧皆入般若，外道语虽初似妙，穷尽所归则虚诳，以着我见、取空相、堕颠倒故。
4. 佛语种种异说不相违背，入蜫勒、阿毗昙、空三门则知皆是实法；不得般若则入三门各堕有、无、有无中。
5. 般若有二相：知一切法一相（无相）复知种种相；菩萨入自性空、无所著，以方便力分别名字度众生。
6. 得般若波罗蜜以无所得为得，诸佛随俗说行五波罗蜜等，非第一义；诸法从本已来常自空、常自无所得。

## 四、易混辨析

- **般若波罗蜜 vs 一切种智**：菩萨求度彼岸、未到智慧边，因中说果名般若波罗蜜；佛已度彼岸、穷尽其底，故名一切种智。体是一慧，位有因果。
- **独觉 vs 因缘觉**：同属辟支佛。独觉者今世自觉不从他闻；因缘觉者因见华果无常等因缘而悟道。独觉中又有本是学人满七生无佛世自悟之小辟支佛，与百劫修功德得相好之大辟支佛之别。
- **观空（真空） vs 邪见空**：邪见人断灭令空、取空相戏论、口说空而爱瞋犹存；观空人知诸法真空不破不坏、不取相不戏论、心不动、结使不生，有空空三昧，先具布施戒定柔软心。
- **生空 vs 法空**：生空者，说「谁老死」是虚妄，无吾我、无人、无神；法空者，说「是老死」是虚妄，乃至无明亦如是，诸法皆空是为实。
- **世谛 vs 第一义谛**：佛随众生所应说法，对治悉檀破常颠倒故说无常、说心去后世，非第一义；诸法实相非常非无常，诸法空中亦无无常。

## 五、阅读提示

读本卷宜把握二条主线：一为「般若即实相、实相即无相无得」之体义，二为「佛语种种异说皆实、三门入法不相违背」之用义。问答密集处皆是破疑入实，偈颂（赞般若偈、义品偈）为全卷眼目，宜细味。
