# 大智度论卷第三十五(释第二品讫第三品上) 导读

## 一、内容总览
本卷为《大智度论》卷三十五，释第二品（报应品）讫第三品（习相应品）之上。全卷以般若波罗蜜为根本，贯穿三层义：其一，菩萨行般若波罗蜜能作功德，四天王乃至阿迦尼吒天欢喜奉钵、请转法轮，世间善男子善女人愿为父母妻子眷属；其二，菩萨当断淫欲修童真行，方便受五欲如幻师化现而不染；其三，菩萨行般若时不见菩萨、不见般若，一切但有名字，性空无生无灭，智慧胜过声闻辟支佛。三品层层递进：先示果报劝进，次明离欲梵行，终归般若空观。

## 二、结构层次
全文按「果报劝进 → 离欲梵行 → 般若空观 → 胜劣较量」之序展开：

- **诸天奉钵欢喜（报应品起）**：四天王奉钵如奉先佛 → 释提桓因、梵天、净居诸天各作供养 → 诸天因佛出世增益减损阿修罗 → 世间善男子善女人愿作菩萨父母妻子眷属。以「尸毗王割肉代鸽」「龙王宫求如意珠」「须摩提买花」「喜德女奉事德主太子」等本生故事，明世世结缘之实。
- **断欲童真（承前转入）**：诸天愿菩萨离淫欲常作童真 → 五欲第一系人心、淫欲为诸结之本 → 三种菩萨（受欲后出家、初发心断欲、法身菩萨方便受欲）→ 以幻师化五欲喻第三种菩萨，欲为炽然、秽恶、毁坏、如怨。
- **般若空观（习相应品初）**：舍利弗问云何行般若 → 佛答不见菩萨、不见般若字，菩萨菩萨字性空 → 空即是色、色即是空 → 但有名字假说，诸法实性无生无灭无垢无净 → 不见故不着，虽不着而不入涅槃（大悲、本愿、般若方便和合故）。
- **众生空与法空（承接空观）**：上多说法空，今杂说众生空 → 我乃至知者见者十六名字皆不可得，随事异名，因缘和合无自性 → 生空故法空，法空故生亦空。
- **胜劣较量（收束全卷）**：菩萨智慧胜声闻辟支佛（空知一切法空、为度一切众生）→ 满阎浮提乃至十方恒河沙世界舍利弗目连智慧不及菩萨百分之一 → 菩萨一日智慧已出过其上 → 以萤火虫喻声闻、日喻菩萨 → 诸贤圣智慧虽体性无别（无生性空），然菩萨发愿度一切众生故胜。

## 三、关键结论
1. 般若波罗蜜有二种果：成佛度众生；虽未成佛受世间果报（转轮圣王、释梵天王主三千世界）。世间乐与涅槃乐皆由佛菩萨得，故诸天见菩萨行般若而欢喜奉钵。
2. 淫欲为诸结之本，受五欲尚不生梵世，何况得阿耨多罗三藐三菩提；菩萨应作童真修梵行。第三种清净法身菩萨得无生法忍，以方便力化作五欲如幻师，不染于欲。
3. 行般若波罗蜜时不见菩萨、不见般若波罗蜜，菩萨菩萨字性空，空即是色色即是空，但有名字假说，诸法实性无生无灭无垢无净；不见故不着，虽不着而不入涅槃。
4. 我、众生、寿者乃至知者见者皆是一我随事异名，因缘和合无自性，毕竟空；生空故法空，法空故生亦空。
5. 菩萨智慧胜声闻辟支佛，以空知一切法空亦不见空、以此智慧度脱一切众生令得涅槃故；虽诸贤圣智慧体性无别（无生性空），然菩萨发菩提心愿度一切众生，故百分千分乃至算数譬喻所不能及。

## 四、易混辨析
- **三种菩萨**：第一种世间人受五欲后舍离出家得菩提；第二种初发心断淫欲修童真行直至成佛；第三种清净法身菩萨得无生法忍住六神通，方便受五欲如幻师化现度众生。第三种以幻师喻，非实受欲。
- **众生空 vs 法空**：我乃至知者见者十六名字皆不可得，是众生空（声闻法中多说）；色等诸法因缘和合假名无自性，是法空（般若中多说）。我空易知（五情求不可得），法空难见（色可眼见声可耳闻）。生空故法空，法空故生亦空。
- **萨婆若慧 vs 一切种智 vs 道种慧**：萨婆若慧是声闻辟支佛事；一切种智是诸佛事；道种慧（道慧）是菩萨事。菩萨一日修道慧，愿以一切种智知一切法度一切众生，胜过声闻辟支佛。
- **必定论 vs 分别论 vs 反问论 vs 置论**：必定论如无我、涅槃寂灭；分别论如受乐得道否须分别答；反问论还以所问答之（佛以此答舍利弗）；置论如十四难世间有常无常等搁置不答。

## 五、阅读提示
读本卷可带着三个问题：(1)诸天为何见菩萨行般若便欢喜奉钵？——以世间果报示众生，明般若二种果不虚；(2)菩萨既不着诸法云何不入涅槃？——大悲、本愿、般若方便和合故；(3)声闻与菩萨智慧体性无别，云何菩萨胜？——以发愿度一切众生、空知一切法空亦不见空故胜。
