# 大智度论卷第三十七 导读

## 一、内容总览

本卷为《大智度论》卷三十七，接续「习相应品」。全卷以「菩萨摩诃萨行般若波罗蜜，某某不与萨婆若合」为基本句式，层层推进「相应」的义涵：先是萨婆若不与三世合，再到不与五蕴、十二入合，不与六波罗蜜、三十七道品、佛十力乃至十八不共法合，乃至佛与菩提亦不与萨婆若合；继而论「不习色有无、常无常」等八对戏论，说菩萨不为种种佛法故行般若，不为五神通故行般若；末段转入空相应为第一相应，以法性、空、十八界为枢纽，收束于「习空能生大慈大悲，不生六恶心」。其主旨是：般若波罗蜜「相应」之相，不在「合」「得」「分别」「取相」，而在「不见」「不坏诸法相」「毕竟空」中起大慈悲、广利众生。

## 二、结构层次

全卷以【经】【论】交替推进，论释随经文展开，可分五层：

- **萨婆若不与三世合（P5-P37）** → 经说萨婆若不与过去、未来、现在世合，论释以「三世虚妄、萨婆若实」破合，兼答「念过去诸佛萨婆若回向」「念未来当成佛」两重疑难 → 结论：以不取相故无合，萨婆若过三界出三世。
- **萨婆若不与蕴处界、六度、三十七品、佛十力、佛菩提合（P38-P100）** → 五众十二入不可见故不合；六度有世间出世间二种，漏未尽故不合；三十七品是二乘法、菩萨以着心行多回向涅槃故不合；佛十力等三种中唯佛所得可合而菩萨未得；佛是人、萨婆若是法，菩提是佛智、萨婆若是一切智，二智不一心生 → 收于「佛即是萨婆若，萨婆若即是佛」。
- **不习色有无等八对戏论、不为佛法故行般若、不为五神通故行般若（P101-P173）** → 经列「有/无、常/无常、苦/乐、我/非我、寂灭/非寂灭、空/非空、有相/无相、有作/无作」八对，论释以世间多着二见、破中道为失，五众因缘生无自性即空；复说菩萨不为六度乃至实际、内空乃至无法有法空、如法性实际、五神通等故行般若，以「不坏诸法相」故 → 五神通虽能利益，得之恐生憍高故不为。
- **五功德与陀罗尼三昧、法性五义、空第一相应（P186-P352）** → 习相应果报：恶魔不得便、世事了意、诸佛拥护不堕二地、诸天拥护、重罪现世轻受（五利），以普慈加众生故；疾得陀罗尼三昧门、所生处常值诸佛；次辨「法性」五重——不得相、不出法性、不分别诸法、不见是法能得法性、法性不与空合；十八界不与空合，空为诸佛深奥之藏、唯一涅槃门，故名第一相应。
- **不堕二地、受记三义、众生五义、生大慈悲不生六恶心（P354-P428）** → 空相应有二种：但空堕二地，不可得空无所堕；有方便空直至菩提。受记分得受记、如受记、近受记三种。众生义开不受、空、不可得、离四门。菩萨行二空、忆本愿度众生，于空事中众生生着即起大慈大悲，由不见我、不见世间乐故不破檀而能行布施 → 收束于「住是空相应中，能常不生悭、犯戒、瞋、懈怠、乱、无智六恶心」。

## 三、关键结论

1. 般若波罗蜜「相应」之相是「不与合」——萨婆若过三界出三世，三世虚妄生灭，真金不与弊铁同相，故求觅不可得，何况与合。
2. 佛是人（假名），萨婆若是法（因缘）；菩提是佛智慧，萨婆若是一切智慧；十力智为菩提，第十一如实智为萨婆若，二智不一心生，故佛、菩提亦不与萨婆若合——而佛即是萨婆若，萨婆若即是佛。
3. 世间多着有无二见，破中道；诸法因缘和合生无自性即空，故菩萨「不习色有无」乃至「有作无作」八对戏论，离二边行中道，即与般若相应。
4. 般若波罗蜜相应为诸相应中第一，空、无相、无作名字虽别其义为一；但空堕声闻辟支佛地，不可得空、有方便空则无所堕直至菩提。
5. 菩萨行空相应，不见我、不见世间乐，故不破六波罗蜜而能行六波罗蜜，以清净空心布施，生大慈大悲，不生悭等六恶心——此即「习空能生大慈大悲」之实义。

## 四、易混辨析

- **萨婆若 vs 菩提**：萨婆若是佛一切智慧（总），菩提是佛智慧（别）；第十一如实智名萨婆若，十力智为菩提；二智不得一心中生。简言之：菩提约能证之智，萨婆若约所证一切法实相之究竟智。
- **但空 vs 不可得空**：但空（无方便空）行则堕声闻、辟支佛二地；不可得空（有方便空）空亦不可得，无处可堕，直至阿耨多罗三藐三菩提。差别在「空」本身是否亦被空掉、是否带大悲方便。
- **得受记 vs 如受记 vs 近受记**：得受记者已得无生法忍、受佛现前记；如受记者新行道、肉身未得无生法忍，但以智慧力深入空，佛赞其入空功德故言「如受记无异」；近受记者钝根行空相应，功德渐熟将近受记。
- **众生不受 vs 众生空 vs 众生不可得 vs 众生离**：不受者不受神、但有虚妄计我；空者众生法无所有；不可得者以实智求索不得；离者一切法自相离（如火离热相）。四门从浅至深，皆明众生毕竟不生不灭。

## 五、阅读提示

读本卷可扣住一个「合」字与一个「不见」：经文反复说「不与萨婆若合，不可见故」，论释则处处以「不可得」「无自性」「毕竟空」释「不可见」；末段「空相应为第一」是全卷高潮，宜对照〈赞般若品〉与〈阿毗跋致品〉参看受记三义与二种空。
