# 大智度论卷第七十二 导读

## 一、内容总览

本卷为《大智度论》卷七十二，释《摩诃般若波罗蜜经》〈大如品〉。全卷以一个“如”字为眼：色、五蕴、六度乃至一切种智，与“如来如”一如无二无别；由天子叹“须菩提是佛子、随佛生”发起，中经大鸟无翅之喻，明般若方便之有无决定成佛或堕二乘，末以菩萨成就菩提应行的等心、下意等众行收束。

## 二、结构层次

全卷依【经】【论】交替，四番推进：

1. **叹深·释“随佛生”**——经：天子散香赞法甚深 → 佛印可“色即是萨婆若……一如无二无别”，历数虚空、如、法性、实际乃至一切种智皆甚深 → 须菩提说“是法随顺一切法、无碍、不生、无处” → 天子叹“须菩提随佛生” → 须菩提以“如来如相不来不去”、三世如与一切法如不二，层层自释 → 大地六种震动。论：释甚深之浅深（如河水有洄复深处）；“阿耨多罗三藐三菩提即般若波罗蜜，名字异耳”；以三种子、佛子五众皆从口生法生释“随佛生”；辨般若有“唯与菩萨说”与“三乘共说”二种，此经共二乘说；五众和合假名如来。
2. **四句破着·大鸟之喻**——经：须菩提以四句破“随佛生”（不从色、不从色如、不离色、不离色如）→ 舍利弗叹“色尚不可得，何况色如” → 闻法者二百比丘漏尽证果，六千菩萨却退成阿罗汉 → 佛说其先世值五百佛而无般若方便、“行别异相”，举大鸟无翅之喻 → 结劝“以无得无相心”修六度。论：释“如”名实相不虚诳；退堕由过去失方便（如人持器诣海，随器取足）；配释鸟喻——身大＝广集五波罗蜜，无翅＝无般若方便，“死”＝阿罗汉道、“死等”＝辟支佛道。
3. **难易·三乘之辨**——经：天子叹菩提难得 → 佛自证“亦无所得，诸法毕竟净” → 须菩提反言“易得” → 舍利弗以恒河沙菩萨退还难 → 须菩提连环问答：色乃至一切种智、如、法性、实际等于菩提退还不？皆“不” → 舍利弗以三乘作难，富楼那提示追问 → 须菩提于如中求三乘人俱不可得 → 佛赞“汝所说者皆是佛力”。论：“法忍”是法门、法修、法行，入则无退还、出则有退还；入毕竟空门一相无别，出毕竟空说三乘有异；“各各有无上，大乘无上”。
4. **菩萨行·四十种行**——经：佛答“应云何行”——于众生起等心、大慈、下意、安隐、无碍、无恼、爱敬七心 → 一切善法皆以“自行、教人、赞叹、欢喜赞叹”四分行之：十善、四禅、四无量、四无色定、六度、十八空、三十七道品、三三昧、佛十力、四无碍智、十八不共法、十二因缘、四谛，乃至须陀洹果“自生证智而不证实际”、净佛世界、一切种智、寿命成就、法住 → 二千菩萨得无生法忍。论：等心是四无量心总相、慈心是一无量，不说悲心恐其退没；“众生忍是法忍初门”；十善是旧法、六度是客法，旧客二轮具足；善说二谛故得无生法忍。

## 三、关键结论

- “如”即诸法真实相、不虚诳义；色等诸法与萨婆若、如来如“一如无二无别”，凡夫见二有别，圣人观无二无别。
- 阿耨多罗三藐三菩提与般若波罗蜜同体异名：在菩萨心中为般若，在佛心中为无上菩提。
- “随佛生”从口生、法生，以如不二故；四句遍破，随佛生亦了不可得。
- 同修空、无相、无作：离萨婆若心、无方便力则于实际作证堕二乘（大鸟无翅），不离者直至佛道。
- 菩萨于一切众生起等心、下意等心，一切善法自行教他赞叹，于声闻果位“自生证智而不证实际”。

## 四、易混辨析

- **萨婆若 vs 一切种智**：萨婆若（一切智）是佛智总名；一切种智知一切法总、别二相。经中并举互通（“一切种智即是萨婆若”）。
- **等心 vs 慈心**：等心是四无量心总相，先舍怨、亲、中人之别；慈心是一无量，加以愍念爱念。不说悲心者，悲或忧念众生而心退没。
- **众生忍 vs 法忍**：于众生不瞋不恼的柔软好心名众生忍，是“法忍初门”；法忍于深法不惊不怖，本卷谓入此法门则于佛道无退还。
- **有余涅槃 vs 无余涅槃**：阿罗汉末后身漏尽而残身尚存，住有余涅槃、近无余之门；无余涅槃身智俱寂，论称第一清净。

## 五、阅读提示

带着一个疑问读：一切法空、菩提“易得”，为何恒河沙菩萨退还？抓两条主线——“如”之不二与般若方便之有无——再看大鸟喻与四十种行，全卷意脉自明。
