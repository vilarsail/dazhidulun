# 大智度论卷第三十 导读

## 一、内容总览

本卷承接前卷「不离诸佛」之余绪，集中阐释菩萨修学般若波罗蜜所能成就的四类大愿：以善根供养诸佛、满一切众生所愿、令众生住六波罗蜜、殖善根于佛田乃至佛道不尽；复更推进至「诸佛称赞其名」「一发意至十方世界」「一音使十方闻声」「佛世界不断」等愿。全卷以「般若波罗蜜为根本所依」为骨，以「财供养/法供养」「今世/后世/出世」三利乐、「五道/六道」众生判摄、「佛田/余田」福德优劣为肉，层层展开菩萨所以须学般若之因缘。

## 二、结构层次

全文依经论对举，按「四段经 + 四段论」之问答题结构推进：

- **善根供养（初品第四十六）**：菩萨既不离诸佛 → 当供养 → 须摩提买华、萨陀波仑卖身之例 → 财供养与法供养俱摄于「善根」 → 随时、随地、随人所宜 → 甚深禅定起神通雨天华、雨七宝、身作灯炷等财供养；六波罗蜜、无生法忍、住十地灭地狱火等法供养 → 结归般若。
- **满众生愿（第四十七之前半）**：菩萨业二种——供养诸佛、度脱众生 → 入佛法海得宝还益众生 → 愿有可得/不可得 → 世间愿、出世间愿 → 下中上三愿次第与今世、后世、涅槃乐 → 频头居士雨百味食、菩萨住十地入首楞严三昧现八相 → 佛真身/化身之别 → 罗频周比丘乞食不得乃至佛持食方得之例 → 「满一切」是名字一切非实一切 → 饮食衣服涂香卧具房舍灯烛之解释 → 何以华香不说 → 檀波罗蜜满愿须般若和合方名檀波罗蜜。
- **立六波罗蜜（第四十七之中段）**：利乐三品——今世、后世、毕竟 → 先以饮食充足身，次以衣服庄严身，复以功德庄严心 → 毓众生住六波罗蜜，列恒河沙世界众生之由 → 详析欲界众生（五道/六道之辨、阿修罗立 sixth 之由） → 别释立檀、立尸罗、立羼提、立毗梨耶、立禅、立般若，每段以喻赞叹一度之德 → 或现神足光明梦中因缘令住。
- **佛田殖善根、诸佛称名、一发意至十方、一音遍闻、佛世界不断（第四十七之后段至卷末）**：三善根为诸善本 → 佛为第一福田，殖福乃至佛中间不尽 → 涅槃不尽、福德入实相故不尽 → 世俗门故求佛称名以决知阿鞞跋致 → 佛三毒永尽能如实赞 → 叹菩萨观空慈悲、生身大施、戒定慧等奇特德 → 文殊、毗摩罗诘、观世音等为上首 → 身通变化力一念至十方 → 五不可思议中佛力最胜 → 梵声相过三千界 → 佛音密/不密二种、三种音声 → 佛世界不断，国国相次令发心作佛，如王立太子国祚不断 → 有佛国/无佛国之贵贱。

## 三、关键结论

1. 财供养与法供养俱摄于「善根供养」一字之中，是故经言善根不言华香。
2. 满众生愿须以般若和合檀波罗蜜方能办，非一阎浮提、非但布施所能成；「满一切」是名字一切，众生罪障故不现得，非菩萨咎。
3. 佛田为第一福田，殖善根于中乃至得佛中间不尽，以福德入诸法实相、如涅槃毕竟空故。
4. 欲界众生应立六道，非五道——善恶各有上中下三品故；阿修罗力似天而近道难，故在人下、别立一道。
5. 佛音常遍满虚空，众生不闻由自罪障，非佛不慈；如雷电霹雳聋者不闻。

## 四、易混辨析

- **财供养 vs 法供养**：财供养谓华香、璎珞、饮食、珍宝乃至以神通雨天华、身作灯炷等事相供养；法供养谓行六波罗蜜、得无生法忍、住十地以神力灭地狱火、令饿鬼饱满等利益众生之德。经言「善根供养」则二俱摄。
- **佛真身 vs 化身**：真身遍虚空、光明音声遍十方、唯十住菩萨能持法性身说法；化身如释迦王宫受身现寒热饥渴老病死，内心智慧神德与真佛无异。众生见真身无愿不满，见化身则随业得利益。
- **五道 vs 六道**：旧经多说五道（地狱、畜生、饿鬼、人、天），摩诃衍《法华》说六趣，益阿修罗道。龙树判善有上中下三品对应天、人、修罗，恶有三品对应地狱、畜生、饿鬼，故六道于义无违。
- **不尽 vs 常不尽**：经言殖善根于佛田乃至得阿耨多罗三藐三菩提不尽，非谓常不尽，乃「中间相续不断」；以福德入诸法实相、喻如涅槃，非即涅槃。

## 五、阅读提示

读本卷可带着一问：菩萨既观诸法毕竟空、破吾我憍慢，何以反求诸佛称名供养、求满众生愿、求佛世界不断？答在世俗门与第一义门二门并行——般若为体，大悲为用，空不碍愿，愿不碍空。
