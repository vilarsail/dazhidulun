# 大智度论卷第九十三 导读

## 一、内容总览
本卷为《大智度论》卷九十三，含两品：先承上卷续释〈净佛国土品〉之余，再释〈毕定品〉。前者说菩萨如何庄严未来佛土——远离取相粗业，自行教他六度，以供养、发愿回向感得清净国土；后者答“菩萨是否必定成佛”：于佛道毕定，不落二乘，不堕恶道，纵受畜生身也是慈悲化现而非业报。两品一修一证，展示菩萨道的远景与保证。

## 二、结构层次
**上半卷〈净佛国土品之余〉**
- 经文：先立“粗业”——于五蕴、六根六尘、男女、三界、有为无为法上取相生着，菩萨皆远离 → 次列善行发愿：自布施亦教他布施，以七宝、天乐、天香、百味、细滑、随意五欲供养佛僧并回向净佛国土 → 自入四禅、慈悲喜舍乃至三十七助道法，亦教众生 → 结归净土果相：无三恶道、二乘、烦恼之名，宝树常出空、无相、无作法音，闻佛名者毕定作佛。
- 论释逐段问答：以众生空、法空破取相（无为法即无相法门，取相便成有为）→ 珍宝何处得：法性生身菩萨神通所作，轻细无碍 → 佛离欲何须伎乐：令众生闻好音声心柔软、易受化 → 五欲如火坑何以愿众生得之：五欲是福德果报，贫穷故造十不善；净土众生五欲一等故不贵着，佛说“舍苦乐，用智慧，处中道”（兼辨阿梨吒比丘案：白衣受欲得道无罪，出家自誓犯欲堕罪）→ 净土诸难：三恶道难度但可种善根，故佛名天人师；佛有净国土、杂国土；五浊世一道分三，阿弥陀佛、阿閦佛因本愿故有三乘；宝树出音以树木无心人皆信受；薄福破法者堕狱，佛令住正定聚。

**下半卷〈毕定品〉**
- 经文问答递进：毕定不毕定？→ 何处毕定（佛道非二乘）？→ 初发意、阿鞞跋致、最后身三种菩萨皆毕定 → 不堕恶道（喻如四果圣人）→ 不生恶道、长寿天、边国、恶邪见家、无作见家 → 问：本生受畜生报，善根何在？→ 答：为利众生随类受身，如佛化畜生、幻师幻作，白净无漏法故“亦不受苦”。
- 论释：会通异说——《法华》说毕定、余经说有退，“二事皆实”，佛对机而说 → 呵二乘于法性少分取证、迂回稽留，阿罗汉往净佛国土闻《法华》具足佛道，“漏尽阿罗汉还作佛”唯佛能知、不应戏论 → 毕定即阿鞞跋致，不堕三恶趣（不善道上堕地狱、中堕畜生、下堕饿鬼）→ 不生长寿天（深着禅味难可度）、不生边国（吝法为因，中国边地之辨）、不生邪见家 → 大力菩萨随类受身不避边地，新发意如真金在泥终不败坏 → 举六牙白象本生，证畜生身是慈悲变化。

## 三、关键结论
1. 净土以因净故净：远离取相粗业，自行教他六度，供养发愿回向，“共清净因缘故，则佛土清净”。
2. 净土果相：无三恶道、无二乘、无结使烦恼之名，宝树昼夜演出空、无相、无作实相之音。
3. 五欲不妨净土：彼土众生五欲一等故不生贵着；佛言“舍苦乐，用智慧，处中道”。
4. 菩萨于佛道毕定（必当作佛），初发心乃至最后身皆毕定，故不堕三恶道。
5. 毕定菩萨受畜生身是大方便力：白净无漏法的化身，为利众生而非业报，声闻、辟支佛所无。

## 四、易混辨析
- **毕定 vs 阿鞞跋致**：毕定＝必当作佛；阿鞞跋致＝不退转、不堕三恶趣。论言“毕定即是阿鞞跋致”，只是般若“种种门”中异门而说。
- **净国土 vs 杂国土**：杂国土五道杂居；净国土无三恶道，或有人天别异、或无（如天王佛国土唯佛为法王）。
- **白衣受五欲 vs 出家犯欲**：白衣五欲是福德果报，受之无罪得道（兜率陀天、郁单曰人为例）；出家人于僧前自誓“尽形寿不犯淫欲”，犯则堕罪——阿梨吒比丘混同二者故被摈。
- **边地 vs 中国**：无三宝之名、不识七众、不贵道法为边地；识三宝、知罪福、解实相者虽生阎浮提外亦“不名为边”。

## 五、阅读提示
读上半卷可带一问：供养与愿力如何“兑换”成国土庄严？读下半卷注意佛说“毕定”与“有退”如何会通——皆是应机之教，“二事皆实”。
