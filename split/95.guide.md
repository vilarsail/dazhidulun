# 大智度论卷第九十五 导读

## 一、内容总览

本卷为《大智度论》第九十五卷，含〈释七喻品第八十五〉与〈释平等品第八十六〉两品，正当般若经文将终（经将讫）之处。两品回应同一个总疑难：诸法无性、毕竟空，为何又现见六道业果、四沙门果、菩萨佛道？前品以梦、镜中像、响（原文作“向”）、焰、揵闼婆城、幻、化七喻总答“业果无实”；后品进一步提出“诸法平等”——平等即净、即三宝，凡夫与佛无二，一切差别皆世谛故说。

## 二、结构层次

**七喻品**（经、论双轨推进）：
- 须菩提立问：诸法性无所有，非佛、辟支佛、阿罗汉乃至菩萨所作 → 云何分别有地狱、人、天乃至四果、菩萨、佛？（以“有”难“空”）
- 佛印可“无性法无业无果报” → 指出凡夫不入圣法、不知无性相，四颠倒与无明故起业受身 → 随以七喻逐一反问：梦中受五欲、镜中像、深涧响、野焰、揵闼婆城、幻事、化人——各有业因缘可堕六道否？有修道可说垢净否？答皆“不也” → 收束：空相中无垢者净者，住我、我所故有垢净。
- 论中层层解释：须菩提经将讫重问，为钝根者（着空亦着“空亦空”，如目翳视珠）→ 佛可其说、不可其难 → 断颠倒即是圣果，“果即是断” → 关键转折：“虽二法皆不实，而不实中有差别”（以十善十不善为例）→ 我见无定缘，我毕竟无故垢净无住处。

**平等品**（从“不垢不净”进至“平等”）：
- 须菩提追问：实见者、不实见者皆不垢不净，云何无异？→ 佛答“诸法平等相我说是净”（如、法性、法住、法位、实际），世谛故说，非第一义。
- 新发意菩萨之疑：一切法如梦如化，云何具足檀波罗蜜乃至十八不共法？→ 佛答：不可取相法不能得不可取相法；菩萨但为一切众生故求阿耨多罗三藐三菩提，置众生甘露性中，自无所著亦令众生无所著。
- 辨二与不二：二法无道无果，不二法亦无道无果 → “无二法、无不二法，即是道、即是果” → 诸法平等，凡夫乃至佛皆不能行、不能到（佛即平等故）→ 三宝即平等 → 诸法各各相异云何不作分别？→ 空中各各相不可得 → 平等非有为非无为，离有为无为不可得 → 菩萨第一义中不动而行菩萨事。
- 论中回护：入道人下、中、上三品（但自度／自为亦为他／但为他人为上）→ 引《毗摩罗诘经》“不二入法门”，佛遮二边说中道 → 牛喻明不一不异 → 破壁出狱喻明“离有为无为不可得”。

## 三、关键结论

1. 无性法无业无果报：业果六道皆凡夫颠倒所现，如梦幻响焰，无毫厘许实事。
2. 不实中有差别：善恶、施盗、恼众生与慈念众生虽俱虚诳，功能各异，故修行不废。
3. 我毕竟无故，垢净无住处；实见者不垢不净。
4. 诸法平等即是净、即是三宝；凡夫与佛平等无二，差别唯世谛故立。
5. 佛有大恩力：于诸法等中不动而分别诸法，如日出照物而不转物相。

## 四、易混辨析

- **世谛 vs 第一义**：佛得菩提、凡圣差别皆世谛故说；第一义过一切语言论议音声，无得无得者。
- **二法 vs 不二法**：二法是各各别相（凡夫），不二是一空相（贤圣）；但着不二亦成戏论，佛说非二非不二的中道。
- **诸法各各相 vs 诸法平等**：色乃至佛相各各异是别相；空中各各相不可得——非凡夫亦不离凡夫，非佛亦不离佛。
- **有为法 vs 无为法**：有为虚诳作法；无为非别有一物，破有为即是无为（如破壁是空），离有为则无为不可得。

## 五、阅读提示

带着两问读：业果既空，凭什么修行？——答在“不实中有差别”与“平等即是净”；佛即平等，凭什么说法度生？——答在“大恩力”与“世谛故说”。
