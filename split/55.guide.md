# 大智度论卷第五十五 导读

## 一、内容总览
本卷含三品连贯的般若义理展开，前承第五十四卷「天上人中谁是听法者」之余绪，后启散华供养与般若波罗蜜「大、无量、无边」之赞。第一部分（幻人听法品余）由诸天子「应用何人听法」之问引发须菩提「如幻化人听法」之答，层层推至「佛道、涅槃亦如幻如梦」；第二部分（散华品）诸天散化华供养三宝，须菩提据「不生」破华与色之生，佛赞其「不坏假名而说诸法实相」，菩萨由此学般若、到一切种智；第三部分论「当于何处求般若波罗蜜」「如来不可得」「摩诃、无量、无边波罗蜜」三义。全卷主线是：般若波罗蜜以毕竟空为相，故说者、听者、所说法、乃至佛与涅槃皆不可得，而不坏假名、不废行业果报。

## 二、结构层次
全卷按「听法者毕竟空 → 供养者不坏假名 → 求般若处不可得」三段递进，每段皆以【经】立事、【论】释义交替推进：

- **如幻人听法（幻人听法品余）**：诸天子问「何人听法」 → 须菩提答「如幻化人听」 → 推广至五蕴、六波罗蜜、四念处乃至十八不共法、须陀洹至佛道、涅槃皆如幻如梦 → 论释「涅槃无上、佛第一，云何如幻」之疑，答以「从虚妄法出故空，般若力能令有法胜涅槃者亦如幻」。
- **散华不生、不坏假名（散华品）**：诸天闻法欢喜化作华散三宝 → 须菩提分别「化华非树生」 → 释提桓因难「华不生，色亦不生耶」 → 须菩提广推色至一切种智皆不生 → 佛赞「不坏假名而说诸法实相」 → 菩萨如是学般若、不增不减、不受不灭、能到一切种智。
- **求般若处、如来不可得、三赞般若（卷末）**：释提桓因问「般若当何处求」 → 舍利弗推须菩提所说品 → 须菩提归佛神力，广说「色如中如来不可得」「不合不散」「不应色中求亦不离色求」 → 论释「无受相与如」之异、如来五种求不可得 → 释提桓因三赞「摩诃、无量、无边波罗蜜」 → 须菩提广解「色大故般若大、色无量故般若无量、色无边故般若无边、缘无边、众生无边故般若无边」。

三段以「空—假名—不可得」为内在脉络：先破听者实有，次立不坏假名而说实相，终泯能求所求，归毕竟无相。

## 三、关键结论
1. 佛与涅槃虽是「最上最妙」之法，亦从因缘、从虚妄法出，故如幻如梦；般若波罗蜜之力能令「假令有法胜涅槃者」亦复如幻，何况涅槃本身——涅槃与幻梦「不二不别」。
2. 能信受甚深般若者有四类：阿鞞跋致菩萨、漏尽阿罗汉、正见成就之学人、福德利根随善知识之菩萨；阿难代答非说空事，而是就「谁能信受」之有事作答。
3. 「不坏假名而说诸法实相」是本卷核心法门：诸法但有假名，圣人知俗谛与第一义谛，于第一义中无彼此亦无诤；菩萨「学空」是以不二故学，非破色令空，亦非离色有空。
4. 般若波罗蜜「非色、非离色」，乃至「非一切种智、非离一切种智」，一相所谓无相；当于五众虚诳中求重宝不可得，离五众亦无可求，故「不应色中求，亦不应离色求」。
5. 般若波罗蜜所以名「摩诃、无量、无边」，因色等五众前后中际不可得故大、量不可得如虚空故无量、三世不可得故无边；又缘无边（四缘遍一切处）、众生无边（但从假名、本自清净）故般若无边。

## 四、易混辨析
- **如幻 vs 如梦**：二者并称皆表无实。幻多指变化所成、似有实无（如化人、化华）；梦指心识所现、觉已即灭。论中以「幻化人」喻听法者无心心数法，以「梦」喻众生知见皆妄，合用表一切法从因缘生、无自性。
- **无受相 vs 如**：论中明辨——诸法中不可着故名「无受」，诸戏论不能破坏故名为「如」；二者皆指诸法实相，而侧重有别：无受约「不可取着」，如约「不改、不异」。
- **俗谛 vs 第一义谛**：名字是俗谛（假名安立），实相是第一义谛（毕竟空无所有）；圣人随凡夫说假名，于第一义中无彼此无诤。须菩提「不坏假名而说实相」即善用二谛。
- **如来（佛如来）vs 如去**：论辨二种如来——先世来、后世亦如是去，通名「如来」亦名「如去」（十四置难所论死后有无）；佛名如来者，如定光佛等行六波罗蜜得成佛道，释迦文佛亦如是来。本卷所说乃「佛如来」，于毕竟空中求不可得。

## 五、阅读提示
读此卷宜扣住「空而不坏假名」一语：每见须菩提说「不生」「不可得」「不受不灭」，并非否定现象，而是破其「定相」；菩萨由此「无所学、无所到」而能到一切种智。又当注意阿难代答一段，论中特为辨明阿难「第三转法轮将」之地位与其「乐说有、未善巧空」之关系，乃理解本卷师资相承之关键。
