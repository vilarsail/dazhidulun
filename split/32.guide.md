# 大智度论卷第三十二 导读

## 一、内容总览
本卷为大智度论卷第三十二，释初品中四缘义第四十九。全卷以般若波罗蜜为枢轴，依次释「四缘」「如·法性·实际」「大神力」「结加趺坐遍满虚空」「一毛举须弥山」「一食供养十方诸佛」「令众生得四果涅槃」「布施果报差别」「以慧方便具足六波罗蜜」「得三世佛功德」等十数门，皆是「菩萨摩诃萨当学般若波罗蜜」的展开。主旨在于：菩萨欲广大知见、成就福慧、度化众生，皆须以般若波罗蜜为根本——以不可得空破诸戏论，而不坏世俗因缘；以大悲方便行施戒等行，而不取证涅槃。

## 二、结构层次（文章的骨架与逻辑推进，★重点）
全卷按「四缘→实相→力用→功德」层层展开，由理及事、由自及他：

- **四缘义（理门，破立双行）**：先举经言「欲知四缘当学般若」→ 论主列因缘、次第缘、缘缘、增上缘四相，复举般若中四缘皆不可得之难 → 答曰「般若无所破」，如水中月「但破可取、不破可见」→ 转辨阿毗昙四缘义初学如实、转深堕邪，唯般若中不可得空无如是过。
- **如·法性·实际（实相门，三名一实）**：问三事为一为异 → 答是「诸法实相」异名 → 别释「各各相」「实相」「法性」「实际」 → 引《杂阿含》明声闻法中亦有说处但少 → 以九事分别下如、中如、上如 → 明入法性、住实际之次第，菩萨悬知实际而以大悲还修诸行。
- **大神力四喻（事门，四大皆心所转）**：地尘、水渧、大火、大风四喻 → 皆归「心力为大，行般若故散地为尘」→ 释火风相因相灭、一指障风之理。
- **遍满虚空·举山·一食供养（力用门，希有起信）**：结加趺坐遍满虚空以息梵天慢 → 一毛举百亿须弥掷过无量世界令众发菩提心 → 一食一衣供养十方恒沙诸佛及僧，以心不在事、涌泉不尽为喻。
- **令得四果与布施果报（化他门，福由心判）**：令众生得须陀洹乃至无余涅槃 → 次明布施果报随心优劣：舍利弗施佛不如佛施狗、亿耳一华施塔、阿输迦土施佛，三事心、物、福田互夺 → 次第配生刹利、婆罗门、居士、六欲天、四禅、四无色，乃至声闻、辟支、佛道。
- **慧方便具足六度·三世佛功德（收束，理事圆融）**：施受物三事不可得即具檀度、罪不罪不可得具尸罗……乃至知一切法不可得具般若 → 慧方便非断灭，坏烦恼、起大悲、回向菩提皆是 → 末以释迦即阿弥陀、十方诸佛皆是我身收束，明诸佛大悲彻髓、随应度者而教化。

## 三、关键结论
1. 般若波罗蜜于一切法无所舍、无所破，毕竟清净无诸戏论；四缘不可得非灭四缘，但破取着，如破水中月之可取而不破可见。
2. 如、法性、实际是诸法实相异名；三世平等、有佛无佛法性常住，菩萨入法性而不证，以大悲精进还修诸行。
3. 心力为大：地水火风虽各有大力，皆由心取相故力劣；诸佛菩萨般若清净故一念中能知十方恒沙世界微尘。
4. 布施得福在心不在田，然大福亦可从良田生；三事心、物、福田皆妙则福最胜，回向阿耨多罗三藐三菩提名慧方便。
5. 诸佛功德皆等无多无少，世界有净不净、杂，皆是佛身随类度化；大悲彻髓，不以世界好丑而舍众生。

## 四、易混辨析
- **四缘 vs 六因**：四缘是因缘、次第缘、缘缘、增上缘；六因是相应、共生、自种、遍、报、总前五者合名因缘。六因摄于四缘之中，第六无障因即增上缘所摄。
- **如 vs 法性 vs 实际**：如者各各自相（地坚水湿等）求实不可得；法性者诸法同为一空；实际者以法性为实证、入处为际。三皆是实相异名，浅深次第有别。
- **须陀洹 vs 斯陀含 vs 阿那含 vs 阿罗汉**：须陀洹断三结、八圣道流入涅槃，名「流·入」；斯陀含（息忌伽弥）一来人天生灭众苦；阿那含（阿那伽弥）不来欲界、于上界漏尽；阿罗汉尽一切烦恼、受天人供、舍五众永灭名无余涅槃。
- **般若波罗蜜 vs 阿毗昙四缘义**：阿毗昙初学如实，求之转深堕邪见（因中先有先无等戏论）；般若中不可得空无如是失，但除邪见不破四缘。

## 五、阅读提示
读此卷可带着两个问题走：其一，龙树既说「四缘不可得」，为何又说「欲知四缘当学般若」？把握「破着不破法」一线即可贯通。其二，菩萨既入法性、悬知实际，为何不证涅槃？留意「以大悲精进力故还修诸行」「妨成佛道」二语，即见大乘不共二乘之关节。
