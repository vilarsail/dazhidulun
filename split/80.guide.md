# 大智度论卷第八十 导读

## 一、内容总览
本卷收论释两段：释《无尽方便品》第六十七（承前卷经文）与释《六度相摄品》第六十八。前半以「虚空不可尽」立般若「不可尽」之义：菩萨以虚空不可尽法观十二因缘、行无所得般若，则魔不得其便、于佛道不退；退转者皆因离般若念、不得方便力。后半明「一波罗蜜能摄五波罗蜜」，枢机全在回向萨婆若。

## 二、结构层次
- **无尽方便品·经**：须菩提闻般若种种相（初闻毕竟空、中闻嘱累、后还闻空），问「般若波罗蜜不可尽」→ 佛答「虚空不可尽故，般若波罗蜜不可尽」→ 问「云何应生般若」→ 佛答：色受想行识、六度乃至一切种智不可尽故般若应生；无明乃至老死、忧悲苦恼「空不可尽」故般若应生 → 「十二因缘是独菩萨法，能除诸边颠倒」，坐道场时应如是观、当得一切种智 → 求菩萨道而转还者皆离般若念、不得方便力；不转还者皆得方便力 → 行无所得般若，诸魔愁毒如箭入心、不得其便 → 布施乃至智慧「皆回向萨婆若」，即具足六波罗蜜
- **论释一**：释须菩提三闻故起问 → 破色生不可得故色无尽、色真相即般若相 → 但观毕竟空多堕断灭边、观有多堕常边，离二边说十二因缘空、假名中道 → 痴实相即是智慧，取着智慧相即是痴 → 判三种十二因缘观：凡夫肉眼所见／二乘与未得无生忍菩萨所观／得无生忍乃至坐道场菩萨所观，深观者过二乘、得一切种智 → 释回向：念萨婆若是信力，如萨婆若回向是智力
- **六度相摄品·经**：须菩提递问「住檀波罗蜜取尸罗乃至般若」「住尸罗取余五」→ 佛一一答：布施回向萨婆若、于众生住慈身口意业即取尸罗；受者嗔骂而忍即取羼提；增益布施、身心精进即取毗梨耶；不趣二乘、一心念萨婆若即取禅；知施空如幻、不见有益无益即取般若；住尸罗例此：具足十善道戒、广行布施，乃至节节支解不生一念瞋
- **论释二**：释相摄所以：以方便力故；善法因缘相续相成；一度为主、余度有分 → 随文决疑：瞋分上中下而意业为本；忍辱但说割截身体，以内着最深、举大摄小；辨变化身与父母生身；禅定折伏烦恼如咒术制毒蛇，心澄静故生实智 → 简真无为（涅槃寂灭无戏论）与相待「无」（庙堂上无马）→ 但见如、法性、实际，以方便力、本愿、悲心不取二乘证

## 三、关键结论
1. 般若以虚空无所有故不可尽；色乃至一切种智不可尽故般若应生——诸法真相即般若相。
2. 十二因缘空观是独菩萨法：离常断二边、假名中道；退转的病根唯在离般若念、不得方便力。
3. 痴实相即是智慧，取着智慧相即是痴；痴实相毕竟清净，如虚空无生无灭。
4. 具足六度唯在回向萨婆若；行一波罗蜜能摄五度，以方便力与「一度为主、余度有分」故。
5. 菩萨有二种破戒：造十不善道、趣向二乘地；与此相违即是二种持戒。

## 四、易混辨析
- **毕竟空 vs 断灭空见**：般若毕竟空是离二边的实相，若单取空相、废却缘起，即堕断灭边；故须以虚空不可尽法观十二因缘空。
- **痴 vs 智慧**：痴若有定相即是明而非痴，痴实相毕竟清净即是智慧；反之取着智慧相又复成痴。
- **父母生身 vs 变化身**：业因缘受生的肉身与神通所变之身。论问「不生一念瞋」者是何身——是化身则不足为奇，是父母生身则由无量劫修慈、观毕竟空所致。
- **真无为 vs 相待无**：涅槃寂灭、无相无戏论是真无为；「庙堂上无马」式的「无」因「有」而立，反是生诸烦恼的因缘，不得名无为。

## 五、阅读提示
带着两问去读：退转的病根在哪里？一行何以能摄六度？前者答案是离般若念与方便力，后者答案是回向萨婆若——信力念之、智力如之，一行即成六行。
