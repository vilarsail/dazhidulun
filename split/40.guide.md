# 大智度论卷第四十 导读

## 一、内容总览

本卷承接〈往生品〉之末，全卷以「五眼 → 六神通 → 六波罗蜜净萨婆若道 → 众生等心 → 比丘施衣发心 → 阿罗汉赞般若 → 佛出舌相」一线串起，从「菩萨眼智之差别」推进到「般若波罗蜜为一切善法本」，最后以舌相光明收束、引出下一卷须菩提说空。核心是论证般若波罗蜜统摄五眼、六通、六度与三世佛，故当学般若。

## 二、结构层次

- **法眼净（经论合释）** → 先以法眼判别三类行人：随信行／随法行／无相行，行三解脱门者得五根、无间三昧、解脱智，断三结成须陀洹，渐断成斯陀含、阿那含、阿罗汉、辟支佛 → 次以法眼分别菩萨：退与不退、受记未受记、阿鞞跋致、具足神通、净佛世界、成就众生、一生补处、坐道场、有魔无魔等对列 → 论释逐项解名义。
- **佛眼净** → 菩萨入如金刚三昧得一切种智，成就十力、四无所畏、四无碍智、十八不共法、大慈大悲 → 论辨「慈悲何以名眼」（与慧眼相应、三缘慈悲、无缘即佛）→ 广明五眼所见不同：肉眼、天眼、慧眼、法眼、佛眼，交叠有无，层层胜进，终归佛眼「无法不见闻觉识」→ 结归「六波罗蜜中摄一切善法，般若为本，能生五眼」。
- **六神通波罗蜜** → 经说如意、天耳、他心、宿命、天眼、漏尽六通，一一皆「不自着、不着神通事、不着己身」，以自性空、离、无生故，除为萨婆若心 → 论释神通所由（取空多地少、福德因缘、心调柔等）与外道神通二失（起吾我、着神通）→ 结归「广利益众生，增益阿耨多罗三藐三菩提」。
- **六波罗蜜净萨婆若道** → 经列六度各以「毕竟空」净萨婆若道：不悭、罪不罪不着、不瞋、不懈、不乱不味、不痴 → 毕竟空中不来不去、不施不受、非戒非犯……无生法中无受毁受害受恭敬者 → 论释菩萨胜声闻处：深慈爱之如子、忍辱慈悲方便深故能净佛世界。
- **等心与发心瑞应** → 经说一切众生中生等心则得法等、为诸佛所念、所生不见不爱色 → 论释众生等、法等二义，福德因缘得现世后世果报 → 经记三百比丘施衣成佛号大相、生阿閦佛国；六万欲天子发心于弥勒法中出家；十千人愿生庄严佛土，佛记当生当得作佛号庄严王 → 论释破戒施衣无犯、佛笑因缘、业果相续不可思议。
- **叹度品（阿罗汉赞般若）** → 舍利弗、目连、须菩提、迦叶等列名赞般若为摩诃、尊、第一、胜、妙、无上、无等、无等等、如虚空等波罗蜜，及自相空、自性空、诸法空、无法有法空等 → 论释四罗汉为无量福田、阿罗汉复赞般若之由 → 佛印可「应当礼敬供养」，自说因菩萨故有人天道、三乘圣果及世间乐具，菩萨为安乐众生出现于世 → 论释乐由菩萨得、与乐非生贪之咎。
- **舌相品（转接下卷）** → 佛出舌相覆三千大千，放光遍照十方恒沙佛土 → 东方菩萨问佛、诣娑婆听般若 → 十万亿人得无生忍、发愿当如今佛、佛记过六十八亿劫作佛劫名华积号觉花 → 论释重出舌相之由、命须菩提说之故（无诤定、深行空）。

## 三、关键结论

1. 五眼次第胜进，佛眼独无所不见闻觉识；五眼皆由般若波罗蜜生，般若为本。
2. 菩萨修六神通，于通、于事、于身皆不着，以自性空、离、无生故；外道神通起吾我、着神通故不及圣人。
3. 菩萨住六波罗蜜净萨婆若道，毕竟空中施戒忍进定智皆不可得，无生法中无毁无害无恭敬，胜过声闻辟支佛。
4. 三世诸佛皆从般若波罗蜜生，般若名为大、尊、第一、胜、妙、无上、无等、无等等、如虚空等，行般若者天人阿修罗当礼敬供养。
5. 因菩萨故出生人天、三乘及世间一切乐具，菩萨为安乐一切众生出现于世。

## 四、易混辨析

- **肉眼·天眼·慧眼·法眼·佛眼**：肉眼见近不见远、内不见外；天眼胜肉眼而凡夫得通者有之；慧眼见空而声闻圣人得之；法眼知度生道而菩萨得之；佛眼无所不见闻觉识，唯佛及等觉具足。论中以「眼所见四分」交叠有无辨之。
- **法眼净 vs 佛眼净**：法眼净分别知声闻辟支佛及菩萨方便行道门，判退不退、受记、补处等；佛眼净则于一切法无法不见闻觉识，得一切种智乃成就。
- **众生缘·法缘·无缘慈悲**：凡夫众生缘；声闻辟支佛及菩萨初众生缘后法缘；诸佛善修毕竟空名无缘，是故慈悲亦名佛眼。
- **随信行·随法行·无相行**：钝根依信力得道名随信行，利根分别诸法得道名随法行，十五心中疾速无人能取其相名无相行。
- **阿罗汉赞般若 vs 菩萨行般若**：阿罗汉结使已断、所作已办，本无可羡；以其现世为无量福田、有慈悲助佛扬化，故以之为证赞叹般若，令众生起敬。

## 五、阅读提示

读此卷宜把握「眼—通—度—心—赞—相」六个台阶，每一台阶都以「般若波罗蜜为本」收束；论中五眼交叠一节最易乱，可先记肉眼→天眼→慧眼→法眼→佛眼之次第，再看两眼、三眼、四眼合见之交叠有无。
