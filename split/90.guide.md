# 大智度论卷第九十 导读

## 一、内容总览
本卷为《大智度论》第九十卷，释《摩诃般若波罗蜜经》〈实际品第八十〉，在全论百卷中已近尾声。前品须菩提曾问“若诸法空，云何有五道生死、善不善法”，本卷更进一问：“若众生毕竟不可得，菩萨为谁故行般若波罗蜜？”佛答：“为实际故，行般若波罗蜜”——实际与众生际不二，为实际即是为众生。全卷主旨是“毕竟空中如何度众生、如何成佛”：一面以方便力建立众生于布施、持戒等善法，一面开示诸法性空、不坏法相，终归于“菩提非取非舍、世谛故说得菩提”。

## 二、结构层次
**经文（须菩提与佛往复问答）**
- 起问：众生毕竟不可得，为谁行般若 → 佛答“为实际故” → 须菩提难“建立实际于实际”是自性之失 → 佛出“方便力”为枢纽
- 方便力次第展开：布施→持戒→忍辱→精进→禅定，各段同一格局——教修善法 → 随说“三世空、能所空” → 结“是世俗法，非第一实义”
- 入性空正说：性空中云何求一切种智 → 依性空成菩提 → 法住相（无聚散生灭垢净）→ 佛化四众喻 → 于颠倒中拔出众生 → 无漏法亦不如第一义 → “色即是性空，性空即是色”
- 菩提行处之辨：一切无分别，云何发愿得菩提 → 菩提不二相、非取中行非舍中行 → 化人喻、阿罗汉梦中菩提喻 → 疑“岂不行十地六度” → 不具足诸法终不得菩提，而得菩提“世谛法故”说

**论释**
- 总释问答大意（上品难法，今难众生；“实法”即实际）
- 十二因缘逆推：老病死←生←有←取←爱←受←触←六入←名色←识←行←无明，逐支释名（业过去但有其名，梵语“删迦罗”曰“行”），并答“何以止齐无明”（良医治未来病、灭未来火二喻）
- 推求无明体即入毕竟空，“求无明体，即时是明”——即实际；蚕作丝自缚喻凡夫自缠烦恼
- 释方便：建立众生于檀，说布施三际空（施者、受者、果报俱空），“甘露味”是八圣道、“甘露果”是涅槃
- 释性空诸问：十八空自不空则坏空体、“常住法相”是性空异名、化人喻、“但破众生妄想，不破众生”、虚空不坏虚空喻、“一切诸佛唯有是道”
- 释“非取非舍”（取＝着实法、着行、二行；舍＝着空法、不二行）：菩提三种之辨、阿罗汉眠与佛现眠（萨遮尼干问）
- 结：世谛故说菩萨得菩提，利益众生

## 三、关键结论
- 实际与众生际无二无别：离众生无实际可立，故“为实际”即“为利益众生”。
- 方便力是空中度生的枢纽：教善法而不坏空理，“空中布施不可得”而布施能取甘露味。
- 性空是诸佛唯一之道：前际中际后际皆性空，非诸佛天人所作；离性空则无道无果。
- 菩提不二不分别、非取非舍，如化人无处行；然不具足十地、六波罗蜜等终不成佛——而“得菩提”唯是世谛故说。

## 四、易混辨析
- **实际 vs 众生际**：实际是诸法毕竟空理；众生际是众生的实际。二者“无二无别”，故为实际行般若不废度生。
- **萨婆若 vs 道种智 vs 一切种智**：萨婆若（一切智）总名佛智；道种智遍知声闻、辟支佛、菩萨诸道差别，菩萨度生所用；一切种智唯佛具有，总别遍知。
- **世谛 vs 第一实义**：众生、得果、得菩提皆世谛安立；第一实义中无得者、无得法，“诸法毕竟空，即是涅槃”。
- **取 vs 舍**：取谓着实法、着行、二行；舍谓着空法、不着行、不二行——着“不二”仍是着，故菩提非取非舍。

## 五、阅读提示
带着“一切性空，为何还要精进度众生”这一问读全卷，所有问答譬喻都在解此一结；论中十二因缘一段名目最密，宜按“老死→生→有→取→爱→受→触→六入→名色→识→行→无明”的逆推次第逐支读。
