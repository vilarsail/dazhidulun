# 大智度论卷第五十一 导读

## 一、内容总览

本卷含三段：释胜出品第二十二、释含受品第二十三，并承接"无来去处住处""三世等"之经论。须菩提先以五事（胜出、与空等、含受、无来去住、三世等）赞摩诃衍，佛一一广述成其义，论主于难解处问答释疑。全卷以"摩诃衍即一切法空"为骨，层层递显大乘所以为大：非体大相大，而是"一切法无所有故能容受、能胜出"。

## 二、结构层次（★重点）

本卷以须菩提五赞为经，佛与论主递相广释为纬，推进如下：

- **胜出品·佛略说相**：须菩提先赞（摩诃衍胜出人天阿修罗、与虚空等、含受众生、无来去住、三世等）→ 佛顺赞略说摩诃衍相，所谓六波罗蜜、陀罗尼三昧门、十八空、四念处至十八不共法。
- **胜出品·佛广述"何以胜出"**（以"若当实有则不能胜出，以虚妄无法故能胜出"为递进骨架）：
  - 总破三界（欲界、色界、无色界皆虚妄忆想、无常破坏相、无法）→ 别破五蕴、十二入、十八界、六触生受 → 同理；
  - 转破无为法（法性、如、实际、不可思议性）"亦无"——论主特释：无为空故言无，离有为无为不可得，有为实相即无为；为破悭贪邪见故说有，为圣人说无故空；
  - 转破六波罗蜜、十八空、四念处至十八不共法 → 同理；
  - 转破贤圣位（性人、八人、须陀洹乃至佛）→ 同理；
  - 转破菩萨从初发心至道场诸心、金刚慧、佛三十二相、光明、六十种庄严音声、法轮、度生入无余涅槃 → 皆"无法非法"故胜出。
  → 论主结释：以"三乘度恶道"喻（罗汉独脱、辟支少悲、菩萨大悲摧魔破外道）显大乘方便之异；以虚空含受三世诸佛显大乘含受之广；复释独举人天阿修罗之故（善道尚破，何况恶道）。
- **含受品·与空等**：佛以十数门显虚空相（无方、无色、无三世、不增减、无垢净生灭、非善不善、无见闻知识、不可知断证修、非染离、不系三界、无十地十果）→ 摩诃衍一一如之 → 论主释难：六波罗蜜有世间出世间，出世间者与如法性实际智慧和合故似虚空，得无生忍后无所分别。
- **含受品·含受众生**：佛以"无所有故能受"为宗，重重相因——我无所有→虚空无所有→摩诃衍无所有→阿僧祇无所有→无量无所有→无边无所有→一切法无所有；复约五蕴、六根、六度、十八空、四念处至不共法、贤圣地、三乘人、一切种智各展"无所有故能受" → 论主反复辩难：虚空无自相、因色立名、相无所住、寂灭如无余涅槃，以粗现事破微细着；复释阿僧祇（阿言无、僧祇言数）、无量无边义。
- **无来去住段**：佛广述一切法（色/色法/色如/色性/色相，乃至六根六境、四大种、如、实际、不可思议、六波罗蜜、四念处至十八不共法、菩萨、佛、阿耨菩提、有为无为）皆无所从来去住→论主以"去者不去"之因明破来去相（已去未去去时俱无去、离去者无去相），显一切法实相不动；复释色/色法/色如/色性/色相五法名义。
- **三世等段**：佛述三世皆空、三世等即空、空非一二三异→ 空中蕴处界、波罗蜜、念处至不共法、凡夫、声闻辟支佛菩萨佛一切不可得 → 菩萨住般若学三世等→ 具足一切种智、胜出世间、成就萨婆若 → 须菩提结赞：三世菩萨皆依此衍得成佛道，佛亦可其言。

## 三、关键结论

1. 摩诃衍"胜出"之因：三界乃至一切有为无为法皆是虚妄忆想、无常破坏、无法——以与三界相违故能摧破胜出；若诸法定实，则力等不能胜出。
2. 摩诃衍"与虚空等"：非谓同无为虚空，乃谓出世间波罗蜜与如法性实际智慧和合、得无生忍后无所分别，故似虚空；佛以无碍智观实相如虚空，余人未毕竟清净故不然。
3. "含受无量众生"以"一切法无所有"为因：我空→众生空→虚空空→摩诃衍空→阿僧祇无量无边空→一切法空；以无所有故能受一切，若有法则不能受。
4. 虚空无自相，因色立名，相无所住，寂灭如无余涅槃——佛以粗现虚空喻破众生微细法执。
5. 三世平等即三世皆空，空相非一非异；菩萨住般若学三世等，具足一切种智，三世诸佛皆由是衍成佛道。

## 四、易混辨析

- **世间六波罗蜜 / 出世间六波罗蜜**：世间者有为色法，不同虚空；出世间者与如法性实际智慧和合，似如虚空——故可与虚空等。论中破檀波罗蜜"无法非法"，约胜义说；为度初学者说言有，约世俗说。
- **如 / 法性 / 实际 / 不可思议性**：同为诸法实相异名——约如本名"如"，约本性名"法性"，约究竟名"实际"，约心思不及名"不可思议性"；此卷皆判为"无为法"，以无为空故言无，非谓断灭。
- **性人 / 八人 / 须陀洹**：性人指性地中人（七贤位中性地行人），八人谓见道八忍八智阶段，须陀洹为初果圣人；此卷将三乘贤圣位与所证一并归入"无法非法"，显三世等中无凡圣可得。
- **无余涅槃（实） / 诸法如无余涅槃相（喻）**：无余涅槃是灭尽五蕴之实果，佛说诸法毕竟空"如无余涅槃相"是借喻显空相，非谓摩诃衍即涅槃；论中两处互用，须辨体喻。

## 五、阅读提示

读本卷宜抓住一条主线：须菩提每赞一相（胜出、与空等、含受、无来去住、三世等），佛即以"一切法无所有"层层广述成其义；论主则于难解处（无为法云何言无、虚空云何含受、来去相云何破）以问答释疑。读时但记"以无所有故能"一语，则全卷可通。
