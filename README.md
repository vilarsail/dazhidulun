# 大智度论 (AI白话文双语对勘版)

本项目致力于通过前沿的人工智能大语言模型，将佛教经典巨著《大智度论》进行现代白话文翻译，并制作为易于阅读的双语对照版电子书。

## 目录说明

*   **`origin/` (原始语料库)**
    包含了《大智度论》未经处理的原始古文文本。这是整个翻译工程的原始基石和对勘基准。
    
*   **`split/` (双语对勘排版库)**
    包含了处理后的 Markdown 格式源文件。全书按卷（1-100卷）进行了精细化切分，并在此完成了大模型译文的自动回填与排版。文件内部采用了“古文原文”与“*斜体现代白话文翻译*”逐段交替对照的格式，同时清除了干扰阅读的数字标号，旨在提供最沉浸、纯净的阅读体验。

## 电子书发布 (EPUB / PDF)

基于 `split/` 目录下的源文件，本项目最终打包生成了精美的电子书文件供读者直接阅读：

*   **EPUB 格式电子书**：提供了带有完整层级目录（支持多级索引阅读）的电子书，并配有精美封面，完美适配手机、平板、Kindle 及各种主流墨水屏阅读器，支持动态响应式排版。
*   **PDF 格式电子书**：提供了固定排版样式的电子文档，便于在桌面端进行深度阅读、批注和文献引用。

读者可直接获取并打开这些电子书文件，获得最佳的阅读体验。

## 翻译说明与模型声明

本项目的现代白话文翻译**主要由人工智能（AI）全自动完成**，人工进行了部分校对，详细请阅读前言中的相关说明。

在保证佛学术语准确性、长句逻辑推演严密性以及上下文语境连贯性的前提下，我们动用了极高规格的推理大模型来执行大规模的批量重译任务。本项目主要使用的 AI 模型包括：

*   **Gemini 3 Pro / Flash**
*   **Z-AI GLM-4.7**

*注：人工智能大模型在翻译过程中展现了惊人的古文理解力与术语准确度，但鉴于《大智度论》本身的深奥哲理，译文主要作为通读辅助，研习精义仍建议对照参考古文原文。*
